# 미사용 train 가족의 과거 기록 수집 입력

기존 `travel_state_transfer/20261109-v1`의 미사용 train 48가족에서 결과를 보기 전에 24가족을 고름. 3/5/7일별 8가족, 학습/개발/확인은 12/6/6가족임. 기존 dev 20·test 40은 사용하지 않음.

`history-jobs.json`은 실제로 생성할 72개 과거 계획과 작업자 입력 ID를 연결함. 정답 선택을 넣지 않음. 실제 생성은 별도 원본에 저장한 뒤 검산하며, 새 상태·필요성 자료는 별도 버전에 구축함. 도시와 카탈로그 항목이 공유되는 같은 원천의 새 요청 가족이지 다른 도메인은 아님.

`config.json`은 학습 조건, `protocol.json`은 분할·출처·기존 모델 해시를 고정함. [실행 계획](../../../docs/reports/2026-11-11-memory-need-learning.md)을 따름.
