# 현재 관측에 따라 필요한 기억이 달라지는 통제 자료

2026-11-11. 기존 Mem2Act 출처의 검토된 원문을 짧은 필드 단위로 분할한 파생 자료임. 새 자연 경험 수집이나 원래 도구 작업의 완료 평가가 아님.

| 구분 | 출처 그룹 | 원래 질문 | 상태(표현 2종 포함) | 기억–상태 쌍 | 필요 양성 |
|---|---:|---:|---:|---:|---:|
| 학습 | 18 | 20 | 246 | 732 | 254 |
| 개발 | 8 | 8 | 100 | 258 | 106 |

원문 80구간을 사용함. 학습 62상태·개발 28상태는 관측되지 않은 요청 필드를 채우기 위해 두 기록 이상이 필요함. 수치상 상태 증가는 독립 경험 증가를 뜻하지 않음. 기존 출처별 train/dev 분할을 유지하며, 이전 test와 BEAM confirm은 사용하지 않음. 개발 출처는 과거에 이미 검토된 출처임.

관측 없음 조건은 두 렌더링의 입력이 동일함. 따라서 실제 고유 입력 맥락은 학습 226개·개발 92개이며, 고유 기억–상태 입력 문자열은 학습 673개·개발 237개임. 문항·표현별 반복을 독립 표본으로 취급하지 않음.

`source-specs.json`은 에이전트가 원문을 직접 대조해 선정한 인용·필드 정의임. `provenance.jsonl`은 원문과 문자 위치, `review-ledger.jsonl`은 원래/파생 요청과 검토 범위를 보존함. 모든 원문 인용은 자동으로 위치·값을 검산하되, 의미 주석은 사람이나 독립 검토자의 확인을 거치지 않았음. 임의의 다른 사용자를 음성으로 섞지 않고 같은 원문 안의 다른 역할·속성을 후보로 구성함.

`goal_link`는 요청한 속성을 제공하는지, `labels`는 현재 관측 후에도 그 속성이 필요한지를 뜻함. 적용 효과·실제 득실 라벨은 `utility: null`로 유지함. `coverage`와 `minimal_support_sets`는 평가 전용이며 모델 입력에는 포함하지 않음. 진행·실패 이력은 원문에서 새로 수집한 실행 로그가 아니라 명시적으로 작성한 통제 상태임.

각 질문에서 목표와 기억 은행은 동일하게 유지함. 관측 없음, 전부 관측, 일부 관측, 다른 속성 관측, 조회 실패, 실패 후 확인 완료를 비교함. 두 표현도 같은 사실과 라벨을 유지함. 두 문장 틀 모두 학습·개발에 등장하므로 처음 보는 표현으로의 전이 검증은 아님. 서로 다른 출처 80개의 이전 학습 상태는 복습 전용이며, 검토되지 않은 PersonaMem 후보를 음성으로 바꾸지 않음.

512토큰·최대 12기록을 공통 상한으로 사용함. 전체 은행은 학습 최대 99토큰·개발 최대 57토큰이며 모든 상태에서 통째로 제공 가능함. 전체 제공 기준선을 반드시 포함하고, 제한된 메모리 예산에서 선택의 우월성을 입증하는 자료로 해석하지 않음.

검산: `.venv/bin/python -m data_pipeline.incremental_evidence_data audit`
