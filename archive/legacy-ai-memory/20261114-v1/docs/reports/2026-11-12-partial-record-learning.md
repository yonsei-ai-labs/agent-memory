# 복합 기억 보강: 새 출처에서의 개선과 과잉 제공의 한계

2026-11-11 설계·실행 시작, 2026-11-12 완료. **현재 일부만 확인된 기억을 통째로 버리는 오류는 데이터 보강으로 줄어들었음.** 새 출처에서도 단순 추가 학습과 임계값 조정보다 개선됐고, 실제 필드 복원으로 연결됐음. 기존 BEAM 자료에서는 불필요한 제공이 늘어, 현재 모델을 모든 용도의 기본 선택기로 교체하기에는 보완이 필요함.

이번 결과는 “같은 경험에서 무엇을 보존해야 이득인가”라는 처음 질문과 연결됨. 같은 기억이라도 현재 요청한 정보가 아직 없으면 제공하고, 필요한 정보가 모두 확인됐으면 보류하는 판단을 학습함. **정보가 일부 중복된다는 사실과 기억 전체가 불필요하다는 판단을 구분하는 대조**가 효과를 보였음.

## 무엇을 바꾸었는가

이전 실험의 일부 관측·복합 기록 조건은 학습과 개발에 각각 한 출처뿐이었음. 이번에는 고정 Mem2Act 원문 풀의 미사용 출처를 먼저 분할한 뒤, 역할이 명확한 두 사실을 원문에서 검토함. 새 출처는 train 12·dev 6·test 12개임. 자연 에이전트 경험을 새로 수집한 것은 아니며, 공개 벤치마크의 기존 대화에서 이전 학습·평가에 쓰지 않은 연결 출처 그룹을 사용함.

같은 두 원문 구절을 별도 기록으로 주는 atomic과 한 기록으로 합치는 compound를 만듦. 두 정보 중 무엇을 요청하고 무엇을 현재 알고 있는지를 바꾼 8개 상태를 구성함. 원문에서 이어져 있지 않은 구절도 통제하여 합쳤으므로, compound가 원래 그대로 존재하던 연속 문장이었다고 주장하지 않음. 현재 관측도 통제하여 작성한 문장임.

| 비교 | 학습 입력 | 고정한 조건 |
|---|---|---|
| 이전 모델 | 추가 학습 없음 | 직전 single 모델의 두 seed |
| 단순 추가 학습(control) | 각 상태에 atomic을 두 번 제시 | 출처·요청·관측·상태 항목 수·업데이트 수·seed별 시작 가중치 |
| 복합 기록 보강(augmented) | 같은 상태에 atomic과 compound를 한 번씩 제시 | 위와 동일 |

기존 검토 완료 train 출처 8개를 추가하여 기록 구성 대조는 20개 학습 출처로 만듦. 두 조건에 같은 기존 train 상태 80개를 섞어 각각 400상태 항목·전체 30출처 그룹, 2epoch·200update로 학습함. 중복 때문에 고유 입력 수는 control 235·augmented 395개이며, 이를 새로운 독립 경험 수로 계산하지 않음.

기록을 합치면 후보 쌍 수와 양성 비율이 달라짐. 양쪽에 동일한 손실 가중치 산정법을 사용하여 전체 양성·음성의 명목 손실 질량을 각각 0.5로 맞춤. 기록 경계·길이·후보 쌍 수는 보강에 수반되는 차이로 남음. Harrier 0.6B의 기존 rank-8 q/v LoRA와 같은 필요성 판독층을 계속 학습했으며 새 판독층이나 보조 손실을 추가하지 않음.

평가는 새 12출처의 384상태임. 같은 출처의 8상태 × atomic/compound × direct/prose 관측 표현이며 384개의 독립 경험이 아님. Prose 관측 문장 틀은 이번 train/dev에 없음. 여러 세션의 배경 원출처까지 연결하여 분할했고, 전체 선택기 입력의 train/dev/test 간 정확 중복은 0개임. 같은 compound 기록의 길이는 제공 필요·불필요 조건에서 평균 14.75토큰으로 같음.

[고정 설계](../design-data/memory-partial-records-20261111-v1/README.md)와 [자료·출처 명세](../../datasets/memory_partial_records/20261111-v1/README.md)를 함께 확인할 수 있음.

## 새 출처의 선택 결과

아래는 사전 고정 임계값 0.5에서 두 seed의 범위임. 관계 점수는 출처별 balanced accuracy의 평균임. 불필요 제공은 **남은 요구를 전혀 충족하지 않는 기록** 수이며, 필요한 복합 기록 안에 중복된 사실이 일부 포함되는 것은 기록 전체의 불필요 제공으로 세지 않음.

| 방법 | 관계 점수 | 필요 근거 완전 확보 /240 | 일부만 확인된 복합 기록 보존 /48 | 불필요 제공 기록 |
|---|---:|---:|---:|---:|
| 이전 모델 | 80.9–81.6% | 150–155 | 18–19 | 13 |
| 단순 추가 학습 | 87.6–89.2% | 182–195 | 25–30 | 9–14 |
| 복합 기록 보강 | **96.1–98.0%** | **228–236** | **44–48** | **8–10** |

학습 자료의 관계 점수는 control에서도 약 99% 이상이었으나, 새 출처의 복합 기억을 놓쳤음. 따라서 학습 자료에 더 잘 맞추는 것만으로 해결되지 않는 약점이었음. 같은 사실을 복합 기록으로 제시하는 대조를 학습에 넣었을 때 두 seed 모두 개선됨.

개발 6출처에서만 제공 임계값을 고르고, 여섯 모델의 값·가중치 해시를 모두 저장한 뒤 test 추론을 시작함. 이전 모델 0.75/0.85, control 0.05/0.10, augmented 0.15/0.05로 선택됨. 임계값 조정 후 복합 기록 보존은 이전 모델 15–18/48, control 29–32/48, augmented 46–48/48임. 따라서 단순 임계값 조정으로 보강 효과가 재현되지는 않았음. 보강 모델에서 기준 조정의 전체 관계 점수 이득은 두 seed에 일관되지 않았고, 낮은 기준으로 불필요 제공이 늘기도 했음. Test 결과를 보고 임계값이나 학습 epoch를 다시 선택하지 않음.

## 같은 작업자에게 제공했을 때

사전에 정한 compound/prose 96상태 전체를 같은 Qwen3.5-4B로 실행함. 작업은 요청 필드를 근거에서 복원하는 것이며 원래의 여행·서버·금융 작업이나 실제 도구 수행 성공이 아님. 17개 정책의 동일 입력을 재사용하여 192개 고유 호출·3개 반복으로 1,632개 정책 결정을 평가함.

| 제공 정책 | 고정 채점 성공 /96 | 완전한 근거가 전달된 상태 /96 |
|---|---:|---:|
| 무기억 | 36 | 36 |
| 전체 제공 / 검색 상위 2개 | 88 | 96 |
| 검토된 필요 근거 진단 | 88 | 96 |
| 이전 모델, 임계값 0.5 | 58–60 | 61–62 |
| 단순 추가 학습, 임계값 0.5 | 67–71 | 70–75 |
| 복합 기록 보강, 임계값 0.5 | **86–87** | **93–95** |
| 복합 기록 보강, 개발 임계값 | 87–88 | 95–96 |

고정 기준에서 보강은 control 대비 seed별 **20개·15개 개선, 악화 0개**였음. 이전 모델 대비는 **29개·26개 개선, 악화 0개**였음. 12출처를 단위로 다시 뽑은 기술적 bootstrap에서 control 대비 성공률 차이의 95% 구간은 각각 +13.5–29.2%p, +10.4–20.8%p임. 작은 출처 수와 여러 관련 비교가 있는 파일럿의 기술 통계이며, 독립 반복 연구나 보정된 확증 검정으로 해석하지 않음.

후보는 1–2개이고 모두 예산 안에 들어감. 따라서 이번 자료에서 여과 없는 검색 상위 2개는 전체 제공과 같음. **학습 선택이 전체 제공의 성공률을 높였다는 결과는 없음.** 관측된 개선은 잘못된 보류를 줄이면서 불필요한 제공을 억제한 것이며, 선택기의 일반적 필요성을 입증한 것은 아님.

## 채점 문구와 실제 실패를 구분한 재검토

완전한 근거를 받았는데도 고정 채점에서 실패한 서로 다른 출력 8개를 전부 재검토함. 이 중 6개는 정답 의미가 맞지만 명사구를 더 길게 복사한 경우였음. 예를 들어 `Ubuntu`와 `Ubuntu template`, `vegetarian`과 `vegetarian diet`, `analytics`와 `analytics folder` 차이임. 추가 문구는 해당 필드의 원문 구절에 그대로 있음.

**원래 채점과 입력·정답·프로토콜은 수정하지 않았음.** 출력 확인 후의 동의 표현 허용은 [별도 사후 진단](../../evaluation/results/memory-partial-records-20261111-v1/posthoc-grading-review.json)에 분리함. 같은 구축 에이전트의 검토이며 독립 인간 판정은 아님.

| 정책, 고정 임계값 | 원래 고정 채점 | 원문 명사구까지 허용한 사후 진단 |
|---|---:|---:|
| 전체 제공 | 88 | 94 |
| 이전 모델 | 58–60 | 60–61 |
| 단순 추가 학습 | 67–71 | 69–73 |
| 복합 기록 보강 | 86–87 | 91–93 |

표현 차이를 분리해도 보강의 개선 방향은 유지됨. 사후 진단 수치를 사전에 정한 주 결과로 바꾸지는 않음. 다음 회차의 채점 규칙에는 원문 기반 표현 변형을 실행 전에 검토하여 고정할 필요가 있음.

남은 실제 실패 2개는 같은 출처의 게임 ID와 라운드 ID 혼동임. 원문에는 게임 ID `456`, 라운드 ID `789`가 있음. 현재 라운드 ID가 알려진 상태에서 게임 ID를 요청했는데 작업자가 `789`를 답했고, 반대 요청에서는 `456`을 답함. **필요한 기억을 전달하는 선택 문제와, 전달된 근거를 올바른 역할에 사용하는 작업자 문제를 분리해야 한다는 실제 사례임.**

선택기에도 잔여 오류가 있음. 예를 들어 `AA123` 항공편 번호가 이미 관측됐고 항공기 모델을 요청하는 상태에서 두 보강 모델의 필요 확률이 0.111·0.193으로 나와 고정 0.5 기준으로 기록을 보류함. 기록에는 `Airbus A320`이 있으므로 잘못된 보류임. 모든 사례의 원문·선택·실제 답변을 [사례별 출력](../../evaluation/results/memory-partial-records-20261111-v1/worker-cases.jsonl)에 보존함.

## 비용과 기존 과제의 성능 유지

보강 모델의 평균 전달 기억은 12.14–12.32토큰, 전체 제공은 18.75토큰임. **전달 기억 토큰은 34–35% 줄었으나 총 작업자 입력은 약 2.9–3.0% 감소**했음. 짧은 기억을 다루는 진단이므로 큰 비용 절감으로 해석하지 않음. 작업자 시간에 batch 4에서 측정한 선택기 비용을 더한 값은 약 1.909–1.914초, 전체 제공의 작업자 평균은 약 1.899초임. 실제 지연 개선은 관찰하지 못함. 선택기 시간은 묶음 처리의 상각값이며 온라인 단일 요청 지연을 직접 측정한 값은 아님.

기존 자료는 새 확인 집합이 아니라 과거부터 사용한 개발 자료임. 아래는 모두 임계값 0.5의 관계 판독 점수이며, BEAM 작업자를 새로 실행한 결과가 아님.

| 기존 평가 | 이전 모델 | 단순 추가 학습 | 복합 기록 보강 |
|---|---:|---:|---:|
| 이전 incremental 개발 | 94.2–95.9% | 94.1–96.3% | 95.8–97.7% |
| source-scale 개발, 두 자료 평균 | 94.1–94.2% | 92.7–93.5% | 94.5–94.7% |
| BEAM context 개발 | **75.6–77.5%** | 75.3–79.0% | **71.4–74.8%** |

BEAM에서 보강 전후 false positive는 seed별 187→220, 172→193으로 늘었고, false negative는 모두 0이었음. 필요한 기억의 회수는 유지됐으나 필요 없는 기록도 더 제공하는 쪽으로 이동함. 새 대조에서의 개선을 범용 판독 개선으로 확대해서 말할 수 없음. 개발 임계값을 다른 자료에 그대로 적용하는 효과도 이번 주 성능 유지 표의 검증 범위가 아님.

## 현재 판단과 다음 범위

이번에 확보한 성과는 세 가지임. 첫째, 같은 사실·같은 현재 상태에서 기록 구성을 바꾸는 대조를 만들고 출처를 격리하여 보강 효과를 측정함. 둘째, 단순 추가 학습·임계값 조정과 비교하여 복합 기록 보존 개선이 새 출처에서도 반복됨을 확인함. 셋째, 선택기의 근거 누락, 작업자의 역할 혼동, 채점 표현 차이, 기존 자료의 과잉 제공을 분리해 실제 득실을 해석함.

다음에는 이 보강 대조를 유지하면서 **원래 train 자료의 이미 충족됨·무관함 조건을 더 넓게 복습하는 비교 하나**를 수행하는 것이 적절함. 현재 BEAM 개발 자료를 학습에 섞지 않고 별도 출처를 유지해야 함. 이번 회차의 네 모델은 비교 결과로 보존하며, 보강 모델을 모든 용도의 기본 모델로 일괄 교체하지 않음. 새 layer나 추가 목표를 늘리기 전에 필요한 기록 보존과 과잉 제공 사이의 균형을 확인하는 것이 우선임.

## 검산과 재현

- 원문 파일 2개 해시, 원문 질문 38개의 연결 출처 그룹, 새 출처의 실제 사용자 발화 30개, 76개 구절과 필드의 근거를 검산함. 주석과 현재 관측은 같은 에이전트가 작성했으며 자연 진행·실패 궤적이나 독립 이중 주석은 아님.
- 저장 후보 예측 17,128행의 두 출력층을 CPU에서 재계산하고, 사용한 임계값의 판정이 모두 같음을 확인함. 이전 모델 두 개는 과거 저장 예측과 확률 오차 0으로 일치함.
- 네 학습 모델의 LoRA tensor 112개씩이 모두 변경됐고, 모든 감독 후보가 정확히 2회 학습에 사용됨. 네 모델 모두 200update이며 마지막 epoch를 사용함.
- 192개 작업 입력의 해시·실제 답변·1,632개 정책 연결을 검산함. 반복 3개의 출력은 모두 동일하고 토큰 제한에 걸린 출력은 없음. 압축 묶음을 임시 경로에 풀어 결과 재계산이 같음을 확인함.
