# 메모리 실험 결과의 의미와 다음 병목

**의미 있는 신호가 관측됨. 가장 분명한 성과는 전체 질문에서 필요한 기억을 앞으로 올리는 학습이며, 실제 기억의 추가 가치는 현재 정보와 작업자의 활용 능력에 따라 달라졌음.** 따라서 현재 연구는 ‘관계를 학습할 수 있는가’에서 ‘그 관계를 어떻게 실제 이득으로 연결하는가’로 넘어갈 근거를 갖춤. 새 출처에서 학습 선택기의 최종 우위를 입증한 단계는 아님.

검토 기준은 `f3ad00a`임. [전체 질문 검색](2026-11-09-full-request-memory-retrieval.md)과 [4B·9B 실제 효용](2026-11-09-travel-worker-utility.md)을 함께 분석함. 두 실험은 같은 기본 계획 분할을 사용하지만 과거 이력이 다름. 전자는 공개 정답 여행 계획, 후자는 작은 메뉴 과제에서 새로 생성한 과거 선택임. 두 성적을 하나의 연속 실행 성과로 합산하지 않음.

## 1. 검색 학습의 개선은 일부 사례에만 의존하지 않음

전체 질문 219개·기본 계획 8개의 결과임. Recall@10은 질문마다 필요한 기억 중 상위 10개에 찾은 비율의 평균이며, 전체 포함은 필요한 기억을 모두 찾은 질문 수임.

| 방법 | Recall@10 | 전체 포함 | 계획별 nDCG@10 |
| --- | ---: | ---: | ---: |
| BM25 | 26.3% | 24/219 | 0.159 |
| 고정 임베딩 | 37.0% | 35/219 | 0.231 |
| BM25+임베딩 RRF | 35.5% | 36/219 | 0.213 |
| 고정 encoder + 학습 MLP | 56.9% | 72/219 | 0.379 |
| LoRA + 같은 MLP | **68.6%** | **96/219** | **0.710** |

고정 MLP 대비 LoRA의 Recall@10은 **+11.7%p**, 전체 포함 질문은 **+24개**임. 질문별 검색률은 75개 개선·1개 악화·143개 동일이었음. 기본 계획 8개 모두 검색률과 nDCG가 개선됐고, 어느 계획 하나를 제외해도 계획별 평균 검색률 개선은 +11.1~+12.8%p로 유지됨.

계획을 묶어서 20,000회 재표집한 탐색적 구간은 다음과 같음. 질문 219개를 서로 독립이라고 가정하지 않음.

| 계획별 평균 차이: LoRA − 고정 MLP | 관측 차이 | 탐색적 95% 재표집 구간 |
| --- | ---: | ---: |
| Recall@10 | +12.0%p | +9.4~+14.6%p |
| nDCG@10 | +0.330 | +0.294~+0.363 |

이 구간은 **고정된 모델과 이미 관찰한 8개 계획의 민감도**임. 새 출처·여러 학습 seed·주석 불확실성까지 포함하지 않으며 확증 검정으로 해석하지 않음. 고정 MLP와 LoRA의 학습 epoch도 달라 동일 계산량의 구조 비교는 아님.

그래도 이번 패널에서 ‘관계 판독을 위한 추가 학습이 순위를 개선했다’는 설명은 상당히 뚜렷함. 이전 문장 하나·6후보의 100%보다 복수 참조와 큰 기억 은행의 병목을 관찰할 수 있다는 점에서 진전임. 주석 생성 규칙은 이 명시적 관계 과제에서 거의 완전하므로 별도 학습 모델의 필요성은 여전히 별도 질문임.

## 2. 남은 검색 오류의 대부분은 앞단 후보 누락임

평가의 정답 연결은 질문–기억 기준 768개임. 이를 독립 경험 768개로 세지 않음.

| 단계 | 정답 연결 수 |
| --- | ---: |
| 전체 필요한 연결 | 768 |
| RRF 상위 32개 후보에 포함 | 470 |
| LoRA 재순위 후 상위 10개에 포함 | 468 |

최종 누락 300개 중 **298개(99.3%)는 앞단에서 이미 빠졌고, 후보 안의 순위 오류는 2개**임. 이 후보에서는 상위 10개 용량 때문에 불가피하게 빠진 정답은 없었음. 후보 32개 안에서 이미 대부분의 올바른 관계를 읽고 있어 판독층만 바꿔 얻을 수 있는 추가 검색률은 작음.

추가로 **이미 저장된 상위 44개 점수**로만 후보 폭을 32→44로 바꿔 사후 재정렬함. 새 모델 호출·학습은 없음.

| 같은 LoRA의 후보 폭 | Recall@10 | 전체 포함 | 찾은 정답 연결 |
| --- | ---: | ---: | ---: |
| 32개: 원래 고정 평가 | 68.6% | 96/219 | 468/768 |
| 44개: 사후 진단 | **77.1%** | **119/219** | **543/768** |

같은 모델인데 후보 확대만으로 검색률 **+8.5%p**, 전체 포함 **+23질문**이 관측됨. 검색률은 62질문 개선·1질문 악화였으며 기본 계획 8개 모두 평균 개선됨. 이 결과는 새 평가 성적이나 후보 44개의 최적성 증명이 아님. 추가 지연·비용도 측정하지 않음. 다만 현재 병목이 후보 접근 범위라는 설명을 강화함.

다음 우선순위는 관계별 질문 분해·후보 합치기, 검색용 표현 학습, 후보 폭과 비용의 대조임. 질문 하나의 임베딩이 원인이라고 이번 비교만으로 특정하지 않음.

## 3. 실제 득실에서는 ‘현재 이미 아는가’가 중요한 설명 변수임

아래는 실제 작업자에서 추가 기억 없음과 정확한 참조 기억 제공을 비교한 결과임. 각 조건은 같은 16요청·8개 기본 계획이며, 학습 선택과 참조 규칙의 평가 입력·출력은 같았음.

| 작업자·현재 정보 | 추가 기억 없음 → 참조 기억 제공 | 성공률 차이 |
| --- | ---: | ---: |
| 4B·과거에만 있음 | 3/16 → 7/16 | +25.0%p |
| 4B·현재에도 보임 | 7/16 → 3/16 | −25.0%p |
| 9B·과거에만 있음 | 1/16 → 10/16 | **+56.3%p** |
| 9B·현재에도 보임 | 11/16 → 9/16 | −12.5%p |

계획 단위 재표집에서 9B 과거 전용의 차이 구간은 +37.5~+75.0%p였음. 반면 현재 관측이 있는 9B의 구간은 −31.3~0%p였고, 4B의 각 조건 구간도 0을 포함했음. 따라서 **필요한 사실 제공의 이득 신호가 평균적인 손해의 확증보다 강함**. 손해가 난 개별 실행의 존재와 새로운 과제에서도 평균 손해가 난다는 주장은 구분함.

같은 요청에서 ‘과거 전용의 제공 효과 − 현재 관측 상태의 제공 효과’를 계산하면 4B +50.0%p, 9B +68.8%p였음. 재표집 구간은 각각 +25.0~+75.0%p, +43.8~+93.8%p임. 현재 정보의 충분성에 따라 추가 가치가 달라지는 패턴은 두 작업자에서 관측됨. 다만 필요한 사실을 숨기거나 보이게 만든 설계이므로 이 차이의 일부는 실험 구성상 예상되는 결과임. 실제 현장에서 두 상태가 얼마나 자주 발생하는지는 측정하지 않음.

실제 예는 `travel-92-turn-8-clause-0`의 Elijah 첫날 저녁 기록임. 같은 정확한 기억 `Elijah·1일차·저녁 → R5591`이 9B에서 과거 전용일 때 실패→성공, 현재에도 보일 때 성공→실패를 만들었음. 이는 기억에 고정된 하나의 득실 라벨을 붙이기보다 **기억·현재 관측·작업자에 조건부인 효과**를 측정해야 한다는 근거임. 중복 길이·위치가 원인인지까지 분리한 실험은 아님.

무기억의 정답에도 주의가 필요함. 4B의 과거 전용 무기억은 전부 NONE이었고 불가능한 3요청에서만 맞았음. 가능한 답이 있는 13요청에서는 두 작업자의 무기억이 모두 0건, 기억 제공은 4B 7건·9B 10건 성공함. 불가능한 3요청은 두 작업자 모두 기억 제공 후 0/3이었음. 이 차이도 [질문별 분석](data/memory-results-analysis-20261109/computed/utility-case-effects.csv)에 보존함.

## 4. 잘 찾은 뒤에도 제공 판단과 활용이 남음

보류 임계값을 적용한 전체 질문 검색에서 LoRA가 전달한 253기록 중 249개는 정답으로 정밀도 **98.4%**였음. 그러나 전체 정답 연결 768개 중 전달한 것은 **32.4%**이며, 필요한 기록을 전부 받은 질문은 **68/219**임. ‘틀린 기억을 적게 줌’과 ‘필요한 기억을 충분히 줌’은 같은 성과가 아님. 정답 제거 진단의 오제공 4/219도 자연적으로 참조가 없는 문제에서의 위험 보장은 아님.

실제 9B 작업자는 과거 전용에서 정확한 참조를 받아도 재사용은 8/8, 가격·평점·음식 조건 비교는 2/8 성공했음. 따라서 검색률을 올린 효과가 작업 성공률에 그대로 옮겨간다고 가정할 수 없음. 조건을 실행에 적용하는 능력도 병목임.

정보 조각의 기여를 분석할 때 입력 전체를 봐야 함. 현재 효용 과제에서는 과거 식당의 가격·평점·음식 종류가 공통 식당 목록에도 존재함. 기억이 새로 알려주는 핵심은 **어느 사람의 어느 날 식사가 어떤 식당이었는지의 연결**임. 기억에서 가격 필드만 지워도 식당 ID로 목록에서 찾을 수 있음. 그런 삭제 비교는 정보의 완전 제거보다 표현·조회 비용의 대조가 됨. 실제 정보 제거를 주장하려면 다른 입력 경로에도 같은 사실이 남아 있는지 확인해야 함.

## 다음 실험의 우선순위

1. **검색:** 새 출처·표현을 별도로 남기고 후보 검색을 개선함. 현재 재순위 모델을 고정한 채 후보 폭 확대와 관계별 질문 분해를 개발에서 비교하고 비용도 측정함. 이후 검색용 표현 학습의 추가 가치를 판단함.
2. **제공 판단:** 새 개발 자료에서 과거 전용·현재 중복·전제 불일치·유효 참조 부재를 구분하고 제공/보류의 실제 결과를 모음. 무기억·고정 기억·참조 규칙·현재 관측 확인 규칙을 함께 비교함.
3. **실제 성과:** 검색 조건을 고정한 뒤 충분한 기억이 전달됐는지와 작업자가 활용했는지를 따로 측정함. 정보 조각 삭제 시 대체 입력 경로를 통제하고, 같은 사실의 길이·위치·직접 명시 여부 대조는 표현 효과로 분리함.

현재 근거는 **검색 관계의 학습 가능성은 뚜렷하며, 실제 득실의 조건부 측정도 가능하다**는 수준임. 작은 모델이 단순 규칙보다 좋은 최종 효용 정책이라는 주장에는 새 출처에서 검색·제공·작업 성공을 연결한 비교가 필요함.

## 분석 근거와 재현

[분석 코드](data/memory-results-analysis-20261109/analyze.py)는 표준 라이브러리만 사용함. 원래 예측 ZIP의 파일별 해시를 대조하고 검색 순위·지표를 별도 계산해 공개 CSV와 일치하는지 검사함. 효과·계획별 민감도·후보 누락·사후 44후보 진단은 [analysis.json](data/memory-results-analysis-20261109/computed/analysis.json)에 있음. 원래 성적은 변경하지 않음.

```bash
python3 -B docs/reports/data/memory-results-analysis-20261109/analyze.py \
  --output /tmp/memory-results-analysis-new
```

기존 출력 경로는 덮어쓰지 않음. 큰 원본 입력·주석은 [자료 카드](../../datasets/travel_retrieval/20261109-full-request-v1/README.md)의 재생성 절차가 필요함. 공식 공유 지표 재검산도 별도로 통과했으며 관련 검사 9개를 확인함. 이번 분석에서 새 GPU·모델 생성·학습은 수행하지 않음.
