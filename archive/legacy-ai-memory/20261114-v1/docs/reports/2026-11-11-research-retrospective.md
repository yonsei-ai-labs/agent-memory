# 메모리 학습 연구의 성과와 남은 검증

2026-11-11. 기준 커밋은 `8d0db42`임. 초기 방향, 데이터 내용 검토, 직접 순위 학습, 상태 필요성 학습, 출처 확대, 최근 BEAM 대조까지 검토함. 이번 원시 산출물 재계산은 최근 `memory-context-value-20261111-v1`과 이전 상태 실험 세 회차에 집중함. 초기 실험의 모든 가중치와 실행을 새로 검산한 것은 아님.

**학습은 실제로 진행됐으며, 좁은 조건에서 관계를 구분하고 불필요한 제공을 줄이는 성과가 있음. 그러나 실제 이득을 예측하거나 강한 검색보다 작업을 잘 풀게 한다는 결론은 아직 성립하지 않음.** 현재 모델의 대체 채택을 보류하고, 관계 판독·기억 확보·작업 결과를 구분해 보고하는 것이 적절함.

| 검토 질문 | 판단 |
| --- | --- |
| 가중치가 학습되고 저장 성적이 재현되는가 | 최근 산출물에서 확인됨 |
| 현재 상태와 기억의 관계를 학습할 수 있는가 | 통제 자료에서 긍정적임. 최근 추가 학습의 성과는 불필요한 기록 구분에 특히 나타남 |
| 필요한 기억을 기존 검색보다 잘 찾는가 | 최근 개발 자료에서는 아님 |
| 관계 점수가 실제 이득을 예측하는가 | 전체 AUC만으로 판단하면 과대 해석임. 조건 내부의 예측력은 확인되지 않음 |
| 처음의 ‘메모리의 득과 실’과 연결되는가 | 필요한 중간 과제와 측정 틀로 연결됨. 아직 일반적인 경험 활용의 득실 모델은 아님 |

**이번에 추가 확인한 핵심 문제는 전체 이득 예측 점수가 상태 구성의 영향을 크게 받는다는 점임.** 같은 과거 근거 묶음을 제공했을 때 무기억보다 답을 맞히는지를, 저장된 작업자 출력으로 다시 집계함. 개발 52상태에서 이득 20, 손해 1, 중립 31건이며, 이득 20건은 모두 `missing/unrelated` 조건에 있음.

| 판독 점수 | 전체 52상태의 이득 예측 AUC | 기억이 필요한 26상태 내부의 AUC |
| --- | ---: | ---: |
| 기존 고정 선택기 | 0.866 | 0.358 |
| 상태 학습 seed 731 | 0.897 | 0.483 |
| 상태 학습 seed 1729 | 0.902 | 0.483 |
| 목표만 학습 | 0.488 | 0.467 |
| 상태 종류만 아는 진단 점수 | 0.906 | 0.500 |

마지막 행은 `missing/unrelated=1`, `known/updated=0`인 **주석 메타데이터 진단**임. 모델에 허용된 입력으로 구현한 실용 기준선이 아님. 전체 0.90이 상태 구성만으로도 나올 수 있음을 보여줌. 필요한 26상태는 이득 20·비이득 6건뿐이고 같은 질문의 변형들이므로, 0.483을 일반적인 무능력의 증거로 확대하지 않음. 관계 라벨로 학습한 모델이 작업자의 실패까지 예측해야 한다는 뜻도 아님. 다만 현재 AUC를 ‘실제 득실을 배웠다’는 근거로 제시할 수는 없음. 손해 1건으로 손해 예측 성능을 논할 수도 없음.

**관계 판독의 개선은 유지되지만, 전체 구분과 상태 내부의 순위는 다른 결과임.** 개발 관계 410쌍은 양성 28·음성 382쌍임. 양성은 13질문의 유효 근거를 두 필요 조건에서 반복 평가한 것이며 독립된 28경험이 아님.

| 점수 | 전체 관계 AUC | 양성 26개 탐지 시 오판 /382 | 필요한 상태에서 첫 기억 정답 /26 | 상태 내부 순위 AUC¹ |
| --- | ---: | ---: | ---: | ---: |
| 기존 고정 선택기 | 0.817 | 139 | 11 | 0.722 |
| 상태 학습 seed 731 | 0.955 | 47 | 15 | 0.892 |
| 상태 학습 seed 1729 | 0.953 | 48 | 15 | 0.888 |
| 목표만 학습 | 0.881 | 88 | 12 | 0.909 |
| 기존 학습 검색 | 0.917 | 84 | 24 | 0.974 |
| 기존 검색 + 기존 상태 제거 규칙² | 0.936 | 71 | 24 | 0.974 |

¹ 양성과 음성이 함께 있는 각 상태의 순위 AUC를 출처별로 평균한 값임. 전체 AUC와 모집단이 다름. ² 이번 검토에서 기존 검색 점수에 이미 정해 둔 관측 중복 제거 규칙을 결합한 사후 진단임. 새 학습·임계값 최적화·작업자 호출은 없음. 이 조합의 최종 작업 성공은 측정하지 않음.

같은 양성 탐지 수에서 기존 선택기 대비 오판 65–66% 감소는 재현됨. 기존 검색과 상태 규칙을 결합한 진단보다도 오판이 적음. 따라서 최근 결과를 임계값을 높여 무조건 덜 주는 변화만으로 설명할 수는 없음. 반면 필요한 기억의 첫 순위는 15/26으로 검색 24/26보다 낮음. 최근 학습은 전체 후보의 필요/불필요 구분을 개선했지만, 최선의 검색 순위를 만든 것은 아님.

여기서 탐지 수를 맞춘 임계값은 **같은 개발 정답에서 사후 계산한 ROC 좌표**임. 운영 정책의 독립 평가가 아니며, 실제 작업자 실행은 원래의 0.5 임계값을 사용함. 개발 자료는 epoch 선택에도 사용됐으므로 이 표를 확인 자료 성과로 부르지 않음.

같은 주된 과거 기억의 두 상태를 모두 맞히는지도 별도 확인함. `missing→known`의 두 판정을 0.5에서 모두 맞힌 질문은 기존 선택기 13/13, 상태 학습 8/13·11/13임. 모든 상태 입력 모델은 13/13에서 점수의 방향을 올바르게 바꿨으므로, 상태 반응 자체는 추가 학습 전부터 있었음. 최근의 전체 점수 상승을 ‘새롭게 상태에 반응하는 능력을 얻었다’고 설명하는 것은 부정확함.

**실제 작업 결과와 이전 과제 유지에서는 채택을 막는 문제가 남음.** 같은 Qwen3.5-4B 작업자와 512토큰 상한을 사용한 최근 개발 결과임. 원답 일치와 검토된 근거가 함께 있는 정답을 구분함. 후자는 주석한 근거의 제공 여부를 보는 보수적인 지표이며, 다른 근거를 사용했을 가능성까지 완전히 판정하지 않음.

| 전달 정책 | 원답 일치 /52 | 정답과 검토 근거 확보 /52 | 총 전달 기억 토큰 |
| --- | ---: | ---: | ---: |
| 무기억 | 25 | 22 | 0 |
| 기존 고정 선택기 | 41 | 37 | 14,796 |
| 상태 학습 seed 731 | 39 | 35 | 2,265 |
| 상태 학습 seed 1729 | 41 | 37 | 2,895 |
| 기존 학습 검색 상위 2개 | 47 | 47 | 6,368 |
| 예산 안에서 기억 채우기 | 47 | 47 | 22,792 |
| 검토된 필요 근거만 제공 | 44 | 44 | 1,789 |

seed 1729는 기존 선택기와 총 정답 수가 같고 기억 토큰이 80.4% 적음. 하지만 상태별로 근거 있는 정답 3건 개선·3건 악화이며, 다른 seed는 순 정답이 줄었음. 비열등성이나 비용 80% 절감이 입증된 것은 아님. 선택기 계산 비용이 추가되고 검색의 상태별 실행 시간도 측정하지 않았음. 정답 근거만 제공한 조건도 44/52이므로 이를 작업자의 성능 상한으로 해석하지 않음.

이 비교에서 0.6B는 기억 선택기이고 4B는 선택된 기억으로 답하는 작업자임. 이전 여행 실험의 9B도 작업자 역할임. 따라서 이 결과를 ‘학습한 0.6B 선택기가 4B·9B 선택기보다 우수하다’고 읽을 수 없음. 큰 모델을 같은 선택 역할에 두는 비교는 별도로 해야 함.

이전 Mem2Act 개발 자료에서는 필요한 근거 확보가 20/30→16/30으로 감소함. 같은 자료의 첫 순위 정답은 20/30으로 유지됨. 이전 평가의 종합 관계 점수는 0.936→0.773·0.787로 하락함. 이는 제공 임계값과 점수 분포의 변화, 누락 증가를 우선 의심하게 하지만, 표현이 완전히 망가졌거나 단순 보정만으로 모두 해결된다는 증거는 아님. 기존 checkpoint는 보존돼 있음.

이전 상태 실험의 7/12 손해와 표현 변화 성적은 [다른 에이전트의 원 출력 재계산 코드](data/reportable-insights-20261111/recheck.py)를 다시 실행했고 [이번 출력](data/research-retrospective-20261111/prior-insights-recheck.txt)이 기존 출력과 바이트 단위로 같았음. 초기 숫자·범위·검색과 120출처 수치는 기존 검토와 보고서를 대조한 범위임.

**데이터는 파일 수와 독립 경험 수를 분리해 관리해야 함.** 최근 BEAM 자료 전체는 검토된 50대화 그룹·58질문이나, 실제 학습은 11그룹·13질문이고 개발도 12그룹·13질문임. 원천 대화는 공개 합성 자료이며, 그룹 사이의 생성 주제·문장 틀까지 독립적이라는 보장은 없음.

현재 정보가 이미 있는 `known` 상태는 58질문 모두 과거 근거를 현재 관측에 그대로 복사함. 정확한 중복 제거의 가치는 시험할 수 있지만, 바꿔 말한 상태·실제 진행·실패 이력을 일반적으로 이해하는지까지 시험하지는 못함. 전체 58은행 중 39은행은 모두 전달할 수 있어, 제한된 예산에서 선택이 필수인 문제도 충분하지 않음. 현재 소규모 자료의 핵심 한계는 단순 행 수보다 독립 경험과 관계 종류가 좁다는 점임.

원문 575구간과 동결 해시, 대화 그룹 분리, 기존 확인 출처의 보존은 재검증됨. 단일 검토자의 주석이며 독립적인 합의 검토는 없음. 숫자만 존재한다고 정답으로 삼지 않고 주체·범위·시점의 불확실성을 `unknown`으로 남긴 개선은 유지해야 함.

다만 `beam:1M-2:ku2`의 “50으로 늘려 봤다”와 실제 설정값 질문의 관계, `beam:100K-6:ku1`의 역할이 명시된 3회 인터뷰와 역할이 생략된 5회 업데이트는 독립적인 답안 계약 검토가 필요함. 현재는 각각 실행의 성립 여부와 생략된 범위의 연속성에 해석 여지가 있음. 이를 작업자의 순수한 실패나 확정적인 메모리 손해로 단정하지 않음. 결과를 본 뒤 원본 라벨을 바꾸거나 어려운 사례를 제외하지 않으며, 새 판단은 별도 버전과 변경 근거로 남기는 것이 적절함.

**구현 검토에서는 현재 수치를 뒤집는 재현 오류를 찾지 못했으나, 재사용 전에 보완할 부분이 있음.**

- 저장 특징과 실제 판독층의 점수 7,032개를 CPU로 검산해 분류·선택·집계가 일치함. 최근 관계 3,312개와 이전 자료 재평가 3,720개임. encoder 전체를 이번에 다시 실행한 것은 아님.
- 세 학습의 LoRA 112텐서씩에 유효한 변화가 있음. 전체 4 epoch 동안 412감독쌍을 각각 네 번 사용했으나, 실제 평가 checkpoint는 모두 2 epoch이므로 그 checkpoint의 노출은 각각 두 번임.
- 미주석 후보는 손실에서 제외되며 상태별 가중치 합은 같음. 현재 구성에서는 양성이 있는 상태가 절반이므로, 누적 분류 손실의 가중치는 양성 약 25%·음성 약 75%임. 이는 구현 실수는 아니지만 확률 보정 없이 0.5를 실제 필요 확률로 읽어서는 안 됨. 누락 증가의 원인을 이 가중치 하나로 확정할 수도 없음.
- [`analyze()`](../../evaluation/context_value_results.py)의 `complete_missing_support < 13`은 현재 13질문에 고정돼 있어 후속 자료에 재사용하면 잘못된 보완 판단을 낼 수 있음. `unresolved_source_reviews: 0`도 검토 기록에서 계산하지 않고 고정함. 현 회차는 별도의 작업자 진단 기준을 못 넘겨 확인 평가가 닫혀 있으므로 이 문제로 확인 자료가 열린 것은 아님. 이후 실행 전에는 상태 수와 검토 상태를 실제 자료에서 읽도록 고쳐야 함.
- 현행 관련 단위 검사 14개가 통과함. 작업자 고유 입력 652개와 재사용을 포함한 정책 결정 1,144개를 구분해 검산함. 같은 입력 6반복은 일치했으나 성공 확률을 추정할 충분한 반복은 아님.

최근 확인 평가의 관문은 ‘필요 근거를 주면 작업자가 각 상태 종류에서 80% 이상 해결하는가’임. 개발 `missing`이 9/13으로 미달함. 이 관문은 작업 결과 측정의 타당성에 관한 것이며 관계 판독의 실패 판정은 아님. **기존 확인 27그룹은 계속 미실행으로 보존함.** 관계만 따로 확인하려면 새로운 평가 계획을 먼저 정해야 하며 기존 관문을 결과에 맞춰 완화하지 않음.

**원래 질문과의 연결은 유지하되, 연구 주장의 단위를 다시 고정하는 것이 우선임.** 처음 질문은 ‘같은 경험에서 무엇을 보존하고 언제 사용하면 득실이 달라지는가’였음. 현재 자료는 그중 ‘현재에 부족하거나 이미 있는 사실을 골라 주기’를 시험함. 실제 작업 절차의 적용 경계, 긴 실패 이력, 여러 기억의 상호 보완, 기억 작성·요약의 손실은 아직 충분히 검증하지 못함. 숫자 답변의 관계 정확도를 연구 전체의 최종 목표로 바꾸지 않아야 함.

다음 작업의 우선순위는 다음과 같음.

1. **보고할 성과를 세 층으로 고정함.** 관계 판독, 필요한 근거 확보, 고정 작업자의 실제 이득·손해를 별도 표로 둠. 최근의 전체 AUC와 같은 탐지율 오판 감소는 탐색적 개발 결과로 표시함. 이전의 상태 부적합 기억 손해와 학습 가능성은 범위를 붙여 유지함.
2. **답안 계약과 평가 설계를 먼저 마감함.** 남은 범위·실행 여부 사례를 독립 검토하고 검토 상태를 실행 관문에 연결함. 새 평가에는 동일 조건 안의 성공·실패, 바꿔 표현된 현재 상태, 실제로 예산을 넘는 은행을 포함하되 효과가 나온 사례만 남기지 않음. 관계 확인과 작업자 타당성 확인의 기준을 미리 나눔.
3. **기존 검색의 장점을 보존한 결합을 제한적으로 확인함.** 이미 잘 찾는 검색 순위에 상태 판독을 결합할 때 필요한 근거를 놓치지 않고 불필요한 제공만 줄이는지 봄. 임계값은 학습·개발에서 고정하고 이전 과제 유지 기준도 함께 둠. 새 출처에서 기존 검색·상태 제거 규칙보다 이득이 없으면 추가 모델의 우위를 주장하지 않음. 지금은 더 큰 모델이나 손실함수 후보를 계속 늘릴 단계가 아님.
