# 같은 과거를 주는 형태와 유효성 표시의 효과 (전달 경로 실험)

2026-11-12. 별도 워크트리(브랜치 `worktree-delivery-path-experiment`, 태그 `archive/delivery-path-experiment-20261112`)에서 한 실험의 정리임. 실행과 분석은 Claude가 했고, 독립 검산은 아직 받지 않았음.

질문은 "긴 작업 중에 사실이 바뀔 때, 같은 모델에게 같은 과거를 어떤 형태로 주느냐가 답을 어떻게 바꾸는가"임. 작업자는 Qwen3.5-9B와 27B이고, greedy로 입력당 한 번 실행했음. 검산을 마친 작업자 호출은 약 2만 6천 번임. **같은 정보도 자기 대화로 받으면 9B가 바뀐 예약을 따라가지만 기록 목록으로 받으면 놓쳤음(60개 중 58 대 38).** 기록할 때 무효 표시를 붙이면 단순한 변경은 풀렸지만, 취소가 얽힌 판단은 풀리지 않았음. 9B는 필요한 기록만 받으면 거의 다 풀었지만, 많은 기록 속에서 고르지 못했고, 스스로 고르면 더 나빠졌음. 공개 지식 갱신 벤치마크(LongMemEval-S, BEAM)에서는 형태의 차이가 작았음.

## 자료

| 실험 | 독립 단위 | 내용 |
| --- | --- | --- |
| 1단계 확인 실행 | 가족 43 | 과거 계획을 참고해 두 항목을 정하는 상태 258개(기억 필요 172) |
| 여행 세션 본 실행 | 세션 20 | 40요청 세션, 변경·취소·조건부 참조 포함, 기억 필요 316(9B)·320(27B) |
| LongMemEval-S | 문항 52 | 지식 갱신(지금 값 45, 예전 값 7), 길이 5천·2.6만·11만 토큰 |
| BEAM | 대화 23 | 지식 갱신 28문항 |

주는 형태는 다음과 같음.
- 자기 대화
- 같은 대화를 인용한 로그
- 기록 쌓기 / 무효 표시 / 최신만
- 필요한 기록만(정답 라벨)
- 다른 모델이 고른 기록

실행 전에 예상을 커밋했음. 맞은 예상은 1단계 확인 24개 중 20개, 여행 세션 10개 중 10개, 공개 자료 15개 중 8개(일부 3개)였음.

## 말할 수 있는 것

1. **형태만 바꿔도 작은 모델의 결과가 갈림.** 바뀐 예약을 묻는 요청 60개에서 9B는 자기 대화로 58, 기록 쌓기로 38을 맞혔음. 틀린 22개 중 18개는 무효가 된 첫 결정을 따랐음. 27B는 어느 형태로든 59–60이었음.
2. **기록할 때 유효성을 정리하면 단순한 변경은 풀림.** 표시는 여행자·날짜를 열쇠로 하는 단순한 규칙이 붙였고, 라벨을 쓰지 않았음.
   - 이 표시나 최신 기록이면 9B가 58–59를 맞혔고, 쌓기 → 최신에서 16세션이 오르고 내린 세션은 없었음.
   - 취소가 얽힌 조건부 참조는 표시로도 40개 중 3개였고, 필요한 기록만 주면 30개였음. 27B는 같은 표시를 보고 무효를 따르는 대신 "모름"으로 물러섰음.
   - 옛 진술을 지우면 "예전엔 무엇이었나"는 답할 수 없음(LongMemEval-S 0/7). 지운 정보이므로 설계상 당연하며, 그 정책의 대가를 확인한 것으로만 씀.
3. **작은 모델은 맞는 기억을 쓰지만 고르지 못함.**
   - 9B는 1단계에서 필요한 기록만 받으면 172/172, 기록 전부면 114였음. 여행 세션에서는 각각 306과 242(최신 266)였음.
   - 9B가 스스로 고르면 1단계에서 33이었음. 여행 세션에서 자기 대화에 자기 선택을 더하면 바뀐 예약·취소된 조건부 100개에서 순변화 −36이었고, 18세션이 모두 내렸음.
4. **경로 효과는 조건에 따라 달랐음.** 1단계에서 27B는 같은 글을 자기 대화보다 인용 로그로 받을 때 더 잘 썼음(121 → 154). 저녁 항목을 보류한 것이 원인이었음. 그러나 처음부터 이어 온 자기 대화(여행 세션)에서는 차이가 없었음.
5. **공개 지식 갱신 벤치마크는 이 약점을 거의 드러내지 않음.** LongMemEval-S는 대부분의 형태 사이에 차이가 없었고, 옛 값 답은 2.6만 토큰까지 45개 중 5개 이하였음. 예상한 길이 효과도 없었음(9B 자기 대화 40 → 38, 11만 토큰).

## 참고값과 진단 (결론으로 쓰지 않음)

- **27B가 먼저 풀고 근거를 지목한 선택(`solve_first`).** 이 선택을 받은 9B는 1단계 167/172, 여행 302/316이었음. 27B의 풀이가 섞여 있어 공정한 기억 선택 비교가 아니고, 상한 참고값임. 27B가 직접 답하면 더 나았음(314/320).
- **27B가 풀지 않고 "필요한 기록만" 고른 선택.** 기억이 필요한 상태에서는 126/172였으나, 이미 충분한 상태 27개를 깨뜨려 전체로는 기록 전부보다 낮았음(185 대 197).
- **main의 학습 선택기(`augmented-seed731`, `replay-seed731`).** 현재 관측을 비워 두고 관련성 점수기로만 채점했음. 그래서 그 모델의 관측과의 관계 판단은 시험하지 않았음.
  - 채점은 Colab L4에서 했고, main이 기록한 dev 확률을 재현했음(로짓 차이 중앙값 0.027).
  - 이 조건에서 여행 파일럿 8세션의 결과는 기록 전부(97)보다 낮았음(82, 64). LongMemEval-S에서는 기록 전부와 비슷했음.
  - 여행 질문은 대상을 직접 말해서 후보 찾기는 쉬웠음. 어려운 부분은 기록 사이의 관계(나중에 바뀜·취소됨)였고, 기록을 하나씩 읽는 방식은 구조상 그 관계를 볼 수 없음.
  - `augmented`의 문턱은 main이 고정한 0.15가 아니라 0.5로 썼음. 0.15로 다시 골라도 거의 같았음.
