## 1. 측정 단위와 득실의 정의

측정 단위는 **현재 상태 × 제공할 기억 묶음 × 고정 작업자**임. 같은 상태의 무기억 출력과 기억 제공 출력을 연결하여 다음을 계산함.

`관측 효과 Δ = 기억 제공의 성공 여부 − 무기억의 성공 여부`

| 무기억 | 기억 제공 | 분류 |
| --- | --- | --- |
| 실패 | 성공 | 이득, Δ=+1 |
| 성공 | 실패 | 손해, Δ=−1 |
| 성공 | 성공 | 둘 다 성공, Δ=0 |
| 실패 | 실패 | 둘 다 실패, Δ=0 |

중립 두 종류를 합쳐 버리지 않음. 성공률의 순증가뿐 아니라 개선 수와 악화 수를 따로 보고함. 작업자가 기억 제공 후 실패했다는 사실만으로 손해 라벨을 붙이지 않음. 기억 묶음의 효과를 구성 기록 각각의 효과로 나누어 부르지도 않음.

여행은 요청한 두 장소 ID의 정답 여부, 정보 복원은 요청 필드의 정답과 제공 근거의 동시 충족을 사용함. STATE-Bench는 저장된 언어 요건과 DB 상태 요건이 모두 통과해야 성공임. 이 세 지표를 합산한 하나의 성능을 만들지 않음.

## 2. 같은 기억이 현재 상황에 따라 이득에서 손해로 바뀌는가

기존 여행 자료에서 각 문제군의 두 상태를 사후에 연결함. 두 상태의 목표 문장·은행 전체·실제로 제공한 기록 ID와 순서가 같음을 검사함.

- 처음: 첫 계획을 아직 시도하지 않았고 현재 확인한 과거 장소가 없음. 첫 계획의 두 기록을 제공함.
- 이후: 첫 시도 실패가 보고됐고, 사용해야 할 대안 장소 두 개가 현재 관측에 이미 있음. 앞과 같은 첫 계획의 두 기록을 제공함.

각 상태 안에서는 같은 현재 입력에 기억만 제공·보류한 출력을 비교함. 두 상태 사이에서는 실패 상태와 현재 관측이 함께 바뀌므로 실패 표시만의 효과로 해석하지 않음.

| 자료 | 목표·은행·제공 묶음이 같은 문제군 | 처음에 이득 | 이후에 손해로 전환 | 이후에 중립으로 전환 |
| --- | ---: | ---: | ---: | ---: |
| 기존 파일럿 | 6 | 6 | 4 | 2 |
| 별도 확인 가족 | 6 | 6 | 3 | 3 |
| 합계 | **12** | **12** | **7** | **5** |

12개는 서로 다른 생성 가족이지만 같은 생성 틀을 쓰고 일부 도시·카탈로그를 공유함. 분석 대상은 결과가 좋은 가족만 추가 선별한 것이 아니라 각 회차의 지정된 모든 가족임. 새 확인 실험을 수행한 결과는 아니며, 이미 수집한 상태의 사후 연결 검증임.

따라서 **한 기억 묶음에 상태와 무관한 고정 득실 라벨을 붙이면 7개 묶음에서는 서로 반대인 실제 관측을 담을 수 없음.** 현재 상태를 함께 보존하는 데이터 단위에 직접적인 근거가 있음. 이 결과는 전체 은행을 항상 제공하는 정책의 손해율이나 학습 선택기의 우위를 뜻하지 않음.

**같은 여행 정책 비교에서도 이득 6과 손해 2가 함께 존재함.** 전체 성공이 12→16으로 늘었다는 숫자만 보고하면 악화 두 건이 숨겨짐. 이 점이 이득·손해를 따로 측정할 이유임.

정보 복원에서 관계 대조 학습과 형식 노출 학습을 비교한 개선 23·24건, 악화 0건도 재현됨. 출처 하나씩을 제외해도 순개선은 seed별 21.6–26.1%p, 22.7–27.3%p 범위로 유지됨. 특정 한 출처만의 개선은 아님. 다만 기존에 본 평가 자료의 진단이며 두 seed가 같은 작업자 출력 캐시를 공유함.

전체 제공과 관계 대조 모델을 비교하면 첫 seed는 개선 0·악화 0, 둘째는 개선 0·악화 1임. 정보 복원에서 제공·보류의 관측 최선도 88/96으로 전체 제공과 같음. 이 자료의 학습 오류 교정 효과와 선택기 도입의 추가 가치를 구분함.

**남겨둔 자료의 문제도 확인함.** 후속 과거 생성 1,080기록에는 유효 장소를 선택하지 못한 87기록이 명시적인 `UNAVAILABLE`로 보존돼 있음. 확인용 실제 은행의 고유 270기록에는 이 중 3개가 포함됐고, 이번 평가 정책이 이 3개를 선택한 횟수는 0임. 필요한 정답 기록은 모두 유효하며 현재 카탈로그에 있음. 이 기록을 사후에 정상 경험으로 바꾸거나 원자료에서 삭제하지 않음.

과거에 원래 요청의 조건을 만족한 선택은 기존 생성 409/540, 후속 생성 710/1,080임. **과거에 실제로 골랐던 사실과 과거 과제를 성공적으로 수행했다는 평가는 서로 다름.** 이번 여행 요청은 과거 실제 선택의 재사용이며, 은행 전체를 성공 경험이라고 부르지 않음. 현재 실패·진행 상태는 통제하여 만든 것이며 자연 에이전트 궤적은 아님.

## 5. 채점과 표본 수가 수치를 얼마나 바꾸는가

### 표현 차이에 따른 오차

이미 별도 보존한 원문 명사구 동등성 검토를 재사용하여 별도 민감도 분석을 수행함. 예를 들어 `vegetarian`과 `vegetarian diet`는 고정 채점에서 다르지만 같은 원문 구절의 값임. 이 검토는 사후이며 독립 인간 판정이 아님. 원래 성적은 바꾸지 않음.

| 정보 복원 전체 제공 vs 무기억 | 이득 | 손해 | 둘 다 성공 | 둘 다 실패 | 전체 제공 성공 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 원래 고정 채점 | 52 | 0 | 36 | 8 | 88/96 |
| 사후 원문 명사구 허용 진단 | 58 | 0 | 36 | 2 | 94/96 |

따라서 전체 성공 수는 채점 정의에 따라 **6/96=6.25%p** 변함. 실패 8건 중 6건을 의미상 실패로 설명하면 과장됨. 나머지 두 출력은 게임 ID·라운드 ID 혼동이므로 계속 실패로 남음. 여행 출력에서는 엄격한 JSON 계약으로 확인해도 성공 판정 차이가 0이었음.

### 실제 표본과 불확실성

- 정보 복원 384상태는 12출처의 8상태×2포장×2표현임. 후속 작업은 그중 compound/prose 96상태에만 있음. 전체 384상태에 실제 득실 라벨이 있는 것으로 설명하지 않음.
- 여행 손해 7/12의 조건부 Wilson 95% 참고구간은 **32.0–80.7%**임. 가족들이 독립 표본이라는 가정 아래의 참고치이며 공유 카탈로그와 설계 표집의 한계가 있음. 일반 메모리 손해율의 추정치가 아님.
- 정보 복원에서 손해가 0건이었다는 사실이 일반적인 손해 확률 0을 뜻하지 않음. 12출처 중 손해를 보인 출처가 0개라는 단위로 계산하면, 같은 가정의 참고구간 상단은 **24.2%**임. 96변형을 독립 표본으로 세어 더 좁은 구간을 제시하지 않음.
- 실제 재호출은 여행 2+2, 정보 복원 3개의 **7입력 문맥**뿐임. 모두 원문·채점이 같았지만, 관측 손해 7쌍에서 양쪽 행동이 모두 반복된 쌍은 0개임. 이는 greedy 안정성의 일부 확인이며 상태별 성공 확률 라벨이 아님.
- 출처 단위 10,000회 재표집과 출처 하나씩 제외한 결과를 JSON에 남김. 이미 관찰한 평가 자료의 조건부 민감도 분석이며, 사전 가설의 유의성 검정이나 새 확인 결과로 사용하지 않음. 모든 출처에서 차이가 0인 비교의 bootstrap 구간이 0으로 나와도 모집단 동등성을 증명하지 않음.

## 6. 필요성 라벨과 실제 이득은 얼마나 일치하는가

정보 복원 96상태에서 관계 라벨과 직접 관측한 전체 제공 효과를 교차 집계함.

| 원문·현재 상태 기준 | 관측 이득 | 관측 손해 | 둘 다 성공 | 둘 다 실패 |
| --- | ---: | ---: | ---: | ---: |
| 과거 기록에 필요한 정보가 남음: 60상태 | 52 | 0 | 0 | 8 |
| 현재 이미 모든 요구를 충족함: 36상태 | 0 | 0 | 36 | 0 |

필요성 양성 60개를 그대로 이득 양성으로 바꾸면 8개를 잘못 라벨링함. 사후 표현 진단에서는 이 8개 중 6개가 달라지므로 실제 득실 라벨에는 채점 계약도 함께 보존해야 함.

이 데이터는 필요한 정보 누락과 실제 복원 성공의 연결을 확인하는 데 적합함. 실제 손해 사례가 없으므로 이것만으로 손해 예측기를 학습·검증할 수는 없음. 여행의 같은 기억 묶음 상태 대조는 양·음 효과를 포함하지만 두 요청 틀과 적은 가족에 한정됨.

## 7. 지금 보장할 수 있는 결과와 후속 보완

**현재 보장할 수 있는 결과:** 기존 원자료에서 고정 조건의 관측 득실을 재계산할 수 있고, 동일 기억의 효과가 현재 상태에 따라 달라지는 사례를 출처·원 출력까지 추적할 수 있음. 관계 대조 학습의 특정 선택 오류 교정도 작업자 결과와 연결하여 검산할 수 있음.

실제 작업 성공률의 일반적인 효과, 새로운 출처에서의 득실 예측, 선택기 비용을 포함한 순이득은 아직 별도 검증 대상임. 정보 복원의 저장 토큰 길이를 재검사하면 전체 제공 평균 입력은 186.67토큰, 관계 모델은 181.91·182.33토큰임. 감소는 2.55%·2.32%이며 새 온라인 선택 비용·지연은 측정하지 않음.

현재 자료를 보완할 우선순위는 다음과 같음. 이번에는 이 작업을 실행하거나 평가 자료를 새 학습에 편입하지 않음.

1. 12개의 같은 기억 상태 대조와 채점 경계 8개를 독립 검토자가 확인하여 관계·효용·표현 판정을 분리함.
2. 추가 실행을 승인받는 회차에서 이득·손해·중립을 포함한 전체 고정 평가 목록의 두 행동을 반복함. 손해가 난 사례만 반복하여 손해율을 다시 추정하지 않음.
3. 이 비교 단위를 유지해 사전에 분리한 새 출처를 확인하고, 같은 은행·현재 상태·예산에서 전체 제공·단순 규칙·학습 선택을 비교함.

이번 작업은 재집계·데이터 검증만 수행함. 새 학습·GPU 할당·유료 호출은 없음. [기존 핵심 성과](2026-11-12-memory-core-findings.md)와 [학습 원인 분해](2026-11-12-augmentation-ablation.md)의 원래 결과를 보존함.
