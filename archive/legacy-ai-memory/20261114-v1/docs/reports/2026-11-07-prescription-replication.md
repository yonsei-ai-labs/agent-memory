## 관찰·감사·비용

## 반복을 추가하며 바뀐 해석

처방 추가 FP−F는 기존 +25%p, 추가분 0%p, 누적 탐색 +16.7%p였다. 새16에서 처방 추가의 성공률 우위를 다시 관측하지 못했다. 반면 F−N은 기존 −12.5%p에서 추가분 +25%p로 방향이 바뀌어 누적 관측 차이가 0이 됐다. 따라서 처음 F를 해로운 기억으로 분류할 근거도 더 약해졌다. 관측 차이 0은 동등성이나 효과 부재의 입증이 아니다.

비용 방향도 안정적이지 않았다. FP−F의 평균 API 비용 차이는 기존 −$0.000123에서 새 표본 +$0.000766으로 바뀌었고 누적은 +$0.000173이었다. 처방 추가가 비용을 절감한다는 초기 관측은 유지되지 않았다. 캐시와 생성 길이를 포함한 실제 비용의 기술 통계이며 유의한 비용 효과를 검증한 것은 아니다.

접두사 문제의 누적 미제출은 FP 5/6, FPA 1/6으로 적용 조건의 제출률 개선 후보는 남았다. 그러나 그 문제는 모두 공식0/6이고, 전체 성공은 FP 5/12 대 FPA 4/12다. 보조 지표가 좋아진 것을 최종 효용 개선으로 바꾸어 말할 수 없다. 한 카드·한 문제에서의 경로 가설로 남긴다.
