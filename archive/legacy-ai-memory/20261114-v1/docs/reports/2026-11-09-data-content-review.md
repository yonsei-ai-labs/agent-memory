## 데이터에서 남은 중요한 문제

### 1. 관련성 자료는 크게 불균형하고 일부 주석의 경계가 불명확함

주석자는 한 assistant이고 독립 이중 검토가 아님. 예를 들어 `rebench-876--literal_escaping`은 생성 코드의 forward reference와 f-string literal escape를 “데이터와 실행 문법”이라는 원리로 연결한 양성임. 구체적인 원리가 같은지에 이견이 있을 수 있음. 현재 이슈 자체가 수정 방향을 충분히 설명하는 양성도 있음. **논란 가능성이 있는 후보이며 이번에 오답으로 확정하거나 원래 라벨을 수정하지 않았음.**

현재 이슈 저장소는 분리하지만 16개 기억 은행은 공유함. 시간상 과거→현재의 순서는 검증하지 않았으므로 역사적 연속 배포나 완전히 새 기억의 일반화로 해석하지 않음.

API 자료도 네 절차와 두 fixture를 확인한 제한된 프로그램 관계임. 현재 점수를 일반적인 사고력·실제 SWE 수행 능력으로 확대하지 않음.

### 3. 행 수가 원천 다양성을 크게 과장할 수 있음

범위 학습 1,316행은 658조건의 A/B 표현이고, dev 594행은 198조건의 세 표현임. 여행 수만 후보 쌍도 기본 계획은 45개임. 후보 검색 학습이 같은 자료를 재사용한다고 원천이 추가되지 않음.

최신 후속 1,536정책 행도 같은 12가족·96상태임. 새로운 표현·반복·모델 교체와 새로운 과거 경험·현재 문제를 구별해야 함.

### 4. 같은 입력에 다른 결과가 붙는 대조는 정보 제한을 함께 해석해야 함

[효용 자료 추가 점검](data/data-content-review-20261109/utility-data-review.json)에서 현재+제안 기억 입력은 96개가 모두 달랐고 동일 문장/다른 네 범주 정답의 충돌은 없었음.

반면 현재만 보는 대조는 고유 문장 72개이며 다른 정답이 겹치는 묶음 20개였음. 현재 문장이 같아도 제안 기억을 숨기면 개선/악화가 달라질 수 있기 때문임. 이 자료 안에서 같은 문장별 다수결의 분류 상한은 76/96이며, 실제 모델 성적이나 새 출처의 성능 상한은 아님.

이는 주 데이터의 라벨 오류라고 볼 근거가 아니라, **대조군이 의도적으로 중요한 정보를 못 본다는 사실**임. 두 모델의 입력 정보가 같은 것으로 해석하거나, 현재만 보는 모델의 정확도가 낮다는 이유만으로 학습 구현을 탓하지 않음.

### 5. 실제 득실 라벨은 특정 worker·기억 묶음·지침에 조건부임

실제 결과는 네 기록의 제공과 보류라는 두 행동, Qwen3.5-9B의 고정 설정에서 나온 관측임. 같은 기억도 표현·전달 개수·현재 입력·worker가 달라지면 효과가 달라질 수 있음. 4B와 9B, 기존 지침과 새 지침의 결과를 조건 없이 같은 정답으로 합치면 안 됨.

실패/실패 범주는 근거 없는 구체적 추측 증가나 비용 증가를 숨김. 최신 worker는 근거 부족과 불가능도 잘 구분하지 못했음. 실제 득실 학습을 성공 네 범주 하나로 끝내기 어려운 이유임.

### 6. 외부 후보는 학습 데이터로 자동 편입할 수 없음

LongMemEval·PersonaMem·Mem2Act·ProofWriter 등 조사는 원천 후보·메타데이터·일부 원문/예외 확인까지임. 전부 정규화해 학습에 넣은 것은 아님. Mem2Act 원문 ID 연결 예외, PersonaMem의 사용자 분할, 파생 벤치의 원천 중복을 처리해야 함.

CL-bench 계열은 확인한 현재 조건상 평가 전용이므로 학습/보정/증류용 파생 예제로 만들지 않음. 데이터 접근·이용 조건은 앞선 [공개 자료 조사](../ai-memory-fresh-dataset-survey-2026-11-09.md)와 [추론 데이터 설계](../ai-memory-reasoning-contrasts-and-data-2026-11-09.md)를 따름.

## 어떤 방향으로 보완할까

1. **기존 자료의 용도를 유지함.** 수치·범위 자료는 기능/회귀 점검, 관련성 자료는 후보 선별, API는 계약 전이, 실제 효용 자료는 고정 worker의 행동 선택에 사용함. 모든 라벨을 0/1/2로 통합해 섞지 않음.
2. **독립 주석을 먼저 확보할 부분을 고름.** 진단 단서 31양성과 가까운 비정답·미확인, 원리 전이 경계 사례부터 다른 검토자가 근거와 현재 관측으로 판정함. 모델 성적이 좋은 쪽으로 라벨을 맞추지 않음.
3. **같은 판단 유형이 다른 원천에서 재등장하도록 수집함.** 현재 자료는 이름/범위/반환·원본 효과에 치우쳐 있음. 정보 부족, 갱신, 여러 근거 결합, 실패 진단, 적용 전제·검증 범위·확인 비용을 독립 가족에서 확보함.
4. **증강은 정답 재계산과 함께 함.** 같은 기억·다른 현재 조건, 근거 삭제/복원, A/B/A+B 조합, 누락 전제 조회, 의미 유지 표현을 구분함. 다른 근거가 남아 있는지 확인한 뒤 충분성 정답을 붙임.
5. **실제 효용 필드를 넓힘.** 성공·근거 없는 구체적 행동·정상 보류·비용을 분리함. 원래 성공 정답을 사후 수정하지 않고 새 버전의 감독/평가로 설계함. 학습은 단순한 상위2/보류 규칙보다 추가 가치가 남는지를 확인함.

현재 자료는 판독·검색·효용을 연결하는 기초 연구와 진단에 사용할 수 있음. 다양한 자연 경험에서 어떤 기억을 남기고 사용할지 일반적으로 배운다고 주장하려면 위의 원천·주석·관측 행동 보강이 필요함.
