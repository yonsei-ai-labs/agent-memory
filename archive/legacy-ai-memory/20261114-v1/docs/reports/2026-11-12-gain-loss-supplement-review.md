# 득실 자료 보완안 검토: 유지할 성과와 조정할 실험

2026-11-12. [외부 검토 노트](../ai-memory-gain-loss-data-supplement-2026-11-12.md)를 원자료와 대조함. **득실의 기준을 명시하고, 같은 상태의 원 출력을 연결하는 데이터 기여는 적절함.** 추가된 전달 경로 자료의 주요 수치도 재현됨. 다만 새로 제안한 무효 기록 제거 조건은 현재 정의에서는 기존 조건과 중복되며, 오답의 기록 일치를 원인 확정으로 설명하는 부분은 조정해야 함.

원본 노트와 원자료는 수정하지 않음. 새 학습·GPU·작업자·유료 호출은 없음. [독립 검산 코드와 결과](data/gain-loss-supplement-review-20261112/README.md)를 별도로 보존함.

## 1. 긍정적으로 확인한 부분

- 데이터 manifest의 134파일 해시·크기가 모두 일치함.
- 태그의 evaluator를 실행하지 않는 별도 코드로 여행 원 출력 **15,740행**, 공개 자료 원 출력 **5,706행**을 다시 채점하여 저장된 성공·오답 유형과 불일치 0건을 확인함.
- 여행의 요청·사건 접두부·작업자 실제 선택에서 **2,240행의 정답·필요/무효 기록 라벨**을 재구성하여 일치함. 독립 인간의 의미 판정은 아님.
- 본 실행의 공통 상태는 9B 396개, 27B 400개이며 각각 20세션임. 원 노트의 기준 조건 대비 손실 표를 재현함.
- main의 이전 12가족과 전달 경로 본 실행 20가족 사이의 가족 ID 중복은 0임. 서로 다른 과제 구성이므로 이를 하나의 손해율로 합산하지 않음.

실행에서 정답이 없어진 상태를 공개하는 것도 적절함. 9B 본 세션 800요청 중 4요청이 앞선 선택 실패로 `answerable=false`가 되어 전체 조건의 채점에서 빠짐. 396과 400은 각 전달 조건이 공통으로 가진 하위 집합이며 두 모델의 공통 고정 과거를 뜻하지 않음. 새로운 기계적 검산의 완료 범위와 인간 의미 검토가 남은 범위를 나누어 발표할 수 있음.

## 2. 가장 먼저 조정할 것: 제안 ④는 기존 최신 기록 조건과 중복됨

노트는 `전체 기록 − 무효 기록`을 약 796호출과 반복으로 새 실행할 것을 제안함. 그러나 무효를 **현재 시점에 나중 변경·취소로 효력을 잃은 예약 사건**으로 정의하면 다음과 같음.

- 각 시점 이전의 예약 중 같은 사람·날짜에 후속 사건이 있는 예약만 제거함.
- 취소 사건과 다른 사람의 아직 유효한 예약은 남김.
- 현재 자료에는 취소 뒤 같은 사람·날짜를 다시 예약하는 사건이 없음.

그 결과, 두 작업자·28세션의 **2,240개 모든 상태 접두부에서 남은 기록 ID·순서·본문이 `records_latest`와 같음.** 실제 실행된 `records_latest` 1,112행의 전달 ID도 이 규칙과 일치함. 세션 끝의 무효 표시를 앞 시점에 소급하지 않고 현재 시점의 사건만 사용하여 확인함.

따라서 이 정의의 조건을 새로 호출할 필요가 없음. 기존 최신 기록 결과를 해당 대조로 사용하면 됨.

다른 뜻으로 **현재 질문과 관련된 무효 기록만 제거**하려는 경우는 새 조건이 될 수 있음. 다만 질문과 무관한 무효 기록을 일부 남기는 진단이므로 글로벌 유효성 정리와 구분해야 함. 정답 라벨의 `counter_memory_ids`로 제거하면 라벨 기반 진단 조건이고, 선택기의 실제 성능이 아님. 이 뜻을 먼저 정해야 비용·가설이 명확해짐.

## 3. 손해 정의의 구분은 유지하고 양방향 변화를 함께 보고함

무기억 대비 악화와 필요한 근거만 주었을 때 대비 악화를 구분한 것은 좋음. 후자는 **필요 근거 조건 대비 손실**로 쓰면 첫 질문과 혼동이 줄어듦. 필요한 근거 조건도 작업자가 가장 잘 답하는 상한은 아님.

다음은 9B 본 실행의 같은 396상태에 대한 재집계임.

| 전달 조건 | 성공 | 필요 기록 조건 대비 개선 | 필요 기록 조건 대비 악화 | 순변화 |
| --- | ---: | ---: | ---: | ---: |
| 자기 대화 | 314 | 4 | 74 | −70 |
| 인용 로그 | 320 | 5 | 69 | −64 |
| 기록 목록 | 322 | 2 | 64 | −62 |
| 무효 표시 | 336 | 3 | 51 | −48 |
| 최신 기록만 | 346 | 2 | 40 | −38 |
| 필요한 기록만 | 384 | 0 | 0 | 0 |

노트의 악화 수는 맞음. 하지만 최신 기록의 악화 40을 그대로 두 조건의 성공 수 차이라고 부르면 안 됨. 반대 방향 개선 2가 있어 순차이는 38임. 9B의 필요한 기록 조건은 12실패를 포함하고, 일부는 더 많은 맥락에서 복구됨. 득실 장부에는 두 중립을 포함한 네 유형과 기준 조건 ID를 모두 남기는 것이 적절함.

무기억 대비 손해 0이라는 설명은 **전달 경로 세션**에 한정해야 함. main의 계획 변경 대조에는 무기억 대비 손해 7/12가 있음. 원 노트의 “여행 자료의 무기억 대비 손해는 0”이라는 사용 금지·설명 문장은 두 여행 자료의 이름을 구분해 쓰는 것이 좋음.

## 4. 오답 일치는 검산 가능하지만 원인 기록의 확정과는 다름

`followed=void` 361행은 모두 현재 작업자 문맥에 포함된 무효 결정의 장소 쌍과 일치함. 이는 재현 가능한 중요한 결과임. 하지만 이 가운데 다음 중복이 있음.

| 오답 일치 진단 | 행 수 |
| --- | ---: |
| 무효 결정 쌍과 일치 | 361 |
| 동시에 다른 비무효 결정 쌍과도 일치 | 21 |
| 그 비무효 결정도 실제 제공 문맥에 포함됨 | 15 |

따라서 적어도 15행에서는 장소 쌍만으로 원인 기록 하나를 고를 수 없음. 나머지 행도 출력 일치가 모델 내부의 참조 과정을 직접 입증하지는 않음. 발표에서는 **“오답이 무효 기록·다른 결정과 일치하는 유형을 추적함”**이라고 쓰는 것이 정확함. 기록 제거 대조는 해당 묶음의 영향을 더 확인할 수 있지만, 그 결과도 모든 오답의 단일 원인을 확정하는 것은 아님.

`fresh`도 “기록에 없는 값”으로 바꾸면 부정확함. 이는 **이전 결정과 일치하는 식당·숙소 조합이 없음**이라는 라벨임. 90행 중 64행은 식당과 숙소가 각각 따로 과거에 나왔고, 15행은 한 항목만 나왔으며, 두 항목 모두 과거에 없던 것은 11행임. 기존 값의 재조합을 새 값 생성과 구분해야 함. 카탈로그 밖의 `invalid` 1행도 별도 보존하는 편이 좋음.

[동시에 제공된 다른 기록과도 일치하는 15행](data/gain-loss-supplement-review-20261112/ambiguous-attributions.jsonl)을 따로 저장함. 이는 15개의 독립 원 경험이나 세션이 아님.

## 5. 작업자 비교와 공개 자료의 해석 범위

**9B와 27B의 기록은 각 모델이 진행한 자기 세션에서 생성됨.** 본 실행 20세션 모두 두 모델의 과거 선택이 달랐으며, 전체 800위치 중 선택이 다른 위치는 90개임. 각 모델 안에서 전달 형태를 비교하는 결과는 유지됨. 두 모델의 차이를 같은 과거를 읽는 모델 크기의 순수한 효과로 설명하려면 하나의 고정된 기록에 두 작업자를 붙이는 비교가 필요함. 기존 stage1의 교차 실행과 이 세션 실험의 범위를 구분해야 함.

공개 자료의 수치 재계산은 통과했지만 “자연 자료에는 이런 손해가 드물다”는 일반적 빈도 주장은 넓음. 표본은 지식 갱신 문항을 골라 검토하고 길이·근거 범위를 구성한 자료임. 맞는 표현은 **“이번에 검토한 공개 갱신문항과 전달 조건에서는 손해가 적게 관측됨”**임. 공개 자료에서도 손해를 검산할 수 있으며, 이번 자료만으로 자연적인 손해의 발생률을 추정하기 어려운 것임.

공개 자료를 통째로 손해 측정에 부적합하다고 버릴 이유는 없음. 실제 손해 사례는 보존하고, 성공·실패의 채점 타당성과 분모를 따로 공개하는 것이 적절함.

## 6. 보완 순서에 대한 판단

1. **득실 장부 통일:** 가장 먼저 할 일임. 기준을 `none`, `needed_records`, `current_evidence` 같은 실제 조건 ID로 기록하고 네 결과 유형을 보존함. 무효·다른 기록 일치는 원인 확정 라벨과 구분함.
2. **교차 검산과 사람 검토:** 이번에 저장된 여행·공개 원문의 기계적 교차 채점과 여행 규칙 라벨 재구성은 완료함. 15GB 원 실행 묶음의 입력·토큰 전체 검산과 독립 인간 의미 판정은 미실행임. 사람에게는 먼저 기존 정답·오답 유형 라벨을 가리고 요청·해당 시점의 기록·출력으로 판단하게 하는 것이 좋음. 손해 40건만 보면 손해 양성의 타당성 점검이며 누락된 손해까지 평가하지 못하므로, 전체 라벨 품질 목적이면 이득·중립 표본도 포함함. 38/40은 초기 품질 관리 기준으로 둘 수 있음.
3. **유형별·세션별 보고:** 유지함. 본 적 있는 유형을 골라 붙인 부호 검정은 탐색으로 표시하고 모든 유형·무변화 세션·반대 방향도 함께 보고함. 작업자 둘을 같은 20가족의 독립 40세션처럼 합치지 않음.
4. **새 실행:** 전역 무효 제거는 현재의 최신 기록 조건을 재사용함. 새 조건이 필요하면 제거 대상·기억 본문·순서가 기존과 다른지 CPU에서 먼저 확인함. 이번 검토에서 GPU 실행은 시작하지 않음.
5. **확대:** 발표 전 필수로 늘리지 않아도 됨. 문장 틀마다 같은 방향이 나와야 자료를 채택한다는 기준은 피하고, 사전 고정한 모든 표현의 결과와 반전을 함께 보고함. 이미 본 자료의 효과가 뒤집힌 경우도 버리지 않음.

현 단계에서는 새 조건을 더 추가하기보다 **관측 득실과 근거 조건 대비 손실을 나누어 정리하고, 기록 일치 라벨의 의미를 다듬는 작업**이 기여를 더 분명하게 함.

## 7. 발표 문장 제안

> 현재 상태와 과거 기록의 변경·취소 관계를 통제한 자료에서, 기억 전달 정책에 따른 작업 결과의 이득과 손실을 짝지어 측정함. 무기억 대비 손해와 필요한 근거 조건 대비 손실을 구분하고, 오답이 무효 기록·다른 결정과 일치하는 유형을 원 출력에서 재계산할 수 있게 구성함. 전달 형태의 효과는 요청 유형과 작업자 조건에 따라 달랐음.

이 문장은 처음의 득실 측정 질문과 연결됨. 학습 선택기의 실용적 우위, 자연 자료의 일반적인 손해율, 모든 오답의 인과적 원인을 주장하지 않으면서도 확보한 데이터와 측정상의 성과를 드러냄.
