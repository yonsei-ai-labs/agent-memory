[11월 9일 누적 실험 점검](2026-11-09-experiment-review.md)은 최신 여행 출력 460건의 별도 채점, 실제 업로드·분할, 기존 저장 결과와 로컬 검사를 대조함. 현재 수치 불일치는 발견하지 못했으나 참조 판독과 효용의 차이, 규칙과 같은 선택, 평가 출처 수·비용 기록의 제한을 정리함.

[11월 8일 통합 리뷰](../../training/memory_selector/reviews/2026-11-08-integrated/README.md)는 현재 결론의 근거와 한계를 다시 연결한다. 저장 가중치·실행 판정 재현은 통과했으나, 최신 주 비교는 학습 이슈에서도 같은 기억을 고르고 기존 효용 개발 자료에는 고정 기억을 넘어설 성공 여지가 없었다. 기존 결과를 바꾸지 않고 다음 설계의 우선순위를 정리했다.
