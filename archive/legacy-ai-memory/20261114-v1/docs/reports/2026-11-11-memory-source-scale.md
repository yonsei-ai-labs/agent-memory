# 120출처 학습과 고정 작업자 평가

2026-11-11. [30출처 수집 파일럿](2026-11-11-memory-source-pilot.md)을 학습 가능한 **120출처 그룹·2,352관계쌍**으로 확대하고, Harrier 0.6B의 30·60·120출처 학습과 고정 Qwen3.5-4B 작업자 평가를 완료함.

시험 자료에서 LoRA는 판독층만 학습한 조건보다 필요한 근거를 잘 확보했고, 근거가 제공된 정답도 21→26/30으로 증가함. 다만 **세 학습 규모 모두 26/30으로 증량 효과는 없었으며, 같은 토큰 예산에 기억을 채워 보내는 정책은 29/30임. 개발 자료에서는 LoRA 우위가 반복되지 않음.** 작은 선택기의 학습 가능성은 남지만 안정적인 실용 우위나 기존 모델의 대체를 주장할 단계는 아님.

학습 120그룹은 Mem2ActBench 66그룹·73질문과 PersonaMem-v2 54사용자·54질문임. 앞서 예약한 출처 분할을 유지하고, 근거가 불명확한 train 출처는 아직 예약되지 않은 Mem2Act 출처로 보충함. 예약된 dev/test를 학습으로 옮기지 않음. 30·60·120은 중첩 집합이며 방해 기억을 제공하는 출처도 각 크기 안으로 제한함.

각 질문에서 `관측 없음 / 필요한 원문이 이미 관측됨 / 무관한 원문이 관측됨`의 세 상태를 구성함. 모델에는 목표·관측·후보 원문만 제공함. 원본 정답·생성 persona 프로필·감독 사실 이름은 입력하지 않음. 이는 공개 합성 대화의 통제 대조이며 실제 에이전트의 진행·실패 이력은 아님.

Mem2Act는 원문에 있는 식별자·대상·설정 등의 좁은 사실을 감독함. 승인된 사실 표현이 없는 후보를 음성으로 삼았으므로, 모든 의미적 도움이나 동일 대상의 조건 충돌을 판정하는 독립 정답은 아님. PersonaMem은 검토한 관련 발화 한 조각의 제공 필요성만 감독하고 나머지 후보는 미주석으로 둠. 다른 사용자의 발화가 후보에 포함된 보조 과제로, 개인의 실제 기억 저장소 전체를 재현하지 않음. 이 부분의 100%를 개인 기억 검색 정확도 100%로 해석하면 안 됨.

원문 1,699조각의 구간·출처와 채택/미채택 이유를 보존함. 분할 간 원문 완전 중복·양성 기억 중복·동일 모델 입력 중복은 0건임. 같은 생성 방식·주제의 유사성이 제거됐다는 뜻은 아님. 독립된 사람의 합의 주석은 수행하지 않음. 실제 득실은 관계 정답에 덮어쓰지 않고 별도 작업자 출력으로 보관함.

## 학습과 비교 조건

기존 reader의 Harrier 0.6B LoRA와 128차원 GELU 판독층을 공통 초기값으로 사용함. rank 8의 q/v LoRA와 판독층을 학습하고, 상태 안의 양·음성을 균형화한 교차 엔트로피를 사용함. 새 손실이나 모델 구조를 동시에 늘리지 않음. 고정 encoder에서 같은 판독층만 학습한 120출처 대조도 실행함.

모든 규모에서 8 epoch·seed 731을 사용함. 개발 자료의 출처별 균형 정확도를 기준으로 2·4·8 epoch 중 선택함. Mem2Act와 부분 감독 PersonaMem의 평균이므로 이 선택 지표를 최종 작업 성공으로 취급하지 않음. 선택 checkpoint는 30출처 8 epoch, 60·120출처 2 epoch임. 전체 실행에서는 모든 감독 쌍을 8회씩 사용했으나 선택된 checkpoint가 본 양은 다름. 같은 epoch는 같은 계산량이 아니므로 순수한 데이터 양의 인과 효과를 분리한 실험도 아님.

기존 고정 reader, 최근 상태 모델 seed 731, BM25, 기존 학습 검색, 관측 중복 제거, 개발 자료에서만 정한 임계값을 비교함. 기본 정책은 같은 후보 10개에서 최대 두 기억·512토큰을 전달함. 추가로 개수 제한을 풀고 같은 512토큰을 고정 순서로 채우는 조건과 LoRA 조건을 실행함. 시험 Mem2Act 15은행 중 12은행은 기억 10개가 모두 이 예산에 들어가므로 이 비교가 필요했음.

## 선택 단계의 결과

아래는 **시험 Mem2Act 15출처·45상태**의 결과임. 근거가 필요한 30상태와 이미 관측된 15상태를 나눔. 불필요한 기록은 현재 필요 사실을 공급하지 않는 전달 기록 수임.

| 선택기 | 출처별 균형 정확도 | 필수 근거 확보 /30 | 이미 알려졌을 때 보류 /15 | 불필요한 기록 |
| --- | ---: | ---: | ---: | ---: |
| 기존 고정 reader | 50.2% | 1 | 4 | 12 |
| 이전 상태 모델 | 50.8% | 2 | 2 | 14 |
| 판독층만 학습 120 | 71.3% | 14 | 9 | 25 |

| 기존 검색 + 중복 제거·개발 임계값 | 78.7% | 24 | 0 | 61 |

LoRA로 판독층만 학습한 조건보다 근거 확보가 개선됨. 검색보다 근거 확보 수는 하나 적지만 불필요한 전달은 줄었음. 반면 120출처가 30출처보다 좋은 결과는 아님. 이전 상태 모델의 낮은 점수는 새로운 질문·입력 계약으로의 전이 결과이며, 보존한 옛 가중치가 손상됐거나 이전 자료의 성과가 사라졌다는 증거는 아님.

정답 기억을 제거한 사후 진단에서는 LoRA 30·60·120이 각각 **4·16·10/30상태**에서 잘못된 기억을 제공함. 독립적으로 계산한 쌍 점수에서 정답 후보만 제거한 진단이며 새 작업자 호출은 없음. 정답이 항상 있는 후보 은행에서의 높은 성적을 근거가 없을 때의 보류 능력으로 확대할 수 없음.

## 고정 작업자의 결과

같은 Qwen3.5-4B가 주어진 도구의 필수 인수를 JSON으로 복원하도록 함. 도구·예약·결제 등을 실제 실행하지 않았으므로 **전체 에이전트 작업 성공률이 아닌 필수 인수 복원 성적**임. 실제 근거가 확인된 필수 인수만 남겨 개발 9질문·8출처·27상태, 시험 10질문·10출처·30상태를 평가함. PersonaMem 추천 답변은 정오가 명확하지 않아 작업 평가에 포함하지 않음.

원래 채점인 `정답 일치`를 보존하고, 출력 확인 후 `정답 일치 + 입력에 검토한 근거가 있음`을 사후 감사로 추가함. 후자는 관계 주석을 공유하며 모델이 근거를 인과적으로 사용했다는 증명이나 독립 정답 주석은 아님. 이 감사로 학습·checkpoint·임계값을 다시 고르지 않음.

| 정책 | 시험 정답 일치 /30 | 시험 정답+근거 /30 | 개발 정답+근거 /27 | 시험 평균 기억 토큰 |
| --- | ---: | ---: | ---: | ---: |
| 무기억 | 11 | 10 | 6 | 0 |
| 기존 고정 reader | 11 | 10 | 6 | 9.4 |
| 이전 상태 모델 | 12 | 11 | 6 | 10.9 |
| BM25 | 16 | 16 | 8 | 97.4 |
| 기존 검색 | 22 | 22 | 12 | 99.3 |
| 기존 검색 + 중복 제거·개발 임계값 | 23 | 23 | 12 | 92.5 |
| 판독층만 학습 120 | 21 | 21 | 13 | 69.6 |
| LoRA 30 | 26 | 26 | 12 | 37.9 |
| LoRA 60 | 26 | 26 | 10 | 80.3 |
| LoRA 120 | 27 | 26 | 10 | 43.8 |
| 검토한 정답 근거만 제공 | 29 | 29 | 18 | 35.7 |
| 고정 순서로 512토큰까지 전달 | 29 | 29 | 15 | 374.3 |
| LoRA 120, 개수 제한 없이 512토큰 | 27 | 26 | 10 | 49.6 |

시험에서는 적은 기억으로 판독층·검색보다 많은 정답을 얻었음. 하지만 개발에서는 판독층만 학습한 조건이나 검색을 넘지 못함. 개발의 정답 근거 조건도 18/27로 낮아 작업자·문항 구성의 영향을 함께 봐야 함. 최종 선택기를 안정적인 개선 정책으로 채택하지 않음.

시험 출처 10개를 단위로 재표집한 탐색적 95% 구간에서 LoRA 120의 `정답+근거` 차이는 검색 대비 +10.0%p [0.0, 23.3], 판독층 대비 +16.7%p [0.0, 33.3]임. 작은 통제 자료·한 학습 seed의 결과로, 일반화나 통계적 우위를 확정하지 않음. 세 규모가 모두 26건이라는 것도 모델이 같거나 이후 증량이 무의미하다는 증명은 아님.

무기억의 근거 있는 정답 10건을 LoRA가 망친 경우는 이번 시험에서 0건임. 전체적으로 손해 사례가 적으므로 악화 방지 학습의 효과를 주장하지 않음. 선택기 비용은 배치에 나눈 평가 시간이 상태당 약 0.20초이며 실제 서비스 지연과 다름. 평균 기억 토큰 감소는 확인했지만, 선택기까지 포함한 지연·금전 비용 개선은 입증하지 않음.

## 재현과 자원

데이터 파일 20개를 원천·동결 주석으로 다시 만들어 바이트 단위 일치를 확인함. 저장 특징과 실제 판독층으로 6모델의 개발·시험 점수 **11,160개**를 재계산했고 분류·선택·지표가 모두 일치함. 3개 LoRA의 각 112텐서에 유효한 변화가 있고, optimizer 116상태는 유한하며 저장 step도 맞음. 실제 encoder를 다시 불러 128쌍의 특징을 재계산한 오차는 0임.

작업자 고유 입력 385호출과 동일 입력 3반복을 수행함. 반복 출력은 3/3 일치함. 같은 입력 결과를 재사용한 912정책 결정은 독립 호출이나 독립 출처 수가 아님. 공유 묶음의 모든 원시 응답·채점을 CPU로 다시 검산함.

로컬 RTX 4080 SUPER에서 세 규모 학습·평가에 약 58.6분, 작업자 실행에 약 9.4분이 걸림. 전처리·별도 기준선·환경 준비 시간은 제외한 값임. 최대 PyTorch 할당은 각각 약 2.71GiB와 8.69GiB임. 최초 작업자 실행은 환경·가중치 준비 부족으로 출력 없이 실패했고, 별도 환경과 고정 가중치를 준비한 뒤 완료함. 실패 기록도 보존함. 새 Colab 할당·유료 API 호출·외부 도구 실행은 없었고 이번 GPU 프로세스는 종료됨.

## 다음 판단

이번 회차에서 수집→관계 학습→실제 출력→검산의 한 묶음을 완료함. 원문 구간·분할·대조·모델·출력을 연결한 자료와, 좁은 관계 감독으로 판독층 이상을 학습한 점을 유지할 성과로 봄. 현재 결과만으로 데이터 양 부족을 유일한 원인으로 보거나 더 많은 같은 대조를 곧바로 학습하는 것은 적절하지 않음.

다음 자료는 **같은 대상의 식별자·수정 이력·현재 조건 때문에 필요한 기억이 달라지고, 전체 은행이 전달 예산을 실제로 넘는 경우**를 포함해야 함. `qa_180`과 같은 실패 유형을 설계용으로 활용하되 이미 본 시험 문항을 수정해 새 독립 시험으로 세지 않음. 현재 관측을 그대로 복사한 대조와 다른 사용자 기억은 보조 진단으로 남기고, 단일 경험 흐름에서 나온 관측·기억을 중심으로 수집하는 것이 적절함. 목표만 입력하는 대조도 아직 없어 이번 학습 개선을 현재 상태 입력 하나의 기여로 귀속하지 않음.

모델을 더 크게 만들거나 새 손실을 늘리는 것보다, 이번 학습 모델을 고정한 채 이 조건을 갖춘 **다음 출처 묶음 전체**에서 선택·근거 확보·작업 결과를 함께 측정하는 것이 우선임. 이 시험 분할은 이제 관찰한 자료로 표시하며 후속 방법 선택의 독립 확인 자료로 재사용하지 않음.
