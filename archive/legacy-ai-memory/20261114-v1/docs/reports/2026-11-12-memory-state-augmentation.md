# 득실 연구를 위한 관계 데이터 증강: 첫 구성 결과

2026-11-12. [득실 자료 보완 노트](../ai-memory-gain-loss-data-supplement-2026-11-12.md)와 [교차 검토](2026-11-12-gain-loss-supplement-review.md)를 바탕으로, 기존 학습용 11출처에서 **1,056상태·고유 판독 입력 4,224쌍**을 생성하고 검증함. 현재 목표·상태·이미 확인한 사실에 따라 필요한 기억이 달라지는 대조를 보강함. 새 모델·손실함수·벤치로 확장하지 않음.

[데이터](../../datasets/memory_state_augmentation/20261112-v1/README.md) · [검산 수치](../../datasets/memory_state_augmentation/20261112-v1/audit.json) · [코드](../../data_pipeline/augment_memory_states.py)

**실제로 추가한 것은 관계 학습 자료임.** 증강한 상태에서 작업자를 실행하지 않았으므로 실제 득실 라벨은 0개이고 모두 미측정으로 남김. 과거 결과를 새 문장의 정답 효과로 복사하지 않음. 생성한 현재 실패·확인 관측은 통제 개입이며 자연 발생 에이전트 경험이 아님.

## 1. 왜 이런 증강을 했는가

기존 결과에서 같은 기억의 가치가 현재 상태에 따라 달라지고, 이미 아는 정보와 아직 필요한 정보의 구분을 학습시키는 것이 중요했음. 문장만 여러 번 바꾸는 증강으로는 이 관계의 빈틈을 충분히 메우기 어려움.

이번에는 세 축을 교차함.

| 축 | 구성 | 확인하려는 판단 |
| --- | --- | --- |
| 현재 분기 | 첫 시도 전 / 첫 시도 실패 후 | 현재 기본 계획과 대안 중 무엇이 적용되는가 |
| 확인한 사실 | 기본·대안 각각의 식당·숙소 4사실에 대한 모든 16부분집합 | 지금 관측이 실제 현재 요구를 충족하는가 |
| 표현 | 명시적 상태, 자연 문장, 다른 조회 실패가 함께 있는 사건 로그의 3방식 | 특정 상태 표식·실패 단어·절 순서에만 의존하는가 |

기본/대안 계획의 각 두 기록은 실제 과거 생성 로그의 원 기록임. 11가족의 원 은행 477기록을 그대로 유지함. 핵심 참조 44개는 모두 유효한 장소 선택을 담음. 전체 은행에는 원래 장소를 고르지 못한 기록 21개도 있으므로 이를 정상 사실로 바꾸지 않고 `unavailable_source`로 구분함.

## 2. 실제 예시

한 학습 출처의 목표는 “기본은 Jacob의 4일차 식당·숙소이며, 첫 결제 실패 뒤에는 Grace의 2일차 계획을 사용”임. 현재 관측에는 Jacob의 두 장소가 이미 확인돼 있음.

| 바뀌는 현재 상태 | 현재 이미 아는 사실 | 필요한 기억의 관계 정답 |
| --- | --- | --- |
| 첫 결제 시도 전 | Jacob의 두 장소 | 추가로 필요한 기록 없음 |
| 첫 결제 실패 후 | 같은 Jacob의 두 장소 | Grace의 식당·숙소 두 기록 필요 |

두 상태의 목표·은행·관측 사실은 같고 첫 결제의 상태만 다름. **정보가 현재 관측에 있다는 사실과, 그 정보가 현재 선택해야 할 분기에 해당한다는 사실을 구분해야 함.**

다른 상태에서는 Grace의 식당만 이미 확인했을 때 숙소 기록을 남기도록 함. 사건 로그 표현에는 두 분기 모두 “관련 없는 지도 조회가 실패했다”를 넣어, 실패라는 단어만 보고 대안으로 옮기는 판단도 점검하게 함. 세 번째 목표 표현에서는 대안을 먼저 언급하므로 첫 번째 사람의 기록만 가져오는 방식도 정답을 유지하지 못함.

이 정답은 원문·목표·현재 상태의 관계임. 실제 작업자가 이 기억을 제공받아 성공하거나 망가졌다는 관측 결과가 아님.

## 3. 구성 규모와 학습에서 사용할 단위

| 항목 | 결과 |
| --- | ---: |
| 기존 학습 출처 | 11가족 |
| 새 독립 출처 | 0 |
| 원 은행 기록 | 477 |
| 상태 | 1,056 = 11 × 2 × 16 × 3 |
| 목표에 언급된 네 기록의 학습쌍 | 4,224 |
| 실제 고유 pair 입력 | 4,224 |
| 같은 실제 입력의 상충 라벨 | 0 |
| 전체 은행의 후보 관계 | 45,792 |
| 필요한 기록 수 0 / 1 / 2인 상태 | 264 / 528 / 264 |
| 실제 득실 라벨 | 0 |
| 독립 검토용 사례 / 완료된 사람 검토 | 24 / 0 |

현재 판독기는 한 번에 목표·상태·후보 기록 하나를 읽음. 은행 순서를 바꾸어도 이 입력은 같으므로, 순서 변경을 새로운 학습 표본으로 세지 않음.

전체 은행은 보존하되 주 학습쌍은 목표에 명시된 기본·대안의 네 기록으로 구성함. 다른 주제의 쉬운 음성 39,552쌍이 학습을 지배하지 않도록 하기 위함임. 전체 은행으로 검색하는 평가와 다른 자료의 복습은 별도임. 이 네 기록만의 학습으로 전체 후보 검색이 좋아졌다고 해석하지 않음.

원 은행을 각 상태마다 반복 복제하지 않고 `bank_id`로 연결하여 전체 생성 자료는 약 7MB임. 지도 신호가 늘어도 출처 수가 11이라는 한계는 그대로임.

## 4. 관계 변화와 보존을 실제로 검사함

| 대조 | 쌍 수 | 필요한 기억 집합이 달라짐 |
| --- | ---: | ---: |
| 목표·은행·확인 사실을 고정하고 현재 분기만 변경 | 528 | 495 |
| 목표·현재 분기를 고정하고 확인한 사실 하나 추가 | 2,112 | 1,056 |
| 의미를 유지하며 목표·상태·관측 표현 변경 | 704 | 0 |

분기 대조에서 변하지 않은 33쌍은 양쪽 분기에 필요한 사실을 모두 확인한 경우임. 관측 추가의 나머지 1,056쌍은 비활성 분기의 정보를 확인한 것이므로 현재 필요한 기록이 바뀌지 않음. 이런 중립 대조도 모두 남김.

공개 목표 문장·상태 문장·관측에 실제 들어간 원 기록에서 적용 분기와 필요한 기록을 다시 계산하여 라벨과 대조함. 판독 입력에는 숨긴 분기 코드·정답·원래 성과를 넣지 않음. 원 기록 변경, 비학습 출처의 혼입, 상충 입력, 관측 한 사실 추가 시 다른 요구의 갑작스러운 변화, 표현만 바꾼 정답 변경을 검사함.

관계 정답은 생성 규칙으로 재현되므로 공개 규칙도 100%임. 이는 자료의 기능 점검이며 학습 선택기의 필요성을 증명하는 성적이 아님.

## 5. 평가에서 주의할 점

전체 은행에서 모든 후보를 불필요하다고 해도 분류 정확도가 **97.69%**임. 핵심 네 참조에서도 **75%**임. 따라서 다음을 함께 기록해야 함.

- 출처별 balanced accuracy와 정확한 필요 기억 집합.
- 필요한 사실 완전 확보와 불필요한 제공을 각각 집계함.
- 같은 기억의 분기 변경 대조를 양쪽 모두 맞힌 비율.
- 현재 이미 충족한 경우의 보류와 일부만 아는 경우의 누락.
- 표현별 결과와 다른 실패 사건이 있는 조건의 결과.

현재 자료는 전부 기존 train에서 파생함. 원래 dev·확인 자료와 봉인된 `new-b`는 증강하지 않음. 이후 학습에서 기존에 본 평가 출처의 성적을 새 독립 확인이라고 부르지 않음. 증강 전 원문 가족으로 분할해야 하며 1,056행을 무작위로 나눠 일반화 점수를 만들지 않음.

실제 득실 측정에는 같은 상태에서 무기억·전체 제공·필요 근거 진단·선택 정책의 원 출력을 다시 확보해야 함. 공통 문맥 예산과 기준 정책을 먼저 고정하고, 작업자가 실패한 결과만으로 관계 음성 라벨을 덮어쓰지 않음. 현재 단계에서 새로운 전송 한도를 설정하여 선택기가 유리해지게 만들지 않음.

## 6. 다음 학습에 연결할 순서

1. 별도 정답 파일을 열기 전에 검토용 24사례의 의미와 필요 기록을 점검함. 현재는 규칙 검사만 완료한 상태임.
2. 같은 출발 가중치·학습량에서 기존 자료 반복과 상태 관계 증강을 비교함. 첫 비교에서는 새 구조·손실함수를 함께 바꾸지 않음. 다른 checkpoint의 pair 입력 지시문을 쓸 경우 실제 입력 중복·누출·길이를 다시 검사함.
3. 관계 판단 개선과 원래 자료의 회귀를 먼저 확인하고, 새로운 문장·상태에서 실제 득실을 측정함. 표현을 바꾼 상태에 이전 worker 캐시의 성공·실패를 복사하지 않음.

이번 요청에서는 **증강 자료 생성·검산과 검토 자료 준비까지 완료함.** 학습이나 실제 작업자 측정은 시작하지 않음. 관련 테스트 41개가 통과함. 원 데이터·평가·기존 모델을 보존함.

새 임시 폴더에 다시 생성한 10파일이 모두 바이트 단위로 일치함. 원 부모 state ID 11개가 실제 `labels-train.jsonl`에 포함되고 비학습 출처 그룹과 겹치지 않음도 별도 확인함.
