# 현재 관측에 따른 기억 가치: 수집·보완 학습·실제 득실 점검

2026-11-11. **현재 관측을 이용하면 불필요한 전달을 크게 줄일 수 있었으나, 이번 보완 학습은 작업 성공을 높이지 못함.** 기존 모델을 대체하지 않으며 확인 27출처는 미실행 상태로 유지함. 같은 기억의 실제 이득·손해를 관계 점수와 연결하는 측정 자료는 확보함.

[데이터](../../datasets/memory_context_value/20261111-v1/README.md) · [실제 가중치·입출력·검산](../../evaluation/results/memory-context-value-20261111-v1/README.md) · [사전 조건](../design-data/memory-context-value-20261111-v1/protocol.json)

BEAM 최상위 100대화의 고정 원천 파일 200개를 대조함. 자동 후보 79문항에 의미 검토로 복원한 4문항을 더하고, 수치 종류·주체·범위·시간이 다르거나 원문이 모순인 25문항을 제외함. 최종 50출처·58문항을 구성함. 검토는 Codex 단일 에이전트가 수행했으며 독립 주석자 일치도는 아직 없음.

| 분할 | 출처 | 질문 | 통제 상태 | 검토 관계쌍 | 이번 모델 실행 |
| --- | ---: | ---: | ---: | ---: | --- |
| 학습 | 11 | 13 | 52 | 412 | 실행함 |
| 개발 | 12 | 13 | 52 | 410 | 실행함 |
| 확인 | 27 | 32 | 128 | 1,000 | 실행하지 않음 |

50출처 전부를 학습한 것은 아님. 같은 질문의 상태 변형을 새 독립 경험으로 세지 않음. 대화 단위로 분리했으며 인물·생성 틀의 독립성까지 검증하지 않음. 정규화된 동일 목표·기억 문장·양성 근거의 분할 간 중복은 0개임. 같은 목표·은행에서 `관측 없음 / 이미 앎 / 새 값 관측 / 무관한 관측`을 비교함. 은행은 원문 7–8조각이며, 19/58은행만 전체 길이가 512토큰 예산을 넘음. 실제 에이전트의 진행·실패 이력이나 전체 작업 성공을 측정한 것은 아님.

선택기는 이전 개발 점수로 고른 Harrier 0.6B train-60을 시작점으로 사용함. 작업자는 Qwen3.5-4B로 고정하고, 모든 정책에 같은 은행·현재 관측·512토큰 상한을 적용함. 관계 라벨은 원문에서 만들며 작업자 실패를 음성으로 치환하지 않음. 상태 입력 두 seed와 목표 입력만의 한 seed를 같은 LoRA·판독층·상태 균형 교차엔트로피로 4 epoch 학습함. 모든 412관계쌍을 4번 사용했고 세 모델 모두 사전 개발 기준으로 epoch 2가 선택됨. 제공 임계값은 0.5로 고정함.

개발 결과는 다음과 같음. 관계 점수는 출처별 균형 정확도의 평균임. `정답+검토 근거`는 수치 일치와 검토된 대상·기간 등의 근거 확보를 함께 요구하는 보수적인 지표임. 해당 근거가 확인되지 않았다고 답이 반드시 추측이었다고 단정하지 않음.

| 정책 | 관계 점수 | 정답 /52 | 정답+검토 근거 /52 | 전달 토큰 합계 |
| --- | ---: | ---: | ---: | ---: |
| 무기억 | — | 25 | 22 | 0 |
| BM25 상위 2개 | — | 44 | 40 | 6,556 |
| 기존 학습 검색 상위 2개 | — | **47** | **47** | 6,368 |
| 어휘·관측 중복 제거 규칙 | — | 44 | 40 | 6,450 |
| 예산까지 채우기 | — | **47** | **47** | 22,792 |
| 기존 선택기 고정 | 71.1% | 41 | 37 | 14,796 |
| 상태 보완 학습 seed 731 | 80.8% | 39 | 35 | 2,265 |
| 상태 보완 학습 seed 1729 | 87.3% | 41 | 37 | 2,895 |
| 목표만 보완 학습 seed 731 | 70.7% | 34 | 33 | 3,852 |

상태 학습 두 seed가 목표만 보는 모델보다 나았다는 점은 긍정적임. seed 1729는 기존 선택기와 같은 정답 수에서 전달 토큰을 80.4% 줄임. 다만 3상태 개선·3상태 악화가 상쇄된 결과이며, 다른 seed는 2상태 순감소임. 두 seed 모두 검색 기준선에 뒤짐. 개발 자료가 checkpoint 선택에도 사용됐으므로 독립 확인 성적으로 부르지 않음.

관계 점수 상승의 상당 부분은 음성 기억을 덜 제공한 데서 나옴. 필요한 근거를 모두 찾은 상태는 기존 22/26, 보완 후 18/26·21/26임. 불필요한 전달 감소와 필요한 근거 누락을 함께 봐야 함. 상태 학습의 성공률 우위를 주장하지 않음.

전달 토큰 감소가 곧 실행 비용 80% 감소를 뜻하지는 않음. 개발에서 선택기 계산과 작업자 계산을 합한 측정 평균은 기존 약 0.712초, 상태 모델 약 0.669·0.676초임. 선택기만 약 0.165–0.172초가 필요했음. 이는 배치에 나눈 순전파 시간과 동일 입력의 저장 작업자 시간을 합한 값으로, 모델 로딩·동시 요청·실제 서비스 지연을 포함하지 않음. 검색·규칙의 상태별 시간을 측정하지 않아 그보다 빠르다는 주장도 하지 않음.

같은 검토된 과거 기억을 항상 제공한 조건과 무기억을 대조하면 개발 52상태에서 **개선 20·악화 1·중립 31**이 관측됨. 학습에는 쓰지 않은 실제 결과 라벨임. 이 고정 기억 묶음의 관계 점수로 개선 사례와 나머지를 나누는 탐색적 AUC는 기존 0.866, 상태 학습 0.897·0.902, 목표만 학습 0.488임. 현재 관측을 읽는 점수가 실제 이득과 연결되는 신호는 있으나, 작은 개발 자료에서 관측 조건과 수치 갱신에 국한됨. 효과 크기를 예측하거나 손해를 일반적으로 판별하는 모델을 입증한 것은 아님. 악화는 개발에서 1상태뿐임.

확인 분할을 열지 않은 이유는 개발의 근거 제공 진단임. 검토된 필요한 근거를 제공했을 때 네 조건의 정답은 **9/13·12/13·12/13·11/13**임. 관측 없는 조건이 사전 80% 기준에 미달함. 이 진단은 작업자의 상한이 아니며, 추가 기억을 보내는 검색이 오히려 더 잘한 사례도 있음. 실패한 문항을 사후 삭제해 기준을 통과시키지 않음.

| 실제 진단 사례 | 관측된 출력 | 해석 |
| --- | --- | --- |
| 과거 초과근무 12시간이 명시됨 | 0 | 제공 근거의 수치를 복원하지 못함 |
| 블로그용 사진 10개를 태그했다고 명시됨 | 0 | 숫자를 전달하는 것만으로 활용을 보장하지 못함 |
| 현재 인터뷰 5회, 과거 동일 기간 3회와 직무 정보 제공 | 3 | 과거 기록의 유용한 맥락과 낡은 수치를 분리하지 못한 사례임 |
| DB 연결 상한을 50으로 늘려 봤다는 기록 | UNKNOWN | ‘시도한 설정’과 ‘실제 적용 설정’의 질문 계약도 추가 검토가 필요함 |

마지막 문항은 모델 오류로만 단정하지 않음. 고정 입력·정답을 바꾸지 않고 별도 사후 진단에 남김. 이 발견은 다음 데이터 버전에서 질문 계약을 보완할 이유임.

이미 관찰한 이전 연구의 개발 자료에서도 보존 여부를 추가 확인함. 새 모델 선택에는 이 결과를 사용하지 않음.

| 모델 | 이전 개발 관계 점수 | Mem2Act 필요 근거 확보 /30 | 같은 과제 Top1 /30 |
| --- | ---: | ---: | ---: |
| 기존 선택기 | 93.6% | 20 | 20 |
| 상태 seed 731 | 77.3% | 16 | 20 |
| 상태 seed 1729 | 78.7% | 16 | 20 |
| 목표만 seed 731 | 76.7% | 10 | 21 |

제공 임계값 기준 성능은 후퇴했지만, 상태 모델의 Top1은 유지됨. 따라서 관계 표현 전체가 망가졌다고 결론 내리기보다, 보완 학습이 제공 점수를 낮추고 보류를 늘린 문제부터 점검하는 것이 적절함. 기존 checkpoint와 원래 데이터는 해시를 대조해 보존했음.

다음 단계는 이 보완 checkpoint를 대체 모델로 채택하는 것이 아님. 학습 자료에서 질문이 ‘보고된 과거 값’을 묻는지 ‘현재 실제 적용 값’을 묻는지 먼저 고정하고, 근거를 줘도 실패하는 작업자의 계약을 보완해야 함. 이후 기존 관계 자료를 함께 유지하면서 필요한 기억 누락과 불필요한 전달의 비용을 구분해 학습·제공 기준을 검토하는 것이 적절함. 확인 27출처의 출력을 보며 조정하지 않음.

이번에는 원문 구간 575개, 관계 점수 3,312개, 이전 자료 점수 3,720개와 실제 가중치를 검산함. 세 adapter의 112개 tensor가 모두 변경됐고, 저장 특징·판독층에서 같은 분류와 선택을 재현함. 작업자 새 입력 652개·반복 6개를 실행했고 반복 텍스트는 모두 일치함. 1,144정책 결정을 독립 호출이나 독립 상태로 세지 않음. 입력 잘림·생성 한도 도달은 없었음. 로컬 GPU 계산은 종료됐으며 Colab·유료 모델 API는 사용하지 않음.
