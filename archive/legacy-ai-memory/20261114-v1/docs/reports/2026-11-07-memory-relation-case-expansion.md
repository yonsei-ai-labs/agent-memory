## 관계를 학습했는지 확인할 수 있도록 만든 대조

**같은 기억, 다른 현재 조건**에서는 기존 기억 본문과 질문을 유지하고 입력·설정·코드를 바꾼다. 그 결과가 바뀌는 17개 묶음을 만들었다. 예를 들어 과거 빈 입력 처방은 현재 학습 완료의 정상 빈 입력과, 미학습·잘못된 모양의 입력에서 같은 관계 정답을 가져서는 안 된다.

**같은 현재 조건, 다른 기억**에서는 상태·질문을 그대로 두고 실제 같은 저장소의 기억을 바꾼다. sklearn의 LabelEncoder / BaseMixture 경험과 현재 LabelEncoder / GaussianMixture를 완전히 교차했다. Django의 Query / Media 경험도 현재 Query / Media와 교차했다. 이 2개의 2×2 구성은 적용 가족에 대한 근거 있음↔모순 대조 4그룹이다. 별도로 필요한 전제가 없는 다른 실제 기억을 넣은 5그룹은 미확인 대조다.

7개 정보 가림은 현재 관측의 모든 사본을 제거했다. 이 행은 새로운 환경 경험이 아니며 “현재 관측이 없다”는 표현 자체가 편법 신호다. 별도 층으로 보고한다. 기억 교체 역시 세밀한 적용성보다 관련성만 읽어 풀릴 수 있어 성적을 분리한다.

입력의 현재 쪽에 과거 근거를 복제하지 않았다. 출력이 필요한 관계에는 실제 관측 후의 원시 값·예외·형태만 보여주고, 답을 직접 표시하는 probe flag는 제거했다. 현재 결과를 본 사례를 행동 전 선택 데이터라고 부르지 않는다. 기억만 보는 제거 대조에도 질문은 남겨, 무엇을 물었는지 모르는 불공정한 비교를 피한다.

## 편법 진단과 아직 부족한 점

[기준선 진단](../../datasets/memory_relations/20261107-discovery-v1/baseline-diagnostics.json)은 각 저장소를 제외한 다른 저장소에서만 단순 기준선을 정했다. 알려진 조건 62개에서 학습 다수 클래스는 48.4%, 출처 성공 여부만 사용한 기준선은 50.0%, 상태 길이의 단일 분기 기준선은 48.4%였다. 전체 74개에서는 현재 정보 부재 문구를 이용한 기준선이 50.0%였다. 작은 발견 자료의 진단이며 신경망 성적이나 일반화 증거가 아니다.

동일 입력의 상충 라벨로 계산한 **자료 내부 정확도 상한**은 다음과 같다.

| 허용 입력 | 전체 74개 | 알려진 조건 62개 |
| --- | ---: | ---: |
| 상태·질문만 | 87.8% | 93.5% |
| 기억·질문만 | 63.5% | 67.7% |
| 기억만, 질문도 제거 | 50.0% | 58.1% |

특히 상태 단독 상한이 높다. 새 모델의 전체 정확도만 높아도 기억과 현재 조건을 비교했다고 할 수 없다. 양쪽 변화 대조의 동시 정답, facet별 결과, 규칙·실행 기준선이 필요하다. 많은 질문은 코드의 인자·클래스·조건을 읽는 규칙으로 풀 수 있다. 별도 신경망이 더 좋은지는 아직 열려 있다.

6개 저장소 단위로 연결 가족을 함께 제외하는 fold를 만들었지만 모든 출처는 이미 본 가족이다. 새로운 출처 경험을 확보하고, 템플릿과 어휘가 다른 확인 사례를 별도로 고정해야 한다. 주석도 연구자 1인의 근거 검토이며 독립 검토자 일치도를 측정하지 않았다. 모호한 “전반적으로 적절한가” 대신 제한된 관계 질문으로 범위를 줄였지만, 독립 의미 검토는 다음 단계다.

## 실제 성과 자료를 따로 정리한 이유

앞선 5개 실행 묶음은 [116건 원장](../../datasets/memory_relations/20261107-discovery-v1/effect-observations.jsonl)으로 보존했다. 누적48회를 최초32회·추가16회와 중복 계산하지 않았다.

| 기존 묶음 | 배정 | 성공 | 결과 미확인 | 정상 미제출 | 요청 한도 |
| --- | ---: | ---: | ---: | ---: | --- |
| framing | 12 | 6 | 0 | 0 | 32단계, $0.05, 600초 |
| transfer | 24 | 18 | 0 | 0 | 32단계, $0.05, 600초 |
| prescription | 32 | 9 | 0 | 12 | 10단계, $0.05, 600초 |
| replication | 16 | 6 | 0 | 6 | 10단계, $0.05, 600초 |
| restoration | 32 | 24 | 1 | 0 | 20단계, $0.10, 900초 |

이 표는 완결성을 확인하기 위한 집계이며 묶음 간 우열 비교가 아니다. 서로 다른 과제·제공 내용·작업 예산이 섞인다. 출처나 과제의 난이도가 성과를 결정하는 패널도 많다. 특히 restoration의 세 과제는 전조건 성공이고, 나머지 한 과제는 완결 실행 전부 실패다. 외부 중단의 결과 범위 차이를 관측 성과 차이로 세지 않도록 정정했다.

각 실행에는 배정 행동·관측 성공·보고 비용·모델·단계/시간/비용 한도·원본 설정 경로가 있다. 반사실 정답과 개별 기억 효용은 null이다. 관측되지 않은 할당 확률도 null로 남겼다. 현재는 실제 효과 학습의 정답표보다 **어디서 추가 비교가 필요한가를 고르는 발견 자료**다.

## 이득·손해를 수치로 확인하는 다음 실험

첫 확인은 모델 구조의 비교보다 **내용 개입의 효과가 관측되는가**에 둔다. 현재 자료로 명세한 전제와 질문을 고정한 뒤 새로운 출처에서 다음 순서로 진행한다. 구체적 후보와 미완료 상태는 [후속 명세](../../datasets/memory_relations/20261107-discovery-v1/next-experiments.json)에 있다.

1. **원문 근거와 구성요소를 고정한다.** 과거 경험에서 실행 준비 정보·적용 조건·구체적 처방을 구분하고 삭제할 정확한 문장을 지정한다. 같은 정보가 요약·근거·프롬프트의 다른 곳에 남아 있는지도 검사한다. “조건 문장 하나 삭제”와 “조건 정보 전체 제거”를 다른 개입으로 기록한다.
2. **같은 조건에서 제공/보류 또는 포함/제외를 배정한다.** 현재 작업 트리·공통 사전 관측·후보·에이전트·예산·공통 제출 안내를 고정한다. 같은 출처→대상 묶음 안에서 순서를 무작위로 섞고 반복한다. 중간 패치와 최종 제출을 각각 저장·채점한다. 현재 관계 분류가 모순이어도 유용한 경고일 수 있으므로 자동 보류 정답으로 바꾸지 않는다.
3. **성공·비용·과정 효과를 별도로 판정한다.** 구성요소 K의 성공 기여는 같은 나머지 기억 S에서 `P(해결|S+K) − P(해결|S)`로 측정한다. 도구 오류 수, 확인 명령 수·시간, 총 API 비용과 선택 비용도 각각 비교한다. 오류가 줄어도 성공이 그대로면 시행착오·비용 이득으로 한정한다. 중간 정답 이후 검증을 곧바로 낭비라 부르지 않는다.
4. **조건에 따른 효과 차이를 확인한다.** 현재 조건과 맞는 층·맞지 않는 층을 결과 전에 정의하고, 각 층의 포함/제외 차이를 비교한다. 개별 한 번의 성공→실패 전환을 인과 정답으로 만들지 않는다. 출처→대상 묶음별 차이와 불확실성을 보고하고, 독립 가족 수를 늘린다. 효과의 부호가 불확실하면 미결론으로 둔다.
5. **고정된 선택 정책을 새 과제에서 비교한다.** 항상 제공·항상 보류·명시적 전제 확인 규칙·학습 선택기를 같은 후보와 전달 예산에서 비교한다. 선택기 자체 비용까지 포함한다. 모델이 맞힌 적용 관계와 실제 선택 정책의 성공 개선을 별도 결과로 제시한다.

작은 통제 작업은 메커니즘을 점검하는 다리로 유용하지만, 본 결과는 원래 benchmark와 새로운 출처→대상에서 확인해야 한다. 현재 다섯 추가 공개 맥락은 **새로운 출처가 아니며** 정식 평가 대조군이 이 확장에서 검증된 것도 아니다. 특히 Django 15213에는 유효한 실행 이미지 준비가 먼저 필요하다.

## 기록·무결성

기본 Python을 잘못 선택한 최초 25개 준비 결과는 보존하고 정답·완료29개에서 제외했다. 올바른 에이전트 환경을 명시한 재확인과 이후 추가 탐색을 각각 계획·코드·출력으로 남겼다. 라이브러리 예외는 실패한 수집과 구분했다. 이 오류를 기억 부적합의 근거로 쓰지 않았다.

[검증 결과](../../datasets/memory_relations/20261107-discovery-v1/validation.json)는 74개 라벨의 기계적 근거·시간 순서, 입력 허용 목록, 결과 flag 제거, 309개 참조 파일 해시, 분할 연결,29개 환경 일치를 통과했다. 기존 고정 기록 **5,528개**와 첫 학습 산출물 **54개**의 해시도 일치했고 전체 실행 집계는318개로 유지됐다. 기존 저장 토크나이저의 원시 입력 필드 최댓값은495토큰이다. 최종 지시 추가 후 길이는 학습 쪽에서 재확인한다.

데이터·코드·근거·이 보고서는 별도 artifact index로 고정한다. 루트 README·진행 기록·학습 README의 탐색 링크는 계속 갱신 가능한 문서다. 이번 작업으로 학습 쪽에는 관계 판독의 재료와 대조 계약을, 데이터·평가 쪽에는 실제 효과를 수집할 다음 작업 명세를 마련했다.
