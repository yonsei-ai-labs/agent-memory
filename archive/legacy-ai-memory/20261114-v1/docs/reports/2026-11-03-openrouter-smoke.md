2026-11-03 · 실제 API·컨테이너·공식 채점 실행 · 메모리 없음

후속 [실험 타당성 감사](2026-11-03-experiment-audit.md)에서 수정 전·정답·두 제출 패치를 재검사했다. 기존 판정은 유지됐으며 DeepSeek의 부분 수정과 상위 포맷 설정 미충족을 확인했다. 채점 완료 여부의 검사가 부족했던 점도 보강했다. 아래는 최초 실행 결과이며 감사 대조군을 모델 실행 횟수에 합치지 않는다.

## 확인한 결과

Luna와 DeepSeek 모두 OpenRouter를 통해 mini-SWE-agent의 도구 사용·패치 제출·SWE-bench 공식 채점까지 연결됐다. 같은 점검 과제에서 Luna의 제출 패치는 해결 판정을 받았고, DeepSeek의 제출 패치는 기존 테스트를 유지했으나 목표 테스트를 통과하지 못했다. **한 과제·모델별 한 번의 실행이며 모델 순위나 메모리 효과를 추정하는 결과가 아니다.**

환경·라우팅 오류 두 건도 삭제하지 않았다. 전체 실행 표는 [CSV](data/runs.csv)와 [JSON](data/runs.json)에 있다.

## 방법과 고정 조건

- 과제: `princeton-nlp/SWE-bench_Lite`, `dev`, `marshmallow-code__marshmallow-1359`.
- 데이터 리비전: `6ec7bb89b9342f664a54a6e0a6ea6501d3437cc2`.
- 기준 커밋: `b40a0f4e33823e6d0f341f7e8684e359a99060d1`.
- 에이전트: mini-SWE-agent 2.4.6의 기본 SWE-bench 프롬프트와 bash 도구, OpenRouter Responses 어댑터. 기록 기능은 하위 클래스로 추가했다.
- 채점: 공식 SWE-bench 4.1.0. 같은 로컬 이미지의 새 컨테이너에서 제출 패치를 평가했다. 현재 데이터 형식과 맞지 않는 5.0.2는 사용하지 않았다.
- 이미지 ID: `sha256:440807ded8d239ea71daaf31d3158013e58b9cdfad8a56d4f82e646426d3f4e6`.
- 추론 환경: CPU 2개, 메모리 4 GiB, 네트워크 없음. 호스트 디렉터리나 API 키는 컨테이너에 전달하지 않았다.
- 한도: 요청 32회, 요청당 출력 8,192토큰, 에이전트 600초, 비용 중단 기준 $0.25. 진행 중 요청 비용·시간만큼 초과할 수 있다.
- 자동 제공자 전환·모델 재시도 없음. 각 모델은 새 컨테이너에서 독립적으로 실행했다. 앞선 모델의 패치나 공식 결과를 다른 모델에 전달하지 않았다.
- 문제의 정답 패치·힌트·공식 테스트 패치를 에이전트에 제공하지 않았다. 공식 채점 결과는 제출 후에만 읽었다.
- Git 최초 커밋 전 실행이므로 커밋 해시 대신 각 실행의 코드·설정 사본과 SHA-256을 보존했다.

이 과제는 작은 Python 라이브러리에서 실행 경로를 확인하려고 결과를 보기 전에 선택했다. 본 실험의 Lite test 과제들과 별도이며, 이 점검 결과를 주 모델 선정용 점수에 합치지 않는다.

## 기록에서 얻은 관측과 가설

### 1. 기존 테스트 통과만으로 성공 기억을 만들면 잘못된 교훈이 축적될 수 있다

**관측:** DeepSeek는 자체 재현 코드와 기존 `pytest -q`의 **911개 테스트 통과**를 확인하고 제출했다. 공식 채점에서는 새 목표 테스트 `test_datetime_list_inner_format`이 실패했다. 기존 테스트를 돌렸다는 사실과 과제를 해결했다는 판정이 달랐다. [명령과 출력 · 별도 원본](../reproduction.md) (`runs/20261103T125247Z-955f5919/commands.jsonl`), [공식 결과 · 별도 원본](../reproduction.md) (`runs/20261103T125247Z-955f5919/official_report.json`)

DeepSeek의 패치는 `schema.opts`가 없는 경우 기본 포맷을 사용하도록 바꿨다. 공식 실패 로그의 관측은 내부 필드 포맷이 기대한 `iso8601` 대신 `iso`였다는 것이다. Luna의 패치는 부모를 따라 `opts`가 있는 객체를 찾았으며 공식 목표 테스트를 통과했다. 이는 제출 패치와 테스트에 대한 관측이며 모델 내부의 의사결정 원인을 설명한 것은 아니다. [DeepSeek 패치 · 별도 원본](../reproduction.md) (`runs/20261103T125247Z-955f5919/model.patch`), [Luna 패치 · 별도 원본](../reproduction.md) (`runs/20261103T124645Z-1b559f36/model.patch`)

**기억 설계에 주는 시사점:** ‘예외가 없어졌고 테스트가 통과했다’는 기록에는 테스트 범위와 판정 출처가 함께 있어야 한다. 자체 확인만 통과한 경험과 공식 해결 경험을 같은 성공 라벨로 저장하지 않는다.

**후속 가설:** 기본값으로 예외를 없애라는 지침은 상위 설정을 보존해야 하는 새 과제에서 손해를 줄 수 있다. 반대로 부모·자식 객체와 설정 전달 관계에 관한 사실, 또는 설정 상속까지 확인하라는 행동 지침은 다른 방식으로 도움이 될 수 있다. 아직 기억을 제공한 실행은 없으므로 득·실이 확인된 것은 아니다.

**다음 검증:** 본 실험에서 수집한 별도 경험으로 사실 카드와 행동 지침을 만들고, 적용 조건을 포함한 카드와 생략한 카드를 비교한다. 한 번에 모두 확대하지 않고 우선 A/B/C에서 현상을 찾은 뒤 문구 삭제·교정 개입을 한다. 이 점검 과제의 공식 테스트를 보고 만든 교훈을 같은 문제에 다시 넣은 결과는 새로운 과제로의 전이 증거로 쓰지 않는다.

### 2. 경로 정보와 탐색 지침을 구분해 볼 구체적인 행동이 관측됐다

**관측:** Luna의 첫 파일 조회는 `marshmallow/fields.py` 경로에서 실패했고, 이후 저장소를 확인하여 `src/marshmallow/fields.py`로 수정했다. [명령 기록 · 별도 원본](../reproduction.md) (`runs/20261103T124645Z-1b559f36/commands.jsonl`)

**후속 가설:** 저장소 경로에 대한 사실 기억과 ‘경로를 추측하기 전에 구조를 확인하라’는 행동 지침은 서로 다른 방법으로 탐색 비용을 줄일 수 있다. 이전 저장소의 경로를 다른 저장소에 그대로 적용하면 오히려 불필요한 조회가 늘어날 수 있다. 한 번의 경로 오류만으로 카드의 효용을 결론 내리지는 않는다.

### 3. 환경·제공자 문제는 모델 실패와 분리해야 한다

최초 컨테이너 검사 실패와 DeepSeek 라우팅 거절은 문제 해결 능력을 관측한 실행이 아니다. 코드 트리 검증과 제공자 변경의 이유를 기록했기 때문에 데이터에서 이 둘을 식별할 수 있다. 앞으로도 오류를 삭제하지 않고 전체 시작 수, 정상 추론 수, 채점 가능 수, 해결 수를 각각 보고한다. [진행 기록](../experiment-log.md)

## 다음 단계와 아직 하지 않은 일

원본 기록·사용량 대조·공식 채점 경로는 작은 사례에서 확인했다. 다음 단계는 과거 경험을 재사용할 수 있는 수집·평가 과제 관계를 검토하고 분할을 고정하는 것이다. 별도 모델 선정용 실행, 기억 생성·검색·입력, A/B/C 반복 실험, 득실의 인과 검증은 아직 수행하지 않았다.

원본은 각 run 폴더에 보존하며 [기록 규약](../experiment-recording.md)을 따른다. 모든 관측은 이 환경·과제·제공 모델에 조건부이며, 보고서의 가설을 확인된 결론과 구분한다.
