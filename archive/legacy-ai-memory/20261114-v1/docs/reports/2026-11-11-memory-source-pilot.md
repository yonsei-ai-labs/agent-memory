# 기억 선택 학습을 위한 공개 자료 파일럿 검토

2026-11-11. **두 공개 자료의 30개 출처를 수집하고 지정 근거를 검토함. 19개에서 좁은 관계 단서를 유지했으나, 이를 그대로 선택 정답으로 쓰거나 200개 규모로 확대하는 것은 보류함.** 다음 수집은 관측으로 뒷받침되는 관계와 현재 상태의 변화를 함께 확보하는 데 집중함. 원래의 연구 질문인 기억의 실제 득·실은 고정 작업자에서 별도로 측정해야 함.

## 이번에 확보한 자료

[공유 묶음](../../datasets/memory_source_pilot/20261111-v1/README.md)에 입력·원문·주석·분할·검산 코드를 연결함. PersonaMem-v2와 Mem2ActBench 각 15개 출처 그룹이며, 질문 30개·전체 후보 2,072조각을 보존함. 정답 후보만 포함한 은행이 아님. 단일 검토자의 지정 구간 검토이며 전체 후보를 모두 양성·음성으로 라벨링하지 않음.

| 출처 | 관계 단서 유지 | 수정 필요 | 모호하거나 근거 부족 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| Mem2ActBench | 10 | 2 | 3 | 15 |
| PersonaMem-v2 | 9 | 1 | 5 | 15 |
| 전체 | 19 | 3 | 8 | 30 |

유지 19건은 정답 전체가 유효하다는 뜻이 아님. 예를 들어 개인 경험은 확인되지만 그 원인까지 확인되지 않으면 경험 관계만 남김. 관계별로 골라 검토했으므로 이 비율을 원천 전체의 품질·수율 추정으로 일반화하지 않음. 자연 발생 에이전트 경험의 독립 평가도 아님.

원문 위치 39개와 PersonaMem의 지정 snippet 50턴을 검산함. 숨은 생성 프로필이 담긴 system 메시지 15개는 모델 입력에서 제외함. 원문 정답·선호·관련 출처 목록은 감독 파일에만 보존함. 새 학습·작업자 호출·GPU 할당은 모두 0회임.

## 데이터 설계에 영향을 주는 발견

**원래 분할과 관련성 메타데이터를 그대로 사용할 수 없음.** PersonaMem train 18,549행의 800명과 val 735명 중 735명이 겹침. 이번에는 사용자별로 새 분할을 예약함. Mem2Act는 출처 ID가 없는 7문항을 제외하고, 배경 대화와 질문의 연결을 전이적으로 묶었을 때 393문항·334그룹임. 질문의 양성 출처만 묶으면 같은 혼합 세션의 배경 기억이 분할을 넘을 수 있음.

**실제 관측과 원본 정답 사이에 틈이 있음.** 다음 사례는 학습 정답의 범위를 줄이거나 보류한 이유임.

| 사례 | 원문과 원본 정답 | 이번 처리 |
| --- | --- | --- |
| Mem2Act qa_134 | 원문은 Apple·Microsoft 둘 다 요청함. 현재 질문은 단수 company, 정답은 Microsoft임 | 대상이 모호하므로 유일 정답을 보류함. 스키마의 msft 기본값을 대상 판단 근거로 삼지 않음 |
| Mem2Act qa_046·252 | 대화 ID를 각각 검색 request_id·업무 entity ID로 사용함 | 모델 입력에 없는 관측 ID이므로 그대로 학습하지 않음. 252는 도구의 업무 목적도 맞지 않음 |
| Mem2Act qa_139 | 문자열·목록 뒤집기 경험 여섯 개를 출처로 제시함 | reverse 주제는 유지하되 여섯 기록을 모두 필수로 표시하지 않음 |

| PersonaMem 472 | 어린 시절부터 완벽주의가 있었다는 자기 보고는 있음 | 경험 관계는 유지하고 원본 선호의 academic/family 원인 주장은 제외함 |

**다른 주체·근거 부족은 곧 ‘쓸모없는 기억’이 아님.** 타인의 이야기가 일반 조언에 참고될 수는 있지만 사용자 자신의 사실은 아님. 마찬가지로 “기억하지 말라”는 과거 요청이 현재 직접 밝힌 요구를 무시하라는 뜻은 아님. 이러한 범위를 분리해야 관계 판독과 실제 득실을 연결할 수 있음.

## 살릴 관계와 남은 공백

유지한 19건은 대상·매개변수·주제 연결 8건, 현재 질문에도 있는 정보 2건, 재사용 철회 5건, 타인 서술 범위 2건, 자기 보고 경험 2건임. 이는 의미 주석의 출발점이며 선택기 정확도나 필요 기억 확보율은 아직 계산하지 않음. 완전한 근거 집합·반사실적 득실·전체 후보 음성 라벨을 만들지 않았기 때문임.

현재 자료에는 **같은 목표에서 에이전트의 진행·실패 상태가 달라지는 실제 대조가 없음.** 인간의 사진 편집 진행과 과거 도구의 조회 실패는 있지만 현재 작업자의 실행 상태가 아님. 명확한 사실 갱신, 검증된 상보적 근거 집합도 이번 유지 주석에 없음. 공개 자료 수만 늘려도 이 공백은 자동으로 채워지지 않음.

## 확대 순서

1. **유지 19건의 좁은 관계부터 재검토함.** 현재 근거 구간과 라벨 범위가 맞는지, 다른 기억으로도 같은 요구를 충족하는지 확인함. 특정 근거 하나를 정답으로 강제하지 않음. 보류 11건은 대체 사례로 숨기지 않고 그대로 기록함.
2. **현재 상태를 바꾸는 대조를 별도로 만듦.** 대상·매개변수가 관측에 없을 때와 이미 있을 때를 같은 목표·은행에서 비교하는 안이 우선임. 원문에서 가져온 관측을 사용하고 통제한 재구성임을 표시함. 이를 실제 진행 이력이라고 부르지 않음. 완성된 원문에 근거한 갱신·철회는 별도 유형으로 둠.
3. **다음 20출처는 관측이 명확한 관계 10개와 실제 진행 상태를 재현할 수 있는 경험 10개를 수집 목표로 둠.** 앞의 10개는 남은 train 예약에서 대상·속성·주체가 확인되는 사례를 찾음. 뒤의 10개는 실행 전후 관측과 필요한 기억의 변화가 연결되는 별도 경험 수집이며, 이번 두 자료만으로 확보됐다고 보지 않음. 적격 사례가 부족하면 실제 확보 수와 탈락 이유를 보고함.
4. **관계 품질과 효과 측정을 분리함.** 좁은 관계와 후보의 대체 근거를 먼저 검토하고, 고정 작업자·은행·전달 예산에서 무기억·검색·규칙·학습 선택의 성공·손해·비용을 측정함. 모델 성공 여부를 관계 라벨로 되돌려 덮어쓰지 않음. 선택이 어려운 상태를 찾아 측정하는 집합과, 원래 분포의 평가 집합을 구분해 선택적 수집 편향을 드러냄.

200출처 그룹의 train 120·dev 40·test 40은 미리 예약했으며 이번 30개는 train 일부임. 남은 train은 90개임. dev·test에서는 내용 주석이나 모델 평가를 하지 않았음. 200개를 이미 확보한 학습 자료로 세지 않음. 재검토·대조 설계가 끝나기 전에는 같은 형태의 대량 증강이나 추가 LoRA 비교를 우선하지 않음.

다음 수집에서 확보할 단위는 `과거 관측 → 현재 목표·관측 → 적용 범위 → 대체 가능한 근거 집합`임. 실제 진행 대조는 동일한 기억 은행에서 필요 정보가 바뀌는 두 시점과 각 시점에서 볼 수 있었던 관측을 요구함. 아직 확인하지 못한 최신 사실·출력·진행 상태를 가정으로 채우지 않음.
