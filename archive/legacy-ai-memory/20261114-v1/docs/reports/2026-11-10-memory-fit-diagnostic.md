# 기존 경쟁 후보 22묶음의 학습 적합 진단

**CE / CE+선택 손실 × 초기값 2개의 네 조건 모두 최종 분류 22/22·관측 최선 선택 7/7을 통과함.** 현재 구조의 기본 학습 경로가 작동한다는 근거임. 같은 학습 자료를 검사한 결과이며, 새 출처 일반화나 선택 손실의 추가 가치를 입증한 결과는 아님.

## 실행 전 고정한 질문과 범위

기존 결과에서 비어 있지 않은 기억 후보의 실제 성과가 다른 상태는 7개였음. 해당 상태의 **전체 22후보**를 모아 현재 Harrier 0.6B·LoRA·판독층이 이 작은 자료부터 맞출 수 있는지 확인함. 잘 맞춘 경우만 고르지 않고 위 조건을 만족하는 상태와 후보를 모두 포함함. 5개 기존 개발 가족이며 새로운 독립 출처는 0개임.

네 범주는 둘 다 실패 5개, 개선 6개, 악화 5개, 둘 다 성공 6개임. 동일한 목표·현재 관측·기억 입력에 모순된 정답이 있는지 먼저 검사함. 라벨은 기존 작업자의 저장 결과로 재구성하며, 관계상 적절한 기억이라는 주석으로 대체하지 않음.

**같은 22입력으로 학습하고 검사하는 적합 진단임.** 성공해도 일반화, 관계 이해, 실제 배포 효과를 입증하지 않음. 기존 분할 평가 점수와 이 학습 정확도를 직접 비교하지 않음.

모델·학습률·손실 가중치·온도·선택 임계값은 [직전 비교](2026-11-10-memory-contrast-loss.md)와 같음. 자료를 좁히고 노출을 8회에서 64회로 늘려 총 update 128회를 유지함. 따라서 직전 결과와의 차이를 노출량 하나의 인과 효과로 해석하지 않음. 데이터 구성·실제 토큰량도 달라짐.

각 조건은 고정된 base revision에서 adapter와 판독층을 새로 초기화함. 동일 초기값의 두 손실 조건은 같은 초기 가중치로 시작함.

선택 점수는 `P(개선)-P(악화)`이며 무기억 점수는 0임. 분류 argmax가 전부 맞아도 후보 사이 점수 크기로 잘못 고를 수 있으므로 두 통과 기준을 분리함. 관측 최선은 이 작은 후보 집합에서 기록된 성과이며 작업자의 보편적 성능 상한이 아님. 비용 최적화는 이번 통과 기준에 포함되지 않음.

## 검산 및 후속 판단

입력·정답을 원본에서 재구성하고, 학습량·동일 초기값·배치·adapter 변화·optimizer step을 검사함. 저장 특징과 판독층을 독립 수치 연산으로 재계산하고, 실제 adapter 재적재로 입력부터 다시 예측함. 학습 예측과 실제 선택을 모두 보존함.

통과하면 현재 구조에서 작은 경쟁 자료를 맞출 수 있다는 근거로만 정리하고, 일관된 작업자 환경에서 원래·추가 후보의 득실을 함께 측정하는 단계로 이어감. 실패하면 이 설정과 학습량에서 적합이 부족하다는 결과로 남기고 어느 범주·상태에서 남는지 확인함. 이 한 번의 실패로 모델이 망가졌거나 구조적으로 학습 불가능하다고 결론내리지 않음.

새 작업자 호출·유료 API·Colab 할당은 사용하지 않음. 직전 실험의 만료된 06:00 마감을 재사용하지 않고 이번 승인된 진단에 위의 별도 실행 제한을 적용함.

## 완료 결과

| 손실 | 초기값 | 최종 분류 | 관측 최선 선택 | 후보 순위 | 처음 관측한 통과 update |
| --- | ---: | ---: | ---: | ---: | ---: |
| CE | 731 | 22/22 | 7/7 | 16/16 | 64 |
| CE + 선택 | 731 | 22/22 | 7/7 | 16/16 | 80 |
| CE | 1729 | 22/22 | 7/7 | 16/16 | 80 |
| CE + 선택 | 1729 | 22/22 | 7/7 | 16/16 | 48 |

모든 조건은 최종 128 update에서 평가함. CE·731은 64 update에서 통과한 뒤 80에서 분류 21/22로 내려갔으며, CE+선택·1729도 48에서 통과한 뒤 64에서 21/22였음. 마지막 세 검사 지점인 96·112·128에서는 네 조건 모두 통과함. 처음 통과한 시점은 16 update 간격으로 관측한 기술값이며, 별도 조기 종료 기준이나 정밀한 수렴 속도 측정이 아님. 선택 손실이 항상 더 빨랐다는 근거도 없음.

최종 epoch의 평균 CE는 약 0.00032–0.00066임. CE+선택 조건의 결합 손실은 약 0.148로 남았음. 선택 손실은 제한된 점수의 softmax로 후보를 확률적으로 고를 때의 기대 후회이며, 실제 평가는 최대 점수 선택임. 완벽한 분류·최대 점수 선택에도 확률적 손실이 0이어야 하는 것은 아님. 서로 다른 목적함수의 총 loss 크기를 같은 척도로 비교하지 않음.

### 어떤 구분을 맞혔는가

한 학습 가족의 예시는 다음과 같음. 동일한 과거 기록 2개에 추가 기록을 더한 3·4개 묶음의 저장 결과를 비교함.

| 현재 상태 | 무기억 | 2기록 제공 | 3·4기록 제공 | 기억 효과 라벨 |
| --- | ---: | ---: | ---: | --- |
| 가용성 변경·이전 관측 없음 | 실패 | 성공 | 실패 | 2기록은 개선, 나머지는 둘 다 실패 |
| 현재 관측에 이전 기록이 있음 | 성공 | 성공 | 실패 | 2기록은 둘 다 성공, 나머지는 악화 |

네 모델 모두 이 여섯 입력의 네 범주를 맞혔으며, 각 상태에서 성공한 2기록 묶음을 선택함. 다만 두 상태에는 관측과 가용성 등 여러 차이가 있으므로 하나의 조건만 바꾼 인과 대조로 해석하지 않음. 왜 추가 기록에서 작업자가 실패했는지까지 이 학습 결과가 설명하지도 않음. [실제 입력·정답·예측](data/memory-fit-diagnostic-20261110/illustrative-state-contrast.json)은 결과를 본 뒤 고른 설명용 사례이며 별도 평가가 아님.

**보류·비용 문제는 남아 있음.** 네 모델 모두 7상태 전체에 기억을 제공했고 전달 토큰도 각각 922개로 같았음. 위의 현재 관측이 충분한 상태에서는 무기억도 정답·근거 기준 모두 성공하지만 2기록을 제공함. 중립 범주를 맞혀도 `P(개선)-P(악화)`의 작은 양수 때문에 제공할 수 있음. 성공만을 목표로 한 이번 손실·임계값이 불필요한 제공까지 해결했다고 주장하지 않음. 이 사례를 악화 정답으로 임의 변경하지 않고 비용과 보류를 별도 평가해야 함.

### 실제 학습과 저장 검산

- 4회 모두 optimizer 128 step, 22예제 각각 64회, 회당 1,619,264 학습 입력 토큰을 확인함. 같은 초기값의 두 손실 조건은 초기 adapter·판독층 해시와 모든 상태 배치가 일치함.
- 매번 실제 LoRA 112개 tensor의 초기값을 다시 생성해 저장 가중치의 변화량을 대조함. optimizer의 두 parameter group·학습률·모든 step과 유한값도 확인함. base는 고정함.
- 실제 adapter 재적재로 **88예측의 특징·확률 최대 오차 0**, 28개 상태별 선택 일치를 확인함. 학습 함수의 인코딩·판독층 구현을 호출하지 않는 별도 경로로 재실행함.
- 별도 NumPy/erf 판독층 재계산의 최대 확률 오차는 `1.23e-7` 미만임. 중간 저장 예측 792개도 지표와 대조함. Python 3.11/3.12의 합산 방식 때문에 약 `1e-19` 차이가 있어, 연속 지표에는 `1e-12` 수준 허용오차를 쓰고 정답 수·선택은 정확히 일치하도록 검사함.
- 공식 고정 tokenizer와 22입력의 token ID가 전부 일치함. 최대 길이는 1,307이며 입력 잘림은 없었음. 자동 regex 경고에 따라 실험 중 토큰화를 변경하지 않았음.
- 학습과 중간 검사를 포함한 전체 실행은 약 18.8분, 실제 체크포인트 재검사는 약 11초였음. 회당 최대 PyTorch 할당 메모리는 약 3.01 GiB임. 시스템 전체 VRAM이나 다른 환경의 최소 요구량을 뜻하지 않음.

## 이번 결과로 정한 다음 순서

1. 현재 구조가 작은 경쟁 자료를 맞출 수 있음을 확인했으므로, 이번 진단의 epoch·손실·구조 탐색은 종료함. CE에서도 통과했으므로 선택 손실이나 LoRA 자체의 필요성을 증명했다고 해석하지 않음.
2. **일관된 작업자 환경에서 무기억·원래 후보·새 대조 후보를 함께 재측정한 별도 데이터 버전**을 준비하는 것이 다음 단계임. 직전 재현 검사에서 거부한 출력을 기존 라벨과 혼합하지 않음.
3. 원래 자료/대조 보강 × CE/CE+선택 손실의 고정 비교를 마치고, 이후 남겨 둔 새 출처에서 선택·성공·악화·보류·비용을 확인함. 이번에 사용한 5가족이나 그 표현 변형을 새 독립 평가로 세지 않음.

이번에 완료한 것은 첫 번째 학습 진단임. 새 득실 라벨 수집, 보강 자료 학습, 새 출처 평가는 아직 실행하지 않았음. 현재 자료에는 실제 연속 진행·실패 이력이 추가된 것도 아님. 원래 연구 질문인 현재 상황에 맞춘 기억의 득실 판단으로 연결하되, 학습 적합만으로 그 질문이 해결됐다고 결론내리지 않음.
