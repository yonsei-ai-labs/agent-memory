## 여행 상태 대조는 핵심 근거로 유지함

같은 목표·은행·기억 묶음을 연결한 12가족에서 최초 상태의 기억 제공은 모두 이득임. 이후 계획 분기와 현재 관측이 바뀐 상태에서는 7가족이 손해, 5가족이 중립으로 바뀜. 양쪽 원 출력·상태·제공 기록을 보존하므로 이 관측을 재계산할 수 있음.

다만 실패 상태만의 효과를 분리한 실험은 아님. 실패 보고와 대안의 확인 사실이 함께 달라짐. 따라서 **현재 조건에 따른 관측 효과 변화**로 설명하고, 실패 이력 하나가 손해를 만들었다는 주장으로 확대하지 않음. 같은 카탈로그·제한된 문장 틀의 통제 상태이므로 일반적인 손해 발생률도 아님.

새 출처에 같은 구조의 대조를 추가하는 것이 차별화 주장을 강화하는 직접적인 다음 작업임. 처음 질문과 분기 이후 질문이 달라지는 자연스러운 세션도 유용하지만, 목표·은행·묶음을 고정한 대조를 대신하지는 않음.

## 정보 복원 자료와 보강 학습은 오류 교정의 근거임

38개 명세의 두 사실씩을 원문 구절과 대조함. 시험 12출처의 전체 문단과 38명세의 사실 역할을 읽었으며, literal offset 76곳이 일치함. 예를 들어 `Ubuntu / medium`, `vegetarian / autumn`, 게임 ID `456` / 라운드 ID `789`는 구별되는 사실임. 과거에 사용자가 요청한 설정·ID를 복원하는 자료이지 서버 배포·게임 실행의 성공을 평가하는 자료가 아님.

1,280상태 항목의 요구·현재 관측·남은 사실과 2,312후보 주석에서 불일치는 없었음. 이 수에는 control/augmented의 같은 상태·반복 항목과 원문에서 파생한 변형이 포함됨. 일부 기존 anchor는 부모 자료의 근거로 연결되며 38개 명세 전체가 새 원천인 것은 아님.

후속 형식/관계 보강은 고유 입력 395개·후보 716쌍·양성 310쌍·손실 질량을 맞추고, 현재 관측이 다른 80행을 확인함. 고정 작업자의 복원은 두 seed에서 65·63/96 → 88·87/96이며 개선 23·24건, 새 악화 0건임. **어떤 관계 조합을 학습에 보여줘야 하는가**에 대한 실증으로 보존함.

11출처를 표현·관측·분기로 늘렸으므로 독립 경험이 증가한 것은 아님. `needed_now`, `already_observed`, `inactive_branch`를 실제 이득·중립·손해로 치환하지 않고 효용을 `null`로 둔 점은 유지해야 함.

## 전달 경로 자료는 기준 조건을 명시하여 사용함

원 출력 15,740+5,706행, 여행 정답·관계 2,240행의 별도 구현 검산이 다시 통과함. 본 실행 공통 상태 9B 396·27B 400에서 기록 목록·최신 기록 등의 차이는 [기존 교차 검토](2026-11-12-gain-loss-supplement-review.md)의 표를 유지함.

이번 출처별 파일에는 그중 기억이 필요한 316·320상태를 따로 묶음. 이 부분집계의 기록 목록은 필요 근거 조건보다 64·24건 악화되지만 무기억보다 악화된 경우는 0임. **필요한 근거만 제공한 조건 대비 손실과 무기억 대비 손해를 분리하는 자료**로 설명함. 전체 공통 상태 396·400의 주 집계를 대체하지 않음.

오답이 무효 기록과 일치한 361건 중 21건은 유효 기록에도 일치하고, 15건은 그 유효 기록이 실제 함께 제공됨. 이들은 특정 무효 기억을 따랐다고 원인을 확정하기 어려움. 기존 자료의 전역 무효 제거와 최신 기록은 2,240접두부 모두 같으므로 추가 조건으로 중복 실행하지 않음. 두 작업자의 과거 기록도 20본 세션 모두 달라 모델 크기만의 효과로 해석하지 않음.

## 새 숨은 함정 파일럿은 실행 전 보완함

다른 작업 트리에서 제작된 파일럿을 읽기 전용으로 복사하여 고정 스냅샷으로 검토함. 12파일의 해시·크기, 2,902개 실제 메시지 해시, 미래 기록 혼입, 동일 입력의 상충 정답, 표현 쌍의 동일 요청을 검사하여 불일치가 없었음. 세션은 과거 대본 응답을 고정한 통제 자료이며 실제 작업자의 새 경험은 아님. 4출처는 기존 증강·전달 경로 여행 세션과 겹치지 않지만 모두 이전 stage1 노출 이력이 있음. 봉인된 new-b 원천은 열지 않음.

### 검토표에 필요한 현재 입력을 복원함

원 검토표는 문장 42개·판단 16개임. 판단 중 4개는 카탈로그에서 선호에 맞는 식당·숙소를 골라야 하는데 카탈로그가 빠져 있음. 예를 들어 과거 가격 상한은 알 수 있어도 현재 숙소별 가격과 가능한 ID를 모르면 허용 정답을 검산할 수 없음. 이는 **사람 검토용 자료의 누락**이며 실제 작업자 입력의 누락은 아님.

원본은 보존하고 16판단 모두에 동일 사례의 `none` 조건 실제 공개 입력을 연결한 [검토용 보완본](data/memory-contribution-review-20261112-v1/hidden-review-packet-with-context.jsonl)을 만듦. 현재 지침·카탈로그·요청만 더했고 정답·필수 기억 ID·선택 결과는 추가하지 않음. 이 보완본으로 사람 검토를 수행한 것은 아님.

### 다른 기록이 있어야 판단할 수 있는 주석을 학습 계약에 반영해야 함

84시점의 state–candidate 관계 중 무효 판단 20개는 `judge_with`에 다른 기록을 지정함. 예를 들어 과거 예약만 보면 유효해 보이지만, 이후 “그날은 가족과 지내므로 예약을 사용하지 않음”이라는 기록을 함께 봐야 무효임. 필요한 근거는 후보 은행에 존재함.

현재 요청과 후보 하나만 읽는 모델을 그대로 학습시킬 경우 이 근거가 빠질 수 있음. 현재 관측에 해당 변경 사건을 넣거나, 비교 기록을 함께 입력하는 계약을 먼저 정해야 함. 이 20개를 문장 단독 분류 정답으로 사용하지 않음. 모델 구조를 늘리기 전에 입력의 판정 가능성을 해결하는 것이 우선임.

### 길이 대조의 뜻과 주석 범위를 조정해야 함

S와 L의 은행은 168개 상태·표현 쌍 모두 달라짐. 길이뿐 아니라 검색 출력·곁가지 메시지·후보 수가 함께 변하므로 현재 결과는 **부가 내용이 늘어난 조건의 효과**임. 순수 토큰 길이의 영향으로 부르려면 은행·전달 묶음을 고정한 별도 대조가 필요함.

곁가지 기록은 M에서 1,324회, L에서 4,402회 후보로 나타나지만 관계 주석에는 없음. 이는 사례별 출현 합계이며 고유 기록 수가 아님. 프로토콜은 의도적으로 무관한 내용이라고 명시함. 관계 학습에 사용할 때에는 생성 근거가 있는 무관 주석으로 명시하거나 미주석을 마스킹해야 하며, 누락됐다는 이유만으로 음성 처리하지 않음.

### 검색이 실패해야만 유효한 자료인 것은 아님

8k BM25는 504사례 모두 전체 기록과 실제 입력까지 동일함. 2k BM25도 표시된 필수 집합이 비어 있지 않은 **456/456사례**에서 해당 집합을 확보함. 나머지 48사례는 필수 집합이 빈 부재 질의임. 따라서 이 파일럿은 우선 **필요 근거가 있어도 불필요·무효 기록이 함께 올 때 오용이 생기는가**를 측정하는 데 맞음.

2k 검색에는 각 길이별 168사례 중 무효 후보를 함께 주는 40사례와 distractor를 함께 주는 72사례가 남아 있음. 두 집단은 중복될 수 있으며 실제 손해는 미측정임. 검색 실패를 만들기 위해 문항이나 예산을 사후 조절할 필요는 없음. 입력이 같은 8k/전체 조건은 작업자 호출을 공유하고 결과의 의미만 구분하면 됨.

### 같은 목표를 유지한 현재 상태 대조를 보충하는 것이 직접적임

15개 `memory_status` 연결은 같은 기록의 관계가 시간에 따라 달라짐을 보여줌. 하지만 요청 번호를 제거해도 관계가 달라지는 동일 요청 쌍은 0임. 세션 내 서로 다른 목적과 시점의 관계 변화로 유용하지만, 기존 여행 12가족의 목표·은행·묶음 고정 대조를 그대로 확대한 것은 아님.

기여의 중심을 위해 일부 새 출처에서 같은 요청·은행·제공 묶음을 두고 **현재 관측의 변경 사건만 달라지는 대조**를 사전에 정하는 것이 적절함. 원래 84시점은 그대로 보존하고, 이 추가 대조의 결과가 이득·손해·중립 어느 쪽이든 보고함. 새 시나리오 종류를 더 늘릴 필요는 없음.

자연 문장 42틀 중 “방에서 작은 생일 모임”과 “묵는 곳에서 친구들과 축하”를 카탈로그의 `No parties` 금지와 연결하는 문구는 특히 사람 검토가 필요함. `ambiguous=false`는 생성 코드의 기본값이며 독립적으로 모호성을 검증한 결과가 아님. 명시적인 취소 단어가 없다는 사실만으로 의미 난도가 높거나, 규칙으로 해결되지 않는다는 주장이 성립하지는 않음. 문장틀을 공유한 출처 분할의 한계도 이후 학습 평가에 남겨야 함.

## 실제 업무와 외부 평가의 역할

STATE-Bench 경험 20개는 관측·활용 가능 조건·확인할 절차·경계를 분리해 작성돼 있음. “이미 취소됨”, “상품 추가는 성공했으나 프로모션은 실패함” 같은 경험은 현재 상태와 과거 처방을 구분하는 방향에 맞음. 그러나 관측 이후의 활용 제안은 검토자의 조건부 해석이며 보장된 성공 절차 20개가 아님. 현재 8과제의 정책 결과를 개별 기억의 정답으로 옮기지 않음.

외부 ConvoMem·AMA 200출처의 기존 검사도 통과함. 현재 학습 모델이 일반적인 기억 회상에서 우수하지 않다는 경계 자료로 유지함. 이들 문항의 관련성·정답을 현재 상태별 득실 라벨로 재사용하지 않으며, 이번 검토에서 외부 질문 200개의 의미를 새로 전수 주석하지 않음.

## 다음 보완 순서

1. 새 파일럿의 검토용 카탈로그·지침 누락을 보완한 사본으로 의미 검토를 진행함. 42문장·16판단의 검토 결과와 보류를 기록함.
2. `judge_with` 20주석의 입력 계약과 곁가지 기록의 주석/마스킹을 확정함. 길이 대조와 동일 입력 조건의 해석도 실행 전에 명시함.
3. 새 출처 일부에서 목표·은행·제공 묶음을 고정한 현재 관측 대조를 추가함. 봉인 확인 자료와 설계용 출처는 계속 분리함.
4. 기존 무기억·전체·검색·규칙과 비교하여 실제 득실을 측정한 뒤, 선택 오류를 줄이는 학습 효과와 연결함. 손해가 없는 상태와 단순 정책이 잘 푸는 상태도 보존함.

현재 기여는 “관계 점수가 높아졌다”보다 **측정할 관계를 타당하게 구성하고, 그 관계의 학습 노출과 실제 작업 효과를 분리하여 확인할 수 있게 했음**에 있음. 한정된 과제의 데이터·평가 기여로 발전할 근거는 있으며, 새 출처의 동일 조건 대조와 독립 의미 검토가 그 주장을 강화하는 우선 보완임.
