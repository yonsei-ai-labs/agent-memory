# 외부 기억 갱신 대조의 설계 검증 결과

2026-11-11. **현재 근거가 있는 상태에 옛 기록을 추가하면 성공을 깨뜨리는 경우와 오히려 성공하게 만드는 경우가 모두 관측됨.** 원문·채점을 보완한 뒤 설계용 47문항을 실행함. BEAM 개발 자료는 근거 제공 시 11/15로 사전 기준인 12/15에 미달해, 고정해 둔 확인 33문항은 실행하지 않음. 이 결과는 설계 진단이며 외부 확인 완료나 선택 모델의 일반화 성과가 아님.

## 먼저 보완한 것

실행 후보 95문항의 질문·새 근거·옛 근거·방해 기록을 읽고, 같은 수량의 갱신으로 보기 어려운 15문항을 제외함. 원 자료와 라벨을 덮어쓰지 않고 사유를 기록함. 시작 시각 3 PM을 3시간 소요로 해석한 사례, 코드 커버리지 95%와 통과율 97%를 연결한 사례, 전체 마케팅 예산과 특정 광고 예산을 연결한 사례가 포함됨.

방해 기록 중 다른 시점의 동일 예산·기여금을 알려 주는 기록은 후보에서 제외함. 현재 상태보다 뒤의 발화도 사용하지 않음. 더 이른 방해 기록이 옛 기록과 같은 개수로 확보되지 않으면 해당 조건을 생략함. 기록을 자르거나 임의 문장으로 늘려 길이를 맞추지 않음.

채점은 값 포함 검사에서 단일 수량의 단정과 검토가 필요한 응답을 구분하는 방식으로 보완함. `150, not 165`는 165가 포함돼 있어도 자동 성공이 아님. 실제 응답에서 단위·설명이 붙은 54건은 원문 및 질문과 대조해 판정하고, 출력 해시와 근거를 저장함. 이 실행의 최종 성공 판정은 v1 값 포함 검사와 372건 모두 같았음. 채점 보완 자체가 이번 성공률을 높인 것은 아님.

입력과 조건·채점 기준은 `afa0eff`와 사전 고정 파일로 모델 실행 전에 고정함. 확인 분할의 정답은 입력 품질 검토에 사용했지만 모델 출력은 생성하지 않음. 입력과 응답 검토는 이 에이전트가 수행한 단일 검토이며 독립된 두 주석자의 검증은 아님.

## 작업자의 실제 성공

작업자는 이전과 같은 가중치의 Qwen3.5-9B이며 학습하지 않음. 과제 지시문은 외부 대화 질문용이고, 시간순 규칙과 단일 수량 응답 규칙을 명시함. 아래는 고정 작업자에 기억을 다르게 전달한 결과임. 작은 선택 모델을 비교한 표가 아님.

| 전달 조건 | LongMemEval-S 설계 /32 | BEAM dev /15 |
| --- | ---: | ---: |
| 무기억 | 0 | 0 |
| 새 근거만 기억으로 제공 | 31 | 11 |
| 현재 관측에 새 근거 | 31 | 11 |
| 현재 새 근거 + 옛 기억 | 28 | 10 |
| 현재 새 근거 + 반복 기억 | 30 | 12 |
| 현재 새 근거 + 방해 기억 | 29/31 | 8/12 |

마지막 행은 더 이른 방해 묶음이 확보된 문항만 포함하므로 다른 행의 전체 점수와 직접 비교하지 않음. 372개 입력을 실행했으며 같은 입력의 greedy 반복 2개는 원 출력과 같았음. 반복 두 개로 성공 확률의 변동을 추정하지 않음.

성공을 깨뜨린 수와 새로 성공시킨 수는 같은 문항끼리 비교함.

| 현재 새 근거에 더한 기억 | LME 성공→실패 | LME 실패→성공 | BEAM 성공→실패 | BEAM 실패→성공 |
| --- | ---: | ---: | ---: | ---: |
| 옛 기억 | 4/31 | 1 | 2/11 | 1 |
| 반복 기억 | 1/31 | 0 | 0/11 | 1 |
| 방해 기억 | 1/30 | 0 | 1/8 | 1 |

서로 다른 두 자료를 합쳐 하나의 일반화 점수로 취급하지 않음. 관측한 옛 기억의 변화만 기술하면 성공을 깨뜨린 6문항과 새로 성공한 2문항이 있음. 반복 기억의 회귀 1건과 방해 기억의 회귀 1건은 같은 근삿값 문항임. 원문은 “1300에 가까운 것 같다”이고 출력이 `1300`에서 `UNKNOWN`으로 바뀜. 이 문항은 입력 검토 때부터 근삿값임을 표시했으며 정확한 수량이 주어진 사례와 구분해 해석해야 함.

개수·길이를 맞춘 문항은 LME 17개와 BEAM 4개임. 그중 현재 새 근거만으로 맞힌 문항은 각각 17개·2개임. 옛 기억 추가로 각각 2개·1개가 틀렸고, 같은 문항의 반복·방해 대조에서는 회귀가 없었음. 작은 표본의 패턴이며 기억 종류 사이의 일반적인 우열이나 유의한 차이를 입증하지 않음.

## 실제 사례와 해석

| 사례 | 현재 새 근거만 | 옛 기록 추가 후 | 원문에서 확인되는 차이 |
| --- | --- | --- | --- |
| 공동 식료품 예산 | 550달러 정답 | 500달러 오답 | 새 550달러 대신 옛 500달러를 답함 |
| 멘토링 가이드 분량 | 7쪽 정답 | 5쪽 오답 | 새 7쪽 대신 옛 5쪽을 답함. 개수·길이 대조에 포함됨 |
| 카메라를 가져간 여행 횟수 | 5회 정답 | 8회 오답 | 새 누적 5회와 옛 누적 3회를 합한 값과 같음. 개수·길이 대조에 포함됨 |
| 플래시카드·예문으로 익힌 단어 | UNKNOWN | 250개 정답 | 새 기록에 값 250이 있고 옛 묶음에 학습 도구의 맥락이 있음 |
| 소유한 자전거 수 | UNKNOWN | 4대 정답 | 새 기록의 여행에 가져갈 4대와 옛 기록의 소유 자전거 설명을 함께 제공함 |

마지막 두 사례는 옛 기억 전체를 항상 음성으로 두면 놓치는 결과임. 옛 수치는 낡았어도 그 기록의 대상·활동 설명이 현재 값의 맥락을 보충했을 가능성이 있음. 출력 비교로 이득은 관측했지만 내부 추론 원인을 증명한 것은 아님. 같은 이유로 8이라는 출력이 5+3과 같다는 관측을 실제 내부 계산 과정의 증명으로 취급하지 않음.

따라서 이번 자료를 `새 기록=양성`, `옛 기록=음성`의 고정 학습 정답으로 바로 사용하지 않음. 묶음의 충분성, 현재 상태와의 관계, 실제 제공 결과를 별도로 보존하는 기존 연구 방향이 필요함.

## 확인 실행을 보류한 이유와 다음 보완

사전 기준은 두 설계 자료 각각에서 `new_only`와 `current_new` 성공이 80% 이상이어야 한다는 것이었음. LME는 31/32로 통과했고 BEAM은 두 조건 모두 11/15로 미달함. 성공·실패 판정 미해결 건은 0이며 실제 토큰·입력·가중치 출처 검산도 통과했음. 손해가 관측됐는지는 진행 기준으로 쓰지 않았음.

BEAM의 실패 4문항은 인터뷰의 직무, 도서 예산의 범위, 운동화 예산의 기간, 단어 학습 도구를 구체적으로 묻고 있음. 새 발화에는 새 수치가 있지만 이런 한정 조건을 모두 다시 명시하지는 않음. 새 기록 하나만으로 충분하다는 검토가 약했을 가능성이 있으며, 작업자가 맥락을 지나치게 엄격하게 판단해 보류했을 가능성도 남음. 단순히 작업자의 능력이 부족하다고 단정하지 않음.

다음 보완 대상은 **새 수치의 존재와 질문에 필요한 근거의 충분성을 구분하는 것**임. 설계 자료에서 대상·기간·활동을 연결하는 원문 근거를 먼저 확인하고, 옛 기록의 맥락과 낡은 수치를 분리했을 때 제공 효과가 어떻게 달라지는지 소규모로 검증하는 것이 적절함. 이미 본 실패 문항을 빼고 이번 성적을 다시 올리지는 않음. 확인 33문항은 실행하지 않은 상태로 유지함.

## 검산과 자원

- 실제 입력·출력 토큰 374건, 업로드 파일, 모델 가중치 revision·해시, 전체 판정과 사례별 변화 재계산을 검산함.
- 평가 검사 265개와 이후 추가한 자료 검사 7개가 통과함. 변경한 공통 검산 함수로 이전 147호출·2반복 결과도 다시 확인함.
- Colab L4 한 세션을 약 337초 사용했고, 실제 생성 시간은 약 125초임. 계정 표시 잔액 차이는 약 0.06 CU였으며 청구 확정 금액을 뜻하지 않음.
- 새 학습 0회, 유료 모델 API 호출 0회, 확인 단계 0호출임. 소유 세션 종료와 서버 활성 세션 0개를 확인함.

공식 벤치마크 전체 점수, 자연 발생 에이전트 실행 이력, 학습 선택기의 우위로 해석하지 않음. 이번 결과는 외부 자료에서 가져온 제한된 수량 갱신 문항의 설계 검증임.
