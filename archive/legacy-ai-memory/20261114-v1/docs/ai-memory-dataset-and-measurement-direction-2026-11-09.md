# 연구 중심 정리: 메모리 득실 데이터셋과 평가 방법

2026-11-09. 사용자가 연구의 주 기여를 **“메모리의 득과 실을 측정하는 데 필요한 데이터셋 확보 및 측정 방법 제안”**으로 명확히 함. 이를 현재 방향으로 둠. 이전 노트의 별도 학습 모델 중심 제안은 당시 판단으로 보존하며, 이후에는 모델 학습·선택기 비교를 데이터와 측정 체계의 활용 가능성을 확인하는 기준선/사례 연구로 배치함.

## 방향에 대한 판단

원래 관심인 “어떤 기억 내용이 어떤 현재 조건에서 이득 또는 손해를 만드는가”와 잘 맞음. 새로운 모델이 단순 규칙보다 항상 우수해야만 연구가 성립하는 것은 아님. 학습 전후 정확도보다 **측정 단위·입력 개입·결과·불확실성·출처를 신뢰할 수 있게 연결하는 것**이 먼저임.

데이터 파일과 재현 가능한 평가 프로토콜·실행 도구를 묶은 벤치마크를 목표로 하는 것이 적절함. 데이터 수집량만으로 기여를 정하지 않으며, 어떤 기존 평가의 빈틈을 어떻게 측정할 수 있게 했는지 보여야 함.

제안하는 연구 질문:

> 과거 경험의 어떤 정보를 보존·삭제·복원하고 어떤 현재 조건에서 제공할 때, 작업 성공·근거 있는 행동·비용이 어떻게 달라지는지 재현 가능하게 측정할 수 있는가?

## 선행연구와의 관계

이번에 아래 원문을 다시 확인함.

| 연구 | 이미 다루는 내용 | 우리 기여를 정할 때의 의미 |
| --- | --- | --- |
| [What Is This Memory Useful For? v1](https://arxiv.org/html/2611.03930v1), 2026-11-02 | 미래 과제를 보지 않는 writer, 고정 reader의 기억 제공/보류, 비용, 조건부 효용 측정과 공개 데이터셋 | “과제별 효용 데이터셋을 처음 만든다”는 주장은 적절하지 않음. 재현 출발점이자 가장 가까운 비교 대상임 |
| [Memory Tax v1](https://arxiv.org/html/2610.34073v1), 2026-10-25 | 원문 RAG 대비 메모리의 이득·손실, 정보 보존·접근·모델 변경의 영향 | 단순 성공/실패 전환과 압축 손실만으로 독창성을 확정하지 않음 |
| [MemDev-Bench v1](https://arxiv.org/html/2610.27524v1), 2026-10-20 | 시간상 유효한 저장소 이력, 관련성 통제, 코드 작업의 개선·회귀 | 유명 SWE 과제를 사용한다는 사실만으로 평가 방법의 새로움이 생기지는 않음 |

우리의 **차별화 후보**는 출처가 연결된 정보 조각의 포함/삭제/복원과 현재 조건을 교차해, 어느 정보가 어떤 조건에서 효과를 바꾸는지 실행 결과와 연결하는 것임. 최종 해결뿐 아니라 근거 없는 행동·부적절한 불가능 판단·확인/제출 비용을 함께 측정하는 방향임. 이 조합의 최초성은 아직 확정하지 않았음.

첫 단계는 가까운 측정 프로토콜을 재현하고 우리 사례에 적용해도 됨. 그 과정에서 발견한 누락·실패·변동을 바탕으로 데이터/프로토콜의 구체적인 확장을 정함.

## 주 산출물 세 가지

### 1. 경험·현재 상태·기억 개입을 연결한 데이터

기본 단위는 단독 기억이 아니라 다음 묶음임.

- 과거 경험 원문과 관측 범위·시점·출처.
- 판단 시점의 현재 과제·관측·실행 환경/snapshot.
- 기억 원형과 정보 조각·삭제/복원/표현 변형의 계보.
- 고정한 제공/보류 조건에서의 실제 출력·행동·성과·비용.
- worker·지침·decoding·예산·반복·실패/누락 상태.
- 부모 경험/현재 문제/파생 사례를 묶은 분할.

필요한 두 기억의 결합, 현재에 이미 알려짐, 전제 불일치, 부분 근거 부족, 시점 갱신을 포함함. 자연 경험과 통제한 변형을 구분함. 실제 효과를 보기 전에 기억 작성·변형·포함 기준을 고정하고, 미래 정답을 보고 과거 기억에 풀이를 추가하지 않음.

모든 기억에 보편적인 beneficial/harmful 라벨 하나를 붙이지 않음. 모델·과제·현재 상태·기억 묶음에 조건부인 결과와 추정치를 저장함. 관계/충분성 주석과 실제 효과는 별도임.

### 2. 득실 측정 프로토콜과 실행 도구

주 비교를 명시함.

- 전체 기억 효과: 제공과 무기억의 성과·행동·비용 차이.
- 조각의 조건부 효과: 조각을 포함한 기억과 그 조각을 제외한 기억의 차이.
- 현재 조건의 영향: 같은 기억을 전제 일치/불일치·새 정보/이미 관측한 상태에 배치했을 때의 효과 차이.
- 필요 시 두 조각의 상호작용: 없음/A/B/A+B의 결과. 개별 기여를 단순 합산하지 않음.

환경·worker·입력 위치·예산을 고정하고 조건 배정·반복·관측 누락을 기록함. 같은 입력의 반복으로 실행 변동을 확인하며, 원형 한 번 성공/변형 한 번 실패를 확정적인 기억 유해성으로 부르지 않음. 반복을 늘리는 것과 독립 원천을 늘리는 것을 구분함.

삭제는 길이·구조도 바꾸므로 우선 삭제 패키지의 총효과를 보고함. 의미 자체의 기여를 주장할 경우 길이·배치·다른 문구를 통제한 추가 비교가 필요함. 일반 조언/무관 문장도 효과가 0인 대조로 가정하지 않음. 삭제 후 정확히 같은 원문으로 복원한 실행은 반복성 확인에도 해당하며 독립적인 기전 증명으로 과장하지 않음.

성공률 차이, 근거 없는 행동, 정상 보류, 잘못된 불가능 판단, 입력/출력·선택/조회/검사 비용을 별도 보고함. 단일 순효용이 필요하면 교환 가중치를 사전에 정함. 성공한 실행만으로 비용을 비교하지 않음.

### 3. 그 측정으로 가능해진 분석

적용 조건·검증 범위·과거 실패 관측·행동 처방 등에서 먼저 한두 종류를 고름. 같은 조각이 현재 조건에 따라 도움이 되거나 불필요·위험할 수 있는지, 제거/복원 효과가 새 출처에서도 관측되는지 확인함.

예를 들어 “요약에서 적용 조건을 빼면 언제 잘못된 행동이 늘며, 조건을 보존하면 새 문제에서도 그 증가를 줄이는가”를 다룰 수 있음. 조건이 원문에 있었는지와 현재에도 성립하는지는 독립적으로 확인함. 사후 궤적 설명만으로 원인을 확정하지 않음.

관측이 특정 worker에만 나타나면 그 범위로 보고함. 모델에 따라 효과가 달라지는 것도 결과이며, 모든 모델에서 같은 부호의 효과가 나와야 하는 것은 아님.

## 기존 자료의 재배치

| 현재 자료 | 새 연구 중심에서의 역할 |
| --- | --- |
| 숫자·검사 범위·명시적 참조 관계 | 판독/평가 코드와 알려진 조건의 기능·회귀 점검 |
| 실제 개발 관계·진단 단서 | 출처 연결·주석 기준·현재 조건 대조의 후보 |
| API 실제 효용 | 조건부 결과·비용 스키마와 실행 판정의 초기 검증 |
| 여행 실제 기록·96상태·후속 정책 비교 | 제공량·근거 부재·행동 차이를 측정할 수 있는 파일럿 |
| 0.6B·LoRA·4B/9B 선택기 | 공개 데이터와 평가 체계의 사용 예·기준선. 주 기여를 대체하지 않음 |
| 외부 공개 벤치 조사 | 원천·평가 자원 후보. 편입/검증을 마친 데이터와 구분 |

현재 자료는 기반이며 완성된 일반 벤치마크가 아님. 특히 실제 득실 원천은 작고, 현재 여행 문제의 두 독립 출력과 한 답을 위한 다중 기억 결합은 다름. 데이터 품질 보완과 [눈가림 재검토 준비](design-data/memory-data-remediation-20261109-v1/README.md)는 계속 유효함.

## 첫 연구의 범위를 좁히는 방법

처음부터 모든 도메인·기억 형태·모델을 포괄하지 않음.

1. 자동 채점·상태 복원이 가능한 과제군 하나에서 과거 경험과 현재 대상의 연결을 확보함. 기존 유명 벤치의 문제·채점기를 재사용하고, 경험·기억 개입·결과를 추가한 계층을 구축할 수 있음.
2. 원문에서 확인되는 정보 조각 하나와 현재 조건 변화 한 축을 선택함. 무기억/기억/조각 삭제/복원을 첫 비교로 두되 중복 조건·길이 효과를 명시함.
3. 실패·중립·악화를 포함해 수집하고, 원문·실행·채점을 독립 경로로 검사함. 자료 수율·오류·비용을 보고 규모를 정함.
4. 이미 본 자료에서 설정을 정한 뒤 새로운 부모 가족에서 확인함. 여력이 있으면 같은 데이터의 두 번째 worker를 통해 조건부 효과의 안정성을 별도로 확인함.
5. 두 번째 도메인·SWE 전체 과제·선택기 학습은 확장/사용 사례로 연결함.

첫 공개물이 측정 단위와 도구를 명확히 하고 타당한 분석을 재현할 수 있다면, 새로운 모델 구조나 최고 성적이 없어도 평가 연구로서 검토할 수 있음. 학술적 기여의 충분성은 기존 자료 대비 추가된 측정 가능성·신뢰성·독립 확인에 달려 있음.

앞으로의 우선순위는 **어떤 데이터를 확보하면 어떤 득실을 구분할 수 있는가 → 그 측정이 신뢰할 만한가 → 그 데이터로 무엇을 새로 알게 됐는가**임.
