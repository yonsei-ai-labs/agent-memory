[새 문제군 공개 데이터 조사](ai-memory-fresh-dataset-survey-2026-11-09.md)는 HF 저장소 18개와 공식 자료를 대조해 후보 24항목의 수집·평가 역할을 정리함. LongMemEval·PersonaMem-v2·Mem2ActBench·LongMemEval-V2의 실제 파일 구조, 원본 ID 연결 예외와 분할 조건을 확인했으며 모델 실행 결과와 구분함.

[새 문제군 일반화 검증안](ai-memory-fresh-source-evaluation-2026-11-09.md)은 현재 준비 중인 60/20/40 분할의 역할, 동결 전이와 새 효용 학습의 구분, 은행 크기·참조 수·전달 예산을 맞춘 비교를 정리함. 실행 결과나 다른 도메인 일반화의 확인과 구분함.

[11월 9일 후보 검색 학습](reports/2026-11-09-candidate-search-learning.md)은 고정 판독기에서 기존 검색 32/64후보와 학습 검색 32후보를 비교함. 검색률은 68.6/86.9/92.0%였으며 실제 작업 성공과 구분함. [앞선 전체 질문 검색](reports/2026-11-09-full-request-memory-retrieval.md)은 관계 판독 학습과 후보 누락을 분리한 단계임. [현재 작업 점검](reports/2026-11-09-workspace-review.md)에서 실제 가중치·저장 출력·실행 원장·공유 안내의 확인 범위를 정리함.

[11월 9일 여행 기억의 실제 득실](reports/2026-11-09-travel-worker-utility.md)은 생성한 과거 선택을 고정하고 무기억·전체·검색·규칙·학습 선택의 실제 출력을 비교한다. 현재 정보와 작업자에 따라 득실이 달랐으며 규칙과 학습 선택의 평가 결과는 같았다. [4B 사전 계획](ai-memory-travel-worker-utility-plan-2026-11-09.md)과 [사후 9B 비교 계획](ai-memory-travel-worker-9b-transfer-2026-11-09.md), 원래 전체 여행 과제와의 차이를 함께 읽는다.

[11월 9일 MemoryArena 여행 학습](reports/2026-11-09-memoryarena-travel-references.md)은 기본 계획 단위로 분리한 자료 수집, 고정 판독층·LoRA 비교, 참조 선택과 보류 진단을 보고한다. Test 참조 선택 100%는 명시적 문장과 깨끗한 과거 기록 조건이며 실제 메모리 득실 평가와 구분한다.

[11월 8일 통합 리뷰](../training/memory_selector/reviews/2026-11-08-integrated/README.md)는 커밋한 전체 실험의 데이터·학습·선택·실제 효용을 함께 점검한다. 최신 모델의 학습 단계부터 이어진 고정 기억 선택, 개발 지표의 한계, 새 clone 재현과 과거 색인의 보존 예외를 먼저 확인한다.

[리뷰 이후 데이터 설계와 정리](ai-memory-next-data-contract-2026-11-08.md)는 기존 자료 9종의 다음 역할, 근거 사례 6개, 새 자료의 판단 시점·관계/효용 정답·정보 제공 행동·학습 재개 조건을 정리한다. 추가 학습 행을 만든 결과와 구분한다.

[그 기준으로 수집한 새 사례](design-data/memory-evidence-discovery-20261108-v1/README.md)는 과거 경험 12개와 현재 문제 18개를 19쌍으로 연결한다. 원문 87개 명령–응답과 수정 전 코드에서 조건을 대조했으며, 관계 주석과 아직 측정하지 않은 기억 효과를 구분한다.

[수집·증강·분류의 통합 방향](ai-memory-data-collection-and-taxonomy-2026-11-08.md)은 동료 공유용 다음 단계다. 자연 출처 확대, 검증 가능한 조건 증강, 기억 내용 6종·선택 문제 8종, 파일럿 이후의 규모와 후보 선택 평가를 연결한다. [다른 수집 제안](ai-memory-data-collection-and-augmentation-plan-2026-11-08.md)과 비교 조건을 조정했으며, [분류표](design-data/memory-taxonomy-20261108-v1/README.md)는 기존 자료의 검토용 태그다.

최근 [실제 개발 이슈의 기억 학습](reports/2026-11-08-development-memory-leads.md)은 40이슈×16기억 자료와 LoRA/순위 손실 비교, 학습 적합과 새 이슈 선택 실패를 다룬다. [11월 8일 낮 보고](reports/2026-11-08-memory-selector-daytime.md)는 실제 기억 효용·4B/9B 전이·선택 비용·추가 layer와 목적함수의 한계를 정리한다. 앞선 [아침 보고](reports/2026-11-08-memory-reader-overnight.md)는 데이터 선별·범위 구조 비교·자연 관계의 미개선·회수하지 못한 실행을 보존한다.
