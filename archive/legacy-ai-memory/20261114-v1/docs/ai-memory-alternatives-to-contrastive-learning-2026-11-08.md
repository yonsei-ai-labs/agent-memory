# 대조학습 외의 선택기 학습 방법: 무엇을 예측하고 어떻게 검증할 것인가

2026-11-08. 현재 코드·실험 기록과 논문 원문을 대조한 조사 노트다. 새 학습·작업자 생성·유료 API 호출은 하지 않았다. 기존 학습 구간의 제공/보류 결과만 별도로 재집계했다.

**우선 시험할 후보는 ① 무기억 능력과 기억의 개선·악화를 나누는 감독, ② 실행으로 확인한 적용 조건을 배우고 개입하는 모델, ③ 기본 정책을 바꿀 때만 개입하는 선택기다.** 층별 판독과 큰 모델의 근거 증류는 앞의 두 후보를 구현·진단하는 수단으로 유망하다. 어느 방법도 현재 자료에서 일반화 효과가 입증됐다는 뜻은 아니다.

연구 목표는 작은 별도 모델이 **현재 상태와 과거 경험을 함께 읽고, 새로운 작업에서 성공·회귀·비용을 고려해 기억 제공을 결정하게 하는 것**이다. 관계 분류, 직접 재사용 가능성, 실제 작업자 효용은 각각 평가한다.

## 후속 학습을 마친 뒤의 재검토

[실제 개발 이슈의 학습](reports/2026-11-08-development-memory-leads.md)을 완료한 뒤 이 제안을 다시 검토했다. 새 40이슈×16기억 자료에서 12개 모델의 관련 기억 첫 선택은 모두 0/4였고, 별도 긴 CPU 학습의 MLP는 학습 432쌍을 두 번 모두 맞혔다. 이는 학습 적합과 일반화가 다른 문제임을 보여주며, 메모리 효용 모델 전체의 실패나 마지막 층의 정보 부재를 증명하지 않는다.

**우선순위는 결과 분해의 작은 비교와 개념 개입 진단을 유지한다.** 다음 보완을 함께 적용해야 한다.

1. **두 자료를 섞지 않는다.** 4범주 효과 라벨을 바로 만들 수 있는 것은 기존 API 작업자의 50상태×8기억, 400개 관측 쌍이다. 이번 재집계에서도 둘 다 실패 218·개선 22·악화 63·둘 다 성공 97이 일치했다. 새 640쌍은 진단 관련성 주석이므로 이를 개선/악화 정답으로 변환하지 않는다.
2. **중립을 0으로 묶은 것이 오류는 아니다.** 목표가 성공의 순증가라면 두 중립의 효과는 모두 0이다. 제곱오차 회귀의 모집단 최적 예측은 조건부 평균 증감이다. 4범주는 상황별 보조 감독과 개선·악화의 별도 추정이 일반화에 도움이 되는지를 시험한다. 기존 MSE, 3범주 CE, 4범주 CE를 같은 입력·충분한 학습 곡선으로 비교해야 손실 종류와 정보 분해를 구별할 수 있다. 개선 사례 22개가 부족하다는 점은 분류 이름을 바꿔도 남는다. [처리 효과 meta-learner 논문](https://arxiv.org/abs/1706.03461)은 방법의 출발점이며 이 4범주 설계의 직접 검증은 아니다.
3. **두 성공 확률과 4범주 확률의 역할을 구별한다.** 현재만 읽는 기본 성공 확률과 현재+기억의 성공 확률 차이는 기대 증감을 추정한다. 같은 현재 상태에서는 기본 확률이 후보마다 같아 기억 사이의 순위에서 상쇄되므로, 그 분해만으로 더 좋은 후보 순위가 보장되지 않는다. 또한 두 주변 성공 확률만으로 개선·악화의 결합 확률을 각각 복원할 수는 없다. 악화에 별도 가중치를 주려면 관측한 짝 결과를 감독하는 4범주 출력 등 추가 설계가 필요하다.
4. **개념 예측 수정과 기억 내용의 개입은 별도다.** 예측한 ‘원본 변경’ 값을 정답으로 교체하는 [CBM 진단](https://proceedings.mlr.press/v119/koh20a.html)은 판독 과정의 어디를 개선해야 하는지 확인한다. 실제 기억에 해당 조건 문장을 넣거나 빼고 작업자의 결과를 비교해야, 그 정보를 보존하는 이득·손해에 답할 수 있다. 직접 적용성 정답이 같은 개념 규칙에서 만들어졌다면 정답 개념으로 높은 점수를 얻는 것은 일부 구성상의 결과다. 현재 목표처럼 이미 입력에 명시된 조건은 실제로 별도 예측을 하지 않았다면 ‘정답 교체한 예측’으로 세지 않는다.
5. **보류는 개선과 함께 평가한다.** 새 학습의 개발 선택 모델은 평가 여섯 이슈에서 모두 제공 문턱을 넘지 못했다. 악화 0만 보면 이런 정책도 좋아 보인다. 기본 정책을 고정하고 개선·악화·개입률·전체 성공·선택기 포함 비용을 함께 제시해야 한다. [Learning to Defer](https://proceedings.mlr.press/v119/mozannar20b.html)는 전문가에게 넘기는 분류 문제의 선례이며 기억 행동 변경에 대한 보장을 그대로 주지 않는다.

층 혼합은 표현을 조사하는 후보로 남긴다. 학습 100% 적합은 사례 암기로도 가능하므로 관계 정보가 일반화 가능한 형태로 들어 있다는 증거가 아니다. 반대로 짧은 판독 학습의 실패만으로 정보가 없다고 결론낼 수도 없다. 검증된 근거 증류는 자료 보강에 유용할 수 있다. 교사가 제시한 span이 원문에 존재하는지와 그 span이 실제로 주석을 지지하는지를 각각 확인한다. [Distilling Step-by-Step](https://aclanthology.org/2023.findings-acl.507/)의 설명 감독 아이디어를 쓰되 교사의 주장을 실행 효용 정답으로 대체하지 않는다.

첫 비교는 기존 API train/dev를 이용한 탐색으로 제한하고 현재 test로 다시 승자를 고르지 않는다. 새 개발 자료에는 여러 출처와 실제 개선·악화·중립, 기본 정책만으로 충분한 상태를 함께 보존한다. 분류 F1 향상 외에 실제 정책의 성공·악화·비용이 바뀌는지를 주 평가로 삼는다. 이 추가 검토에서는 문헌 대조와 기존 라벨 검산만 했으며 새 학습·GPU 할당은 하지 않았다.

### 1. 무기억 결과와 기억 제공 결과를 나눠 학습

[Metalearners for estimating heterogeneous treatment effects](https://pmc.ncbi.nlm.nih.gov/articles/PMC6410831/)는 조건에 따른 처리 효과를 결과 예측과 구분해 학습하는 S/T/X 계열 접근을 다룬다. 이 관점에서 가져올 것은 ‘성공할 법한 기억’만 찾는 대신 **같은 작업자의 기본 행동에 비해 얼마나 바뀌는가**를 목표로 삼는 것이다. 아래의 4범주 구현은 이 논문의 알고리즘을 그대로 재현한 것이 아니라 우리 자료에 맞춘 제안이다.

현재 `api_utility.py`의 value 목표는 이미 `Y_memory − Y_none`을 MSE로 학습한다. 따라서 ‘차이를 학습하자’만으로는 새 실험이 아니다. 후속의 차이는 **기본 능력을 따로 감독하고 결과의 구조를 보존하는가**다.

| 무기억 결과 Y0 | 기억 제공 결과 Ym | 새 감독 범주 | 기존 차이 라벨 |
| --- | --- | --- | --- |
| 실패 | 실패 | 둘 다 실패 | 0 |
| 실패 | 성공 | 개선 | +1 |
| 성공 | 실패 | 악화 | −1 |
| 성공 | 성공 | 둘 다 성공 | 0 |

기존 학습 50상태×단일 기억 8행동을 재집계하면 **둘 다 실패 218, 개선 22, 악화 63, 둘 다 성공 97쌍**이다. 0 효과가 315/400=78.75%이고, 개선은 5.5%다. 이는 불균형과 감독 설계를 점검할 이유이며, 현재 실패의 원인이 이것이라고 입증한 결과는 아니다. 400쌍은 독립 과제 400개가 아니다. 무기억 성공은 20/50상태다. [원자료 해시·집계](design-data/contrastive-alternatives-20261108/train-label-audit.json).

작은 비교는 다음처럼 구성한다.

1. 기존 −1/0/+1 MSE를 동일 입력·표현의 기준으로 유지한다.
2. −1/0/+1 **3분류 CE**를 비교한다. 손실 종류 변경 효과를 분리한다.
3. **4범주 CE**를 비교한다. 중립 두 종류를 나눈 추가 효과를 확인한다.
4. 현재 상태만 보는 `P(Y0=1|s)`와 현재+기억을 보는 `P(Ym=1|s,m)`을 각각 감독하는 두 출력 모델을 비교한다. 두 예측의 차이는 기대 개선 추정이며, 두 사건의 독립성을 가정할 필요가 없다.

4범주 모델에서는 `P(개선) − λ P(악화) − η 예상 추가 비용`으로 결정을 만들 수 있다. λ·η와 보류 임계값은 개발에서 정하고 성공·악화·비용 원지표도 각각 보고한다. 4범주가 새로운 정보를 생성하는 것은 아니다. 같은 관측을 다르게 감독했을 때 일반화가 좋아지는지를 묻는 실험이다.

학습의 실제 무기억 성공 여부는 **정답 감독에만** 쓴다. 새 상태의 입력으로 정답을 넣지 않는다. 기본 능력 출력은 동일 상태의 후보마다 일치하도록 현재만 읽는다. 클래스 가중치를 쓰면 확률 보정과의 관계를 별도로 확인한다.

현재는 고정 greedy 생성에서 양쪽 행동을 실제 실행했으므로 관측된 짝 라벨을 만들 수 있다. 한 행동만 있는 일반 로그에서 4범주를 추정 정답처럼 만들면 안 된다. 무작위 생성 작업자로 확대할 때는 반복·seed 짝짓기와 효과의 정의를 새로 고정한다. 개별 시행착오의 차이와 모집단 인과 효과도 구분한다.

### 2. 검증된 적용 조건을 배우고, 그 판단을 고쳐 보며 분석

[Concept Bottleneck Models](https://proceedings.mlr.press/v119/koh20a.html)는 입력에서 개념을 예측하고 개념으로 최종 판단을 하며, 예측 개념의 수정 효과를 측정할 수 있게 한다. [개념 개입 절차 분석](https://proceedings.mlr.press/v202/shin23a.html)은 어떤 개념을 어떤 단위로 고치는지가 평가에 영향을 준다는 점을 보여준다. 이 분야의 실험 형태가 사용자의 ‘무엇이 득실을 바꾸는가’라는 질문과 잘 맞는다.

일반 CBM은 이미 시험했다. 후속은 다음 둘로 좁힌다.

- **진단적 개입:** 반환 결과 위치만 정답으로 교체, 원본 변경만 교체, 둘 다 교체한다. 원래 예측과의 짝 차이를 계산하고 판단·선택·작업자 결과가 어디까지 개선되는지 본다. 개념 정답을 사용하는 오라클 진단이며 배포 성적으로 세지 않는다. 현재 직접 적용성 정답 자체를 같은 개념·논리로 정의한 범위에서 정답 개념이 높은 점수를 얻는 것은 구성상의 결과다. 유용한 관측은 어떤 예측 오류를 고쳐야 실제 선택도 좋아지는가이며, 모델의 내부 인과 추론을 자동으로 증명하는 것은 아니다.
- **결합 개념 분포:** 현재 코드는 반환 R·변경 M의 Bernoulli 확률을 곱한다. `P(R,M)` 네 조합을 직접 예측하는 모델과 비교하면 독립성 가정의 영향을 분리할 수 있다. 가능한 두 구현 사이의 확률 조합도 별도 가정이므로 그대로 보존하고 명시한다. [Probabilistic CBM](https://proceedings.mlr.press/v202/kim23g.html)은 개념의 불확실성을 다루는 참고이며, 이 4조합 CE 제안과 동일한 모델은 아니다.

새 자연 경험에는 ‘버전·상태 전제’, ‘명령이 실제로 실행됐는가’, ‘어느 검사 범위를 확인했는가’, ‘현재 목표와 과거 결과가 같은가’를 출처에 연결해 주석한다. 확인하지 못한 전제는 미확인으로 둔다. 실제 생성 결과를 보고 만든 속성은 학습 정답이 될 수 있어도 판단 전 입력에는 넣지 않는다.

직접 적용 조건이 맞아도 작업자가 기억을 잘못 사용할 수 있고, 맞지 않는 절차를 수정해서 유용하게 쓸 수도 있다. 따라서 개념 정답 → 직접 적용성 → 실제 효용을 같은 라벨로 합치지 않는다. 사람이 만든 논리 규칙과 현재만 보는 모델도 유지한다.

### 3. 기본 정책을 바꿀 때의 개선·악화를 학습

[Consistent Estimators for Learning to Defer to an Expert](https://proceedings.mlr.press/v119/mozannar20b.html)는 예측과 전문가에게 넘기는 결정을 비용 민감 학습으로 다룬다. 우리에게는 **기본 정책을 유지할지, 다른 기억 행동으로 바꿀지**를 나누는 아이디어를 적용할 수 있다. 원 논문의 전문가 분류 설정을 그대로 재현한 것은 아니다.

기본 정책은 무기억 또는 개발에서 고른 저렴한 고정 기억이다. 선택기는 그 기본 정책보다 좋아질 근거가 있을 때 행동을 바꾼다. 기본 행동이 항상 무기억이라고 고정할 필요는 없다. 9B 결과에서 고정 절차가 강했던 사실도 반영해야 한다.

단순 임계값 정책을 먼저 비교하고, 개선·악화 예측을 따로 학습하는 모델을 붙인다. 지표는 기본 정책 대비 개선·악화, 변경 비율, 전체 성공, 전체 비용이다. 선택기를 항상 실행하면 보류해도 encoder 비용이 든다. ‘아무것도 제공하지 않음’이 자동으로 저비용 시스템을 뜻하지 않는다.

[Conformal Risk Control](https://arxiv.org/abs/2208.02814)은 보정 표본으로 단조 손실의 기대 위험을 제어하는 참고다. 예를 들어 후보 선택 함수를 먼저 고정하고 문턱을 높일수록 개입만 줄어드는 정책에서, **전체 과제 중 악화 발생률**을 보정하는 구성을 검토할 수 있다. ‘제공한 경우에만 계산한 악화율’은 분모도 변하므로 같은 단조성 보장을 바로 옮길 수 없다. 모델 선택과 보정 자료를 분리하고 필요한 교환 가능성 가정을 명시해야 한다. 새 라이브러리로 분포가 바뀌는 현재 평가와 18상태만으로 악화율 보장을 주장하지 않는다.

### 4. 층별 판독을 수렴시키고 층을 섞어 보기

[ELMo](https://aclanthology.org/N18-1202/)는 여러 층의 표현을 과제별 가중합으로 사용하는 선례다. 이를 Harrier에 적용하는 것은 구조적 아이디어의 응용이다. ELMo는 biLSTM 기반이며 Harrier 실험의 성능을 보장하지 않는다.

이미 일부 중간층을 판독했으므로, 새 질문은 **충분히 최적화한 같은 판독기에서도 어느 층이 유리한가, 소수 층을 섞으면 역할·전제 정보가 더 잘 읽히는가**다.

- 저장된 층별 표현에 ridge/logistic을 학습하고, 층마다 train 적합·개발 성능·수렴을 확인한다. 중간층 정규화·정규화 강도는 train/dev에서만 정한다.
- 같은 층의 linear와 작은 MLP, 마지막 층, 균일 평균, 학습한 scalar mix를 비교한다. 층 혼합 가중치 수가 작아도 encoder 전체 비용은 유지된다.
- 층·pooling 선택은 개발에서 끝내고 새 출처에서 평가한다. 단순 구조화 필드·길이 규칙으로 풀리는 기존 범위 자료만으로 관계 이해를 주장하지 않는다.

선형 판독 성공은 그 입력·분포에서 정보가 읽힌다는 증거다. 실패는 정보 부재의 증명이 아니다. 실제 행동에 그 정보를 사용한다는 주장에는 별도의 개념 개입과 작업자 효용 검증이 필요하다.

### 5. 큰 모델의 검증된 근거를 작은 모델로 증류

[Distilling Step-by-Step](https://aclanthology.org/2023.findings-acl.507/)는 큰 모델의 설명을 정답 예측과 함께 감독해 작은 모델을 학습한다. 원 논문은 설명 생성이 가능한 모델을 사용한다. Harrier 판독기에 적용하려면 설명 문장 전체 대신 **근거 위치·전제·관계 속성**을 추가 출력으로 감독하는 변경이 필요하다.

제안은 Qwen 27B급 또는 MoE 교사가 짧은 적용 조건과 출처 span을 제안하고, 실행·원문으로 확인한 것만 감독으로 쓰는 것이다. 교사 모델 이름·규모·출력만으로 정답을 보증하지 않는다. 기존 9B의 강제 토큰 판독이 실패했으므로 교사 프로토콜부터 소수 정답으로 확인해야 한다.

비교는 `라벨만` / `라벨+검증된 속성` / `라벨+검증된 근거 위치`로 좁힌다. 같은 입력·학습 행·학생 계산량을 맞추고, 교사가 추가한 정보와 원래 입력에서 추출한 감독을 구분한다. 추론 때 교사 설명을 새로 받아야 한다면 그 비용도 포함한다. 표준 증류처럼 학습 때만 교사를 쓰는 경우와 구분한다.

학생 작업자가 4B라면 효용 정답은 4B의 실제 행동 결과를 사용한다. 9B에서만 효과적인 기억을 4B의 효용 정답으로 복제하지 않는다. 교사는 현재-출처 관계를 도울 수 있지만 작은 작업자의 활용 효과를 대신 관측하지는 못한다.

또 다른 선례인 [REPLUG](https://aclanthology.org/2024.naacl-long.463/)는 고정 LM의 정답 continuation 확률을 이용해 검색 분포를 감독한다. 정확도 0/1보다 조밀한 신호를 얻을 가능성이 있지만, **우리 과제에서는 특정 정답 코드의 우도와 실행 성공이 같지 않다.** 저장된 정답 우도도 없으므로 즉시 사용할 수 있는 무비용 라벨이 아니다. 현재는 실행 검증된 속성 감독을 먼저 권한다.

### 6. 얕은 정책 트리와 그룹별 학습

[policytree](https://joss.theoj.org/papers/10.21105/joss.02232)는 상태 특징과 행동별 보상 행렬에서 직접 정책 트리를 최적화한다. [저자 문서](https://grf-labs.github.io/policytree/reference/policy_tree.html)의 입력도 N×행동 수의 보상 표다. 우리 전체 행동 표와 잘 맞는다. 현재 코드는 상태-기억 행의 **차이 점수 회귀 트리**이므로, 얕은 트리로 행동별 보상 합을 직접 최적화하는 비교는 구별된다.

depth 1–2, 충분한 최소 leaf 상태 수와 적은 관측 특징으로 시작한다. 예측된 반환·변경 특성을 쓰면 학습 행에도 OOF 예측을 사용해 유리한 train 정답을 몰래 넣지 않는다. 미리 정한 구문 규칙과 fixed 정책도 비교한다. 현재는 모든 행동의 결과를 관측했으므로 propensity나 doubly robust 점수를 추정할 필요가 없다. 순차 행동의 장기 보상을 학습하는 RL도 아니다.

[Group DRO](https://arxiv.org/abs/1911.08731)는 미리 정의한 그룹의 최악 손실을 줄이는 접근이며 정규화·early stopping의 중요성도 다룬다. 현재 평균 점수가 숨기는 역할 충돌이나 특정 전제를 보완할 후보지만, 먼저 같은 그룹을 균등하게 학습하는 ERM과 비교한다. 학습 가족·목표·관측 조건으로 그룹을 정하고 새 가족의 최악 성능도 보고한다. 그룹이 적은 현재 자료에서 보장 없이 가중치만 키우면 소수 사례에 과적합할 수 있다. 모든 행동이 실패하는 상태에 선택 regret이 있다고 인위적으로 만들지도 않는다.

### 7. RL과 확인 행동은 다음 데이터가 있을 때

메모리 분야에도 대조학습 외의 직접 선례가 있다. [Memory-R1](https://arxiv.org/abs/2508.19828)은 메모리 관리와 답변 에이전트를 PPO/GRPO로 학습한다. [MemRL](https://arxiv.org/abs/2601.03192)은 동결 LLM과 기억별 효용 갱신을 분리한다. 후자는 별도 신경 선택기 가중치를 학습하는 접근과 다르다. 두 논문의 대화·에이전트 결과를 현재 작은 코드 작업자의 효과로 옮겨 주장하지 않는다.

저장·수정·삭제·조회가 이후 상태와 미래 성공을 바꾸는 자료가 생기면 순차 RL을 검토할 이유가 있다. 지금의 한 번 제공하는 9행동 전체 결과 표에는 감독 정책 학습이 직접 맞는다. PPO/GRPO를 먼저 붙여도 새 출처 부족이나 개발 선택 불가능성이 해결되지는 않는다.

‘확인하고 기억을 사용’하는 행동도 유망하지만 **확인 명령의 실제 관측·비용과 그 뒤 행동 결과**가 있어야 한다. 현재 기억 제공 표에서 확인 행동 보상을 추정 정답처럼 만들어 오프라인 RL 자료로 부르지 않는다. 확인 비용 대비 행동이 바뀌고 최종 결과가 좋아지는지를 별도로 관측한다.

## 실제 실험 순서와 논문에서 보여줄 증거

**1단계 — 현재 자료의 저비용 진단.** 결과 분해의 MSE/3분류/4분류/두 출력 중 작은 사전 비교를 고정한다. 기존 train/dev만 재사용해 학습 적합·개선/악화 확률·오류 종류를 본다. 이는 기존 test를 본 뒤의 탐색이다. 현재 개발의 선택 여지가 0이므로 승자를 확정하는 실험으로 쓰지 않는다. 같은 시기에 기존 개념 모델의 부분 정답 교체로 다음 감독이 필요한 판단을 찾는다. 처음부터 위 후보 전체를 수십 조합으로 돌리지 않는다.

**2단계 — 독립 경험과 개발 자료.** 실제 과거 로그와 별도의 현재 판단 시점을 연결하고, 출처 재현성·관측 가능한 전제·평가 계약을 기준으로 수집한다. 파생 생성 전에 가족 분할을 정한다. 무효·중복·단순 해법으로 충분한 사례도 보존한다. 선택 여지가 적다는 부정 결과도 보고하며, 새 확인 결과에서 좋은 상태만 골라 자료를 꾸미지 않는다. 개발 가족 수와 상태 수를 늘리는 것이 같은 상태의 문장 변형보다 우선이다.

**3단계 — 한 가지 학생 개선 + 작은 통제 묶음.** 1단계에서 확인한 병목에 맞춰 결과 분해 또는 검증된 개념 감독 하나를 주 모델로 정한다. 같은 encoder·표현·예산·학습 상태·seed 목록을 맞추고, 필요하면 동결 표현 비교 후 encoder 학습을 별도로 추가한다. seed 반복은 최적화 안정성 자료이며 독립 출처 반복으로 세지 않는다. 기본 정책·선택·보정 임계값을 모두 고정한 뒤 새로운 확인 가족을 평가한다.

| 제시할 주장 | 필요한 비교·제거 실험 | 필요한 관측 |
| --- | --- | --- |
| 무기억 능력을 나누는 감독이 유용하다 | MSE vs 3분류 vs 4분류 vs 두 출력; 같은 입력과 예산 | 새 가족의 개선·악화, 확률 NLL/Brier, 정책 결과 |
| 특정 적용 조건을 배우는 것이 유용하다 | 정답만 vs 속성 감독; 한 속성씩 제거해 재학습; 부분 오라클 교체 | 직접 적용성·실제 효용을 각각 평가, 개선/악화 사례 연결 |
| 선택기가 고정 제공보다 유용하다 | 무기억·개발 고정 기억·검색·규칙·학습 선택기 | 성공 차이, 해친 기존 성공 수, 제공률, 선택기 포함 총비용 |
| 정보 조각의 포함이 작업 결과를 바꾼다 | 같은 현재 상태에서 근거 있는 조각 포함/제거, 공통 안내·예산 통제 | 동일 worker의 실제 출력·검사·비용, 조각 간 상호작용 |
| 큰 모델의 감독이 유용하다 | 라벨만 vs 검증된 속성/근거; 교사 품질 사전 확인 | 독립 가족의 효과, 교사 작성 비용·추론 의존성 |
| 악화를 억제하면서 필요한 개입을 한다 | 사전 고정 기본 정책과 여러 보류율 | 전체 악화율·개입 중 악화율·개선·제공률·비용 곡선 |

모델에 입력 특징을 사후 삭제하는 것만으로 그 특징의 학습상 필요성을 입증하지 않는다. 재학습한 제거 비교와 예측 개념 수정의 진단을 구분한다. 기억 문장 삭제의 영향도 길이·배치·정보량이 함께 변하면 ‘그 문장의 행동 지시성만의 효과’로 해석하지 않는다.

주 지표는 기본 정책 대비 짝 성공 차이와 악화 수, 선택기 포함 비용이다. 가능하면 독립 가족 단위의 불확실성 구간을 보고한다. 가족이 매우 적으면 정밀한 유의성 주장 대신 사례·구간·전체 분모를 제시한다. 관측 행동 oracle의 선택 regret도 유용하지만 전체 과제의 최적 해법과 같지는 않다. 과제당 여러 행동·fixture·파생 문장을 독립 표본으로 세지 않는다.

이 조사에서 권하는 기여는 새로운 손실함수의 이름이 아니다. **출처에서 검증한 어떤 조건을 남기고 학습시킬 때, 어떤 작업자의 어떤 현재 상태에서 기억의 개선·악화가 달라지는지를 재현 가능하게 보여주는 것**이다. 결과 분해·개념 감독·보류 정책은 그 질문을 측정할 수 있게 만드는 후보들이다.
