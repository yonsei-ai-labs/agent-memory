## 이후 학습과 데이터의 판단 기준

1. 자료 설계: 같은 적용 관계를 여러 실제 출처에서 확보한다. 명령·응답·코드·버전과 현재 관측을 연결하고, 관측된 상태와 편집한 상태를 분리한다. 불충분한 관측을 자동으로 충돌/무용함으로 바꾸지 않는다. 자료와 검토된 출처 수·핵심 대조 수를 별도로 센다.
2. 좁은 학습 진단: CE, 기존 margin 대조, 관계별 일관성 제약, 직접 분류를 보존한 표현 대조를 비교한다. 같은 데이터·초기화·업데이트·개발 선택을 유지하고 추가 연산을 기록한다. 틀린 두 답의 상대 점수만 벌리는 것을 성공으로 세지 않는다.
3. 표현 경로: pair/joint의 기존 비교를 유지한다. token 수준 상호작용이나 역할별 보정층은 남은 오류에 맞는 비교로 한정한다. 층 수·자료·감독을 동시에 바꾸어 한 요소의 효과로 해석하지 않는다.
4. 선택 정책: 관계 판단, 후보 순위/제공·보류, 실제 고정 작업자의 성공·오류·비용을 구분한다. 항상 제공·항상 보류·검색/규칙·학습 선택과 비교한다. 관계 라벨을 실제 득실 정답으로 복사하지 않는다. 실행형 소규모 과제를 쓰면 SWE 전체 개선과 구분한다.
5. 새 확인: 개발 오류를 보고 바꾼 모델에는 새 출처 또는 미사용 조건의 확인 집합을 둔다. 같은 부모의 표현·가림·상태 대조는 동일 분할로 묶는다. 자료의 불확실성이 해소되지 않으면 억지로 학습 조건을 늘리지 않는다.

## 검토할 학습 아이디어

- [Supervised Contrastive Learning](https://arxiv.org/abs/2004.11362): 같은 정답 관계의 표현을 모으는 보조 손실. 이미지 논문의 이득을 코드 기억에 전제하지 않고 CE와 함께 비교한다.
- [ColBERTv2](https://arxiv.org/abs/2112.01488): 한 벡터 이전의 token 수준 상호작용에 관한 참고. 검색 relevance와 기억 적용 가능성은 다른 목표다.
- [SelectiveNet](https://arxiv.org/abs/1901.09192): 보류를 포함한 학습·risk/coverage 비교의 참고. 오류가 적다는 이유만으로 대부분의 기억을 버리는 정책을 우수하다고 판단하지 않는다.
- [MGPO](https://arxiv.org/abs/2609.37930): 고정 reader에 대한 기억의 추가 기여를 학습 신호로 분리하는 참고. 실제 반사실 실행 없는 관계 주석을 효용으로 대신하지 않는다.

위는 검토 후보이며 구현·효과가 확인됐다는 기록이 아니다. 추가 논문의 구체 방법과 우리의 변형은 실행 전 개별 설계에서 구분한다.
