# 같은 여행 기억·입력의 9B 작업자 전이 진단

4B 파일럿 생성·채점·토큰 검산 후 추가하는 **사후 진단**이다. 평가 16개 요청의 무기억 출력이 모두 `NONE`이었고, 정확한 참조 기록을 받은 경우에도 가격 조건 위반과 불필요한 무응답이 남았다. 이 결과로 기억 선택기의 일반적 효과를 결론 내리기 전에 작업자 의존성을 확인한다.

Qwen3.5-4B가 이미 생성한 과거 선택 132개, 현재 22개 요청, 두 정보 조건, 5개 정책, 기본 생성 220개와 반복 10개를 모두 고정한다. **새로운 과거 선택은 만들지 않는다.** 현재 작업자만 `Qwen/Qwen3.5-9B@c202236235762e1c871ad0ccb60c8ee5ba337b9a`로 바꾼다. LoRA 모델·임계값 0.25·BM25·규칙·출력 48토큰·greedy·thinking off는 유지한다.

새 GPU에서 선택기를 다시 추론하고 시간을 측정하되, 4B 실행과 선택된 기억 ID 및 230개 작업자의 메시지가 모두 같아야 현재 생성을 시작한다. Test 결과를 본 뒤 선택기를 재학습하거나 프롬프트를 수정하지 않는다. 같은 자료의 사후 모델 비교이므로 새 독립 출처의 확인 실험이라고 주장하지 않는다.

원래 채점과 정책 비교를 유지한다. 추가 분석에서는 가능한 식당이 있는/없는 경우와 재사용/비교를 나눈다. 4B의 무기억 성공은 모두 실제 가능한 식당이 없는 경우의 `NONE` 출력에서 발생했으며, 기억의 득실 해석에서 이 우연한 정답을 숨기지 않는다. `UNKNOWN`과 `NONE`의 구별 실패도 기록한다.

9B의 과거 생성 비용은 새로 발생하지 않는다. 원래 과거 출력에 저장된 비용은 출처 기록이며 이번 비용에 다시 합산하지 않는다. 현재 작업자 생성·새 선택기 측정·모델 로딩과 전용 Colab 실행 비용을 따로 기록한다. A100 controller 상한 2,100초, 실행 상한 1,800초이며 중간 회수와 종료 처리는 동일하다.

이 비교는 더 큰 작업자가 무조건 좋다는 주장을 위한 것이 아니다. **관계 선택의 정확성, 선택한 정보를 사용한 판단, 실제 성공·비용의 차이를 구분**하는 것이 목적이다. 결과와 무관하게 같은 과제를 계속 고쳐 점수를 올리는 실험은 이 회차에서 진행하지 않는다.
