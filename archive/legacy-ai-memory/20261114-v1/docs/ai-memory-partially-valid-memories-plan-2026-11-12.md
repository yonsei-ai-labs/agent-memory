# 현재 일부 정보가 갱신된 기억의 활용 연구안

**현재 우선 방향에서 보류함.** “상황을 한정해도 된다”는 요청을 기억 내용의 부분적 유효성으로 좁혀 해석한 제안이었음. 현재 방향은 [특정 업무 상황에서의 경험 기억 선택](ai-memory-situation-specific-direction-2026-11-12.md)에 정리함. 아래 문헌·기존 결과 재집계는 보존하며, 이 제안에 따른 새 학습은 실행하지 않았음.

2026-11-12. 동료 논의와 다음 개발 실험을 위한 제안임. 연구 범위를 **현재 관측으로 일부 정보가 갱신됐지만, 과거 기록의 다른 정보는 현재 요청에 여전히 필요한 경우**로 정함. 목표는 필요한 근거를 보존하면서 과거 값을 현재 값으로 잘못 적용하는 일을 줄이는 것임. 일반적인 기억 질문 전체에서 검색을 대체할 필요는 없음.

핵심 질문은 다음과 같음.

> 같은 과거 기록에서 현재에도 필요한 정보와 현재 답에 적용할 수 없는 정보를 구분하여 전달하면, 전체 제공·전체 보류·간단한 갱신 규칙보다 실제 득실이 개선되는가?

최신 STATE-Bench의 중복 교환은 후속 적용 후보로 유지함. 현재 선택 시점 안에서 개입할 수 없었던 한 사례를 이번 연구의 대표 성과나 확정된 선택기 실패로 사용하지 않음. 이번 작업은 문헌 확인·저장 결과 재집계·설계 정리이며 새 학습·작업자 호출·GPU 사용은 없음.

## 범위를 이렇게 정하는 이유

처음 질문인 “같은 경험에서 무엇을 보존하고 어떻게 사용해야 이득인가”와 직접 연결됨. 현재 정보가 추가됐을 때 과거 기억 전체를 버리면 여전히 필요한 대상·기간·목적을 잃을 수 있음. 반대로 전체를 제공하면 이전 값이 현재 답을 방해할 수 있음. 두 비용을 같은 출처·같은 질문에서 비교할 수 있는 좁은 연구 문제임.

설명을 위한 예를 들면 과거 기록에는 “팀 A의 X서비스는 월 단위로 갱신됐고 요금은 10만 원이었다”가 있고, 현재 관측에는 “같은 계약의 요금만 12만 원으로 변경됐으며 다른 조건은 같다”가 있음. 현재 요금과 갱신 주기를 묻는다면 과거의 월 단위라는 정보는 필요하지만 10만 원을 현재 요금으로 답하면 안 됨. 이 예는 설계 설명이며 새로 측정한 자료가 아님.

범위는 한두 상품이나 문장 틀로 제한하지 않음. 동일 대상·속성·적용 기간을 확인할 수 있는 비용·수량·설정 등의 원문에서 같은 관계를 확보함. 최신 발화라는 사실만으로 권위나 갱신을 가정하지 않음. 서로 다른 사람·기간·예산 범위의 숫자는 갱신 쌍이 아님.

기존 47행 저장 CSV를 다시 집계함. 기록된 출처 그룹은 LME 32개와 BEAM 11개이며, 총 47문항을 47개의 독립 출처로 세지 않음. `현재 관측만 / 옛 원문 추가 / 옛 값 표시 / 옛 값 가림`의 정답은 LME 31/28/28/24, BEAM 11/10/10/5로 기존 보고와 일치함. [재집계 코드·결과](design-data/memory-partial-validity-20261112-v1/README.md)에 입력 해시를 보존함. 기존 채점의 재집계이며 의미적 독립 재주석이나 새로운 성공률 측정은 아님.

따라서 “일부 정보만 전달하면 좋아질 것”은 여전히 가설임. 다음 실험의 첫 목적은 사람이 근거를 검토하여 구성한 조건에서도 이득을 유지하며 손해를 줄일 여지가 있는지 확인하는 것임.

## 자료의 포함 기준과 대조

자격은 작업자 결과를 보기 전에 원문·현재 관측·질문으로 정함. 같은 대상과 속성의 명시적 갱신, 옛 기록에 남은 별도 정보, 그 정보가 필요한 요청을 근거 위치로 연결함. 대상·기간이 불명확하면 미확인으로 남김. 실패를 만든다는 이유로 포함하거나, 모델이 이미 잘 푼다는 이유로 제외하지 않음.

| 상태 | 현재 관측과 질문 | 검사할 판단 |
| --- | --- | --- |
| 미갱신 | 현재 값에 대한 새 관측이 없음 | 옛 정보를 무조건 폐기하지 않는가 |
| 일부 갱신 | 같은 대상의 값만 명시적으로 바뀌었고 다른 필요한 맥락은 과거에만 있음 | 남은 맥락을 유지하면서 이전 값을 현재에 적용하지 않는가 |
| 전부 충족 | 현재 관측에 값·대상·기간 등 필요한 정보가 모두 있음 | 불필요한 과거 제공을 줄이는가 |
| 다른 범위 | 새 발화가 다른 사람·속성·기간을 설명함 | 새 숫자를 무관한 과거 정보의 대체값으로 취급하지 않는가 |
| 과거 질문 | 최신 상태가 있더라도 질문이 이전 시점을 지정함 | 과거 값을 역사적 정답으로 사용할 수 있는가 |

가능하면 실제 시간순 발화에서 관측 상태를 확보함. 통제된 상태 변경은 원문과 분리해 표시하고, 바꾼 전제에 따라 관계 정답을 재검토함. 문장 변형·상태 변경은 같은 출처 그룹에 묶음. 원래 자료의 알려진 정답이나 채점기 필드를 모델 입력에 넣지 않음.

기존 47문항과 복합 기억 평가 자료는 발견·회귀 진단에 사용함. 새 수집은 별도 원문 그룹에서 진행하고, 학습·개발·확인 분할을 증강 전에 고정함. 기존 확인 예약 자료를 자동으로 새 train으로 돌리지 않음. 수집 대장은 검토 후보 수·적격 수·제외 사유·독립 출처 그룹 수를 모두 기록함. 이 좁은 조건의 적격 비율을 전체 사용자 업무에서의 발생률로 부르지 않음.

자료 확대의 첫 작업 단위는 별도 후보 출처 100개의 자격 검토를 제안함. 이는 수집 목표이며 충분한 표본 수라는 주장이 아님. 효과를 보고 적격 기준을 바꾸지 않고, 적격 출처가 부족하면 변형 수로 채우지 않음. 후속 확인 규모는 개발에서 관측한 출처별 차이와 검출하려는 효과 크기로 정함.

## 전달 행동을 먼저 검증함

원본 저장소와 검색은 유지하고, 같은 후보를 받은 뒤 전달 내용을 정하는 부분을 비교함. 첫 단계의 행동은 **원문 제공 / 근거가 연결된 원문 구절 제공 / 해당 기록 보류**로 제한함. 원본은 덮어쓰지 않으며 새 사실이나 새 값을 생성해 넣지 않음.

구절을 제공할 때 주체·날짜·적용 범위·부정·인용·대명사 선행어가 필요한지 확인함. 원문에서 그대로 잘랐더라도 의미가 변할 수 있음. 독립된 의미를 유지할 수 없는 혼합 문장은 구절 추출 부적격으로 기록함. 검토자도 보존과 배제를 동시에 할 수 없는 사례를 작은 모델의 실패로 바꾸지 않음.

먼저 고정 작업자에서 현재 관측만, 옛 원문 전체, 시간·범위 표시를 일관되게 붙인 원문, 검토한 근거 구절을 비교함. 마지막은 사람의 근거 주석을 쓰는 진단 조건이며 배포 가능한 정책이나 이론적 성능 상한이 아님. 공통 표시만의 효과와 구절 제거 효과를 구분하고, 양쪽에 같은 안내를 사용함. 과거 물음표 가림은 기존 실패 결과로 유지함.

이 비교에서도 필요한 맥락의 이득이 유지되지 않거나 단순히 현재 관측만 주는 것이 우세하면, 구절 선택 학습으로 넘어갈 근거가 약함. 다른 원문 의미 단위를 검토하거나 해당 가설의 제한으로 보고함. 실패 사례를 지워 평균을 올리지 않음.

## 학습할 경우의 최소 구성

기존 Harrier를 사용하되 이번 관계를 기존 모델이 이미 배웠다고 가정하지 않음. 기본 검색이 만든 고정 후보를 대상으로 목표·현재 관측·기억 구절과 주변 문맥을 읽는 판독기를 비교함. 두 판단을 각각 감독함.

1. 이 구절이 현재 요청에서 아직 부족한 근거를 제공하는가.
2. 이 구절의 값을 현재 답에 적용하는 것이 관측된 갱신·적용 범위와 어긋나는가.

한 기록 안에서 두 신호가 동시에 존재할 수 있으므로 단일 “좋은 기억/나쁜 기억” 정답으로 압축하지 않음. 과거에는 사실이었던 값도 현재 답에 적용할 수 없을 수 있음. 두 번째 라벨을 출처의 거짓 여부나 실제 손해 라벨로 부르지 않음. 미확인은 손실 계산에서 가리고, 이후 작업자 결과는 별도 저장함.

첫 학습은 알려진 근거의 필요성·현재 적용 불가 여부에 대한 분류 손실로 시작함. 같은 기억·질문에서 현재 관측만 바꾼 대조에 보조 손실을 넣는 조건 하나를 추가 비교할 수 있음. 대조 점수 차이가 커졌다는 것만으로 양쪽 분류가 맞았다고 보지 않음. 정확한 상태별 판정과 작게 고정한 자료의 학습 가능성을 먼저 확인함.

판독층만 학습한 기준과 LoRA를 같은 입력·출처·실제 학습 토큰량·두 seed로 비교함. 가중치와 임계값은 개발 자료로 고정함. 첫 회차에서 새 대형 모델·강화학습·복수의 추가 계층을 동시에 도입하지 않음. 작업자의 성공 여부로 원문 관계 주석을 덮어쓰지 않음.

## 성공을 판단할 비교와 지표

기본 Harrier 검색, 최신 기록 우선, 동일 대상·속성의 명시적 갱신 규칙, 질문만 보는 구절 선택, 질문+현재 상태를 보는 구절 선택을 비교함. 모든 정책이 같은 후보·관측 시점·작업자·전달 예산을 받게 함. 정상적인 단순 검색 조건도 함께 유지하여 특수 조건 밖의 회귀를 확인함.

| 측정 수준 | 지표 | 해석 |
| --- | --- | --- |
| 관계 판단 | 필요한 근거 확보, 현재 적용할 수 없는 값의 전달, 미확인 비율 | 실제 성공·손해와 분리한 중간 판단 |
| 작업 결과 | 정답, 잘못된 값 단정, 적절·부적절한 보류, 업무라면 상태 변경 | 답변을 모두 보류해서 오류만 줄이는 결과를 개선으로 채택하지 않음 |
| 대응 득실 | 기준 정책의 실패→성공, 성공→실패 | 같은 출처·같은 시작 상태에서 비교하며 한 번의 출력을 고정 인과효과 라벨로 부르지 않음 |
| 비용 | 전체 입력·출력, 선택기 포함 지연, 추가 도구·검증 호출 | 기억 토큰만 줄어든 결과와 실제 비용 절감을 구분함 |
| 적용 범위 | 적격 비율, 특수 조건·일반 조건별 효과, 출처별 편차 | 좁은 효과를 전체 업무 성적으로 확대하지 않음 |

개발에서는 원문 전체보다 손해를 줄이면서 전체 보류보다 필요한 맥락을 잘 보존하는 정책이 있는지 확인함. 확인 단계에서는 미리 고정한 주 기준선과 성공률 차이·잘못된 적용·비용을 함께 보고하고 출처 그룹 단위의 불확실성을 제시함. 같은 출처의 여러 상태를 독립 표본으로 세지 않음.

단순 규칙으로 같은 결과가 나면 데이터·측정의 결과와 규칙의 효과를 정리할 수 있음. 학습 모델의 추가 가치는 그 이후의 주장임. 구조화된 갱신이 주어지는 이 범위에서 성과가 나더라도 자유로운 에이전트 진행 이력 전체로 일반화하지 않음.

## 바로 이어갈 작업

기존 47문항을 이용해 의미가 분명한 구절과 맥락이 얽힌 구절을 구분하는 주석 예시를 정리하고, 별도 후보 출처 100개의 포함 기준·분할 대장을 먼저 마련함. 학습보다 앞서 원문 전체·현재 관측만·근거 구절의 개발 진단을 고정함. 이 과정에서 순 이득을 보존할 수 있는 전달 단위가 확인되면, 그 관계를 작은 모델이 학습하는 실험으로 이어감.
