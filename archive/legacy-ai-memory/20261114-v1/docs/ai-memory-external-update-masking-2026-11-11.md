# 옛 기억의 맥락과 수치를 분리하는 설계 실험

2026-11-11. [직전 설계 결과](reports/2026-11-11-external-update-validation.md)에서 옛 기억 추가로 6문항 악화·2문항 개선이 관측됨. **옛 기록의 대상·기간·활동 설명을 남기면서 이전 수량을 가리면, 맥락의 이득을 남기고 수치 간섭을 줄일 수 있는지** 검토함. 이는 이미 본 설계 자료의 개입 진단이며 새 선택기의 성능이나 외부 일반화 시험이 아님.

## 실행 전에 고정한 비교

기존 설계 47문항(LME 32·BEAM dev 15)을 전부 유지함. 실패한 문항만 고르거나 정답·질문·새 근거를 수정하지 않음. Qwen3.5-9B의 가중치 revision, greedy 생성, 단일 수량 지시문, 기억 예산 8기록·1,024토큰을 유지함.

| 조건 | 현재 관측 | 옛 기록 처리 | 실행 |
| --- | --- | --- | --- |
| current_new | 새 근거 | 없음 | 같은 입력의 기존 47출력 재사용 |
| current_new_plus_old | 새 근거 | 원문 | 같은 입력의 기존 47출력 재사용 |
| old_values_marked | 새 근거 | 검토한 부분을 `[[value: 원문]]`으로 표시 | 47호출 |
| old_values_masked | 새 근거 | 같은 부분을 `[[value: ?]]` 형태로 가림 | 47호출 |

물음표 수를 조정해 **표시 조건과 가림 조건의 전체 입력 토큰 수를 정확히 같게 함**. 새 사실이나 무관한 문장을 넣지 않음. 양쪽 모두 같은 표시 형식을 사용하며 '낡음', '오답' 같은 판단은 주입하지 않음. 원문↔표시 비교로 형식 자체의 영향을 따로 봄. 가림↔현재 관측만 비교는 맥락 제공 효과의 진단이며 길이가 같은 대조가 아님.

## 가릴 부분과 남길 부분

[47문항·61구간의 주석](design-data/external-update-masking-20261111-v1/span-reviews.jsonl)에 원문 위치·인용·해시·이유를 기록함. 수정하지 않는 부분은 글자 단위로 보존함. 주석은 이 에이전트의 단일 검토이며 독립 주석자 일치도를 측정하지 않음.

- 과거 예산 35뿐 아니라 '43을 써서 8 초과'의 계산 피연산자도 가림. 같은 변수의 더 오래된 값과 반복된 값도 가림.
- 날짜, 모델명, HTTP 오류 코드, 다른 시장의 매출처럼 별도 변수는 유지함. 모든 숫자를 지우는 실험이 아님.
- 여성 수는 '10명 중 half'의 half를 가림. 팀 크기와 다른 모집단의 비율은 남김.
- 카메라 여행과 자전거 문항은 열거 목록으로도 과거 개수를 알 수 있어 목록도 가림. 장소·종류까지 제거하는 2문항은 `quantity_and_enumeration`으로 표시하고 **수량 표현만 제거한 주 분석 45문항과 분리**함. 전체 47문항 결과도 빠짐없이 보고함.
- 근삿값 인스타그램 문항은 기존 모호성 표시를 유지함. 현재 자전거 발화에도 소유 단서가 있으므로 그 실패를 근거 부족으로 단정하지 않음.

책·구독료의 범위, 운동화의 연간 예산, 인터뷰 직무, 단어 학습 도구는 옛 기록의 맥락이 새 발화와 연결될 가능성이 있으나, 옛 기록을 붙였다고 그 연결의 논리적 충분성을 보장하지 않음. 특히 '책 예산'이 '책과 구독료 전체'를 뜻하는지, 새 250단어 모두 같은 도구로 학습했는지는 별도 가정이 남음. 이번 실험은 원래 정답 계약을 유지하되 이러한 해석 한계를 결과에 표시함.

## 분석·중단 경계

주 분석은 출처별 `old_values_marked → old_values_masked`의 성공→실패·실패→성공 및 수량 표현만 가린 하위 집합임. 원문→표시, 현재 관측만→가림, 원문→가림도 보고함. 같은 대화의 문항과 같은 문항의 네 조건을 독립 표본으로 늘려 세지 않음.

채점은 직전의 단일 수량 판정기를 그대로 사용함. 단위·설명이 있는 답은 출력 해시·근거와 함께 검토하고 미해결은 null로 유지함. 캐시한 답의 판정은 바꾸지 않음. 토큰 검산, 원문 복원, 실제 업로드·결과 ZIP, 모델 해시를 CPU로 검산함.

이번 회차는 **94개 새 입력·고정 2반복까지만** 실행함. 확인용 BEAM 33문항의 모델 출력은 생성하지 않음. 설계 결과를 본 뒤 편리한 가림 형태를 골라 확인 결과와 합치지 않음. 다음 확인 실행은 여기서 얻은 입력 설계와 충분성 해석을 정리한 별도 고정 계획으로 진행할 사안임.

목표는 사람이 정답 근거를 아는 상태에서 한 조각의 개입 효과를 측정하는 것임. 유효한 결과가 나오더라도 자동 선택·가림 모델을 이미 만들었다고 주장하지 않음. 이후 원문 근거 위치·적용 조건을 감독하는 학습 자료 후보로 사용할 수 있으며, 실제 제공 효과 라벨은 관계 주석과 별도로 보존함.

## 자원과 기록

추가 학습·유료 모델 API 호출은 없음. 소유 Colab L4 한 세션에서 고정 작업자만 실행하고 회수 직후 종료함. 기존 컨트롤러 3,300초 상한을 사용하며, 새 부트스트랩은 비-daemon 타이머로 3,600초 자체 반환을 유지해 본문 종료 후에도 반환 시도가 사라지지 않게 함. 정상 종료는 컨트롤러가 먼저 처리함.

입력·코드·이 계획의 해시는 [사전 고정 파일](design-data/external-update-masking-20261111-v1/preregistration.json)에 기록함. 이전 v2 고정 코드·자료는 수정하지 않음.
