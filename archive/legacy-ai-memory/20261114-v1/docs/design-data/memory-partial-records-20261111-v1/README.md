# 일부만 확인된 복합 기억의 보존: 고정 실험안

2026-11-11 작성. 첫 모델 실행 전에 자료·손실·학습량·판정 기준을 고정함. 결과는 별도 보고서에 기록함.

이전 실험의 개선은 유지되지만, 한 기록에 두 사실이 있고 그중 하나만 현재 관측에 나타나면 기록 전체를 보류하는 실패가 남았음. 이전 개발 자료에서 이 조건의 독립 출처는 1개뿐이었음. 이번에는 원문 근거가 있는 여러 출처로 이 조건을 보강하고, 데이터 보강 효과를 단순 임계값 조정과 분리해 검사함.

## 출처와 구성

- 고정 Mem2Act 원문 풀에서 이전 source-scale 기록 및 최초 예약 집합에 속한 그룹을 제외함. 여러 세션의 원출처 연결을 합친 그룹으로 먼저 train/dev/test를 예약함. 이후 각 구간에서 역할이 명확한 두 정보를 가진 실제 원문을 검토함.
- 새 출처 30개: 학습 12개, 개발 6개, 평가 12개. 이미 내려받은 공개 벤치마크의 미사용 출처이며 새로 수집한 자연 에이전트 실행은 아님.
- 학습에는 기존 검토 완료 train 출처 8개도 포함하여 복합 기록 대조 출처 20개를 구성함. 기존 train 상태 80개를 양쪽 조건에 똑같이 섞음. 전체 학습 그룹은 30개임.
- 각 출처의 두 원문 구절을 각각 별도 기록으로 주는 atomic과, 두 구절을 개행으로 이어 한 기록으로 주는 compound를 만듦. 합친 문장이 원문에서 연속된 하나의 문장이었다고 주장하지 않음. 사실은 같고 기록의 경계만 다름.
- 두 사실 모두 요청 / 하나만 요청, 관측 없음 / 하나 관측 / 둘 다 관측을 조합한 8개 상태를 고정함. 같은 기억·같은 관측이어도 요청한 정보에 따라 제공 필요성이 바뀌는 대조를 포함함.
- 현재 관측은 통제하여 작성한 문장임. 실제 도구 수행 이력이나 실패 이력이 아님. 주석은 구축 에이전트의 원문 검토이며 독립 인간 이중 주석이 아님.
- 평가 384상태는 12출처의 종속된 변형임. 384개의 독립 경험으로 계산하지 않음. 학습·개발에 없는 prose 관측 표현을 평가에만 포함함.

원문·구절·위치·역할은 `source-specs.json`, 선예약은 `source-reservation.json`, 검토 내역은 `intake-decisions.jsonl`에 기록함. 코드에서 원문 부분문자열과 정답 근거, 출처 격리, 필드 이름의 정답 누출, 학습 조건 간 사실 보존을 검사함.

## 학습과 임계값 비교

| 조건 | 같은 현재 상태를 두 번 보여주는 방식 | 학습량 |
|---|---|---|
| 고정 이전 모델 | 추가 학습 없음 | seed 731/1729의 이전 single 모델 |
| control | atomic + atomic | 400상태 항목 × 2 epoch, 200 update |
| augmented | atomic + compound | 400상태 항목 × 2 epoch, 200 update |

각 seed의 두 학습 조건은 동일한 이전 가중치에서 시작함. 마지막 epoch를 사용하며 개발 최고점으로 checkpoint를 고르지 않음. Harrier 0.6B의 기존 rank-8 q/v LoRA와 동일한 need 판독층을 계속 학습함. 별도 goal-link 손실은 추가하지 않음.

기록을 합치면 후보 개수와 제공 필요 정답 비율이 달라짐. 상태별 균형 교차 엔트로피에 학습 집합 전체 클래스 보정 계수를 곱해 양·음성의 총 손실 질량을 각각 0.5로 맞춤. 이 알고리즘은 두 조건에 동일하게 적용함. 입력 길이와 후보 쌍 수는 기록 결합에 수반되는 차이로 남으며, 완전히 같은 토큰 수의 비교는 아님.

각 모델은 고정 임계값 0.5와 개발 출처에서만 고른 임계값을 둘 다 보고함. 개발 기준은 출처별 균형 정확도의 평균이며, 후보 임계값은 0.05 간격의 0.05–0.95임. 동률이면 0.5에 가까운 값, 다시 동률이면 높은 값을 사용함. 여섯 모델의 임계값과 가중치 해시를 모두 저장한 뒤 평가 추론을 시작함. 작업자 결과는 임계값 선택에 쓰지 않음.

## 평가와 해석

선택 평가: 현재 필요한 정보의 완전 확보, 불필요한 기록 제공, 모두 알려진 상태의 보류, 출처별 균형 정확도, atomic/compound 및 direct/prose 조건별 결과를 보고함. 새 자료뿐 아니라 기존 incremental·source-scale·BEAM 개발 자료도 고정 임계값으로 다시 평가하여 손실을 확인함. 기존 개발 자료는 새로운 확인 자료로 취급하지 않음.

작업자 평가: 사전에 정한 전체 compound/prose 96상태를 같은 Qwen3.5-4B로 실행함. 모든 학습 조건과 임계값을 비교하며, 무기억·BM25·문자열 중복 제거·전체 제공·정답 근거 제공 조건도 유지함. 정답 문자열과 근거가 함께 충족된 성공, 근거 없는 추측, 제공 토큰과 시간을 구분함. 정답 근거 조건은 진단이며 작업자 성능의 수학적 상한이 아님.

후보 은행은 1–2개 기록이며 모두 예산 안에 들어감. 따라서 여과 없는 검색 상위 2개와 전체 제공은 같은 정책임. 이 실험만으로 복잡한 검색, 실제 예산 경쟁, 장기 작업 수행이나 학습 선택기의 일반적 우월성을 입증하지 않음. 이번 질문은 부분 관측 때문에 필요한 기록을 잘못 버리는 오류의 수리 가능성과 비용임.

로컬 GPU 한 작업만 사용하고 종료 시 해제함. 추가 API 호출·Colab 할당은 없음. 원본 자료·이전 checkpoint는 수정하지 않음.

## 실행

```bash
.venv/bin/python -m data_pipeline.partial_record_data audit
.venv/bin/python -m unittest tests.test_partial_records tests.test_incremental_evidence
runs/memory-source-scale-20261111-v1/env-harrier/bin/python -m training.memory_selector.train_partial_records
runs/memory-source-scale-20261111-v1/env-worker/bin/python -m training.memory_selector.run_source_scale_worker_local --data runs/memory-partial-records-20261111-v1/worker-input --output runs/memory-partial-records-20261111-v1/worker-results
```
