# 데이터 보완을 위한 첫 재검토 묶음

2026-11-09. 기존 데이터·라벨을 바꾸지 않고, 학습 split의 기존 관계를 눈가림 재판정할 자료를 준비함.

- `review-batch/reviewer/`: 검토자에게 전달할 폴더. 현재 이슈·기억·과거 근거와 빈 양식만 포함함.
- `review-batch/maintainer/`: 기존 정답·대응표·선정 규칙. 검토자에게 같이 전달하지 않음.
- `prepare_review.py`: 새 출력 폴더에만 생성하는 준비 코드. 기본 라이브러리만 사용함.
- `verification.json`: 입력 원문 일치·학습 split 한정·미작성 양식 확인.

기존 train의 양성 18개·미확인 23개와, 어휘가 겹치는 기존 음성 후보 23개를 합친 64개임. 현재 이슈 27개·기억 16개를 재사용함. **새 원천 0개·완료한 재주석 0개·새 학습 정답 0개임.** 음성 선정 점수는 검토 순서 제안이며, 진짜 어려운 음성임을 확인한 정답은 아님.

두 독립 검토자에게 reviewer 폴더의 별도 사본을 제공함. 사람이 검토하지 않았다면 사람 검수라고 부르지 않음. 원래 라벨과 모델 성적은 판정 후에 비교함. 현재 대조는 train만 사용하므로 dev/test 현재 문제의 새 검토를 시작하지 않았음.

새 위치에 재생성하는 예:

```bash
python3 docs/design-data/memory-data-remediation-20261109-v1/prepare_review.py \
  --output /tmp/memory-blind-review-new
```

기존 v1을 덮어쓰거나 이 묶음을 새 독립 평가로 쓰지 않음. 재검토가 완료되면 수정 이유와 출처·기존 분할을 보존한 새 데이터 버전을 만듦. 연구 보완의 전체 순서는 [보완 계획](../../ai-memory-data-remediation-plan-2026-11-09.md)에 있음.
