# 데이터 보강의 원인 분해: 형식 노출과 부분 관측 관계

2026-11-12. 새 학습 전에 고정하는 실행안임. 기존 세 성과 중 **데이터 보강으로 특정 선택 오류를 줄인 성과**를 더 정확히 설명하기 위한 실험임. 새 모델·벤치·업무 상황을 추가하지 않음.

## 질문과 핵심 비교

> 같은 기록 형식·사실·필요성 정답·고유 입력 수·학습량에서, 복합 기억을 부분적으로만 알고 있는 상태를 학습에 넣으면 형식 노출만 한 경우보다 제공·보류 판단이 나아지는가?

| 조건 | 모든 조건에 공통인 자료 | 나머지 160항목 |
| --- | --- | --- |
| repeat | 20출처의 atomic 160상태 + 이전 train anchor 80상태 | 원래 atomic 160상태 반복 |
| format | 같음 | compound를 사용하되 현재 관측은 없음 또는 요청 정보가 모두 확인된 상태 |
| relation | 같음 | compound에서 원래 8개 요청·관측 조합을 유지하여 부분 관측 상태까지 포함 |

주 비교는 **relation − format**임. 두 조건은 행마다 같은 원문·기억·요청·양성/음성 정답을 가지며, 후보 쌍 수·양성 비율·기록 형식 분포·고유 선택기 입력 수·손실 가중치도 같음. Format의 80행에서 부분 관측을 제거하되 그 기억이 여전히 필요한 양성이라는 사실은 유지함. 공통 atomic 자료에는 두 조건 모두 부분 관측 관계가 있음. 이 실험은 복합 기록 형식과 부분 관측 관계를 함께 경험한 효과를 구분함.

Format의 반복되는 무관측 상태는 네 가지 자연스러운 동일 의미 요청 문장으로 구분함. Relation도 정확히 같은 행에 같은 문장을 사용함. 문장 틀은 출처에 따라 순환 배정하여 각 틀의 양성/음성 수를 동일하게 맞춤. ID나 정답 이름을 입력에 넣어 고유 입력 수를 늘리지 않음.

관측을 제거하므로 **관측의 의미·길이 분포는 다름**. 의미 변화가 개입 대상이며, 총 선택기 토큰량까지 완전히 같은 실험으로 주장하지 않음. 원문 사실·기억 길이는 동일함. Repeat는 고유 입력 수와 형식 분포가 다른 추가 참고 조건이며, 주 비교와 섞어 단일 원인 효과로 해석하지 않음.

## 학습·평가 고정

- 기존 seed 731/1729의 같은 single checkpoint에서 각각 시작함. Harrier 0.6B·rank-8 q/v LoRA·need 판독층·원래 손실함수를 그대로 사용함.
- 세 조건 × 두 seed = 6회 학습. 각 400상태 항목·2epoch·200update, 마지막 checkpoint 사용. 평가 성적에 따른 조기 종료·추가 epoch·seed 선택 없음.
- 임계값은 0.5로 고정함. 이번에는 별도 임계값 탐색을 하지 않음. 모든 학습 종료 후 모델 해시를 고정한 다음 평가함.
- 주 지표는 기존 48개 부분 관측 compound 상태의 필요한 기록 보존임. 전체 384상태의 근거 확보·불필요 제공·이미 충족된 상태의 보류·출처별 관계 점수도 함께 보고함.
- 기존 BEAM 개발 자료의 과잉 제공을 회귀 진단으로 유지함. 개발 자료이며 새 외부 확인이라고 부르지 않음.
- 작업자 평가는 기존 compound/prose 96상태를 유지함. 동일 메시지 해시에 해당하는 Qwen3.5-4B 원 출력을 재사용하고, 새 호출은 하지 않음. 빠진 캐시가 있으면 새로 생성하지 않고 중단·보고함. 원래 고정 채점을 유지함.

평가 12출처는 학습에는 없으나 결과를 이미 여러 차례 확인한 자료임. 따라서 이번 결과는 **기존 평가에서의 원인 분해 진단**임. 새 독립 확인 결과로 설명하지 않고, 같은 상태의 문장 변형을 독립 경험으로 세지 않음.

## 해석 기준과 종료

Relation이 두 seed에서 부분 관측 보존과 후속 복원을 개선하고 불필요 제공의 증가도 제한적이면 관계 대조의 추가 기여를 지지함. Format만으로 비슷하게 회복되면 형식 노출·다양화가 주요 설명 후보임. 방향이 seed에 따라 다르거나 다른 상태의 회귀가 크면 그 범위를 그대로 보고함. 이번 결과에 맞춰 추가 조건을 늘리지 않음.

원문·가중치·기존 결과는 보존함. 실행 전 데이터 감사와 의미 대조 검사를 통과해야 함. 로컬 GPU의 다른 학습 작업이 없을 때 한 프로세스로만 실행하고 2시간 상한을 둠. 종료 후 GPU 메모리를 해제하며 Colab·유료 API는 사용하지 않음. 설계·자료 해시, 학습 노출 횟수, 실제 가중치·벡터·예측, 고정 채점·비용을 저장함.
