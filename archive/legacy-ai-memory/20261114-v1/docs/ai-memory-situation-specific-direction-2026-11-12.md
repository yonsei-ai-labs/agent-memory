# 특정 업무 상황에서의 경험 기억 선택 연구 방향

2026-11-12. 연구 범위를 특정 업무나 문제가 발생하는 상황으로 한정할 수 있음. 목표는 **그 상황에서 현재 조건에 맞는 과거 경험을 선택하여 성공을 높이거나 반복 실수·비용을 줄이는 것**임. 기억의 일부를 추출하거나 가공하는 것은 필수 연구 목표가 아님.

직전 [일부 정보가 갱신된 기억 연구안](ai-memory-partially-valid-memories-plan-2026-11-12.md)은 상황을 한정해도 된다는 요청을 기억 내용의 부분적 유효성으로 좁힌 제안이었음. 현재 우선 방향에서 보류하고 기존 근거·재집계 기록만 보존함. 사용자가 특정 상황 하나를 최종 선정한 상태는 아니며, 아래는 검토 후보임.

**현재 집중 범위 확정:** 사용자가 기존에 얻을 수 있는 성과에 집중하도록 요청함. [핵심 성과 보고서](reports/2026-11-12-memory-core-findings.md)에 상황별 득실·데이터 보강·측정 방법을 정리하고 [원 출력 재검산과 대표 사례](reports/data/memory-core-findings-20261112-v1/README.md)를 완료함. 아래 새 상황 후보는 현재 실행 대상으로 선택하지 않으며, 새 모델·벤치·상황으로 확장하지 않음.

이 범위 안에서 사용자가 승인한 [데이터 보강의 원인 분해](reports/2026-11-12-augmentation-ablation.md)도 완료함. 형식·고유 입력 수·정답 분포를 맞춘 두 조건에서 관계 대조의 추가 효과와 과잉 제공을 함께 확인함. 같은 모델·기존 출처를 사용한 후속 진단이며 새 업무 상황으로의 확대는 아님.

## 우선 완성할 연구 성과

우선순위는 **기존에 확인한 상황별 득실, 이를 측정하는 자료와 방법, 데이터 보강에 따른 학습 효과를 하나의 설명 가능한 결과로 정리하는 것**임. 검색보다 우수한 선택 모델의 개발은 이와 구분하여 검증함. 기존 비교 결과는 유지하고 연구 주장별로 필요한 근거를 연결함.

| 얻으려는 성과 | 이미 확보한 근거 | 완성할 산출물 |
| --- | --- | --- |
| 어떤 상황에서 기억이 도움이 되거나 해로운지 설명함 | 구성한 계획 변경 과제에서 이전 계획의 기억 두 개를 추가하면 12가족 중 7에서 성공이 깨졌음. 같은 실험의 반복 기억 30입력과 무관한 기억 12입력에서는 회귀가 없었음 | 원문·현재 상태·제공한 기억·실제 행동을 연결한 사례와 조건별 결과표. 문장 틀·출처·작업자 범위를 함께 명시함 |
| 관계 판단과 실제 득실을 구분하여 측정함 | 동일 작업자의 제공 전후 결과, 근거 확보, 비용을 분리한 실행 자료와 검산 코드가 있음. STATE-Bench에서는 도구 실행·DB 변화도 재계산함 | 다른 연구자가 같은 비교를 수행할 수 있는 데이터 명세·기준선·채점·재현 절차. 실제 측정하지 않은 효용 라벨은 비워 둠 |
| 어떤 학습 자료가 판단을 개선하는지 보여줌 | 같은 출처·상태 항목 수·업데이트 수의 복합 기록 보강 비교에서 새 12출처의 필드 복원이 단순 추가 학습 67–71/96에서 86–87/96으로 개선됨 | 데이터 구성의 차이, 고정한 조건, 관계 오류·후속 작업의 변화, 기존 자료 회귀를 연결한 학습 비교. 전체 제공/검색 88/96도 함께 보고함 |

첫 행의 근거는 [상태별 손해 분석](reports/2026-11-11-reportable-insights-note.md), 셋째 행은 [데이터 보강 실험](reports/2026-11-12-partial-record-learning.md)임. 이 두 결과는 서로 다른 자료·모델 비교이므로 보강 학습이 첫 행의 손해를 줄였다고 이어 붙이지 않음. 복합 기록 실험은 데이터 설계의 효과를 보여주는 기존 성과로 사용하며, 기억의 일부 가공을 앞으로의 필수 목표로 다시 설정하지 않음.

현재 이야기의 중심은 “같은 목표에서도 진행 상황이 달라지면 필요한 경험이 달라지고, 이를 구분하는 대조 자료로 특정 판단을 학습시킬 수 있으며, 관계 점수와 실제 작업 효과는 함께 측정해야 한다”임. 이 내용의 적용 범위와 선행연구 대비 차이를 명시하여 데이터·측정·학습에 관한 기여 후보로 정리함.

기존 결과의 대표 사례·비교표·재현 경로 정돈을 완료함. 당분간 이 근거 묶음의 정확성과 설명력을 보완하는 데 집중함. 새 모델·새 벤치·새 연구 방향을 추가하는 것을 진행량의 기준으로 삼지 않음. 아래 상황 후보는 검토 이력으로 보존하며 현재 착수 범위에서 보류함.

## 이후 상황 후보 — 현재 착수 보류

| 상황 | 선택할 경험과 측정할 효과 | 현재 근거와 제약 |
| --- | --- | --- |
| 상품 검색에서 빈 결과가 나오거나 비슷한 검색을 반복함 | 검색 조건 확인·사용자 재질문·대안 제시·종료 중 현재 제약에 맞는 과거 경험을 선택함. 조건을 어기지 않고 완료하는지와 반복 호출을 측정함 | 예산 초과 상품의 설명을 마친 사례가 있었지만 한 번 관측임. 일반적인 검색 안내만으로 같은 효과가 나는지 비교해야 함 |
| 도구 호출 실패 뒤 다음 행동을 정함 | 같은 재시도가 타당한지, 다른 절차가 필요한지, 이미 일부 처리됐는지에 맞는 복구 경험을 선택함 | 오류 응답 뒤 상태 일부가 바뀌는 도구 진단이 있음. 오류 기록이 일부 출처에 집중되어 독립 경험의 폭을 먼저 확인해야 함 |
| 사용자 요청이 바뀌거나 기존 처리가 끝난 뒤 대응함 | 이전 절차를 계속해도 되는지, 새 요청에 필요한 경험이 무엇인지 판단함. 중복 처리·잘못된 대상 변경을 측정함 | 중복 교환을 관측했지만 현 선택기는 해당 도구 루프 안에서 재판단하지 못했음. 같은 시점의 개입 비교가 먼저 필요함 |

검토 당시 첫 후보는 **쇼핑 탐색이 막힌 뒤의 대응**이었음. 현재 실행 환경과 긍정적 사례를 활용할 수 있기 때문이었으나, 기존 성과 정리에 집중하는 현재 범위에서는 새 실험에 착수하지 않음. 추후 다시 검토한다면 검색 조건을 잘못 좁힌 경우, 실제로 조건을 만족하는 상품이 없는 경우, 사용자가 대안을 허용하지 않는 경우를 구별할 자료가 필요함.

실행 결과의 근거는 [STATE-Bench 파일럿](reports/2026-11-12-statebench-experience-pilot.md), 도구의 부분 변경과 오류 기록 분포는 [준비 검토](reports/2026-11-12-statebench-preparation.md)에 있음. 이 후보들에서 학습 선택기의 추가 이득이 이미 입증된 것은 아님.

## 연구 질문과 비교

> 정해진 업무 상황에서 에이전트가 막혔을 때, 현재 목표·관측·시도 이력에 맞는 과거 경험을 선택하면 단순 검색보다 성공적으로 대응하고 같은 실패를 덜 반복하는가?

경험 단위와 표현은 먼저 고정하고, 작은 모델은 경험의 선택·보류를 학습함. 기억을 잘게 나누는 방법이나 새 요약 방식을 동시에 바꾸지 않음. 좁은 상황 안에서 기본 Harrier 검색, 일반적인 대응 안내, 간단한 상황 규칙, 학습 선택기를 같은 작업자·후보·예산으로 비교함. 일반 안내와 규칙은 경험 선택 없이도 해결되는 경우를 확인하는 데 필요함.

선택 시점은 결과를 보고 바꾸지 않음. 예를 들어 빈 검색 결과를 받은 직후를 대상으로 삼는다면 모든 정책이 같은 도구 결과를 본 상태에서 분기하도록 구성함. 현재의 사용자 턴별 선택과 혼합하여 비교하지 않음. 실패·미완료가 발생한 에이전트만 사후에 골라 모델 성적을 계산하지 않고, 관측 가능한 상황 기준으로 대상 집합을 정함.

## 데이터를 모으고 결과를 해석하는 기준

1. 먼저 해당 상황의 자연 경험과 대응 결과가 충분히 있는지 검토함. 같은 로그의 반복 오류나 여러 문장 변형을 독립 출처로 세지 않음.
2. 같은 업무 안에서 과거 절차가 유효한 경우·지금은 부적절한 경우·이미 할 필요가 없는 경우를 확보함. 적용 관계 주석과 실제 제공 효과는 분리함.
3. 새로운 출처를 남겨 학습·개발·확인을 구분함. 대상 상황에 해당하는 성공·실패 사례를 모두 집계함.
4. 작업 성공, 반복 호출, 잘못된 변경, 선택기 포함 비용을 함께 측정함. 좁은 상황의 효과와 그 상황 밖의 효과를 구분함.

모델의 추가 가치를 주장할 때에는 해당 상황 안에서 무기억·단순 검색·일반 안내·규칙과 비교해야 함. 데이터·측정 방법의 가치는 출처와 라벨의 타당성, 상황 대조의 설명력, 기존 평가에서 구분하기 어려웠던 실패의 진단, 재현 가능성을 기준으로 평가함. 규칙이 강한 결과도 학습 모델의 추가 가치와 구분해 보고함. 각 산출물의 연구 기여와 새로움은 그 범위를 명시해 판단함.

이번 정리에서는 기존 성과의 원 출력·정책 결정·채점을 CPU로 다시 대조함. 새 데이터 수집·학습·GPU·작업자 실행은 진행하지 않음.
