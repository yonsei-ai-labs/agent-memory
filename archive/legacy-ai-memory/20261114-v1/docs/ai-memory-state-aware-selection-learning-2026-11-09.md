# 작업 상태를 사용하는 기억 선택: 중심 가설과 학습 비교

2026-11-09. 최신 사용자 명확화를 반영함.

> 주 모델과 메모리 저장소를 동일하게 유지했을 때, 현재 목표·진행 상황·실패 이력을 고려하는 메모리 선택 모델이 같은 컨텍스트 예산에서 에이전트의 작업 성공률을 높일 수 있는가?

**이 질문을 중심 가설로 둠.** 데이터셋·측정 방법은 이 가설을 검증할 기반이자 연구 산출물이며, 상태를 사용하는 선택 모델과 실제 성공률 비교도 연구에 포함함. 직전의 모델을 활용 사례로만 두자는 제안은 이 목표를 충분히 반영하지 못했음. [앞선 데이터·측정 방향](ai-memory-dataset-and-measurement-direction-2026-11-09.md)은 당시 판단으로 보존함.

이번 작업은 기존 학습 코드·최신 자료 계약·관련 문헌 검토와 후속 설계임. 새 학습·worker/API 호출·GPU 할당은 하지 않았음.

## 현재 학습 방법에 대한 판단

기본 분류·질문별 순위·대조·일관성 학습은 적절한 비교 후보임. 이미 여러 방식을 구현·실험했으므로 단일 학습법만 시도한 상태는 아님.

| 확인한 코드 | 실제 수행하는 것 | 후속에서 볼 점 |
| --- | --- | --- |
| `train_development_leads.py` | 클래스 가중 분류, 질문별 후보 배치, 분류+질문별 순위 | 불균형 가중치만 추가하면 된다는 새 제안은 아님. 주석 품질·원천·관계 일반화를 별도로 봄 |
| `scope_method_objectives.py`, `train_scope_methods.py` | 두 관계의 분류·감독 대조·PCGrad·선택한 출력의 일관성 | 범위 과제에서 시도한 것이며 실제 기억 효용까지 학습했다고 부르지 않음 |
| `scope_method_design.py` | 해당 관계와 무관한 역할만 바뀌고 정답은 유지되는 짝 구성 | 이 일관성 제약은 역할/정답을 확인해 적용함. 모든 상태 변형에 일반화하지 않음 |
| `travel_candidate_search_loss.py` | 질문 은행 안의 여러 정답 기억을 올리는 분포 기반 검색 손실 | 하나의 정답만 있다는 가정을 하지 않는 기반임. 참조 검색과 실제 효용은 다름 |
| `train_travel_state_gate.py` | 현재+제안 묶음의 실제 제공/보류 네 결과를 학습 | 단일 고정 묶음의 제공/보류이며 진행·실패 이력을 쓰는 일반 선택 정책과 다름 |

방법이 다양하다는 사실 자체가 편향을 줄였다는 증거는 아님. 어떤 정보가 보이고, 무엇이 바뀌면 정답도 바뀌는지, 새 출처에서 판단을 유지하는지를 확인해야 함.

## 중심 가설을 검증하는 공정한 비교

고정할 것은 작업자 모델/revision·메모리 저장소·작업자의 초기 대화/도구 상태·전달 예산·채점·실행 예산임. 작업자는 모든 정책에서 같은 목표·진행·실패 관측을 유지함. **선택기가 그 상태를 이용하는지**를 주 비교로 둠.

필요한 기준선:

1. 무기억.
2. 목표/질문만 쓰는 단순 검색.
3. 목표/질문만 읽는 학습 선택기.
4. 목표+현재 관측+진행+실패 이력을 읽는 같은 계열의 학습 선택기.
5. 현재 정보 중복·명시적 전제를 사용하는 규칙 선택기.

3과 4의 구조·학습 예산·출력 행동을 맞춰야 상태 정보의 추가 가치를 평가하기 좋음. 선택기와 작업자까지 동시에 바꾼 비교는 주 가설의 검증으로 사용하지 않음.

같은 컨텍스트 예산은 같은 **상한**임. 빈 집합·작은 집합도 허용하며 길이를 채우기 위해 불필요한 기억을 넣도록 강제하지 않음. 전달 길이 차이를 포함한 실제 정책 효과를 먼저 보고함. 순수한 내용 선택 효과를 주장하려면 비슷한 길이/위치의 보조 비교를 추가함. 선택기의 계산·조회 비용도 별도 기록함.

진행/실패 이력을 추가로 수집하는 한 정책에만 도구 관측을 더 허용하지 않음. 공통 조사 prefix의 관측을 먼저 고정하거나, 추가 관측과 비용을 별도 정책으로 정의함.

## 관계를 배우게 하는 대조

| 대조 | 배우거나 검사할 것 | 정답 처리 |
| --- | --- | --- |
| 같은 기억, 다른 현재 조건 | 전제가 맞을 때와 틀릴 때 구분함 | 관계·충분성을 재판정함. 실제 효용은 새 실행으로 측정함 |
| 같은 현재 상태, 다른 기억 | 같은 용어지만 주체·원인·범위가 다른 가까운 후보 구분 | 근거를 검토한 양성·음성·미확인을 사용함 |
| 다른 표현, 같은 관계 | 표현·불필요한 순서·이름 단서에 덜 의존함 | 의미/주체/시간/수량 보존이 확인된 범위에서만 정답 유지 |
| 일부 근거 삭제·복원 | 충분한 근거와 부족한 근거의 구분 | 대체 경로와 현재 입력에 남은 정보를 확인함 |
| 없음/A/B/A+B | 한 답에 여러 기억이 함께 필요한 관계 | 개별 참조와 묶음 충분성을 구분함 |
| 다른 원천, 같은 판단 원리 | 특정 저장소·문장 틀을 넘어 전이함 | 부모 가족을 먼저 분리하고 별도로 확인함 |

대조 사례를 만든다고 특정 contrastive loss를 반드시 사용할 필요는 없음. 같은 검증된 짝을 기본 분류·순위 학습에도 사용하고 비교할 수 있음.

기억과 현재 상태의 관계는 역할을 가지므로, 두 입력을 서로 바꾸어도 같은 답이 되도록 학습시키지 않음. 요청 범위·완료 범위처럼 서로 다른 관계도 한 라벨로 합치지 않음.

## 학습 목표를 나누어 사용함

### 관계·근거 감독

현재 목표의 어느 부분과 과거 기억의 어느 관측이 연결되는지, 적용 전제가 충족됐는지, 추가 근거가 필요한지를 감독할 수 있음. 우선 근거 ID/span·전제·부족 변수처럼 검산할 수 있는 짧은 주석을 사용함.

현재 결과 벡터만 있는 데이터에서 이런 관계 정답이 자동으로 생기지는 않음. 새 v2 요약의 `new_relation_labels=0`을 관계 재주석 완료로 해석하지 않음. 교사의 설명도 원문·실행 근거를 확인한 뒤 보조 감독으로 사용함. 설명 감독의 선례인 [Distilling Step-by-Step](https://aclanthology.org/2023.findings-acl.507/)가 현재 기억 선택에서 개선을 보장하는 것은 아님.

### 실제 효용 감독

입력은 현재 상태와 **제안된 기억 묶음**임. 실제로 관측한 성공·근거 없는 행동·비용 등을 예측함. 같은 상태에서 측정한 묶음들의 차이로 순위를 학습하는 비교를 추가할 수 있음.

- 같은 상태에서 A묶음 성공/B묶음 실패를 관측한 쌍은 그 실행 조건의 순위 감독 후보임.
- 성공이 같아도 오류·비용이 상충하면 보편적인 우열을 강제하지 않음. 각 지표를 따로 예측하거나 개발에서 정한 결정 규칙을 사용함.
- 묶음의 개선을 그 안의 모든 기억의 개별 양성 라벨로 복사하지 않음.
- 관측하지 않은 묶음·확인 행동의 보상은 0으로 채우지 않음. 새 실행이 필요한 제안으로 남김.
- 한 번의 결과 전환을 모든 환경에 적용되는 확정 유익/유해 라벨로 부르지 않음.

### 표집과 규칙화

부모 가족과 대조 유형을 기준으로 표집하고, 같은 경험의 많은 표현이 학습을 독점하지 않도록 노출을 기록함. 라벨 가중치·가족 균등 표집·Group DRO를 한꺼번에 추가하지 않음. [Group DRO 연구](https://arxiv.org/abs/1911.08731)도 최악 그룹의 일반화에 정규화가 중요함을 보이므로, 적은 사례의 손실을 크게 만드는 것만으로 해결된다고 보지 않음.

부정 예제는 현재 질문 기준으로 판정함. 다른 질문의 정답 기억이나 미주석 기억을 무조건 비정답으로 밀지 않음. 무작위 부정에 실제 양성이 섞일 수 있다는 문제는 [Debiased Contrastive Learning](https://arxiv.org/abs/2007.00224)이 다루는 일반적인 주의점임. 해당 논문의 보정식을 우리 주석/효용 문제의 검증된 해결책으로 바로 옮기지는 않음.

## 적용하면 안 되는 일관성

[CheckList](https://aclanthology.org/2020.acl-main.442/)의 기능·불변성·방향성 검사처럼, 유지해야 하는 판단과 바뀌어야 하는 판단을 구별함. 이는 이 연구의 설계 응용임.

- 필요한 현재 관측을 지우고도 같은 예측을 강제하지 않음. 관측 부족과 반대 근거를 구분함.
- 과거/현재 가격·버전·가용성이 바뀐 경우 관계/효용이 유지된다고 가정하지 않음.
- **같은 사실을 정보형/지침형으로 표현한 두 기억의 실제 효용을 같게 강제하지 않음.** 표현이 행동을 바꾸는지는 원래 연구할 효과임.
- 관계의 정답은 후보 순서에 불변일 수 있지만, 작업자에 대한 전달 순서가 효용을 바꿀 수도 있음. 두 평가를 구분함.
- 미확인 라벨과 null/미측정 라벨을 구분함. 구조화된 사실상 오류와 근거 없는 판단도 구분함.

## 첫 학습 비교안

같은 encoder·판독 구조·준비된 데이터에서 다음 2×2를 제안함. 아직 실행 계획을 동결하거나 새 학습을 시작한 것은 아님.

| 선택기 입력 | 실제 관측 결과 학습 | 관측 결과 + 같은 상태의 묶음 순위 학습 |
| --- | --- | --- |
| 목표 + 제안 기억 묶음 | A | B |
| 목표·현재 관측·진행·실패 이력 + 제안 기억 묶음 | C | D |

A–C/B–D는 상태 사용의 가치, A–B/C–D는 순위 감독의 추가 효과를 봄. 목표만 보는 대조는 숨긴 정보 때문에 결과를 완전히 구분할 수 없을 수 있으며, 이를 구현 실패로 해석하지 않음.

학습 데이터·업데이트/토큰 예산·초기값·seed 목록·개발 선택 규칙을 맞춤. 대조 그룹별 노출과 실제 최적화 상태도 보고함. 새로운 관계 주석이 확정되면 검증된 관계 보조 감독을 하나의 추가 비교로 둠. 처음부터 수십 손실/층 조합으로 확대하지 않음.

관계 근거/정답의 대조는 실제 효용 모델과 별도 진단으로 유지함. 모델의 관계 설명이 정확하다는 것과 기억을 전달한 작업자의 성공률이 오르는 것은 별도로 검증함.

## 현재 데이터로 바로 주장할 수 없는 부분

새 observed-v2는 기존 **12가족·96상태·333관측 묶음**의 재구성이고 새 학습 결과는 아님. 같은 기록에서 `appropriate_abstention` 양성은 0/666항목임. 이 필드만으로 적절한 보류 행동을 학습시킬 감독이 충분하다고 할 수 없음. 사실상 잘못된 불가능 판단의 미확인 83항목도 false로 학습하지 않음.

현재 여행 자료는 목표·카탈로그·현재 관측/가용성 변화가 중심임. **실제 작업의 진행과 실패 이력이 달라지는 상황까지 검증한 자료는 아님.** 이를 포함하려면 선택 시점 이전의 실제 명령·오류·완료 상태를 수집해야 함.

과거 query-only 검색은 같은 질문의 네 상태에 점수를 재사용했음. 새 계약이 current_context를 제공하는 방향으로 보완되고 있으므로, 이후 학습 코드도 그 관측을 실제 입력으로 사용하는지 확인해야 함. 이전 짧은 pair 입력 길이 제한으로 새 현재 관측을 조용히 자르지 않음.

기록된 행동 내 최선 고정 정책 55/96과 사후 상태별 최대 58/96의 간격도 작음. 이 자료를 주 확인 집합으로 삼아 학습 방법의 일반적 우열을 결론내리지 않음.

## 진행·실패 이력을 포함하는 측정

처음에는 공통 무기억 조사 prefix 후 한 결정 시점의 환경/작업 트리/대화를 복원하고, 상태를 쓰는 선택과 쓰지 않는 선택으로 분기하는 것이 해석하기 좋음. 작업자는 양쪽에서 같은 prefix를 이어서 수행함. 관측·실패 이력을 언제 알았는지 보존하고 정답 패치·사후 채점 결과를 선택기 입력에 넣지 않음.

이 단일 시점 비교로 조건부 효과를 확인한 뒤 여러 시점에 재선택하는 전체 정책을 평가할 수 있음. 정책이 달라져 발생한 서로 다른 중간 상태를 같은 상태처럼 취급해 단계별 정답을 섞지 않음.

확인 지표는 새 가족에서의 작업 성공률 차이·관측 악화·근거/사실 오류·총비용임. 관계 판독은 원형/변형을 둘 다 맞힌 비율, 상태만/기억만/함께 읽기, 근거 완전 확보, 보지 않은 원천/관계 조합으로 진단함. 주 가설은 실제 작업 성공이며, 관계 점수만의 상승으로 대체하지 않음.
