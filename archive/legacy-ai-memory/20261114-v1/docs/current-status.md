# 메모리 연구: 현재 상태와 다음 검증

**프레임워크 상세 설계 작성(2026-11-13):** [상세 설계](ai-memory-framework-detailed-design-2026-11-13.md)에 모듈·상태 전이·도구·은행 버전·복제·노출·벤치별 연결·측정·기록·재개의 구현 계약을 정의함. 두 회차의 독립 세션과 같은 기억의 자기 경험/혼합 후보 풀 비교, τ² 초기 연결 및 AppWorld·BFCL 확장 구조를 구체화함. 부속 스키마와 합성 예시의 정적 검증은 제공하되 실행기·벤치 어댑터·실제 성능 검증은 앞으로 구현·실행할 대상임.

**실험 계획 보고서 작성용 인계(2026-11-13):** [핵심 정리](ai-memory-experiment-report-brief-2026-11-13.md)에 연구 목적·질문·도구와 정책·비교 설계·측정·기여 목표·기대 효과를 연결함. 다른 에이전트가 실험 계획 보고서의 초안으로 전개할 수 있는 개요와 해석 조건을 제공하며, 성능 개선과 독창성은 검증 목표로 둠.

**유사 벤치의 지표·노벨티 대조(2026-11-13):** [비교 보고서](reports/2026-11-13-memory-benchmark-metrics-and-novelty.md)에 12개 벤치·평가 프레임워크와 추가 측정 후보를 정리함. MemoryArena의 PS·sPS, AgentBoard의 진척·유효 행동, STATE-Bench의 신뢰성·UX·비용, HaluMem의 단계별 품질, MemTools·EvoMemBench의 직접적인 설계 중복을 반영함. Luna 고정·공통 랜덤 순서에서 작성·조회·회복·회귀·진척을 연결하는 진단과 실증은 기여 후보이며 신규성은 미확정임. 범위 축소·지표 채택·구현·모델 실행을 확정한 상태는 아님.

**평가 프레임워크 설계 검토안 작성(2026-11-13):** [시작 전 검토 문서](ai-memory-evaluation-framework-design-2026-11-13.md)에 평가 프레임워크·측정 절차·실증 분석의 산출물과 기능·도구 계약·비교·실행·집계·원본 기록을 구체화함. 저장·조회·반복·전이·누적·득실·비용의 연구 범위를 유지함. 벤치·모델·반복 수·비용과 세부 정책은 검토 후 확정하며, 이번 작업은 문서 작성이고 새 프레임워크 구현·모델 실행은 시작하지 않음.

**기억 저장·활용 실험 재검토 보완(2026-11-13):** [설계 노트](ai-memory-write-read-experiment-note-2026-11-13.md)에 저장·조회·반복·전이·득실·비용의 전체 연구 범위를 유지한다는 점을 반영함. 수행 중에만 저장을 추가한 네 조건, 형태·조회 정책의 교차 비교, 원기록·단순 요약 기준선, 실행 변동과 관측된 득실의 구분, 누적 회귀·작업 순서와 원인 검증을 보강함. 더 가까운 선행연구를 대조했으며 실험 방향은 타당하나 구체적인 벤치·모델·규모와 독창성은 미확정임. 기존 오프라인 패킷은 개발 자료로 보존하고 BM25·최근 2k+기억 2k 배분은 필수 조건으로 삼지 않음. 새 벤치 통합·모델 실행에 착수한 상태는 아님.

**평가 기준·오프라인 입력 준비 완료(2026-11-13):** [새 v2 패킷](../datasets/memory_context_session/20261113-offline-v2/README.md)에 관계/득실/누적 효과의 구분, UNKNOWN과 가상 추천의 의미, 부모 버전·본문 해시를 묶는 기록 연결을 고정함. 기존 1가족·4문항에서 대본 답의 17기록을 제외하고, 모의 답변 2종의 32입력·제공/보류 16쌍을 CPU 검사함. 직렬화 예산 초과·미래 관측·스냅샷 불일치 0건, 관련 테스트 33개 통과. 고정 기억 조건도 마지막 질문에서 이전 답변을 노출하나, 각 모의 답변의 모드 대응 8쌍 중 5쌍은 여전히 같은 입력임. 실제 모델 호출·성능·득실 측정은 없고, 원본 552사례는 수정하지 않음. 다음은 모델·네이티브 입력 계약을 정한 작은 실제 점검이며 본평가·새 학습은 아직 시작하지 않음.

**Luna 세팅·첫 테스트 완료(2026-11-12):** [정량 기준과 결과](reports/2026-11-12-luna-session-setup.md)에 1가족·4문항의 실제 점검을 정리함. 15개 CPU 테스트, 기본 계약 2/2, 주 결정 16개·같은 상태의 국소 대조 8쌍을 확인함. 주 테스트는 14호출이고 네 조건 모두 3/4임. 모드 입력 8쌍 중 6쌍이 같아 누적 노출이 부족했고, 추천 계약을 명확히 한 사후 진단 1문항에서 UNKNOWN→정답이 관측됨. 전체 18호출의 reported cost는 $0.00809535임. 원 성적·v1 입력을 보존하며, 문구와 이력 노출을 보완한 다음 작은 테스트 전까지 본실험을 확대하지 않음. GPU·Colab·학습은 없음.

**현재 범위 정정(2026-11-12):** 이번 목표는 모델 경쟁이 아니라 같은 문제의 누적/분리 세션 차이와 기억 제공/보류의 득실 측정임. 주 모델·기억 전달 정책을 고정함. Harrier를 별도 필수 비교군으로 추가한 요구는 철회하고, 학습 선택기의 우위를 검증하는 후속 연구와 구분함.

**전체 재검토 반영(2026-11-12):** [검토 결과](reports/2026-11-12-overall-protocol-review.md)에서 기존 학습 개선과 패킷 검산을 재확인함. 비교 설계에는 최근 대화만 4k 기준선을 추가하고, 같은 직전 상태의 국소 제공/보류와 서로 다른 누적 경로의 정책 효과를 분리함. 원본의 질문 답에서 생성한 기록 408행은 새 조회형 은행에서 제외해야 함. 예산 수정·새 은행/입력·스냅샷 검사는 아직 구현 전이므로 새 성능 측정 완료로 해석하지 않음. 원본·가중치·다른 작업 트리는 보존했고 새 GPU·학습·작업자 호출은 없음.

**누적/분리 세션의 짝 비교로 구체화(2026-11-12):** [통합안](ai-memory-data-cleanup-and-context-stream-plan-2026-11-12.md)에 같은 질문·외부 사건·시점별 기억 은행을 유지한 D(문제별 새 대화)/C(자기 답변도 이어지는 대화) 평가를 반영함. 각 모드에서 최근 대화만 4k와 고정 정책의 최근 2k+기억 2k를 비교하고, 분리만 성공/누적만 성공과 같은 스냅샷의 기억 제공 득실을 별도 집계함. 최근 창에서 사실이 밀려나는 효과와 이전 오답의 영향을 구분해 진단함. 실행 전 설계 보완이며 새 작업자·학습·GPU 사용은 없음.

**데이터 정리와 누적 세션의 다음 단계(2026-11-12):** [역할·버전·누적 실험 통합안](ai-memory-data-cleanup-and-context-stream-plan-2026-11-12.md)에 학습 증강, 이전 부모의 192상태 진단, 새 92판단 패킷을 구분함. 새 README·인계의 UNKNOWN·부가 메시지 설명을 정정했으며 원본 JSON·protocol·해시는 보존함. [CPU 검사](design-data/memory-context-stream-20261112-v1/README.md)에서 질문 정답의 예약 저장 72회를 빼도 92정답과 각 시점 접두부 정답이 일치함. 다음은 실제 블록 예산 수정본과 누적 입력 계약을 먼저 만들고, 공통 접두부 분기 진단에서 답변 이력 누적으로 이어가는 순서임. 아직 누적 작업자 실행·새 학습·GPU 사용은 없음.

2026-11-12. **현재 상황에 맞는 기억을 선택하면 실제 성공·손해·비용이 어떻게 바뀌는지 측정하고, 그 판단을 작은 모델이 학습할 수 있는지 검증함.** 관계 판단과 실제 득실은 별도 지표로 유지함.

**새 납품 파일럿 검토:** [숨은 함정 92판단 패킷 검토](reports/2026-11-12-hidden-memory-traps-pilot-review.md)를 완료함. main `d1177d4`의 4세션·552사례·3,468입력과 코드·원천 해시가 일치하고, 별도 장부의 92정답도 일치함. 모델 해석은 문장 42개·판단 16개에서 핵심 뜻·답 집합이 일치했으나 사람 검토는 아님. 긴 단계의 실제 기억 블록은 M 약 1.7–1.85만·L 약 7.8–8만 토큰으로 이전의 짧은 은행 한계가 보완됨. 실제 블록 기준 예산 초과와 UNKNOWN의 효용 방향 가정을 실행 전에 수정해야 함. 이 새 패킷은 아래 보완본의 이전 부모와 다르며, 같은 기록 키 338행의 본문이 달라 라벨·캐시를 ID만으로 합치지 않음. 원본 수정·작업자·학습·GPU·유료 호출은 없음.

**현재 관측 대조 보완 완료:** [입력·근거·같은 목표 대조 보완](reports/2026-11-12-memory-state-supplement.md)에서 기존 4출처의 96쌍·192상태를 구성함. 관측 문자열만 보거나 관측을 뺀 목표·대상 기억만 보면 현재 구성 표의 최대 조회 정답률이 각각 50%임. 원 주석의 근거 누락 40진단, 모호한 18후보와 미주석 5,726출현의 마스킹, 검토 16판단의 카탈로그 보완도 완료함. [자료](../datasets/memory_state_supplement/20261112-v3/README.md)는 설계용 dev이며 새로운 독립 출처나 실제 득실·학습 결과는 아님. 1,152정책 배정·402고유 작업자 입력은 실행 전 상태임.

**기여 후보별 데이터 검토:** [자료별 원문·입력·관계·득실 검토](reports/2026-11-12-memory-contribution-data-review.md)를 완료함. 새 학습 증강 4,224입력은 상태·관측을 제거하면 상충 정답이 생기며, 현재 표의 최선 조회 정답률이 75%로 제한됨. 이는 학습 결과가 아닌 구성 진단임. 별도 작업 트리의 새 4세션·84시점 파일럿도 스냅샷으로 검토함. 검토표 4문항의 카탈로그 누락을 별도 사본에서 보완하고, 다른 기록이 필요한 무효 판단 20개·길이별 후보 변화·8k/전체 조건 중복을 확인함. 원본은 보존했고 새 학습·작업자 실행은 없음. 아래 인수 준비 기록은 새 파일럿 확인 전의 상태임.

**자료 인수 준비 완료:** [기존 증강 자체 검토와 인수 검사](reports/2026-11-12-data-intake-readiness.md)를 마침. `new-a` 44가족 중 본 세션 미사용 후보는 24개이고, 전부 stage1에서는 평가한 출처임. 24사례 자체 검토의 관계 불일치는 없었지만 독립 검토는 아니며, 현재 카탈로그를 추가한 별도 검토표를 준비함. 선언된 근거가 입력에 있는지 확인하는 검사에서 4,224입력·8,448근거 구간이 통과했고 테스트 54개가 통과함. [인계 문서](ai-memory-data-augmentation-handoff-2026-11-12.md)에 반영함. 새 제작본·독립 인간 검토·새 학습·작업자 실행은 아직 없음.

**학습용 관계 증강 자료 준비:** [상태·관측·표현 증강](reports/2026-11-12-memory-state-augmentation.md)에서 기존 train 11출처의 원 기록 477개를 그대로 두고 1,056상태·고유 pair 입력 4,224쌍을 생성함. 목표·은행·확인 사실이 같은 분기 대조 528쌍 중 495쌍에서 필요한 기억이 달라지며, 동등 표현 704쌍은 정답이 유지됨. 학습·비학습 출처 혼입 0, 관련 테스트 41개와 새 폴더 10파일 재생성이 통과함. [데이터·검토용 24사례](../datasets/memory_state_augmentation/20261112-v1/README.md)를 보존함. 새 독립 출처는 0이며 실제 득실·사람 검토는 미측정, 새 학습·GPU·유료 호출은 없음. 원래 평가와 봉인 자료는 증강하지 않음.

**득실 자료의 정량 검증 완료:** [원자료 검증 보고서](reports/2026-11-12-memory-effect-measurement-audit.md)에서 같은 상태의 두 행동을 원 출력에 연결함. 여행의 같은 목표·은행·제공 묶음 12가족은 처음 모두 이득이고, 계획 변경·대안 확인 뒤 7가족에서 손해로 바뀜. 기존 목표 검색의 확인 36상태에서도 이득 6·손해 2가 함께 관측됨. 정보 복원은 이득 52·손해 0·둘 다 성공 36·둘 다 실패 8이며 독립 채점 구현이 1,056정책 행에서 일치함. 다만 96상태의 단위는 12출처이고, 표현 민감도는 성공 88→94/96, 실제 반복은 총 7입력뿐임. [검산 묶음](reports/data/memory-effect-measurement-20261112-v1/README.md)에 같은 기억의 상태 대조·양쪽 원 출력·분할·입력 해시를 보존함. 이는 관측 득실의 검산과 사후 상태 대조이며 일반적인 효과 예측·새 확인 실험·순비용 우위로 해석하지 않음. 새 GPU·학습·유료 호출은 없음.

현재는 [기억의 득실: 확보한 세 가지 결과](reports/2026-11-12-memory-core-findings.md)에 집중함. 상황별 득실, 데이터 보강의 학습 효과, 관계 판단·실제 행동·비용을 분리한 측정 방법을 하나의 보고서와 대표 사례 5개로 정리하고 원 출력을 재검산함. 새 모델·벤치·상황 확장은 보류하며, [이전 방향 문서](ai-memory-situation-specific-direction-2026-11-12.md)의 상황 후보는 현재 착수 목록이 아님. 상황을 한정한다는 것은 특정 업무에서 효과를 보여도 된다는 뜻이며, 기억 일부의 가공을 필수 목표로 삼지 않음.

변경 전 계획 기억의 손해 7/12, 보강 학습의 필드 복원 67·71→87·86/96을 재확인함. 두 seed의 보강은 개선 20·15건·새 악화 0건이며 전체 제공·검색은 88/96임. 두 결과는 서로 다른 실험이므로 하나의 손해 예방 성과로 합치지 않음. [재현 묶음](reports/data/memory-core-findings-20261112-v1/README.md)에 원자료 해시·입력 단위·대표 사례 선택 기준을 보존함. 해당 핵심 성과 재집계는 새 학습·GPU·작업자 실행 없이 저장 자료만 사용함. 아래 개별 실험의 후속 제안은 당시 판단을 보존한 기록임.

**집중 범위 안의 후속 실험 완료:** [데이터 보강의 원인 분해](reports/2026-11-12-augmentation-ablation.md)에서 repeat / format / relation을 같은 출발 가중치로 두 seed·각 200업데이트 학습함. 주 비교 두 조건의 고유 입력 수·기록 형식·후보별 정답·손실 가중치를 맞춘 뒤, 필요 복합 기억 보존은 형식 조건 22·17/48→관계 조건 48·48/48, 후속 복원은 65·63/96→88·87/96으로 개선됨. 각각 개선 23·24건·새 답변 악화 0건이나 불필요 제공과 기존 BEAM 회귀가 늘었음. 전체 제공은 88/96이고, 기존 12평가 출처를 이용한 진단이며 새 독립 확인은 아님. 11,432예측·1,056정책 결정을 CPU·압축본에서 검산함. [공유 결과](../evaluation/results/memory-augmentation-ablation-20261112-v1/README.md)에 실제 가중치와 재현 차이도 보존함. 로컬 GPU 실행은 종료됐고 Colab·새 작업자·유료 API 호출은 없음. 승인한 1번 원인 분해를 완료했으며 다른 상황·수집 실험으로 자동 확대하지 않음.

**전체 제공 대비 해석을 명확히 함:** 후속 복원은 은행에 기록 1개인 96상태임. 제공·보류의 저장 결과를 짝지으면 둘 다 성공 36, 제공만 성공 52, 보류만 성공 0, 둘 다 실패 8임. 관측된 두 행동의 사후 최선도 전체 제공과 같은 88/96이므로 이 자료에는 선택으로 성공률을 더 높일 여지가 없었음. 현재 성과는 학습형 선택기의 오류를 고친 데이터 진단으로 보존하며, 별도 선택기의 실용적 우위로 설명하지 않음. 같은 자료의 성공률을 더 높이려는 추가 학습은 우선하지 않음.

## 최근 완료: STATE-Bench 실제 업무 파일럿

[경험 기억 20개·개발 8과제의 실제 실행](reports/2026-11-12-statebench-experience-pilot.md)을 완료함. 같은 Qwen3.5-9B 작업자·은행·최대 3개/1,024토큰에서 무기억 / 고정 Harrier 요청 / 요청+관측의 성공은 5/8·6/8·5/8임. 24개 실행 중 4개는 원래 도구 루프 한도에서 미완료되어 실패로 포함함. 새 선택기 학습·공식 test 실행은 없음.

예산 초과 상품을 설명하고 완료한 개선 1건과 관측 조건에서 교환을 중복 실행한 악화 1건을 확인함. 후자는 한 사용자 턴의 도구 루프 안에서 발생해 현재 선택기가 재판단할 기회가 없었음. 은행에 직접 근거가 부족한 공통 실패도 있으며, 이번 1회 관측으로 작은 모델 학습의 필요성이나 상태 입력의 우위를 입증하지 않음.

선택 65회·응답 단계 209개·도구 호출 재실행 167개를 검산하고 관련 테스트 23개를 통과함. [공유 압축](../evaluation/results/statebench-pilot-20261112-v1/README.md)은 코드·자료·토크나이저와 저장 응답을 포함함. 준비 실패까지 포함한 응답 기록 비용은 $0.6917, 실패 요청 예약액을 포함한 보수적 장부는 $0.8633 이하임. 로컬 Harrier GPU 프로세스는 종료했고 Colab 할당은 없음.

다음은 기억 출처에서 직접 근거와 적용 경계를 보강하고, 같은 진행 시점의 환경·대화를 복제한 분기 측정으로 선택 누락과 작업자의 오용을 나누는 것임. 이번 8과제는 개발 진단으로 유지하고, 이 실행 결과를 개별 기억의 득실 정답으로 소급하지 않음.

## 앞선 단계: STATE-Bench 준비

[STATE-Bench 적용 재검토](reports/2026-11-12-statebench-preparation.md)를 마치고 공개 학습 기록 300개·유효한 관측 접두부 860개를 수집함. 기억 출처 239개·개발 대상 61개를 분리하고, 지정 구간 12기록을 검토함. 같은 관측을 받는 Harrier 기준선, 사용자 턴별 고정 선택 시점, 최대 3개·1,024토큰의 통제 경로를 준비함.

공식 런타임 연결과 입력 누출·예산·도구 동작 검사 17개가 통과함. 원본 기록에는 최종 성공·실제 득실 라벨이 없으며 관측 후보 2,842개는 전수 검토하지 않음. 이 준비 시점에는 공식 평가 endpoint/deployment 설정이 없어 실제 작업자 실행을 하지 않았고, 이후 위 파일럿에서 OpenRouter를 통한 통제 실행을 진행함. 기존 ConvoMem·AMA의 부정 결과는 검색 회귀 자료로 유지함.

CPU 선택 로그 567개를 공유 사본에서 검산함. 원문 은행 후보 2,297개 중 825개가 단독으로도 예산을 넘으므로, 실제 모델 비교 전에 조건과 근거를 보존하는 기억 단위를 정리해야 함. 상태 입력의 최대 길이도 7,991토큰이어서 선택기별 입력 절단을 명시해야 함. 이 준비 결과를 선택 성능이나 실제 득실 개선으로 해석하지 않음.

## 최근 완료: 두 외부 벤치 각 100출처

[후속 원인 진단](reports/2026-11-12-external-selection-diagnosis.md): 기존 모델은 근거 순위가 약하고 보완은 순위를 개선했으나 많은 근거를 보류함. 답변 가능 주석 93개의 확보는 이전 21·26, 보완 25·22, 보완의 보류 제거 47·56, 기본 검색 82임. 보완의 순위 성과를 유지하면서 제공 기준과 남은 검색 격차를 나눠 다뤄야 함. 새 학습·GPU·작업자 호출 없이 저장 점수로 진단했으며, 이 수치를 새 실제 성공률로 해석하지 않음.

[ConvoMem·AMA 외부 평가](reports/2026-11-12-external-memory-benchmarks.md)를 완료함. 추가 학습 없이 이전 augmented·보완 replay의 두 seed와 검색 기준선을 같은 Qwen3.5-4B 작업자·공통 BM25 후보·1,024토큰/12조각 상한에서 비교함. 실제 에이전트 과제 전체 재실행이 아닌 원래 기억 질문 응답 평가임.

- ConvoMem 자동 정답은 이전 49·47→보완 50·51/100이며 전달 기억은 54.3%·70.5% 감소함. 대응 개선·악화가 16/15·18/14이므로 비열등성이나 안정적인 정확도 향상을 입증하지 않음. 기본 임베딩 83·BM25 80보다 낮음.
- AMA는 이전 9·9→보완 4·5/100임. 기본 임베딩 11·BM25 13도 낮아 후보 검색·선택·작업자 활용의 병목을 분리해야 함. 이번 결과로 모델을 범용 기본값으로 교체하지 않음.
- 점수는 로컬 9B 자동 채점임. 사전 20개 보조 검토와 17개가 일치함. 자동 손해 2건은 원문 검토상 타당한 보류 답변이므로 손해 감소 성과로 주장하지 않음. 원래 자동 결과와 검토를 분리해 보존함.
- 원본 200질문/답변·7,852기록과 후보를 대조했고 46,995점·1,400정책 결정의 CPU 검산을 통과함. [공유 압축](../evaluation/results/memory-external-test-20261112-v1/README.md)을 새 폴더에 풀어 같은 지표와 6개 테스트를 확인함. GPU 작업 종료, 새 학습·Colab·유료 API 없음.

유지할 성과는 상태 대조·복합 기록 보강의 통제된 개선과 일부 외부 자료의 전달 효율임. 다음 개선은 별도 개발 자료에서 선호·중간 단서·자연 문장 근거를 보존하고, 순위와 보류를 분리하는 방향이 적절함. 이번 200출처는 이제 관찰한 자료이며 이를 조정한 뒤 새 시험 성적으로 취급하지 않음. 실제 진행·실패 이력을 쓰는 선택과 손해 감소의 일반화는 여전히 별도 검증 대상임.

## 최근 완료: 복습 교체와 예산 제약 진단

[복습 교체·예산 비교](reports/2026-11-12-balanced-replay-and-budget.md)를 완료함. 같은 320개 핵심 대조와 학습량을 유지하고 복습 80상태를 교체하는 두 조건을 각각 두 seed로 학습함. 학습 400상태·200업데이트는 같지만 replay의 입력 토큰은 약 2.2배임.

- BEAM 개발의 불필요 기억 오탐이 220·193→28·33개로 줄고, 이전 부분 관측 복합 기억 보존은 48·44/48→48·47/48임. 필요한 기억도 3·1개 새로 놓침.
- 같은 128토큰에서 근거 있는 응답은 이전 33·31/52→38·39/52임. 교체에 따른 득실은 8개선·3악화, 10개선·2악화이며 전달 토큰은 약 45–55% 감소함. 기본 임베딩 검색 44/52보다 낮고, 기존 개발 자료의 진단임.
- 512토큰에서는 44·43→41·43/52임. 새 평가 12출처의 필드 복원도 105·104→102·101/120으로 줄고, 기존 Mem2Act·PersonaMem의 검토된 양성 기억을 더 놓침. **이번 모델을 기본값으로 교체하지 않음.**
- 새 출처에서 모든 근거를 주어도 108/120임. 같은 목표·기억에 조회 실패 관측만 추가한 두 대조는 12→9/12, 12→6/12임. 관계 판독과 실제 활용의 병목을 구분함.

[공유 결과](../evaluation/results/memory-balanced-replay-20261112-v1/README.md)에 실제 가중치·19,016개 검산 예측·690개 작업자 입력과 6반복·2,776개 정책 결정을 보존함. 압축본 재검산과 관련 테스트 31개가 통과함. 로컬 GPU 작업은 종료했고 유료 API·Colab 할당은 없음. BEAM 확인 27출처는 미실행 상태임. 후속 보완은 train에서 조회 대상·작업 인수·선호 같은 중간 단서를 돕는 양성을 보존하는 방향이 적절함.

## 최근 완료: 복합 기억 보강의 새 출처 검증

[복합 기억 보강 실험](reports/2026-11-12-partial-record-learning.md)을 완료함. 새 출처 30개를 train 12·dev 6·test 12개로 먼저 분리하고 원문의 두 사실을 별도/복합 기록으로 구성함. 같은 출처·현재 상태·학습량에서 단순 추가 학습과 복합 기록 보강을 두 seed로 비교하고, 개발 임계값 조정도 분리함.

- 새 평가 12출처·384상태에서 일부만 확인된 복합 기록 보존은 이전 모델 18–19/48, 단순 추가 학습 25–30/48, 보강 44–48/48임. 상태들은 출처별 변형이며 독립 경험 384개가 아님.
- 같은 Qwen3.5-4B의 사전 지정 96상태 필드 복원은 고정 채점에서 이전 58–60, 추가 학습 67–71, 보강 86–87 성공임. 보강은 추가 학습보다 15–20개 개선·악화 0개임. 전체 제공/검색 상위 2개는 88로, 학습 선택의 성공률 우위를 입증한 결과는 아님.
- 고정 채점의 명사구 표현 차이 6출력을 원문으로 재검토한 사후 진단은 별도 보존함. 원래 점수를 덮어쓰지 않음. 실제 게임/라운드 ID 혼동 2출력은 실패로 유지함.
- 전달 기억 토큰은 전체 제공보다 34–35% 줄지만 총 입력 감소는 약 3%이고 지연 개선은 관찰되지 않음. 기존 BEAM 개발에서 과잉 제공이 늘어 관계 점수가 75.6–77.5%→71.4–74.8%로 낮아짐. 현재 보강 모델을 일괄 기본 모델로 교체하지 않음.

저장 예측 17,128행·4개 LoRA의 실제 변화·전체 학습 노출·작업자 출력과 반복을 검산하고 관련 테스트 20개를 통과함. [공유 결과](../evaluation/results/memory-partial-records-20261111-v1/README.md)에 고정 결과와 사후 채점 진단을 분리함. 로컬 GPU 작업은 종료했으며 추가 API·Colab 할당은 없음. 다음은 기존 train 자료의 충족·무관 조건 복습을 보강하는 비교가 적절하며, 평가용 BEAM을 학습에 섞지 않음.

## 최근 완료: 원문 대조 보강과 필요성·관련성 학습

[부분 관측·같은 원문의 다른 역할을 보강한 학습](reports/2026-11-11-incremental-evidence-learning.md)을 완료함. 기존 Mem2Act 원문 80구간에서 학습 18출처·246상태, 개발 8출처·100상태를 파생하고 단일 필요성 / 관련성 보조 / 기존 자료 혼합의 세 방법을 두 시드로 비교함. 새 독립 경험을 수집한 것은 아니며 개발 출처는 이전에도 본 자료임.

- 개발 관계 점수는 67.5%→93.0–96.2%, 필요 근거 확보는 27/78→65–74/78로 개선됨. 관련성 보조 손실은 불필요 제공을 줄이는 대신 누락도 늘려 단일 학습보다 일관되게 우수하지 않았음.
- 같은 Qwen3.5-4B의 근거 있는 필드 복원은 기존 선택기 24/50→43–47/50임. 기존 선택기 대비 20–24개선·1악화, 무기억 대비 32–36개선·0악화임. 검색은 50/50, 전체 은행은 49/50이라 학습 선택기 우위와 처리 시간 이득은 입증하지 못함.
- BEAM 라벨 없이 이전 BEAM 개발 관계 점수가 71.1%→83.1–85.1%로 개선된 비교가 있음. 새 작업 성공·봉인 확인 평가를 뜻하지 않음. 부분적으로만 알려진 복합 기록은 학습·개발 각각 한 출처뿐이고 여전히 잘못 보류하므로 보강이 필요함.
- 원문이 지지하지 않는 통화 방향 주석을 발견해 v1 실행을 중단·보존하고 v2에서 재학습함. 작업자 호출 전에는 정답이 포함된 내부 필드 키도 익명화함. 문자열 근거 검산과 의미 검토를 별도로 수행해야 함을 확인함.

[공유 묶음](../evaluation/results/memory-incremental-evidence-20261111-v2/README.md)에 6개 실제 adapter·두 출력 head·저장 특징·작업자 입출력을 보존함. 16,352후보 행의 두 출력과 실제 168고유 입력·3반복·650정책 결정의 CPU 검산을 통과함. 관련 테스트 23개 통과, GPU 계산 프로세스 종료, Colab·유료 API 호출 없음. 기존 자료와 체크포인트·BEAM 확인 분할은 보존함.

다음은 단일 필요성 학습을 기준선으로 유지하면서 ‘한 기록 중 일부만 알려진 경우’를 여러 출처에서 보강하고, 새 출처·처음 보는 표현에서 판단과 실제 효과를 함께 확인하는 것임.

## 앞선 완료: 현재 관측별 기억 가치와 보완 학습

[50출처 자료 구성·실제 득실·보완 학습](reports/2026-11-11-memory-context-value.md)을 완료함. BEAM 100대화 원문에서 50출처·58문항·232통제 상태를 구성하고, 기존 분할을 유지해 학습 11출처·개발 12출처·확인 27출처로 나눔. 원문 관계와 실제 작업자 득실을 분리함. 실제 진행·실패 이력은 아직 아님.

- Harrier 0.6B 상태 보완 학습 두 seed의 개발 관계 점수는 71.1%→80.8%·87.3%임. 같은 Qwen3.5-4B 작업자의 정답은 41/52→39/52·41/52이며 검색 47/52를 넘지 못함. 한 seed는 같은 정답 수에서 전달 토큰을 80.4% 줄임.
- 같은 과거 기억 제공 대조에서 개발 개선 20·악화 1·중립 31상태를 측정함. 관계 점수와 이득의 탐색적 연결은 있으나 일반적인 득실 예측이나 성공률 개선을 입증하지 못함.
- 정답 근거만 제공한 개발 관측 없음 조건이 9/13으로 사전 80% 기준에 미달해 확인 27출처는 미실행임. DB 설정 문항의 ‘시도’와 ‘적용’ 구분도 별도 재검토 대상으로 남김.
- 이전 개발 관계 점수는 93.6%→77.3%·78.7%로 하락함. 같은 과제의 Top1은 20/30으로 유지돼, 전반적인 관계 능력 붕괴보다 보류 증가와 제공 기준을 먼저 점검하는 것이 적절함. 기존 checkpoint는 보존하며 새 모델을 대체품으로 채택하지 않음.

[공유 묶음](../evaluation/results/memory-context-value-20261111-v1/README.md)에 실제 adapter·head·저장 특징·작업자 입출력·사후 진단을 포함함. 관계 및 이전 자료 점수 7,032개와 작업자 새 입력 652개·6반복·1,144정책 결정의 CPU 검산을 완료함. 로컬 GPU 작업은 종료했고 Colab·유료 API는 사용하지 않음.

다음은 질문의 값·시점·적용 범위와 작업자 근거 활용을 먼저 보완하고, 기존 관계 자료를 유지하면서 필요 기억 누락과 불필요한 전달을 구분해 학습·제공 기준을 검토하는 것임. 확인 분할을 열어 조정하지 않음.

## 앞선 완료: 120출처 학습·고정 작업자 평가

[120출처 학습 비교](reports/2026-11-11-memory-source-scale.md)를 완료함. 이전 공개 자료 파일럿을 학습 120출처·127질문·2,352관계쌍으로 확대하고 개발 30출처·시험 31출처를 분리함. 원문 구간과 채택/제외 이유를 보존하고 30·60·120출처의 같은 Harrier 0.6B LoRA를 학습함. 실제 진행·실패 이력이 아닌 관측 유무의 통제 대조임.

- 시험 관계 평가에서 필수 근거 확보는 판독층만 학습 14/30→LoRA 23/30임. 기존 검색은 24/30이며 LoRA는 불필요한 전달을 줄임. 세 학습 규모의 근거 확보 수는 같음.
- 고정 Qwen3.5-4B의 시험 필수 인수 복원에서 `정답+입력 근거`는 판독층 21/30, 검색·중복 제거 23/30, 세 LoRA 모두 26/30임. 120출처의 원래 정답 일치 27건에는 근거 없이 맞힌 1건이 포함됨. 실제 단위는 10출처의 세 통제 상태이며 전체 에이전트 작업 성공과 구분함.
- 같은 512토큰에 기억을 채워 보내면 29/30임. 개발 자료에서는 LoRA 우위가 반복되지 않아 증량 효과·안정적인 선택기 우위는 확인되지 않음. 다음에는 같은 대상의 조건·수정 이력과 실제 예산 제약이 있는 새 출처 묶음을 평가하는 것이 적절함. 이번 시험 자료는 이제 관찰한 자료임.

[공유 결과](../evaluation/results/memory-source-scale-20261111-v1/README.md)에 실제 adapter·head·저장 특징·작업자 입력과 답변을 포함함. 점수 11,160개와 전체 작업자 채점의 CPU 검산을 통과함. 새 작업자 385입력·3반복을 실행했고, 912정책 결정을 독립 호출로 세지 않음. 로컬 GPU 작업은 종료됐으며 이번 회차에서 Colab·유료 API는 사용하지 않음.

## 앞선 데이터 보완

[공개 자료 30출처 파일럿](reports/2026-11-11-memory-source-pilot.md)을 수집·검토함. Mem2ActBench와 PersonaMem-v2 각 15개 중 19개에서 좁은 관계 단서를 유지하고, 3개는 수정 필요·8개는 근거 부족 또는 모호성으로 보류함. 관계 단서 19개를 완성된 선택 정답이나 실제 득실 라벨로 바꾸지 않음.

원문 기반 후보 2,072조각, 검토 근거 위치 39개를 [공유 묶음](../datasets/memory_source_pilot/20261111-v1/README.md)에 보존함. PersonaMem의 원래 train·val에 사용자 735명이 겹쳐 사용자 단위로 다시 분리했고, Mem2Act는 혼합 세션의 배경 출처까지 함께 묶음. 200출처 그룹을 train 120·dev 40·test 40으로 예약했지만 이번 검토는 train 30개만 수행함.

이 파일럿 자체에는 학습·작업자 호출·GPU 할당이 없었음. 위 후속 회차에서 원문 주석과 현재 관측 대조를 보완해 학습함. 현재 에이전트 진행·실패의 실제 대조는 아직 없음.

## 최근 보완: 옛 수치 일괄 가림은 채택하지 않음

[원문 맥락을 남기고 옛 수치를 가리는 설계 실험](reports/2026-11-11-external-update-masking.md)을 완료함. 기존 47문항 전체에서 94입력·2반복을 새로 실행하고 같은 입력의 기존 94출력을 재사용함. 실제 토큰 길이가 같은 표시/가림 대조와 원문 조건을 함께 검산함.

- 옛 원문 대비 가림 성공은 LME 28→24/32, BEAM 10→5/15로 감소함. 가림 조건의 실패는 모두 `UNKNOWN`임. 잘못된 수치 단정은 줄었으나 현재 새 근거만 제공할 때보다 성공이 낮아 개선 정책으로 채택하지 않음.
- 옛 기억 때문에 깨졌던 6문항 중 4문항이 복구됐지만 형식 변경·열거 목록 제거의 영향도 포함됨. 수량 표현만 가린 주 분석에서는 출처별 1건 개선·6건 악화임.
- 기존 상태 선택 모델은 변경하지 않음. 후속 데이터에서는 현재 충족된 요구·추가 맥락·충돌하는 값과 실제 정답·오답 단정·보류를 분리하는 것이 적절함. 관계 정답을 작업자 실패와 혼동하지 않음.

BEAM 확인 33문항은 미실행 상태를 유지함. Colab 세션은 종료했으며 [공유 결과](../evaluation/results/external-update-masking-20261111-v1/README.md)에서 원문 구간·실제 답변·득실을 CPU로 재계산할 수 있음.

## 외부 기억 갱신 대조의 설계 검증

[원문·채점 보완 후 설계 실행](reports/2026-11-11-external-update-validation.md)을 완료함. 후보 95문항의 내용 검토에서 15문항을 제외하고 설계용 47문항·372입력·2반복을 실행함. 작은 선택기의 새 학습은 없음.

- 새 근거 제공 시 LME 설계 31/32, BEAM dev 11/15 성공임. BEAM은 사전 80% 기준에 미달해 확인 33문항은 실행하지 않음.
- 현재 새 근거가 있는 상태에 옛 기억을 추가했을 때 LME는 4건 악화·1건 개선, BEAM은 2건 악화·1건 개선임. 옛 기록의 낡은 수치와 유용한 맥락을 구분할 필요가 있음.
- 개수·길이를 맞추고 현재 근거로 성공했던 문항에서 옛 기억 회귀는 LME 2/17, BEAM 1/2임. 같은 문항의 반복·방해 대조는 0건이나 표본이 작음.
- 새 수치가 기록에 있다는 것과 질문의 대상·기간·활동까지 충분히 확인된다는 것은 다름. 설계 자료의 근거 충분성을 보완하는 것이 다음 단계임.

Colab 소유 세션은 종료됐고 서버 활성 세션 0개를 확인함. [공유 묶음](../evaluation/results/external-memory-updates-20261111-v2/README.md)에서 실제 입력·출력 및 판정을 CPU로 재현할 수 있음.

상태 학습의 실제 이득은 같은 입력 비교에서도 남았지만 규칙을 넘지 못함. 이번 모든 조건에서 무기억 성공을 망친 경우는 0건이므로 손해 감소를 성과로 주장하지 않음. 기존 목표 학습 모델에도 상태를 제공했으며 그 전체 결과는 보고서에 있음. 이전 목표 입력만의 24/36과 이번 점수를 직접 연결하지 않음.

## 유지할 성과와 한계

[이전 검색 LoRA](reports/2026-11-09-candidate-search-learning.md)의 후보 확보 개선과 [상태 대조 학습](reports/2026-11-11-memory-need-learning.md)의 작업 효과를 유지함. 이번 검증은 그 모델을 범용 대체품으로 승격하는 근거가 아님. 같은 목표·은행에서 필요한 기억을 바꾸고, 필요성 라벨과 실제 작업 결과를 분리한 데이터 설계가 평가에 도움이 됐음.

이전 [직접 성공·순위 학습](reports/2026-11-10-memory-direct-ranking.md)은 여전히 단순 긴 묶음·참조 규칙보다 낮았음. 이번 개별 기억 판독과 입력·학습 목표가 다르므로 점수를 합치거나 그 문제가 해결됐다고 부르지 않음.

## 자료와 다음 경계

이번 219질문·8기본 계획과 36상태·6가족은 이미 관찰한 자료임. 표현 변화 역시 통제 개입이며 새 자연 발생 경험이 아님. 기존 모델·새 모델·규칙에 같은 정보를 주는 평가 묶음을 다음 검증에도 유지하는 것이 적절함. 임계값을 확인 성적에 맞춰 바꾸거나 만점이 나오는 틀만 늘리지 않음.

다른 에이전트의 [BEAM·LongMemEval 지식 갱신 자료](ai-memory-external-update-data-2026-11-11.md)를 확인한 뒤, 위 현재 관측별 가치 실험에서 BEAM 원문을 재검토해 파생 자료의 학습·개발 선택을 실행함. 기록 순서와 관측을 공통으로 제공하고 새·옛 값 및 남은 범위의 불확실성을 구분함. BEAM 확인 분할의 모델 출력은 여전히 생성하지 않음. LongMemEval-S는 이전에 본 설계·회귀 자료임.

여행 원천 train 60가족 중 36가족을 사용한 상태는 그대로이며 24가족이 남음. 원천 dev 20·test 40은 이번 작업에서도 사용하지 않음.

## 이전 공통 평가의 검산과 자원

해당 공통 평가에서는 새 학습 0회, 실제 checkpoint 5개로 85,800점 추론 및 전체 저장 특징·head 검산을 완료함. 새 작업자 30호출·2반복만 수행하고 이전과 원문까지 같은 114호출을 재사용함. 756정책 결정을 독립 호출 수로 세지 않음.

로컬 GPU 계산과 이번 Colab L4 세션은 종료됨. 서버 활성 세션 0개를 확인함. [공유 묶음](../evaluation/results/memory-selector-regression-20261111-v1/README.md)은 GPU 없이 전체 점수·지표·실제 작업 결과와 특징 표본 640개의 head를 검산할 수 있음.
