# 보관 자료 안내

이 디렉터리는 과거 작업 트리의 고정 보관본이다. 내부 README·설계·코드·예산·명령은 당시의 자료이며 현재 프레임워크의 작업 지침이 아니다. 현재 기준은 루트 `AGENTS.md`와 `docs/`다.

원본 파일의 내용·이름·줄바꿈·버전·라벨을 수정하지 않는다. 재사용·보완·변환은 새 위치와 새 버전에서 하고 원본 snapshot·경로·해시를 연결한다. 폴더를 재생성하거나 보관된 생성 스크립트를 원본 위치에서 실행하지 않는다.

보관본 검증은 루트에서 `uv run python scripts/verify_legacy_data.py`로 수행한다. 파일 내용이 맞는다는 검증이며 의미적 정답·실험 재현·효용 검증은 아니다.
