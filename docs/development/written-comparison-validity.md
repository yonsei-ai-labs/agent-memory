# 작성 기억 비교의 근거와 판정 보완

2026-11-17 · 현재 경로의 정확성·연구 방향 점검 · 새 모델 호출 없음

현재 후속 비교에서 **정확히 어떤 요청을 비교하는지, 공개 정보로 무엇을 판정할 수 있는지, 어느 연구 질문까지 답하는지**를 명시하고 검사한다. 새 [v2 초안](../../protocols/drafts/tau2-written-memory-replay-v2.json)과 준비 산출물을 사용하며 기존 v1 초안·원본·과거 분석은 보존한다. 일반 journal v1.1과 snapshot 제공 v1.2는 변경하지 않았다.

## 고친 경계

기존 준비기는 과제·반복·요청·응답 hash를 검증했지만 문서의 ‘유일한 예약’ 또는 ‘세 예약 중 첫 번째’라는 선정 의미까지 검사하지 않았다. v2는 대상 도구, 요청 순번, 해당 run의 전체 대상 요청 수를 구조화해 검증한다. 다른 유효한 worker 요청이나 후속 예약을 바꿔 넣거나, 잘린 응답·여러 대상 호출로 선정이 모호해지면 거절한다. v1은 과거 준비 호환용이며 현재 CLI 기본값은 v2다.

기억 원본 재계산에서 전체 audit와 피드백별 집계를 receipt와 대조한다. 배정 수와 기억 수가 같다는 이유만으로 다른 작성 기록을 통과시키지 않는다. 빈 작성도 포함한 전체 10개 배정과 원래 제목·본문·버전을 유지한다.

`--audit-only`는 원천에서 준비물을 다시 구성해 manifest, 모든 요청 파일의 바이트와 파일 목록을 대조한다. 준비 폴더에서 변조·누락·추가 파일을 탐지한다. 원천 로그의 고정 hash와 불변 blob 검사는 재구성에 포함되며 출력이나 원본을 쓰지 않는다. 준비 행 160개·서로 다른 요청 48개는 실행 수나 독립 표본 수가 아니다.

## 공개 근거와 좁은 인수 검사

준비 manifest의 `case_review_packet`은 결정 이전의 공개 메시지, 원래 공개 응답, 선정 근거만 담는다. 공식 결과·비공개 추론·숨은 사용자 의도·DB 정답을 넣지 않는다. 통제 메모의 작성 출처는 검토자에게 보이지만 모델 입력에는 들어가지 않는다.

[잠정 rubric](../../artifacts/analyses/20261117-written-memory-public-rubrics.json)은 공개 메시지의 위치·hash·직접 인용에 결합한다. 현재 작성자는 기존 결과를 본 단일 분석 에이전트이며 독립 판정이 아니다. 검증기는 인용과 출처가 맞는지 검사한다. 인용문의 의미 해석이나 판정자 독립성을 자동 입증하지 않는다.

`public-booking-checks/v1`은 수하물 수량과 예약당 증서 수만 검사한다. 수량은 case별 공개 요구에 연결하며, 증서 종류는 결정 이전 `get_user_details` 호출에 대응하는 공개 반환에서 읽는다. ID 접두부나 숨은 DB로 종류를 추정하지 않는다. 공개 결제 수단의 종류가 null·빈 문자열·알 수 없는 값이면 증서 0장으로 통과시키지 않고 미확정으로 남긴다. 명확한 양수 수량도 합법적인 비교값이다. 사용자가 특정 수량을 요구하지 않은 경우에는 0을 정답으로 보충하지 않는다.

| 기존 공개 응답을 검사한 사례 | 좁은 검사 결과 | 남는 한계 |
| --- | --- | --- |
| 14·2 | 실제 호출은 6개·증서 1장. 공개 필요 수량은 미확정 | 무료 6개 안내 뒤의 ‘no extra bags’로 0 또는 6을 확정할 수 없다. 수량 확인·승인 누락이라는 기존 절차 오류 판단은 유지 |
| 14·1 | 명시적 ‘No bags’에 0개·증서 1장으로 두 인수 검사 통과 | 전체 정책 적합성·선행 행동은 별도 검토 |
| 23·2 | 명시적 수하물 없음에 0개. 증서 3장은 한 장 제한 위반 | 결제 수정에는 새 금액·승인 검토도 필요 |
| 23·1 첫 예약 | 명시적 수하물 없음에 0개·증서 1장으로 두 인수 검사 통과 | 세 개로 나누는 전체 예약의 완료는 한 호출로 판단하지 않음 |

[재계산 결과](../../artifacts/analyses/20261117-written-memory-source-calibration.json)는 **과거 응답으로 검사기의 판정 범위를 확인한 자료**다. 새로운 무기억 반복이나 기억 효과가 아니다. 과거 120요청의 참조 기반 검사를 다시 채점하지 않았으며, 새 공개 정보 검사의 분모·정보 접근 범위와 합치지 않는다.

대상 쓰기 없는 질문·조회, 부분/잘린 응답, 알려지지 않은 인수, 명백한 대상 위반, 좁은 검사 통과, 미확정을 구분한다. `target_checks_passed`는 공식 성공이 아니며 `official_success`는 항상 null이다. 승인·신원·가격·항공편·승객·다른 정책 판단은 명시적으로 미판정이다. 기존 실행의 성공도 새 결정의 올바름을 보장하지 않는다.

## 연구 방향과의 연결

이 경로는 `common_experience`의 과거 결정 한 응답 진단이다. 전체 작업자 정책의 효과와 구분한다. 모델이 판단한 작성·조회 선택과 첫 회차 경험 자체가 달라지는 자연 실행 비교는 별도로 유지한다.

| 비교 범위 | 이번 경로 | 이어갈 연구 |
| --- | --- | --- |
| 현재 기억의 국소 효과 | 빈 기억·일반 주의·모델 작성·연구자 메모의 입력 준비 | 실제 새 응답과 case별 판정, 이후 전체 에피소드 |
| 작성의 추가 가치 | 일반 주의와 연구자 메모는 진단 대조 | 무기억 반복·동일 원경험 기록 접근·단순 요약을 포함한 작성 비교 |
| 선택·조회 | 시작 제공만 구성 | 같은 은행의 자율 조회 교차, 자기 경험·혼합 은행에서의 선택 |
| 전이·누적 | 14·23의 공유 고객 개발 출처 하나 | 별도 확인 출처, 재시도·새 과제·조건 변경·누적·체크포인트 회귀 |
| 전체 정책 | 자연 실행·전체 업무 성공 미측정 | 수행 중·종료 후·병행 저장과 읽기, 경험 수집부터 수행까지 전체 비용 |

이 표를 `research_coverage`로 준비 산출물에도 기록한다. 형식 검사는 범위를 잘못 바꾼 v2 설정을 거절하며, 실행/효과의 증명은 아니다. 각 비교에 모든 진단을 강제하거나 이 작은 초안을 전체 PlanCompiler로 취급하지 않는다. 시작 제공에서 개선이 있어야만 다음 비교를 할 수 있다는 조건을 두지 않는다. 저장 0·미조회·효과 없음·악화도 보존한다.

현재 정상 입력을 숨겨 기억 필요성을 만들지 않는다. 원기록·요약 접근 범위는 후속 프로토콜에서 정하며 자동 자르기·BM25·고정 2k를 추가하지 않는다. 구조화된 기억·비평은 별도 비교 후보로 두고, 자유 작성과 원래 피드백 조건을 유지한다.

## 실행과 검증

최종 **전체 273개 테스트가 443.869초에 통과**했다. 기본 검사 3종(설계·저장소 링크·보관본)도 통과했으며 [검증 기록](../../artifacts/analyses/20261117-written-comparison-validity-validation.json)에 실행 범위·개발 코드의 파일 hash·원본 감사 결과를 남겼다. 이는 현재 작업 트리의 개발 검증이며 유료 프로토콜 동결이나 과거 구현 commit의 재현을 대신하지 않는다.

새 행동 검사 13개는 선정 요청의 교체·잘린 응답·근거 위조·원문과 다른 작성 receipt·준비 파일의 변조/추가/누락과 잘못된 성공 판정을 거절하는지 확인한다. 결제 종류 미확정의 세 입력은 수정 전에 잘못 통과하는 것을 재현한 뒤 고쳤다. 실제 네 사례의 좁은 판정은 이 수정 전후에 같다.

실제 원본을 사용한 v2 준비와 읽기 전용 재구성 감사도 통과했다. 작성 배정 10개(빈 작성 1개), 준비 행 160개, 고유 입력 48개다. 감사 중 네트워크·프로세스 실행·파일 쓰기를 막았고 금지된 시도는 0이었다. 무기억 원본 6,591개 파일·작성 원본 410개 파일·준비 산출물 49개 파일의 목록·크기·수정 시각이 전후 동일했다. `943fe94`의 renderer 함수와도 48개 입력 바이트·160개 대응 행이 같았다. 이 비교는 현재 공유 의존성을 사용하는 함수 비교이며 고정 checkout의 전체 과거 재현을 대신하지 않는다.

```bash
uv run --frozen python scripts/prepare_written_memory_comparison.py \
  --output outputs/NEW_WRITTEN_MEMORY_COMPARISON
uv run --frozen python scripts/prepare_written_memory_comparison.py \
  --output outputs/NEW_WRITTEN_MEMORY_COMPARISON --audit-only
uv run --frozen python scripts/review_written_memory_cases.py \
  --preparation outputs/NEW_WRITTEN_MEMORY_COMPARISON \
  --rubrics artifacts/analyses/20261117-written-memory-public-rubrics.json
```

잠정 rubric은 현재 고정 v2 profile에서 만든 packet에만 적용한다. 과제·출처·통제 메모가 바뀌면 근거를 다시 검토해야 한다. 새 준비 패킷에 과거 판정을 자동 전용하지 않는다. 검토 명령의 packet hash 검사는 내부 연결 확인이며, 원본부터의 무결성은 먼저 실행한 `--audit-only`에서 확인한다.

새 모델 호출·업무 도구 실행·새 공식 점수는 없다. 독립 의미 검토, 1차 비교·반복/의존성 분석, 새 실행 한도, 실제 요청 기록기 연결과 동결된 실행 프로필은 후속으로 남는다. 기존 유료 승인·실측 결과를 새 실험으로 전용하지 않는다.
