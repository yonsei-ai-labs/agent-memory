# 과거 메모가 후속 상담을 바꾼 조건

2026-11-23 · τ² 소매·항공 실험의 기억 효과 리뷰

**지난번에 어느 주문을 이야기했는지가 필요한 상담에서는 메모를 시작할 때 제공하면 첫 주문 선택이 개선됐고, 고객이 같은 정보를 다시 말하는 일도 줄었다.** 일반 소매·항공 과제의 최종 성공률에서는 일관된 개선을 확인하기 어렵다. 메모를 쓸 기회, 실제 입력에 들어간 내용, 행동과 최종 성적을 각각 살펴보면 이 차이를 설명할 수 있다. [원래 연구 질문](../research/plan.md) · [측정 명세](../research/metrics.md)

## 지난 주문을 알아야 하는 재방문

공식 소매 과제에 쓰이지 않은 고객 77명에게 두 가지 첫 방문 이력을 구성했다. 같은 고객이 재방문 때 똑같이 “지난번에 이야기한 주문”을 가리켜도 어느 주문을 뜻하는지는 이전 상담에 따라 달라진다. 주 비교에서는 안내와 현재 주문 목록을 같게 두고, 한 조건에는 첫 방문 뒤 작성한 메모 묶음을, 다른 조건에는 빈 묶음을 제공했다. 무노트 조건은 기억 안내와 도구가 없는 별도 대조다. [배정과 대조 조건](20261122-retail-two-visit-results.md#같은-고객의-지난-주문을-바꾼-비교)

| 판단과 상담 결과 | 메모 자동 제공 | 빈 자동 제공 |
| --- | ---: | ---: |
| 첫 행동으로 목표 주문만 조회 | 129/154 | 27/154 |
| 어느 주문인지 고객에게 되물음 | 24/153 | 128/153 |
| 틀린 주문의 취소를 제안 | 5/153 | 26/153 |
| 대상·사유를 설명하고 승인받아 목표 주문 취소 | 153/153 | 148/153 |
| 최종 DB에서 목표 주문 취소 성공 | 153/153 | 153/153 |

첫 판단의 고객별 평균 차이는 **+66.2%p**로 70명이 개선됐고 7명은 같았다. 나머지 네 행은 두 조건 모두 끝까지 관측한 같은 153쌍이다. 고객은 되물음에 답하거나 잘못된 제안을 고칠 수 있어 양쪽 모두 목표 주문을 취소했다. 승인 절차까지 충족한 차이는 +3.2%p였고, 양측 정확 부호검정은 p=0.0625였다. [상담별 결과와 짝비교](20261122-retail-two-visit-results.md#지난-주문을-지칭한-상담)

어떤 정보가 차이와 연결됐는지도 확인했다. 첫 판단 순증 102건 중 **101건이 목표 주문번호를 담은 메모 묶음**에서 나왔다. 작성자가 번호와 함께 어떤 내용을 남길지도 결정했으므로 이는 사후 내용별 집계다. 고객이 현재 주문번호를 직접 알려 준 1,540건에서는 다섯 조건 모두 해당 주문부터 조회했다. [메모 내용과 현재 정보](20261122-retail-two-visit-results.md#주문의-위치와-현재-정보)

## 저장·조회·최종 성과의 관계

- **일반 과제의 성공률.** 기존 소매 세 실험의 채점 상담 2,012건에서 같은 과제·반복을 짝지어 구한 고객별 평균 차이는 메모가 무노트 대비 −0.9%p(95% 구간 −6.0∼+4.2), 빈 메모 대비 +0.1%p(−5.1∼+5.3)였다. 여러 메모 조건이 한 대조 상담을 공유한다. 항공 재수행에서도 무기억과 함께 채점한 149쌍 중 메모만 성공한 경우가 18쌍, 무기억만 성공한 경우가 16쌍이었다. 네 작성 형식의 우열은 과제에 따라 달라졌다. [소매 세 실험 종합](20261122-retail-handoff-factors.md#합친-자료와-평균-차이) · [항공 짝비교](20261118-two-pass-memory-success-factors.md)
- **저장.** 같은 소매 원천 상담 22개에서 작성 지침을 보완하자 실제로 저장한 메모가 73/88개에서 83/88개로 늘었다. 같은 본인확인 안내 아래 기존 작성물과 보완 작성물의 후속 상담이 모두 채점된 106쌍에서는 보완 쪽만 성공한 경우와 기존 쪽만 성공한 경우가 각각 15쌍이었다. [작성률과 후속 상담](20261121-retail-transfer-revision.md)
- **자율 조회.** 자기 메모와 여러 과제의 메모를 비교한 소매 상담 528회에서 목록·본문 조회가 0회였다. 483회에는 실제 열 수 있는 메모가 있었다. 77명 재방문에서도 조회 도구가 열린 첫 판단 924회와 그중 정상 종료한 상담 923회에서 조회가 0회였다. 이 모델·안내·과제 조합에서는 목록을 여는 단계에서 멈췄으므로, 여러 기억 중 유용한 항목을 고르는 능력은 평가할 수 없었다. [자기·혼합 메모 비교](20261120-retail-candidate-pools.md) · [재방문 조회 기록](20261122-retail-two-visit-results.md#주문의-위치와-현재-정보)
- **잘못 남긴 교훈.** 소매 31번 과제에 쓰인 원천 상담은 사람에게 이관하지 않고 공식 성공했다. 성적을 전달받지 않은 작성자는 이관하지 않은 점을 문제로 적었다. 이관을 언급한 메모를 받은 상담 7회 중 5회는 주문을 하나도 바꾸기 전에 이관했다. 이 사례는 사후에 찾아낸 연관이며 문구 하나를 통제해 바꾼 비교는 별도로 필요하다. [31번의 원천과 후속 행동](20261122-retail-handoff-factors.md#두-과제의-사례)

## 재방문 모델 비용

본 실행과 복구 원장에서 같은 사례의 두 조건이 모두 정상 종료한 쌍을 골랐다. 표는 첫 판단부터 종료까지 상담원과 고객 시뮬레이터의 **확인 요금 합계**다. ‘현재 주문번호 명시’는 지난번과 같은 주문을 지정한 경우와 다른 주문을 지정한 경우를 합쳤다. 상대 차이는 `(메모 비용 ÷ 빈 메모 비용 − 1) × 100`이다.

| 현재 고객 요청 | 짝 수 | 메모 요청 수 | 빈 메모 요청 수 | 메모 비용 (USD) | 빈 메모 비용 (USD) | 상대 차이 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 번호 없이 지난 주문을 지칭 | 153 | 992 | 1,278 | 0.170542701 | 0.197003961 | −13.4% |
| 현재 주문번호 명시 | 305 | 1,832 | 1,844 | 0.311099989 | 0.265862726 | +17.0% |

지난 주문을 찾아야 할 때는 메모가 있는 상담에서 요청과 요금이 함께 줄었다. 번호가 이미 주어진 상담에서는 요청 수가 비슷했고 메모 조건의 요금이 더 컸다. 이는 정상 종료한 짝의 사후 비교다. 표에 포함된 요청의 미확정 청구는 0건이다. 첫 방문과 작성 비용은 별도로 기록했다. 154개 이력에서 네 형식으로 메모를 작성한 616건의 확인 비용은 $0.303743410이었다. 전체 운영 비용을 추정하려면 같은 메모를 몇 번 재사용하는지도 정해야 한다. 저장소 루트에서 실행한다. 분석 커밋 `6b66799`의 공개 결과와 감사 파일, 로컬의 본 실행·복구 폴더 두 개를 사용한다. 각 원장 안에서 예약과 정산을 `seq`로 연결하고, 공개 결과의 `recovery_slot`으로 각 배정이 실제로 수행된 원본을 선택한다.

```bash
python3 - <<'PY'
from collections import defaultdict
from decimal import Decimal
from hashlib import sha256
import json
from pathlib import Path

def checked_bytes(path, expected):
    data = path.read_bytes()
    if sha256(data).hexdigest() != expected:
        raise ValueError(f"Input hash mismatch: {path}")
    return data

prefix = "artifacts/analyses/20261122-retail-two-visit-"
audit = json.loads(Path(prefix + "final-audit.json").read_bytes())
results = json.loads(checked_bytes(Path(prefix + "results-with-recovery.json"),
                                   audit["analysis_sha256"]["augmented"]))
charges = defaultdict(list)
writing_cost = Decimal(0)
batches = [("original", "", "registration_sha256"),
           ("supplement", "-recovery", "recovery_registration_sha256")]
for cohort, suffix, registration_hash in batches:
    folder = Path("runs/tau2-retail-two-visit-01" + suffix)
    jobs = json.loads(checked_bytes(folder / "registration.json", results[registration_hash]))["jobs"]
    cases = {(stage, j["run"]): (j["task"], j["arm"])
             for stage in ("decision", "continuation") for j in jobs[stage]}
    ledger = checked_bytes(folder / "expense.jsonl", audit["evidence"][cohort]["billing"]["ledger_sha256"])
    entries = [json.loads(line) for line in ledger.splitlines()]
    settled = {e["seq"]: Decimal(e["cost"]) for e in entries if "cost" in e}
    for e in entries:
        if "reserved" not in e:
            continue
        if e["stage"] == "writer":
            writing_cost += settled[e["seq"]]
        elif e["stage"] in ("decision", "continuation"):
            task, arm = cases[e["stage"], e["run"]]
            charges[cohort, task, arm].append(settled.get(e["seq"]))

arms = ("preload", "empty_preload")
completed = defaultdict(dict)
for row in results["continuations"]:
    if row["completion"] == "completed" and row["arm"] in arms:
        cohort = "supplement" if row["recovery_slot"] else "original"
        values = charges[cohort, row["task"], row["arm"]]
        if not values or None in values:
            raise ValueError("Missing confirmed charge in a completed consultation")
        completed[row["mode"], row["task"]][row["arm"]] = values

for modes in [("previous_only",), ("explicit_same", "explicit_other")]:
    pairs = [p for (mode, task), p in completed.items() if mode in modes and len(p) == 2]
    totals = []
    for arm in arms:
        values = [cost for p in pairs for cost in p[arm]]
        totals.append(sum(values))
        print(modes, arm, len(pairs), len(values), totals[-1])
    print(f"Relative change: {(totals[0] / totals[1] - 1) * 100:+.1f}%")
print("Writer USD:", writing_cost)
```

## 프레임워크에서 확인한 범위

지금까지 자료로 추적할 수 있는 것은 과거 경험의 어떤 사실이 저장됐고, 어느 판단 직전에 전달됐으며, 같은 사례의 대조와 행동·고객 부담·최종 점수·비용이 얼마나 달라졌는지다. 개별 상담에서 근거와 행동이 일치했다는 관측과, 사전 배정한 두 정책의 차이는 각각 보고한다. 자율 조회를 시작하는 조건, 현재 상황에 맞지 않는 교훈을 걸러내는 능력, 여러 회차에 걸친 기억 누적의 순이득은 남은 연구 질문이다.
