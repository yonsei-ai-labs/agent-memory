# 지난 상담 메모를 주면 지금 찾는 주문부터 여는가

고객이 주문번호 없이 상품을 설명한 시점에서, 상담원에게 과거 메모를 자동으로 보여 주자 해당 주문 하나부터 조회한 횟수가 **16/28회(57.1%)**였다. 같은 안내에 빈 메모를 준 조건은 **9/28회(32.1%)**, 무노트는 **7/28회(25.0%)**였다. 각 고객에 같은 가중치를 준 사전 지정 주 비교에서 자동 제공과 빈 메모의 차이는 **+35.7%p**였다(고객 재표집 95% 구간 +14.3∼+64.3%p). 같은 메모를 자율 조회할 수 있게 한 28회에서 상담원이 목록이나 본문을 연 횟수는 0회였다. ## 어떤 판단을 비교했나

기존 관련 과제 24개에서 무노트 상담의 본인확인이 끝나고 고객 프로필에 주문 후보가 나타난 첫 시점을 찾았다. 후보가 여럿인 23개 중, 고객이 말한 상품 조합이 고정 소매 DB의 주문 한 건에만 있고 고객이 주문번호를 알려 주지 않은 11개를 채택했다. 대조 시점까지 주문 상세 조회와 변경은 모두 0건이었다. 과거의 다른 상담 145건도 확인했지만, 메모 삽입분을 거두고 도구 호출 식별자까지 맞춘 뒤에도 공개 요청이 같은 사례는 없었다. [판단 선정 기준](../../protocols/diagnostics/tau2-retail-order-choice-v1.json) · [24개 과제의 포함·제외 근거](../../artifacts/analyses/20261122-retail-order-choice.json)

목표 11개와 기존 원천 과제 8개가 같은 고객 7명에서 14쌍을 이뤘다. 한 원천의 사실·일기·교훈·절차 네 형식에서 실제로 저장한 제목과 본문을 묶었다. 작성자가 저장을 생략한 경우가 있어 쌍마다 메모가 2∼4개였다. 각 쌍에 다섯 조건을 두 번씩 배정했다. 매번 새로운 세션을 열고, 같은 대화·프로필·업무 도구·모델 설정을 복원했다. 자동 제공은 그 판단 요청에 과거 메모를 넣었다. 자율 조회에는 선택 가능한 목록·본문 도구를 제공했다. 자율 조회와 빈 자율 조회는 목록을 열기 전까지 전송 바이트가 같았다. 무노트는 보관된 무노트 요청과 바이트가 같았다. 정답 주문번호는 분석용 DB에서 정했다. ## 어떤 메모가 도움이 됐나

- **같은 고객의 태블릿 과제 30·31번.** 원천 32번의 사실 메모에는 분실한 태블릿과 그 주문번호가 함께 적혀 있었다. 현재 프로필에는 주문이 5개였고 태블릿 주문은 세 번째였다. 자동 제공 4회는 모두 해당 주문 하나를 조회했다. 빈 자동 제공 4회는 다른 주문만 3회, 해당 주문이 포함된 복수 조회 1회였다. 무노트 4회는 모두 다른 주문을 조회했다. 이 두 과제는 같은 고객과 같은 원천을 공유한다. [판단별 기록](../../artifacts/analyses/20261122-retail-order-choice-replay-results.json) · [상품 단서와 프로필 순서](../../artifacts/analyses/20261122-retail-order-choice.json)
- **물병과 책상 조명 과제 6·7·8번.** 원천 9번은 두 상품과 주문번호를 함께 남겼지만, 이 메모를 제공한 6회 모두 상담원이 고객에게 어느 주문인지 되물었다. 반대로 같은 세 과제에서 고객의 주문번호가 메모에 없던 원천 5번을 제공한 6회는 모두 해당 주문 하나를 조회했다. 세 과제 모두 목표 주문이 프로필 첫 번째였다. 메모에 번호가 있는지와 실제로 어떤 판단을 내렸는지는 따로 읽어야 한다. 원천의 제목·본문에 목표 주문번호와 다른 주문번호가 함께 있었던 배정에서 자동 제공과 빈 자동 제공은 각각 5/6회와 0/6회 바로 조회했다. 목표 번호만 적힌 배정은 5/12회와 6/12회, 고객 소유 주문번호가 한 개도 적히지 않은 배정은 6/10회와 3/10회였다. 내용과 고객·과제·주문 목록 순서가 함께 달라지므로 이 분류로 특정 문구나 작성 형식의 효과를 추정할 수 있는 범위는 제한된다.
