## 실험 조건

BFCL V4의 단일 질문 8개를 응답을 생성하기 전에 골랐다. 4개는 업무 함수를 호출해야 하고 4개는 호출을 삼가야 한다. 각 질문을 로컬 Qwen3.5-4B가 먼저 무기억으로 풀었다. 같은 모델이 같은 공개 질문·함수 명세·자신의 응답과 1회차 성패 한 비트를 보고 사실·경험·절차·교훈·자유 메모를 하나씩 썼다. 작성 시 저장 함수 이름만 지정했고 제목과 본문은 모델이 생성했다. 작성자에게 함수의 실제 반환값, 정답, 범주 이름을 제공하지 않았다.
