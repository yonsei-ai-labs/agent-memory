# 어떤 메모를 열었고, 같은 성공까지 얼마가 들었나

## 소매에서 본문을 고를 때 볼 수 있었던 것

지난 주문을 번호 없이 지칭한 소매 사례 154건에서 조건부 안내와 실제 메모를 받은 상담원의 **첫 본문 조회**를 확인했다. 각 요청의 공개 고객 발화·도구 결과, 목록에 표시된 제목과 순서, 실제로 요청한 항목, 반환된 버전을 원기록에서 대조했다. 131건에서 본문을 요청해 모두 정상 반환됐고 23건은 첫 업무 판단까지 본문을 요청하지 않았다. 본문을 연 131건 중 처음 고른 제목에 목표 주문번호 전체(`#W`로 시작하는 원문 표기)가 그대로 적힌 경우는 1건이었다. | --- | ---: | ---: | ---: |

선택지가 둘 이상이었던 116건 중 109건(94.0%)에서 첫 제목을 열었다. 이 비교에서는 제목과 위치가 함께 움직인다. 첫 위치를 선호했는지, 첫 제목이 더 적합했는지를 검증하려면 현재 요청·메모 내용·조회 안내를 고정하고 **제목의 순서만 바꾸는** 판단 비교가 필요하다. 이 결과는 조건부 안내가 있는 한 모델·업무에서 관측한 선택 분포다.

한 사례에서 고객은 “the order we discussed last time”을 취소해 달라고 했고, 현재 도구 결과에는 주문 일곱 개가 있었다. 첫 요청에서 상담원이 목록을 열자 “Order lookup example and outcome”, “Retail order lookup example”, “Retail order lookup procedure” 세 제목이 표시됐다. 상담원은 첫 제목의 본문을 요청했다. 다음 업무 요청에 그 본문이 포함됐고 상담원은 그 안에 적힌 주문 `#W9903153` 하나를 조회했다. 같은 안내의 빈 메모 조건은 다른 주문을 조회했다. 어떤 정보를 언제 볼 수 있었고 다음 행동이 무엇이었는지는 검증됐다. 개별 선택의 동기는 미확정이다. [이 사례의 원천 문장·대조 조건](20261123-memory-claim-evidence.md)

154건 전체에서 목표번호가 **메모를 통해 업무 판단 입력에 나타난** 94건 중 91건은 그 주문만 바로 조회했다. 같은 안내 아래 정확한 첫 조회는 실제 메모 106/154, 빈 메모 34/154였다. 94건은 노출 이후의 부분집합이고, 154쌍은 배정된 정책 비교다. 이 실험이 관측한 끝점은 첫 업무 판단이다. [단계별 분모·공식 결과 범위](20261123-retail-conditional-retrieval.md)

## 항공에서 같은 성공에 도달한 비용과 고객 부담

기존 사실 메모와 재확인 지침을 추가한 사실 메모를 같은 평가 과제 2개에서 두 번씩 비교했다. 공식 성적은 4쌍 중 양쪽 성공 3쌍, 재확인 조건만 성공 1쌍이었다. 아래는 **양쪽 모두 공식 성공한 같은 3쌍**의 합계다. 첫 세 행은 행동·고객 부담이며, 나머지는 상담원과 고객 시뮬레이터의 2회차 실제 사용량이다. 이 실험은 시작할 때 메모 본문을 제공했다. [조건·평가 과제와 채점 차이](20261118-fact-recheck-results.md)

| 측정 | 기존 메모 | 재확인 메모 | 변화 |
| --- | ---: | ---: | ---: |
| 고객 발화 | 11 | 9 | −2 |
| 업무 도구 호출 | 5 | 5 | 0 |
| 메모 목록·본문 조회 호출 | 0 | 0 | 0 |
| 모델 HTTP 요청 | 30 | 26 | −4 |
| 토큰 | 80,263 | 70,249 | −12.5% |
| 확인된 모델 요금 | $0.004004167 | $0.004148845 | +3.6% |

재확인 메모와 **보관된 1회차 무기억**의 비교에서는 평가 배정 4쌍 모두 양쪽 성공이었다. 같은 기준으로 1회차→재확인의 고객 발화는 16→13회, 업무 호출은 8→9회, 토큰은 104,074→107,089였다. 이 합계에서 각 1회차 원천은 두 반복이 공유한다. 원천을 실제로 수집한 횟수는 2회다. 회차 간 변화에는 재실행 변동이 포함되며 실제 요금에는 시점별 결제 조건도 반영된다.

표의 발화 수는 공개 사용자 메시지 중 종료 신호만 보낸 메시지를 제외한다. 고객에게 같은 정보를 되묻거나 잘못된 제안을 한 횟수는 별도 업무 주석이 필요하다. 소매 자동 제공 전체 상담에서는 같은 153쌍 모두 목표 주문을 취소했지만, 어느 주문인지 되물은 상담은 빈 메모 128건에서 실제 메모 24건으로 줄었다. 이 전체 상담 자료와 위 조건부 조회의 첫 판단 자료는 각각 다른 실행이다. [소매 상담 과정·채점 결과](20261122-retail-two-visit-results.md)

효율 보고서는 양쪽이 채점된 전체와 양쪽 성공한 부분집합을 함께 제공한다. 한 지표의 양쪽 값이 모두 확인된 쌍에서 합계·차이·상대 변화와 감소·동일·증가 건수를 계산한다. 미확정 요금·토큰은 그 지표의 결측으로 남긴다. 작성·갱신 비용은 각 상담의 사용량과 별도로 계산해야 메모 재사용 횟수에 따른 순비용을 평가할 수 있다.
