분석 JSON의 `core_error`는 명시적 부분 교정·잔존·미시험·미확정을 남긴 보조 주석이다. 예를 들어 39의 날짜·24시간 판단을 교정하면서 보험 규칙을 어기거나, 17의 등급 규칙을 교정하면서 날짜를 틀릴 수 있다. `corrected` 하나를 모든 정책 위반의 해소로 해석하지 않는다. 핵심 비교는 근거가 붙은 전체 응답 범주와 지점별 실제 호출이다.

## 재검증

```bash
uv run --frozen --extra tau2 python scripts/run_decision_replay.py --audit-only --output runs/tau2-decision-replay-luna-120-01
uv run --frozen --extra tau2 python scripts/review_decision_replay_120.py
```

두 명령은 저장된 자료만 사용하며 모델·업무 도구를 호출하지 않는다. 분석 코드는 수집 중 별도로 작성했고 판정 기준·packet ID 알고리즘은 첫 호출 전에 동결했다. 실행 구현 128개 참조와 프로필·판정·출처 참조는 유지한다. 원본 응답을 숨긴 packet을 다시 만들 수 있고, 보존된 주석과 근거 구간을 자동 검사한다. 자동 검사가 단일 검토자의 의미 판정 자체를 입증하지는 않는다.

유료 실행 전 재전송 행동 테스트 16개, 분석 packet·주석 검증 테스트 3개가 각각 통과했다. 결과 작성 뒤 기본 검사 3개·보존된 분석의 재계산·기존 동결 참조 85개/64개와 현재 133개 대조도 통과했다. 현재 133개는 실행 구현 128개와 별도 출처·판정 참조 5개다. 기존 전체 148개 통과는 전 단계의 이력이며 전체 151개를 이번에 다시 실행했다고 보고하지 않는다. 큰 raw는 Git 밖에 보존하며 공유 위치는 [팀 원본 공유 안내](../data/team-run-sharing.md)를 따른다.
