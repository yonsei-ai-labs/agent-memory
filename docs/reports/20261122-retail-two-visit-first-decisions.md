# 새 고객 77명의 두 번째 방문에서 기억이 첫 주문 선택에 미친 효과

고객이 “지난번에 얘기한 주문”만 가리켰을 때, 자동으로 받은 과거 메모가 있으면 같은 143쌍에서 목표 주문 하나를 바로 조회한 횟수가 **26회에서 119회**로 늘었다. 고객마다 같은 비중을 준 사전 지정 차이는 **+64.3%p**였다. 77명 중 66명이 개선됐고 11명은 같았다. 자기 판단으로 메모를 여는 도구를 제공한 조건에서는 첫 업무 판단까지 한 번도 메모를 열지 않았다. 고객이 현재 주문번호를 말한 경우에는 관측된 다섯 조건 모두 해당 주문을 바로 조회했다. 지난 주문만 지칭한 요청의 주 비교에서 고객별 차이의 10,000회 재표집 구간은 +56.5∼+72.1%p였다. 개선·악화 고객 수에 대한 양측 부호검정은 p < 0.0001이었다. 미관측 11건 각각에 가능한 성패를 모두 대입해 원래 154쌍으로 계산한 차이의 범위도 +59.7∼+66.9%p였다. 목록 뒤쪽과 맨 앞 사이의 고객 단위 효과 차이는 +35.2%p였고, 같은 고객들을 함께 재표집한 구간은 +17.2∼+53.1%p였다. 목록 위치는 고객의 프로필에서 정해지므로 위치 자체를 무작위로 바꾸었을 때의 효과는 별도 질문이다. 빈 자동 제공 154건 전체로는 지난 주문을 바로 조회한 것이 27회, 무노트는 16회였다. 자율 조회와 빈 자율 조회를 같은 143쌍에서 보면 32회와 28회였다. 이 차이의 고객별 평균은 +2.6%p이고 재표집 구간은 −4.5∼+9.7%p였다. 자율 조회 429건과 빈 자율 조회 462건에서 첫 판단 전에 목록·본문을 요청한 횟수는 모두 0이었다. 이 인터페이스에서의 첫 선택 차이에 메모 본문을 읽은 사례는 없다. ## 과거 주문번호를 남겼을 때

지난 주문만 지칭한 143쌍을 작성된 메모 내용으로 나눈 탐색적 집계다. 자동 제공의 전체 순증 93회 중 92회가 목표 주문번호가 실제로 저장된 112쌍에서 나왔다. 번호를 저장할지는 작성자가 결정했으므로 특정 문구의 독립적 효과는 이 표로 정할 수 없다. [내용별 원계수](../../artifacts/analyses/20261122-retail-two-visit-first.json)

## 관측 범위와 비용

원천 상담 154건 중 143건은 정상 종료해 공식 점수 1점을 받았다. 고객 시뮬레이터의 HTTP 503으로 11명이 과거 주문 이력 하나씩을 잃었다. 해당 주문 이력이 필요한 메모 작성 44건과 후속 첫 판단 66건에 결측을 기록했다. 정상 원천에서 작성한 572건은 저장 347건과 자발적 생략 225건이었다. 2회차 첫 판단 2,310건의 배정 중 2,244건에 응답이 도착했다. 관측된 다섯 조건의 실제 원문과 각 원천의 작성 은행 143개를 다시 대조해 서로 다른 세션 2,244개를 확인했다. ‘바로 조회’는 첫 업무 응답에 목표 주문에 대한 조회 한 건만 있었음을 뜻한다. 고객에게 주문번호를 물어도 이후 정확한 주문을 확인하고 동의를 받아 상담을 성공시킬 수 있다. 이 보고서의 측정은 본인확인 직후 고정한 첫 판단까지다. 실제 취소, 고객 승인, 최종 성공, 끝까지 든 비용은 이어진 상담의 자료에서 집계한다. 대상은 같은 소매 DB의 별도 고객으로 만든 두 번 방문 과제다. [전체 상담의 판독 기준과 범위](../research/retail-two-visit-v1.md)

## 재현

원본 영수증이 있는 작업 공간에서 다음 명령으로 결과를 다시 생성할 수 있다. 첫 판단 이후 시작한 상담의 비용과 대화는 이 출력에 들어가지 않는다. 독립된 두 출력의 바이트가 일치했다.

```bash
visit_first_dir=$(mktemp -d)
uv run --frozen --no-sync python -m scripts.analyze_retail_two_visit --first-only --run runs/tau2-retail-two-visit-01 --output "$visit_first_dir/first.json"
cmp "$visit_first_dir/first.json" artifacts/analyses/20261122-retail-two-visit-first.json
```
