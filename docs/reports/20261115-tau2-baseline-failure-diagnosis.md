# 무기억 기준선 실패의 원인 진단

2026-11-15 · 원본 입력 대조·native 오프라인 재생 · 새 모델 호출 0

**현재 확인한 문제는 정책·관측의 전달 누락, 모델의 조건 적용, 사용자 시나리오, 채점을 구분해서 봐야 한다.** 결정 직전 입력에서 전달 누락은 발견하지 못했다. 정책을 받았어도 잘못 적용한 행동이 있었고, 공식 실패 중에는 실현된 요청과 고정 정답을 먼저 맞춰야 하는 사례도 있었다. 모델이 왜 그런 판단을 생성했는지까지 식별한 결과는 아니다.

[원래 측정](20261115-tau2-baseline-screening-results.md)의 공식 성공 **44/55**, 미채점 1·미시작 4, 비용 미확인 요청 1건은 유지한다. 이 진단으로 조정 성공률을 만들거나 실패를 재실행으로 대체하지 않았다. [기계적 진단 근거](../../artifacts/analyses/20261115-tau2-baseline-failure-diagnosis.json)와 기존 [공개 행동 주석](../../artifacts/analyses/20261115-tau2-baseline-behavior-review.json)은 분석 전용이다.

## 점수가 갈리는 지점을 좁힌 오프라인 점검

이 점검은 별도 메모리·모델 실행이 아니다. 격리된 로컬 환경에서 호출 인수나 복사한 답변만 바꿨다. 모델이 스스로 그 변경을 선택하거나 이후 올바르게 행동할지는 측정하지 않았다.

### 7: 질문 시점 외에 대상 범위도 문제다

초기 미래 예약 네 개의 지급액은 **402 + 306 + 296 + 624 = 1,628**이다. 취소 요청 대상 두 예약을 제외한 다른 미래 예약은 **402 + 306 = 708**이고, 두 취소가 끝난 후 남은 예약의 합계도 708이다.

실제 질문은 두 취소 후 ‘다른 upcoming flights’의 합계를 물었다. 원래 시나리오에도 ‘other upcoming flights’가 있으므로, 질문을 지시된 세 번째 agent 메시지 뒤로 옮기는 것만으로 1,628이 타당해지는 것은 아니다. 무엇을 합산할지 먼저 정의해야 한다.

원래 답변의 **708만 1,628로 바꾸자 COMMUNICATE가 0→1**로 바뀌었다. DB는 원래도 1이었다. 이는 native substring 채점이 질문의 대상·상태를 판정하지 않는다는 구체적인 예다. 현재 요청과 덜 맞는 값을 기억해서 답하도록 개선하면 점수만 높아질 수 있다. 별도로 첫 취소의 명시적 확인 절차는 기존 검토 문제로 남는다.

### 39: 보험 보유와 보장 사유를 구분해야 한다

첫 반복에서 거절한 MSJ4OA는 economy·보험 있음·약 240시간 전 예약이며 항공편은 available이었다. 사용자가 말한 이유는 남에게 자리를 양보하기 위해서였다. 정책은 건강/기상 사유의 보험 보장을 요구한다.

원래 두 business 취소 뒤 **MSJ4OA 취소 하나를 인위적으로 추가하면 참조 DB와 일치**했다. backend도 이 취소를 받아들였다. 정책에는 취소 조건을 API가 검사하지 않는다고 명시돼 있다. 따라서 API 반환 성공과 참조 DB 일치를 정책상 올바른 행동의 대체 근거로 쓸 수 없다.

두 번째 반복의 UDMOP1·XAZ3C0 취소는 별개다. 이들은 무보험 basic economy이고 24시간도 넘었다. 참조 정합성 문제가 있다는 이유로 이 실제 부적합 취소까지 설명해 없애지 않는다.

### 14: DB 차이는 특정됐고, 의도 전달은 여전히 검토해야 한다

같은 호출 순서에서 **book의 `total_baggages`만 6→0**으로 바꾸자 참조 DB와 일치했다. 증서 1장 제한과 Mastercard $1,786 계산은 원래도 맞았다.

성공한 첫 반복에서는 사용자가 수하물이 없다고 명확히 말했다. 실패한 두 번째 반복에서는 agent가 무료 허용량 6개를 제시한 뒤 사용자가 추가 수하물이 없다고 답했다. 시나리오의 실제 의도는 0개였지만 공개 대화는 같은 정도로 명확하지 않았다. 이 진단은 숨은 수량을 기억에 넣어도 된다는 근거가 아니며, 허용량과 필요한 수량을 별도로 확인할 필요를 보여준다.

### 23: backend가 규칙 위반을 막아주지 않았다

원래 잘못된 한 예약·증서 세 장 적용이 strict 재생에서도 성공 반환됐다. 참조는 **승객별 예약 세 개·각 증서 한 장**이다. 이름이나 인수가 중간에서 변한 문제가 아니라 원응답에 있던 호출이었다.

원래 시나리오는 agent가 한 장 제한을 설명하면 사용자가 분할 예약을 제안하도록 작성돼 있다. 실제 성공 반복에서는 그 제안이 예약 전에 나왔고, 실패 반복에서는 위반 예약 뒤에 나왔다. 점수 차이는 worker의 규칙 적용과 그에 반응한 사용자 대화가 함께 만든 경로다. 단순히 같은 지식을 알고 있었는지만 비교한 결과로 해석하기 어렵다.

### 20: 거짓 시간 판단이 검색 조건을 바꿨다

잘못된 발화 직전 worker 입력에는 **2024-05-15 15:00 EST**가 있었다. 우리 worker system에 2026이라는 연도는 없었다. 반면 사용자 system에는 같은 기준 시각이 명시돼 있지 않았다. agent의 잘못된 과거 판단 뒤 사용자 발화가 2025를 새로 지정했다.

따라서 2025년 검색 실패를 원래 날짜의 검색 능력 부족으로 동일시하지 않는다. 제공자 내부 시각이나 긴 문맥·reasoning low 중 무엇이 최초 판단을 유발했는지는 현재 자료로 분리할 수 없다. 날짜를 함께 명시하는 진단은 별도 변형으로 검토할 수 있다.

## HTTP 503으로 배치가 멈춘 경로

미채점 과제 28의 두 번째 반복은 user_simulator 요청에서 `HTTP_503`을 받았다. 보존된 응답은 **code 503·routing_reason provider**뿐이다. transport는 원래 오류 본문·헤더를 그대로 저장하지 않고 이 정보로 축약한다. 특정 상위 제공자의 장애인지, 일시적인 혼잡인지, 구체적인 요청 거절인지는 복원할 수 없다.

이 경로에서 비용을 미확인으로 표시하고 전체 배치를 멈춘 것은 고정한 guard의 동작이다. $1 예산이나 native 단계/오류 한도가 원인이 아니며, 앞서 채점된 55회의 업무 실패와도 다른 종류다. 향후 재시도를 허용하려면 횟수·비용 미확인·표본 처리 규칙을 새 프로토콜에 먼저 적는다. 원본은 자동 재개하지 않았다.

## 연구와 다음 보완에 반영할 판단

1. **평가 정합성부터 고친 새 버전을 준비한다.** 7은 합산 대상과 시점, 39는 보험 사유와 취소 목표, 11은 원래 결제수단과 실현된 승인, 14는 실제 수하물 수량을 검토한다. 기존 원본·공식 점수와 새 진단 과제를 분리한다. 현재 검토는 단일 검토자이므로 독립 재판정은 아직 남아 있다.
2. **절차 후보의 오류가 무엇인지 고정한다.** 17의 등급 변경 예외, 23의 증서 제한과 분할 조건, 42의 예약별 관측·목표 대조, 21의 시각 확보를 후보로 둔다. 현재 정책에 이미 있는 규칙과 과거에만 있는 정보의 효과는 별도 질문으로 다룬다.
3. **잘못된 경험이 기억으로 굳는지도 본다.** 17의 첫 반복에서는 잘못된 제한 설명을 사용자가 수용하고 만족하며 끝냈다. 그 대화를 요약하면 무엇이 남는지, writer가 원래 정책의 예외를 보존하거나 교정하는지는 아직 측정 전이다. 분석자의 정답·주석을 writer에 넣지 않고 실제 공개 경험과 사전에 허용한 피드백을 고정한다.

모든 실패를 ‘기억이 없어서’라고 설명하거나, 반대로 현재 규칙이 제공됐다는 이유로 기억이 쓸모없다고 결론내릴 근거는 없다. 먼저 본문 제공에서 재사용 가치와 손해를 측정하고 이후 자율 조회와 연결한다. 쉬운 대조와 새 확인용 반복도 유지한다.

## 재검증 범위

```bash
uv run --frozen --extra tau2 python scripts/diagnose_tau2_baseline_failures.py
```

이 명령은 입력 노출·종료 이유·11회 strict DB/채점 재생·위 5개 점검을 원본에서 재계산한다. 모델 함수와 네트워크 연결을 차단하고 시도 0을 확인한다. 주요 원응답 도구 호출 3개의 인수 일치는 별도로 원응답 참조와 공개 메시지를 직접 대조했다.

실행 전 동결 참조 85개와 이전 전달 비교 참조 64개, 원본 로그·summary 해시는 유지됐다. 모델의 내부 원인·기억으로 바뀔 행동·의미 판정의 독립 합의까지 입증하는 검사는 아니다. 공식 성공 44회 전체의 과정·정책 준수는 이번에 전수 재판정하지 않았다.
