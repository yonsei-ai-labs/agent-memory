# 무엇을 근거로 메모를 썼고, 어느 판단에서 득실이 관측됐는가

지난 주문을 지칭한 소매 재방문에서, 같은 조건부 안내에 실제 메모를 연결했을 때와 빈 메모를 연결했을 때의 첫 판단을 비교했다. 실제 메모 쪽에서 올바른 주문 조회가 순증한 72건 중 70건은 **지난 주문번호를 담은 메모가 있던 사례**에서 나왔다. 항공에서는 **과거 경험과 일치하는 절차를 전달하고도** 가격을 알리기 전에 승급해 실패한 사례가 있었다. 두 결과를 설명하려면 작성자가 보았던 사실, 그 사실에서 끌어낸 조언, 현재 고객의 요청, 행동 시점에 실제로 전달된 내용, 뒤이은 결과를 각각 볼 수 있어야 한다. [배정 집계와 원문 대조 결과](../../artifacts/analyses/20261123-memory-claim-evidence.json)

## 같은 방법으로 확인한 세 가지 메모

세 사례는 결과를 본 뒤 서로 다른 경로를 설명하기 위해 골랐다. 1회차 원본에서 공개 대화를 재구성해 작성 모델이 받은 내용 전체와 대조했다. 이어서 모델의 저장 호출, 저장한 항목·버전, 행동을 생성한 요청 안의 제목·본문 범위, 모델의 공개 응답을 확인했다. 세 작성자 모두 1회차 성패 피드백을 받지 않았다. 아래에서 과거의 발화·도구 결과와 정책을 어떻게 해석했는지는 분석자 한 명의 판독이다. 원문 인용의 위치와 해시는 다시 검증할 수 있다. ## 사례 밖에서도 같은 양상이 나타났는가

**소매.** 지난 주문을 지칭한 77명의 두 이력, 총 154쌍 전부를 같은 조건부 안내에서 비교했다. 아래의 주문번호 유무는 1회차에 작성한 메모 전체에서 판정했고, 실제 응답 입력에 노출됐는지는 별도로 셌다. 표의 개선·악화는 한 쌍의 첫 업무 판단이 갈린 방향이다. ## 다른 벤치에 적용할 기준

공통 분석의 단위는 **다음 행동을 결정할 때 필요했던 사실·조건·절차 한 가지**다. 벤치 어댑터가 공개 관찰, 행동, 상태 변화, 요구사항의 판정 방법을 제공하면 작성 근거·노출·행동의 연결은 같은 방식으로 검사할 수 있다. 벤치 고유의 성공 점수는 결과 중 한 항목으로 보관한다. [프레임워크 측정 명세](../research/metrics.md#메모-문장과-득실을-연결하는-근거)

- **생성 근거.** 작성자가 볼 수 있었던 원천 발화·도구 결과·정책·피드백을 인용한다. 직접 관찰한 사실, 조건부로 도출한 절차, 작성자의 추론, 확인할 수 없는 주장에 서로 다른 판정을 부여한다. 원천과 충돌하는 근거, 적용 조건과 유효 시점도 남긴다.
- **활용 기회.** 현재 대화·도구에서 이미 얻을 수 있던 정보, 과거에만 있던 정보, 바뀐 조건을 표시한다. 저장·조회 요청·도구 반환·행동 직전 입력 포함·행동 일치를 각각 확인한다. 상담원이 왜 그렇게 생각했는지는 공개 기록으로 확정할 수 없다.
- **득실의 범위.** 같은 배정과 대조의 행동 정확성, 되물음·재작업, 동의·제약 위반, 부분 진척, 최종 상태, 호출과 비용을 해당되는 단위로 보고한다. 각 지표에 분모·결측·비교 조건을 적고, 실제 메모를 조회한 사례만 골라 정책 효과를 계산하지 않는다.
- **주장의 강도.** 원문 대조는 어떤 문장을 보고 무엇을 했는지 확인한다. 대응 배정은 은행이나 전달 정책의 효과를 추정한다. 문장 자체의 효과에는 그 문장만 변경한 대조가, 특정 행동의 결과에는 해당 행동을 바꾼 환경 재생 등 별도의 근거가 필요하다.

이번 공통 코드는 사후 작성한 제목·본문과 그 버전의 자동 제공·조회 반환을 검증했다. 두 업무 도메인은 모두 τ²에 속한다. 전체 문장을 독립 판독한 자료, 수행 중 작성이나 요약을 거친 노출, 별도 벤치에서의 실증은 아직 남아 있다.

## 재현

세 사례의 원천·작성·재수행 저널 9개와 해당 blob을 보관한 체크아웃에서 아래 명령으로 원문 대조와 두 모집단 집계를 재현한다. Git 자료만 있는 환경에서는 `--cohorts-only`로 두 표와 소매 비용을 재계산할 수 있다. 분석자가 추가한 인용과 판독은 에이전트 입력 밖에만 두었고 이번 분석의 모델 호출은 0건이다.

```bash
claim_check=$(mktemp -d)
uv run --frozen --no-sync python -m scripts.analyze_memory_claims --output "$claim_check/evidence.json"
cmp "$claim_check/evidence.json" artifacts/analyses/20261123-memory-claim-evidence.json
uv run --frozen --no-sync python -m scripts.analyze_memory_claims --cohorts-only --output "$claim_check/cohorts.json"
```
