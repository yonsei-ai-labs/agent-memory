## 같은 메모를 다시 쓰면

같은 작성물에서 두 수행이 갈린 횟수는 단순 정보 1/10쌍, 일기 3/9쌍, 교훈 2/10쌍, 절차 4/9쌍이었다. 반대로 과제·형식·수행 시드를 맞춰 서로 다른 작성물을 비교하면 38쌍 중 12쌍이 갈렸다. 양쪽 모두 고객 대화와 모델 출력도 새로 발생한다. 순수 무기억을 같은 과제·시드에서 별도로 수행한 두 성적도 10쌍 중 3쌍이 달랐다.

## 어떻게 비교했나

같은 1회차 공개 경험에서 단순 정보·일기·교훈·절차별로 기존에 독립 작성한 두 메모를 가져왔다. 원래 작성 세션과 저장된 버전을 확인한 뒤, 각 메모를 새 세션 두 개에서 한 번씩 제공했다. 작업자와 업무 환경 시드는 4·5로 교차했고 고객 시뮬레이터에는 시드를 보내지 않았다. 첫 묶음에서 첫 작성물은 시드 4, 둘째 작성물은 5를 사용한다. 다음 묶음에서 두 시드를 맞바꾼다. 모델에 보여 주는 원래 제목·본문·순서는 고정했다. [40개 은행의 원본 식별자와 120개 사전 배정](../../artifacts/analyses/20261119-frozen-bank-preflight.json)

각 과제·작성 반복·시드에 순수 무기억과 빈 메모를 각각 새로 수행했다. 순수 무기억은 기본 벤치 입력을 받고, 빈 메모는 기억 조건과 같은 안내에 빈 목록을 받는다. 과제당 24회, 총 120회 배정이다. 원래 작성자가 아무것도 저장하지 않은 7개 은행도 원래 형식에 남겼다. 실제 본문을 남긴 은행은 단순 정보 7/10, 일기 7/10, 교훈 10/10, 절차 9/10이다. 같은 고객·묶음 안에서는 네 형식이 두 대조 실행을 공유한다.

성패의 주 비교는 각 형식과 같은 묶음의 순수 무기억이 모두 채점된 쌍이다. 기억 조건만 성공한 경우와 무기억만 성공한 경우를 따로 세고, 과제마다 반복의 성공률 차이를 구한 뒤 과제에 같은 가중치를 준다. 같은 메모의 두 결과와 같은 시드의 서로 다른 작성물 결과도 따로 남긴다. 차이에는 새 고객 대화와 모델 출력의 변동이 포함된다. 수수료와 지급 금액은 실제 예약 데이터와 연결하고, 공식 미채점은 별도 상태로 유지한다.
