# 네 벤치에서 1회차 경험이 메모로 남은 내용

## 메모가 다른 과제에서 왔는지 확인한 방법

1. **원천과 저장물 연결.** 작성 1,032건마다 실제 첫 요청의 공개 경험·성패 한 비트·원천 실행 ID를 확인했다. 저장 이벤트가 가리킨 제목과 본문을 원문과 해시까지 대조했다. 같은 과제에서 사실·교훈 작성자가 받은 경험은 516쌍 모두 같았다. 제목이 맞거나 저장 경로가 맞더라도 본문에 잘못된 주장이 생길 수 있어, 아래 두 검사를 별도로 했다. [작성 실행 색인](../../artifacts/studies/own-mixed-writers-01/writer-outcomes.csv)
2. **다른 원천 515개와의 대조.** 모든 메모에서 성패 첫 줄을 빼고 단어·인접 단어쌍 유사도를 비교했다. 제목과 본문을 함께 썼을 때 1,015/1,032개, 본문만 썼을 때도 1,015/1,032개가 자기 원천과 가장 유사했다. 어느 한 방식에서라도 다른 원천이 앞선 메모는 18개였다. 18개 모두 같은 벤치 안의 유사 과제였고 원천과 경쟁 과제를 직접 대조했다. 예를 들어 항공 0·28은 둘 다 기본석 취소 후 이관이지만 해당 예약과 예약일이 달랐다. BFCL 23·24는 질문과 답까지 거의 같고, 리테일 6은 ID 오류가 포함된 짧은 메모였다. 유사도만으로 출처를 가를 수 없는 사례다.
3. **판독 기준과 재현.** 고정 표본은 각 벤치의 성패별 과제 ID를 `SHA256(writer-content-review-v1|벤치|과제)` 순으로 정렬해 각 12개까지 골랐다. BFCL은 호출 필요 16개 전부와 호출 불필요 성공·실패 각 12개를 골랐다. 의미 판독은 해당 공개 상담의 발화, 도구 인수와 반환, 당시 정책을 근거로 삼았다. 항공 14의 도구 기능처럼 다른 과제로 확인한 내용은 그 출처도 기록했다. 벤치마다 판독자가 달랐고 독립적인 이중 판독은 하지 않았다.

유사도는 원천 516개를 문서로 삼아 TF-IDF 코사인으로 계산했다. 단어 빈도에는 `1 + ln(tf)`, 역문서 빈도에는 `1 + ln(517 / (df + 1))`을 썼다. 원천에는 고객·상담원 발화와 도구 이름·호출 인수를, BFCL에는 제시한 함수명·설명도 넣었다. τ²의 긴 도구 반환은 검색에서 제외하고 의미 판독에서 원문을 읽었다. 메모에 등장하는 정형 식별자·함수명도 보조로 살폈다. 정형 식별자가 자기 원천에는 없고 다른 원천에만 있던 경우는 검사한 패턴에서 0건이었다. 리테일 6·8 사실 메모의 고객 ID 철자 오류는 어느 원천에도 맞지 않았다.

CSV의 `review_selection`이 빈 680개는 전수 출처·유사도 검사까지만 받았다. `fixed`와 `additional`에는 직접 읽은 주장과 근거가 있다. `topic`은 주제, `assessment`는 주장의 근거를 가리킨다. 리테일 6·8 사실 메모의 자기수정 문구와 BFCL 107의 교훈 제목은 주제 표현에도 일부 문제가 있어 `topic=mixed`로 남겼다. `message_numbering`은 근거에 적힌 메시지 번호가 0부터인지 1부터인지 표시한다. 로컬 메모와 실제 작성 입력은 CSV의 `writer_run`, `public_context_sha256`, `body_sha256`로 추적할 수 있다. 오프라인 재구성 절차는 `outputs/own-mixed-writers-01/reproduction/content_review/`에 있다.

## 2회차에서 구분할 것

자기 경험을 잘못 기록한 경우와 혼합 조건에서 다른 주제의 메모가 제시되는 경우는 별개다. BFCL 케이프타운 극장 검색의 다른 두 메모는 앤티오크 미용실 검색과 친구의 성격 유형 질문이다. 이는 계획에 이미 정해진 배정이다. BFCL 256개 목표와 각각의 다른 두 원천 사이 **512개 연결에서 제시된 함수명이 하나라도 겹친 연결은 0개**였다. 함수명이 달라도 검색 전에 위치를 확인하는 식의 일반적인 교훈은 공유할 수 있다. 이 조건으로 측정하는 것은 미리 정한 다른 메모 두 개가 함께 있을 때의 선택과 수행이다. [BFCL 혼합 배정](../../protocols/studies/cohort/own-mixed-bfcl-01.json) · [자기·혼합 비교 설계](../research/own-mixed-cohort.md)

고정 표본에서는 사실 메모 105개 중 13개, 교훈 메모 105개 중 15개에 부분 문제 또는 핵심 모순을 표시했다. 성공 원천에서도 104개 중 12개, 실패 원천에서도 106개 중 16개가 해당했다. 벤치·성패별 표집과 판독 방식 때문에 전체 오류율이나 작성법의 우열로 일반화할 수 없다. 2회차에는 저장된 메모를 그대로 사용하고, 문제가 표시된 제목이나 본문이 실제 판단 전에 노출됐는지, 이어서 같은 실수를 반복했는지 또는 도구를 재조회해 바로잡았는지를 연결해야 한다. 이번 판독에는 2회차 행동·점수 관측이 없으며, 각 오류가 성패에 미치는 영향은 아직 미측정이다.
