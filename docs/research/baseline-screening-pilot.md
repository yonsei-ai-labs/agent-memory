# 무기억 train 탐색: 실행 전 고정 프로토콜

2026-11-15 · 개발 탐색 · 첫 유료 요청 전에 고정

**항공 공식 train 30개를 Luna 무기억으로 각 2회 측정해, 현재 작업자의 성공·실패 경로와 경험 재사용 후보를 찾는다.** 기억 정책 비교나 시험 분할 일반화 평가가 아니다. 사용자는 전체 $1 상한을 제안받은 뒤 “측정먼저 해보자”라고 실행을 지시했다. 이 실행에는 새 $1 한도를 적용하며 이전 48회의 $3 승인을 전용하지 않는다.

## 배정과 실행 설정

## 중단과 분석

run 한도는 그 run의 종료/미완료로 기록하고 나머지를 계속한다. 전체 한도·비용 미확인·복구되지 않은 runtime 오류는 나머지 배정을 생략 기록으로 남긴다. 실패·중단을 재실행 성공으로 교체하지 않는다. 중단 후 자동 재개·한도 증액·모델이나 제공 경로 교체는 하지 않는다.

보고는 planned/started/graded/successful/skipped/ungraded/bounded와 요청·역할별 사용량/비용을 포함한다. 공식 성공률은 채점된 실행의 분모와 전체 60배정의 완료 범위를 함께 적는다. 각 과제의 두 결과와 공개 행동·종료 이유를 나란히 본다. 2/2를 일반적인 천장 효과, 1/2를 확정된 중간 난도로 분류하지 않는다.

실패 검토는 필요한 변경의 누락, 공개된 정보의 미사용, 조건·대상 판단, 탐색/계산의 반복을 후보로 삼는다. native 한도·입력/출력 한도·시스템/제공자 오류와 구분하며, 비공개 추론이나 사후 자기 설명을 원인 증거로 사용하지 않는다. 공식 점수와 별도 행동 주석을 분리하고, 과제 39의 보험 사유 모호함과 무행동 DB 채점의 한계도 유지한다.

전체 train에 공유 사용자·예약이 있으므로 과제 30개를 독립 출처 30개로 간주하지 않는다. 같은 seed·호스팅 모델·사용자 시뮬레이터의 반복도 독립성을 보장하지 않는다. 외부의 옛 모델 성공률은 이번 선정·실행 순서에 사용하지 않는다.

이 결과로 선정한 개발 후보에는 원천 공개 경험 → 재사용할 내용 → 현재 경로에서 재획득 가능한 범위 → 후속 행동/채점 → 적용 조건이 바뀐 대조를 적는다. 현재 실패의 정답·채점 주석을 writer에 넘기지 않는다. 후보 선정에 사용한 실행을 본 비교 기준선으로 재사용하지 않고, 후속 비교에는 새 배정을 사용한다.
