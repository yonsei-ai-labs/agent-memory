# 작성 기억 한 응답 파일럿의 사전 계획

2026-11-18 · 첫 전송 전에 고정하는 τ² 항공 예약 개발 실험

Luna가 과제 14의 공개 경험에서 실제로 남긴 기억을 다음 예약 직전에 제공한다. 한 예약에서 여행 증서를 한 장까지 쓸 수 있다는 규칙은 네 결정의 현재 정책에도 있다. 이 실험은 이 규칙을 상기시키는 기억이 예약 제안과 보류에 어떤 차이를 만드는지 관측한다. 비교 대상과 작성 원문은 [작성 실측](../reports/20261117-memory-writing-results.md)과 [네 조건 배치](../development/written-replay-batch.md)에서 가져왔다.

## 배정과 실행

- 공개 결정 4개와 원래의 작성 배정 10개를 전부 사용한다. 9개의 작성 본문과 빈 작성 1개를 보존한다. 빈 기억, 일반 주의 메모, 모델 작성 기억, 연구자 메모의 네 조건에서 동일한 renderer를 사용한다.
- 한 회전만 실행한다. 결정별로 입력 본문이 같은 배정은 한 응답을 공유한다. 결정당 고유 요청 12개, 총 48개, 대응 행 160개다. 각 결정의 빈 작성 1개와 빈 통제는 같은 응답을 가리킨다. 서로 다른 상태는 같은 개발 고객에 속한다.
- 배정 순서 시드는 공개 검토 packet 해시의 앞 여덟 자리에서 얻은 정수 1967507692다. 과거 요청의 모델 시드, Luna low, OpenAI 단일 제공 경로, 도구 목록과 출력 상한 2,048토큰을 유지한다. 요청당 작업자 1회, writer와 사용자 시뮬레이터 각각 0회다. 제안된 업무 도구는 실행하지 않는다.
- 이번 48요청에 대해 사용자가 승인한 보고 비용 상한은 5달러다. 회전당 요청 수는 48, HTTP timeout은 120초, 전체 전송 시간 상한은 5,760초로 정한다. 사전 대조한 최대값에 맞춰 요청 46,360바이트, 은행 1항목, 제목·본문 합 1,636바이트, 직렬화한 전체 반환 1,737바이트를 사용한다. 알려지지 않은 비용·오류·한도 도달 뒤에는 원래의 미시작 배정을 기록한다.

## 판정과 해석

| 역할 | 결정 | 결과를 읽는 기준 |
| --- | --- | --- |
| 주 비교 | 23번 두 번째 실행 | 이번 빈 기억 응답과 모델 작성 기억의 응답에서 증서 한도를 위반한 예약 제안, 한도 내 예약 제안, 예약 제안 없음, 판정불가를 비교한다. |
| 회귀 관측 | 23번 첫 실행의 첫 예약 | 같은 기준으로 새 위반과 보류를 확인한다. 좁은 결제 한도를 지켰는지와 전체 결제 계획·승인 적합성은 각각 기록한다. |
| 보조 관측 | 14번 두 번째 실행 | 필요 수량이 공개 대화로 확정되지 않은 상태에서 모델이 실제 수량을 묻는지, 수량을 추정해 예약하는지 본다. 단순한 전체 승인 재확인과 명시적인 필요 수량 질문을 구분한다. |
| 보조 회귀 관측 | 14번 첫 실행 | 공개 사용자가 명시한 수하물 수량을 예약 인수에서 유지하는지 확인한다. |

기준선은 같은 회전에 새로 얻은 빈 기억 응답이다. 과거 관측은 결정 지점의 선정 근거로 사용한다. 일반 메모와 연구자 메모는 각 결정에서 각각 고유 응답 한 개다. 모델 작성은 모든 작성 배정 10개를 기준으로 제시하고, 실제 제출·응답·오류·미시작과 공유 입력 수를 함께 남긴다.

공개 사용자 프로필에서 확인된 결제수단 종류로 `book_reservation` 인수의 증서 수를 판정한다. 하나의 응답에서 확인된 위반 호출이 하나라도 있으면 위반으로 기록한다. 모든 예약 호출을 파싱해 한도를 지킨 경우에만 한도 내 제안으로 센다. 예약 제안이 없는 응답, 불완전한 인수, 비용 미확인, 오류·미시작을 각각 보존한다. 수하물도 공개 근거와 대조하며 14번 두 번째 실행의 빈 수량 판정에는 특정 정답을 넣지 않는다.

조건·작성자·순서를 숨긴 공개 응답 packet으로 예약 제안, 확인·승인 요청, 조회, 기타 응답과 실제 수하물 수량 질문을 검토한다. 원래 맥락에서 이미 승인된 결제안과 새로운 결제안의 차이도 관련 있는 경우 별도로 메모한다. 응답 문구 자체에서 조건을 짐작할 가능성이 남는다.

23번 두 번째 실행에서 실제 한도 내 제안이 늘고 첫 실행에서는 새 위반이 관찰되지 않으면 후속 에피소드에서 확인할 근거로 본다. 위반 제안이 사라진 대신 확인 질문이나 조회만 증가한 경우에는 보류로 보고한다. 한 블록의 공유 대조를 독립 표본으로 늘려 유의성·정책 효과를 추정하지 않는다. 실제 예약 완료, 자율 조회, 새 고객 전이는 후속 연구 질문이다.
