# 측정과 분석

2026-11-14 · 정의·분모·근거와 해석의 기준

공식 성공과 진단값을 함께 보되 별도 필드로 보존한다. 다음 수치는 기존 지표의 재사용과 도입 후보를 포함한다. 모든 후보의 채택이나 새 수학적 지표를 주장하는 것은 아니다. 원본 계약은 [기록 설계](../design/recording.md)를 따른다.

## 성공과 관측된 득실

무기억 결과를 a, 기억 사용 결과를 b로 두고 실패=0·성공=1로 표시한다. `n_ab`는 미리 정한 짝짓기 규칙에서 해당 결과가 관측된 쌍의 수이며, `N = n_00 + n_01 + n_10 + n_11`이다. 아래 식은 유효한 관측 쌍을 같은 가중치로 요약하는 기술 통계다. 실행·채점 결측은 별도로 보고하며 실패로 채우지 않는다.

| 보고할 값 | 계산과 단위 | 읽는 방법 |
| --- | --- | --- |
| 무기억·기억 성공률 | 무기억 `100 × (n_10 + n_11) / N`, 기억 `100 × (n_01 + n_11) / N` (%) | 같은 과제·반복 집합에서 관측한 성능 |
| 개선·악화 반전률 | `100 × n_01 / N`, `100 × n_10 / N` (%) | 전체 쌍 중 실패→성공과 성공→실패의 비중 |
| 실패 조건부 회복률 | `100 × n_01 / (n_00 + n_01)` (%) | 무기억 실패 중 기억 사용 시 성공한 비중 |
| 성공 조건부 회귀율 | `100 × n_10 / (n_10 + n_11)` (%) | 무기억 성공 중 기억 사용 시 실패한 비중 |
| 관측 성공률 차이 | `100 × (n_01 - n_10) / N` (%p) | 같은 가중치에서는 두 성공률의 차이와 일치 |
| 양쪽 실패의 진척 변화 | `mean(q_memory,final - q_no_memory,final \| a=0, b=0)` | 성공하지 못했어도 최종 요구사항 충족률이 달라졌는지 |

조건부 비율의 분모가 0이면 해당 없음으로 표시한다. 양쪽 실패의 진척 변화는 성공 여부로 선택한 부분집합의 진단이므로 전체 과제의 진척 변화도 함께 보고한다. 더 많은 호출을 했다는 이유만으로 더 진척했다고 채점하지 않는다.

회복률과 회귀율은 실행 변동을 포함한 관측값이다. 같은 모델이라도 반복 결과가 바뀔 수 있으므로 무기억 대 무기억 비교를 함께 두고, 주된 정책 효과는 과제별 반복 성공 확률 차이와 불확실성으로 추정한다. 과제별 반복 수가 다르면 단순 합산과 과제별 동일 가중 평균은 달라지므로 최종 집계 가중치를 명시한다. 올바른 기억의 선택·노출·활용은 아래의 내용 주석과 개입 분석으로 별도 검증한다.

## 기억 품질과 선택

주석 가능한 과제에서 과거 경험으로부터 가져와야 할 근거 집합 R, 은행에 보존된 근거 A, 기억 반환·자동 제공·가공을 통해 입력에서 확인한 근거 E를 구분한다. 현재 과제의 기본 입력만으로 주어진 정보는 별도로 표시한다. 항목 수가 아닌 정보 단위로 주석해 저장 분할 방식의 차이를 완화한다.

| 측정 | 계산 또는 판정 |
| --- | --- |
| 저장 보존 | 필요한 근거 중 은행에 남은 비율 `count(R∩A)/count(R)` |
| 저장 정확성 | 저장한 검증 가능 주장 중 원천 경험·적용 조건과 일치한 비율 |
| 조회 도달 | 은행에 있던 필요 근거 중 입력에 들어온 비율 `count(R∩A∩E)/count(R∩A)` |
| 전체 근거 도달 | 필요한 근거 중 입력에서 확인한 비율 `count(R∩E)/count(R)` |
| 시점 적합성 | 필요한 의사결정 이전에 해당 근거가 도달했는지 |
| 부적합 노출 | 현재 조건에 적용되지 않는 주장·절차의 노출과 이후 행동 |
| 정정 | 정정 관측부터 은행·노출에 반영되기까지의 지연과 미도달 비율 |

근거 없는 과제·분모 0·불확실한 주석은 해당 없음 또는 미확정으로 남긴다. 모든 유용한 전략에 유일한 정답 기억이 있다고 가정하지 않는다. 추측으로 적은 문장과 확정 사실로 적은 문장을 구분하고, 제목·본문·가공본의 정보 변화를 함께 주석한다. 최종 은행의 보존과 실제 판단 시점 은행의 보존도 구분한다.

주석에는 protocol 버전, 과제·항목·버전, 정보/요구사항 ID, 원천 근거 위치, 현재 조건의 적용 가능성, 판정·미확정, 판정자와 불일치 처리를 남긴다. LLM 판정자를 쓰면 모델·지침·입력·비용과 사람 검토 범위를 기록한다. 주석 일치와 판정 가능 범위를 함께 보고하며 분석 주석을 에이전트에게 되돌려 주지 않는다.

## 추가 측정 후보와 검증 근거

다음은 도입 후보 목록이다. 표준 지표의 재사용, 기존 지표를 우리 비교에 적용한 진단, 추가 주석·개입이 필요한 제안을 구분한다. 모두를 새 지표로 주장하거나 하나의 점수로 합치지 않는다.

### 진척과 행동

**부분 진척의 변화.** 같은 과제에서 `완료 하위 과제 수 / 전체 하위 과제 수` 또는 제약 충족률을 계산한다. 전체 과제의 평균 변화와 양쪽 모두 실패한 과제의 평균 변화를 함께 보고한다. 후자는 관측된 결과로 정의된 부분집합의 진단이며 전체 인과 효과를 대체하지 않는다. MemoryArena의 PS·sPS를 활용하는 안이다.

**단계별 진척 곡선과 곡선 면적.** 업무 행동 t 직후 현재 상태의 요구사항 충족률을 `q_t`로 두고, 사전에 정한 공통 분석 구간 H에서 `mean(q_1, ..., q_H)`를 계산한다. 같은 최종 진척이라도 더 일찍 진척했는지 구분한다. 조기 종료 후에는 마지막 상태를 유지해 비교하며, 분석 구간과 단계 단위는 고정한다. 기억 도구 호출 수·시간·비용은 별도로 보고한다. AgentBoard의 단계별 진척 분석을 확장해 적용하는 후보이며 AUC 자체는 새로운 수학적 지표가 아니다.

**달성 후 후퇴량.** `max_t(q_t) - q_final`로 도중에 달성한 상태를 얼마나 잃었는지 본다. AgentBoard가 보고하는 누적 최고 진척값에 이 식을 직접 적용하면 의미가 없으므로, 현재 업무 상태의 충족률을 별도로 재계산해야 한다. 중간에 주소를 고쳤다가 잘못된 후속 처리로 되돌린 경우를 구분할 수 있다. 이 수치만으로 후퇴가 기억 때문이라고 단정하지 않는다.

**유효 행동 비율과 오류 재발률.** 유효한 업무 도구 호출 수를 전체 업무 도구 호출 수로 나눈 값은 AgentBoard의 grounding accuracy와 연결된다. 동일한 실패 유형이 다음 시도에서도 재발한 비율은 별도 진단으로 정의할 수 있다. 도구 호출의 형식·실행 가능성과 목표에 대한 적절성은 다르며, 오류 유형·발생 기회·정당한 재시도를 구분하는 판정 규칙이 필요하다.

### 학습 속도와 안정성

**누적 개선 곡선과 평균 개선.** 체크포인트 t마다 같은 확인 과제 집합에서 `delta_t = SR_memory,t - SR_no_memory,t`를 계산한다. 같은 간격의 체크포인트라면 `mean(delta_t)`를 초기 학습 구간을 포함한 성능 개선 속도의 요약으로 쓸 수 있다. 간격이 다르면 구간 길이를 반영한다. 금전 비용은 별도 지표로 계산한다. 온라인 스트림의 누적 정답률도 함께 보되, 새로 도착한 과제의 난이도 변화와 학습 효과를 혼동하지 않는다. MemoryBench·Evo-Memory의 단계별·누적 평가가 선례다.

**이전 과제 유지와 새 과제 전이.** 고정된 이전 과제 집합에서 새로운 경험을 쌓기 전후의 성공률 차이, 새 과제 집합에서 경험 보유·무기억의 차이를 각각 보고한다. 정방향·역방향 전이와 망각은 지속 학습의 기존 개념이다. [When Continual Learning Moves to Memory](https://arxiv.org/html/2604.27003)도 외부 기억의 표현·조회와 전이·간섭을 분석하므로, 이 개념 자체를 신규 지표로 주장하지 않는다.

**작업 순서 민감도.** 공통으로 배정한 여러 랜덤 순서에서 정책 효과의 평균·표준편차·하위 분위수를 비교한다. 한 순서에서의 우수함과 순서가 바뀌어도 유지되는 효과를 구분한다. 순서와 LLM의 실행 변동을 분리할 수 있도록 순서별 독립 반복도 기록한다. Evo-Memory가 이미 순서 난이도를 비교했으므로 랜덤화만으로 신규성을 주장할 수는 없다.

### 기억 내용과 노출

**정보 보존·정확도와 정정 반영.** 주석된 경험에서 보존해야 할 정보 중 실제로 남은 비율, 저장한 정보 중 근거와 일치하는 비율, 정정 이후 올바르게 갱신한 비율을 측정한다. HaluMem의 보존·정확도·갱신 지표를 참고한다. 더해 정정 관측부터 은행·실제 노출에 수정이 반영되기까지의 지연을 회차·업무 단계·시간 단위로 기록할 수 있다. 관측 기간 안에 미반영된 경우는 지연 0이 아닌 미도달로 구분한다. 모든 유용한 전략에 유일한 정답 기억이 존재한다고 가정하지 않는다.

**필요한 근거의 도달과 노출 시점.** 근거 주석이 있는 과제에서 은행에 존재하는 근거 중 실제 모델 입력에 들어온 비율을 계산한다. 필요한 의사결정 전에 도달했는지도 별도 주석으로 판정할 수 있다. LongMemEval의 Recall@k·NDCG@k와 연결되지만, 자율 조회에서는 항목 수·크기·시점이 다르므로 고정 k를 강제할 필요는 없다. 제목·목록·재가공 결과도 노출에 포함한다. 근거가 없는 과제나 주석이 불확실한 경우는 해당 없음·미확정으로 남기고 판정 가능 범위를 보고한다.

**저장·조회 조합 효과.** 같은 원천 경험에서 만든 은행 A·B와 조회 정책 X·Y를 교차하고, 성공 확률의 차이의 차이를 계산한다.

`interaction = [p(A,X) - p(A,Y)] - [p(B,X) - p(B,Y)]`

가령 A/X=80%, A/Y=60%, B/X=65%, B/Y=70%라면 상호작용 대조값은 25%p다. 이는 가상 예시이며 표준 요인 실험의 대조식이다. 어느 저장 방식이 모든 조회 방식에서 우수한지, 조회 방식에 따라 순위가 바뀌는지 검증한다. MemTools가 이미 구성요소를 교체하므로, 교차 기능이나 이 공식 자체보다 실제로 발견·검증한 조합 효과가 기여 후보다.

**개입에 따른 회복 차이.** 원래 기억과 내용 교정, 자연 조회와 같은 은행의 참조 근거 직접 제공을 각각 비교해 성공 확률·진척 변화와 관측된 회복 수를 기록한다. 직접 제공으로 회복하면 그 제공 방식으로 구제 가능한 실패라는 근거가 된다. 그것이 유일한 원인이었거나 직접 제공이 성능 상한이라는 뜻은 아니다. 여러 단계의 개입 효과를 합해 저장·조회·활용의 고유 기여율로 계산하지 않는다.

### 조회 필터와 적용 조건 행동

[적용 조건 기억 파일럿](condition-sensitive-pilot.md)의 행동 진단과 선택적 필터를 도입할 때 아래 분모를 명시한다. 원천/현재 상태에 대한 적용 가능성 주석은 실제 득실 라벨과 구분한다.

| 측정 | 판정·분모 |
| --- | --- |
| 변경 판단 전 조건 근거 확보율 | 조건 확인이 필요한 진단 시도 중, 최초 관련 변경 판단 전에 현재 등급/상태 근거가 공개 입력이나 정상 관측으로 확보된 비율 |
| 금지 행동 시도율 | 금지 동작이 정의된 진단 시도 중 해당 동작을 요청한 비율. 함수·인수·직전 상태·승인을 함께 판정하고 도구 오류/실제 DB 변경을 분리 |
| 부적합 차단율 | 필터 전 후보 Q 중 부적합 주석 I에 속하는 후보에서 차단된 비율 `count(I∩(Q−F))/count(I∩Q)` |
| 적합 차단율 | 필터 전 후보 Q 중 적합 주석 D에 속하는 후보에서 차단된 비율 `count(D∩(Q−F))/count(D∩Q)` |
| 제공 비율 | `count(F)/count(Q)`. F는 실제 통과 후보. 작업자 입력 포함 여부는 별도 측정 |
| 판단 범위와 노출 | 미확정·미주석 비율, 제목/본문 노출, 판정기만 본 정보와 작업자가 본 정보를 구분 |

Q·F는 같은 조회 사건에서 `(query_id, item_id, version_id)`로 식별한 후보 출현의 집합이다. 조회·과제별 비율을 어떻게 집계하는지와 가중치를 정하고, 반복 노출을 독립 기억으로 부풀리지 않는다. 분모 0은 해당 없음이다. 행동 로그가 없거나 판정 불가능한 시도는 정상/무위반으로 채우지 않고 누락·불확실성을 보고한다. 확인 기회·변경 판단·상태 적합성을 판정하는 규칙은 실행 전에 고정한다.

적합한 기억의 차단은 유용할 가능성의 손실이며 그 자체로 실제 성능 손해를 증명하지 않는다. 부적합 차단도 실제 회귀 예방과 동일하지 않다. 각 효과는 무기억·비필터·필터 조건의 반복 성공률·진척·행동과 통제된 노출 비교로 확인한다.

판정기가 본문을 읽은 비용과 입력은 별도 기록한다. 같은 worker 문맥에서 먼저 읽고 거절한 것은 부적합 기억 미노출이 아니다. 목록 제목·거절 설명·이력 재전송으로 생긴 노출도 포함한다. 필터 오류·근거 부족·추가 지연/호출·판정 모델 변경을 보존한다.

### 전체 비용

**품질을 함께 본 비용 회수 시점.** 작성·갱신의 선행 비용부터 후속 수행까지 누적 비용을 비교해, 기억 정책의 비용이 무기억 비용 이하가 되는 최초 시점을 기록한다. 성공률·진척도도 함께 제시하고 실패로 빨리 종료한 절감을 개선으로 해석하지 않는다. 관측 기간 안에 비용을 회수하지 못하면 미도달로 남긴다. 여러 번 쓰는 은행의 생성 비용을 각 사용에 중복 합산하지 않는다. STATE-Bench의 과제당 비용과 비교할 때 비용 포함 범위를 먼저 맞춘다.

## 계산에 필요한 근거와 지표 검증

| 수치 유형 | 필요한 추가 근거 | 해석의 범위 |
| --- | --- | --- |
| 성공·회복·회귀·누적 개선 | 동일 과제·초기 상태, 결과 짝, 독립 은행·스트림 반복 | 관측된 반전과 성공 확률 차이. 같은 모델이라는 이유만으로 우연 변동이 없어지지 않음 |
| 진척·후퇴·행동 오류 | 상태별 요구사항 검증, 동등한 성공 경로를 허용하는 규칙 | 호출 수 증가와 구분한 목표 충족. 공식 점수와 별도 진단으로 보존 |
| 보존·정정·근거 도달 | 원천 경험·현재 조건에 대한 내용 주석, 실제 입력 노출과 버전 | 판정 가능한 정보의 품질. 텍스트 품질이 실제 효용을 보장하지 않음 |
| 저장·조회 상호작용 | 공통 경험, 복제한 은행, 동일 작업자·과제, 교차 배정 | 주어진 조건에서 조합에 따라 달라지는 효과 |
| 개입 회복 | 동일 상태 또는 검증된 재생, 정보 노출 이전 분기, 단일 변경의 기록 | 해당 개입으로 회복 가능한 정도. 유일한 실패 원인이나 보편적인 기억 가치가 아님 |
| 비용·순서 민감도 | 전체 단계 비용, 결측, 공통 순서와 반복, 평가 시점 | 정해진 비용 범위·순서·기간 안에서의 효과 |

새 진단값은 이름을 붙이는 것만으로 타당해지지 않는다. 요구사항 채점의 일치, 반복 실행의 변동, 주석의 일치와 미확정 비율, 개입 전후 결과를 검토한다. 점수가 높은 기억이 실제 성능도 높이는지 확인하고, 맞지 않는 사례도 보고한다. 단계별 품질·노출·행동을 연결하는 것이 관측이고, 원인 주장은 통제 개입이 뒷받침하는 범위로 둔다.

## 정책 효과와 불확실성

주된 효과는 같은 과제 집합에서 반복에 기반한 기억 정책과 무기억의 성공 확률 차이다. 과제별 동일 가중 평균을 기본 집계안으로 두고 출처 그룹별 결과도 제시한다. 여러 벤치의 서로 다른 점수는 별도로 보고한다.

무기억 대 무기억 반복, 정책 간 공통 배정, 여러 독립 은행·순서·반복을 보존한다. 불확실성은 실제 배정 구조에 맞춰 출처 과제와 은행·스트림의 의존성을 반영한다. 단일 은행 안의 항목·호출을 독립 표본으로 bootstrap하지 않는다. 평가 과제·반복·seed의 짝짓기는 결과를 보기 전에 고정한다.

고정한 벤치 과제 집합에 대한 효과를 추정할 때는 과제를 유지하고, 정책 간 대응을 유지한 독립 은행·순서 반복 블록을 재표집하는 방법을 기본 구현 후보로 둔다. 새 원천 과제 모집단으로의 일반화를 추정하면 출처 그룹의 재표집도 별도로 설계한다. 두 추론 범위를 같은 신뢰구간으로 표시하지 않는다. 배정 수·채점 완료·결측과 유효 짝 수를 조건별로 보고한다.

## 비용 원본과 배분

모델 요청마다 업무 작업자·기억 작성자·조회 가공·사용자 시뮬레이터·채점의 역할과 단계를 기록한다. 정책 운영 비용, 환경·채점 비용, 연구용 반복·개입 비용을 분리한다. 미확인 금액·사용량은 `null`과 상태로 남긴다.

한 모델 요청이 업무 행동과 수행 중 저장을 함께 결정하면 그 비용은 공유 결정 비용으로 남긴다. 요청 전체 비용을 두 역할에 중복 합산하거나 관측 근거 없이 저장만의 비용으로 분할하지 않는다.

공유 경험 수집과 한 번 작성한 은행의 비용은 고유 요청 ID에 연결한다. 여러 평가 과제에 중복 합산하지 않고 실제 지출과 조건별 비용 배분 규칙을 함께 보고한다. 자연 실행은 경험 수집 비용 차이까지 정책 효과에 포함한다. 동일 경험 비교의 공유 원천 비용은 별도 항목으로 남긴다.

입력 총 토큰에 포함된 캐시 토큰·기억 텍스트 추정치를 다시 더하지 않는다. 모델의 추론 토큰, 도구 지연 합과 전체 경과 시간도 구분한다. 비용 회수 시점은 성공·진척과 함께 보고하고 관측 기간 내 미도달을 표시한다.
