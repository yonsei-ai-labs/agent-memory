# 은행에서 메모 한 문장의 기여와 작성 규칙의 새 과제 성과 측정

같은 공개 상태에서 과거 메모의 한 문장이 업무 행동을 바꾸는지 측정한다. 개발 결과를 근거로 작성 규칙 한 개를 제안하고, 개발에 쓰지 않은 네 과제에서 기존 규칙과 비교한다. 목표는 어떤 문장이 실제 입력에 들어갔고, 어떤 행동이 달라졌고, 그 정책의 이득과 손실이 새 과제에서도 나타났는지 연결하는 것이다. ## 같은 판단에서 문장 하나를 바꾸기

메모에 노출된 적 없는 원래 1회차의 작업자 요청을 쓴다. 아래 지점은 이전 실험을 본 뒤 개발용으로 선정했다. 두 지점씩 같은 과거 상담을 공유한다. 현재 은행 문서에도 네 지점 모두에서 대상 사유나 도구명이 있었다. 따라서 과거 메모가 같은 정보를 덧붙였을 때의 추가 기여를 측정할 수 있다. [같은 업무 입력·모델·도구의 해시와 원문](../../artifacts/pilots/20261125-banking-policy-cycle-preflight.json)

| 과제와 1회차 작업자 판단 | 고객에게 당장 가능한 행동 | 보관된 1회차의 다음 행동 |
| --- | --- | --- |
| 008의 17·18번째 판단 | 미확인 판촉을 거절한 뒤 고객이 계속 요구한 사유로 이관 | 은행 문서 검색 / 해당 사유로 이관 |
| 015의 5·6번째 판단 | 추천 링크 발급 도구를 고객에게 실제로 제공 | 제공했다고 텍스트로 안내 / 도구 호출 |

각 지점에 같은 1회차에서 성패를 받고 작성한 사실·경험 메모를 쓴다. 두 형식 모두 해당 도구명 또는 사유가 제목에 없고 본문의 한 문장에 들어 있다. 원문 그대로, 그 문장만 삭제, 길이가 비슷한 다른 배경 문장만 삭제한 세 조건을 같은 횟수로 돌린다. 제거하는 두 문장의 원문·위치·길이를 먼저 고정했다. 나머지 메모에 담긴 의미와 현재 문서의 단서는 그대로 보인다. 세 조건 모두 동일한 공개 식별자를 쓰고 서로 다른 기록 저장소에 실제 본문과 버전을 연결한다. 원래 메모는 수정하지 않는다.

4지점 × 2메모 × 3조건 × 4반복은 **96개의 한 응답 판단**이다. 같은 지점·형식·반복 안의 세 조건 순서와 블록 순서를 고정 시드로 섞었다. 주 비교는 배경 문장을 지운 조건과 대상 문장을 지운 조건의 즉시 목표 행동 차이다. 원문과 두 삭제 조건의 차이도 함께 낸다. 목표 행동은 네이티브 도구 스키마에 맞는 한 번의 지정 호출과 해당 인수로 판정한다. 텍스트로 도구를 제공했다고 말한 경우, 재검색, 다른 사유, 결측을 따로 센다. 이 단계에서는 제안한 도구를 실행하지 않으므로 고객의 실제 발급이나 상담의 공식 성패는 후속 전체 상담에서 평가한다. ## 개발 근거로 만든 규칙을 새 과제에서 평가하기

은행 공식 후보를 기존과 같은 기준으로 분류하고, 이전 실험에서 사용한 각 부류의 첫 ID를 건너뛰어 두 번째 ID를 고정했다. 검증 과제는 002·014·016·017이다. 과제·초기 DB·고객 설정·채점 기준·문서 집합은 사전등록에 해시로 남겼다. 이 분할의 단위는 과제다.

개발 판단의 실제 응답과 원기록을 인용해 기존 작성 지침에 덧붙일 도메인 중립 규칙 하나를 정한다. 연구자의 편집과 모델이 실제 작성한 메모를 구별한다. 후보의 문장, 예상 행동, 예측과 어긋나는 결과, 근거가 된 개발 응답을 고정한 뒤에만 검증 과제의 1회차를 시작한다. 실험 업무 모델에 과제 번호나 채점 정답을 넣지 않는다. 후보를 고르는 중에 검증 성적을 다시 읽어 바꾸는 과정은 없다.

| 단계 | 배정 |
| --- | --- |
| 무기억 1회차 | 새 과제 각 1건, 총 4건 |
| 기존·후보 규칙으로 메모 작성 | 같은 공개 궤적과 공식 성패에서 사실·경험·절차·교훈·자유 각 1개씩, 총 40건 |
| 2회차 | 해당 과제의 첫 공개 질문·초기 환경을 복원하고 메모를 자동 제공하는 상담 40건 |

양쪽 작성 조건에 같은 모델·시드·성패 한 값·도구와 필수 저장 규칙을 쓴다. 소속 과제·정책의 다섯 메모가 모두 봉인돼야 후속 풀이를 진행한다. 비용과 미시작·기술 실패는 사전 배정 분모에 남긴다. 2회차 무기억 배정은 0건이다. 주 지표는 같은 과제·형식의 **기존 대비 후보의 공식 성공 회복과 손실**이다. 과제별 결과, 1회차 대비 변화, 실제 본문 노출, 네이티브 행동, 양쪽 성공의 검색·업무 호출·고객 발화·토큰·비용 및 양 정책의 작성비를 함께 본다. 네 개의 독립 과제로 관측한 방향과 개별 사례를 보고한다. [실행기](../../scripts/run_banking_policy_cycle.py) · [원장과 짝을 확인하는 분석기](../../scripts/analyze_banking_policy_cycle.py)
