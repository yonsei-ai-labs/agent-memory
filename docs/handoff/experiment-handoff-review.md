# 실험팀 인계 문서 검토와 반영

2026-11-14 · 다운로드 문서와 현재 저장소 설계의 비교

**추가로 인계할 내용이 있다.** 같은 경험의 일반 요약과 적용 조건·절차 기억을 비교하는 파일럿, 현재 관측으로 조회 후보의 적용 가능성을 확인하는 필터, 항공 과제의 구체적인 행동 판정을 보완했다. 전체 연구 범위와 첫 오프라인 구현 순서는 유지한다.

이 파일럿은 계측 연결과 정책 차이의 원인을 확인하는 실증 후보이며 독창성이 확정된 결과는 아니다. [기여 비교](../research/related-work.md)에 따라 저장·조회 교차·노출/행동 연결·개입이 추가로 설명한 현상을 검증한다.

검토한 [원문 보관본](../references/feedback/20261114-memory-evaluation-experiment-handoff.md)은 Windows 다운로드 파일의 bytes 그대로다. [이관 기록](../../artifacts/experiment-handoff-import.json)에 원본 경로·SHA-256·확인한 공식 소스 버전·미열람 참고 자료를 남겼다. 원문을 수정하거나 새 실험의 확정 계획으로 취급하지 않았다.

## 공식 항공 자료에서 확인한 보완점

검토한 τ² 소스는 `c06b07dd7c4d4ec61ba6ff9bcdf0b15dd7ef36d4`다. 이는 이번 문서 검토의 참조 버전이며, 실제 실행 벤치 버전을 확정한 것은 아니다.

33번은 일정 변경 뒤 좌석 등급·수하물·예산 조건이 이어지는 복합 요청이다. 36번은 basic economy와 이미 출발한 상황이 함께 명시된다. 원래 두 과제의 결과 차이를 등급 하나의 효과로 해석하지 않는다. 제안 원문도 이 차이를 인식하고 출발 전의 새 과제쌍을 제안하므로 그 의도를 유지했다. [고정된 과제 원본](https://github.com/sierra-research/tau2-bench/blob/c06b07dd7c4d4ec61ba6ff9bcdf0b15dd7ef36d4/data/tau2/domains/airline/tasks.json)

업무 규칙은 basic economy의 항공편 변경을 금지하지만 출발 전의 좌석 등급 변경 등은 따로 다룬다. 실제 `update_reservation_flights`는 항공편 배열과 cabin을 함께 받는다. 따라서 함수 이름만으로 금지 행동을 판정하지 않고, 요청의 의미·직전 상태·변경 인수를 확인해야 한다. [정책](https://github.com/sierra-research/tau2-bench/blob/c06b07dd7c4d4ec61ba6ff9bcdf0b15dd7ef36d4/data/tau2/domains/airline/policy.md), [도구 구현](https://github.com/sierra-research/tau2-bench/blob/c06b07dd7c4d4ec61ba6ff9bcdf0b15dd7ef36d4/src/tau2/domains/airline/tools.py#L665-L760)

현재 등급을 정상적인 예약 조회로 확인했는지와 매번 특정 도구를 호출했는지도 구분한다. 이미 공개 입력에 등급이 주어진 경우는 그 근거를 사용하면 된다. 금지된 상태에서 DB가 바뀌지 않았다는 사실만으로 올바른 거절·설명·업무 처리가 모두 이뤄졌다고 채점하지 않는다.

## 조회 필터에서 특히 남겨야 할 구분

필터가 부적합한 본문을 작업자에게 보여준 뒤 무시하라고 지시했다면 이미 노출된 것이다. 별도 문맥의 판정기에서만 읽고 작업자에게 전달하지 않은 경우와 분리한다. 목록 제목이 먼저 보였다면 그 노출도 남긴다.

적용 가능성 주석은 실제 유용함/유해함의 정답과 다르다. 적합한 후보를 차단한 비율과 부적합 후보를 차단한 비율을 함께 계산하되, 실제 득실은 반복 수행·통제된 노출 비교로 확인한다. 필터 지연·모델 호출·판정 오류와 근거 부족도 기록한다. 자세한 분모와 기록 항목은 [측정 보완](../research/metrics.md#조회-필터와-적용-조건-행동)을 따른다.

## 확인한 문헌과 확인하지 못한 연결 자료

STATE-Bench Agent Learning Track은 과거 궤적에서 산출물을 만들고 held-out 수행을 채점하며, retrieval hook을 읽기 전용으로 둔다. 기존 비교 문서의 설명과 일치한다. [확인한 공식 버전](https://github.com/microsoft/STATE-Bench/blob/5644b1838d96bc4483da29642d058ecaa6f80f7f/docs/AGENT_LEARNING_TRACK.md)

Jev 논문 v2는 고정 선택·확률 판단과 임계값 조정을 다루지만, 해당 논문은 relevance 판단 과제가 없다고 명시한다. 우리 기억의 적용 가능성·득실을 검증한 근거는 아니다. 도입한다면 같은 입력·후보에서 규칙/Luna 판정과 별도 비교하고, 개발 분할에서 정한 임계값·모델 버전을 고정해야 한다. [Jev v2의 방법과 한계](https://arxiv.org/html/2609.37647v2)

원문에 있는 `memory.html` 및 나머지 네 ChatGPT Library 문서는 본문을 제공받지 않았고 로컬 `memory.html`도 찾지 못했다. 이 다섯 연결 자료 전체를 읽거나 반영했다고 표시하지 않는다. 관련 아이디어는 이번 Markdown에 적힌 범위에서만 제안으로 보존한다. HB-Mem·그래프·학습 모델은 별도 검토·검증이 필요한 후속 후보이며 새 기본 구현 요구사항이 아니다.
